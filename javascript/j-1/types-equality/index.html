原始类型、引用类型与类型转换

掌握 7 种原始类型与引用类型的 typeof 行为、显式转换（Number/String/Boolean）、隐式转换规则，以及 == 与 === 的经典差异。

开场问题：表单校验里写了 if (value == 0) 拦截「数量为 0」，结果用户什么都没填也弹出了提示——空字符串究竟是怎么混进来的？

动态类型相等判断

你想做一件很小的事：判断两个值是不是「一样」。在静态类型语言里，这几乎是废话——两个变量类型不同，编译器根本不让你比较。但在 JavaScript 里，同一个变量今天装字符串、明天装对象，比较两个「长得像」的值时，语言必须自己拿主意：是先转换再比，还是类型不同直接判不等？

JavaScript 给的两个答案就是 == 和 ===。先说清它们的差别在哪：=== 先看类型，类型不同立刻返回 false；== 先按一套规则把两边转成同一类型，再比数值。麻烦全部出在「转成同一类型」这一步上——它不是随机的，但规则足够反直觉，反直觉到会悄悄吃掉你的业务判断。

宽松相等隐式转换

最省事的做法：统一用 ==，反正它「聪明」，会自动帮我们把字符串和数字对齐。于是 '0' == 0 得到 true，表单里那个空字符串也就能冒充数字 0 通过校验。

这个方案确实做对了一件事：比较这件事必须能跨越类型边界完成，否则用户从输入框拿到的永远只是字符串，业务里全是 Number() 噪音。问题在于，把「转换」藏进比较运算符里，等于把一步显式的数据处理偷偷塞进了判断表达式——你看代码时看到的是「相等」，运行时发生的却是「先转换再相等」。

隐式转换反常结果

  • '0' == 0 是 true，'' == 0 也是 true——空字符串被当成 0，校验直接失效。
  • null == undefined 是 true，而这两个值跟别的任何值比都是 false，是一对只跟彼此相等的特例。
  • [] == '' 是 true，空数组 toString() 之后成了空字符串，两边就「相等」了。
  • NaN == NaN 是 false，一个值连自己都不等于，用相等判断来识别 NaN 天然做不到。
  • 0 === -0 是 true，但这两者做除数会得到完全不同的结果，严格相等在这里又不够严格。

转换与比较分离

不推翻「比较」，而是把「转换」和「比较」拆成两步：转换显式做，比较一律用严格相等。需要数字就在输入边界上调用 Number()，需要字符串调用 String()，需要布尔调用 Boolean()；判断里只留 === 与 !==。这样一来，「相等」在代码里就是字面意思。

接着补上类型识别这一步。运行时要判断值的类型，用 typeof，但要记住两个例外：

  • typeof null 返回 'object'，这是语言最早实现的遗留问题，判断 null 请直接写 x === null。
  • 除函数外，所有引用类型的 typeof 都是 'object'，数组要用 Array.isArray() 单独判断。

再往下走，会发现还有两个边界必须单独处理。第一是 NaN：全局 isNaN() 会先把参数转成数字再判断，传字符串进去也可能为真，所以要用 Number.isNaN()。第二是 +0 与 -0：如果业务要区分它们，用 Object.is()——它认为 NaN 与自身相等，同时能区分正负零。

最后一个容易被忽略的事实是 falsy 值清单是固定且很短的：false、0、-0、0n、''、null、undefined、NaN，就这八种。除此之外全是 truthy——空数组 [] 和空对象 {} 都是 truthy，所以用「非空判断」兜底数组和对象时，真正该看的是 length 或 Object.keys()，而不是真假值。

反常相等逐条验证

严格相等判定原则

类型与相等这两件事，本质上是把「隐式转换」从表达式里请出来，放到你能看见的地方。判断一律用 ===，转换在输入边界显式完成，类型识别绕开 typeof null、数组和 NaN 这三个坑——反直觉的 bug 就少了一大半。

「严格相等」指 ===，要求类型与值同时一致，不做任何隐式转换；与之相对的 == 会先转换再比较。判断 null 用 x === null，判断数组用 Array.isArray()，判断 NaN 用 Number.isNaN()，需要区分 +0 / -0 时用 Object.is()。

关键代码

JavaScript
// ═══════════════════════════════════════════
// 1. JavaScript 的 7 种原始类型
// ═══════════════════════════════════════════

typeof 'hello'     // 'string'
typeof 42          // 'number'
typeof true        // 'boolean'
typeof undefined   // 'undefined'
typeof null        // 'object'  ← 历史遗留 bug
typeof Symbol()    // 'symbol'
typeof 1n          // 'bigint'

// ═══════════════════════════════════════════
// 2. 引用类型（typeof 全部返回 'object'）
// ═══════════════════════════════════════════

typeof {}           // 'object'
typeof []           // 'object'  ← 需要用 Array.isArray() 判断
typeof (() => {})   // 'function' ← 唯一例外
Array.isArray([])   // true

// ═══════════════════════════════════════════
// 3. 显式类型转换 — 推荐做法
// ═══════════════════════════════════════════

// 转数字
Number('42')       // 42
Number('')         // 0
Number('abc')      // NaN
Number(true)       // 1
Number(null)       // 0
Number(undefined)  // NaN

// 转字符串
String(42)         // '42'
String(null)       // 'null'
String(undefined)  // 'undefined'

// 转布尔 — 只有 5 个 falsy 值
// '', 0, NaN, null, undefined
Boolean('')        // false
Boolean(0)         // false
Boolean(NaN)       // false
Boolean(null)      // false
Boolean(undefined) // false
// 其余全是 truthy，包括空数组和空对象
Boolean([])        // true
Boolean({})        // true

// ═══════════════════════════════════════════
// 4. 隐式转换规则
// ═══════════════════════════════════════════

// + 运算符：有字符串则拼接，否则转数字相加
'5' + 3            // '53'   ← 字符串拼接
+'5' + 3           // 8      ← + 号前缀强制转数字

// -、*、/ 运算符：两侧都转数字
'5' - 3            // 2
'5' * '2'          // 10

// ═══════════════════════════════════════════
// 5. == 宽松相等 vs === 严格相等
// ═══════════════════════════════════════════

// == 会先隐式转换再比较
'0' == 0           // true   ← '0' 转为 0
'' == 0            // true   ← '' 转为 0
null == undefined  // true   ← 规范规定
null == 0          // false  ← null 只与 undefined 宽松相等
Array() == ''      // true   ← [] → '' → ''
Array() == false   // true   ← [] → '' → 0, false → 0

// === 不转换类型，类型不同直接 false
'0' === 0          // false
'' === 0           // false
null === undefined // false

// 特殊值
NaN === NaN        // false  ← NaN 不等于任何值
Number.isNaN(NaN)  // true   ← 正确判断方式
Object.is(NaN, NaN) // true  ← 同值相等

// ═══════════════════════════════════════════
// 6. 最佳实践
// ═══════════════════════════════════════════

// ✓ 需要转换时显式调用 Number() / String() / Boolean()
// ✓ 用 Number.isNaN() 代替 isNaN()（全局 isNaN 会先转数字）
// ✓ 用 Array.isArray() 判断数组
