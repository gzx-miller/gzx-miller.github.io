高阶函数、柯里化与函数组合

用函数组合构建价格计算器，掌握柯里化、偏函数、pipe/compose 与防抖节流。

开场问题：搜索框里每敲一个字符就发一次请求，字还没输完接口已经被打了七八次；同事说改成「等一会儿再发」就行，可「等一会儿」到底该等多久、期间又该不该再发，谁也说不清。

函数能收也能给

想给一批课程算价格，最直白的写法是每处都手写一遍 for 循环。写着写着你发现：循环的骨架每次都一样，变的只是「对每个元素做什么」。于是把「做什么」抽成一个函数传进去，就有了 arr.map(calculate)。

这类接收函数作为参数、或者返回一个函数的函数，就是高阶函数。它做对的事是把「流程」和「具体动作」拆开：骨架只写一次，动作按需传入。map、filter、reduce 都是它的例子——它们不认识你的业务，却能替你跑完全程。

纯函数与副作用

把动作交出去以后，你会开始在意交出去的函数「干净不干净」。一个纯函数要求两件事：相同输入永远得到相同输出，并且不改动外部任何状态。

纯函数好在哪里？好测、好缓存、好组合——因为它没有隐藏的依赖，看一眼输入就能推出输出。可现实里发请求、写 DOM、打日志都是必要的副作用。务实的做法不是消灭副作用，而是把它挤到系统的边界上：核心计算保持纯，脏活留给最外层的调度函数去干。

柯里化与偏函数

参数一多，调用点就不好读。设想 applyDiscount(0.2, 200)，两个参数谁是谁，光看调用处还得回翻定义。柯里化把「一次收齐」改成「一次收一个」：const applyDiscount = (rate) => (price) => price * (1 - rate)。于是可以先固定折扣率，得到一个专用函数 memberPrice，之后只管把价格喂进去。

和它成对的是偏函数：用 bind 预填前面若干参数，剩下的等调用时再给，比如 addTax.bind(null, 0.06) 把税率固定下来。两者的共同点，是把「配置」与「数据」分成两次传入，让专用函数比通用函数更好用、也更好读。

组合的方向

折算价格要经过打折、加税、格式化三步。最省事的写法是嵌套：format(addVat(discount(price)))。它能跑，可括号一多就得从最里面往外读，顺序和眼睛的阅读方向正好相反。

组合把这件事捋直：pipe 让函数从左到右依次执行，compose 则从右到左。两者只是方向不同，核心都是「把上一步的输出喂给下一步」。配合柯里化，一条 pipe(打折, 加税, 格式化)(price) 读起来就像流水线，数据往哪走一目了然。

用闭包记住状态

还有一类高阶函数，靠闭包替调用者「记住」点什么：

  • once：只允许真正执行一次，后续调用直接返回首次的结果——适合初始化逻辑。
  • memoize：把参数和结果存进缓存，同样的输入不再重算——适合耗时的纯函数。
  • 防抖 debounce：每次触发都重新计时，停止触发后只执行最后这一次——正适合搜索框输入。
  • 节流 throttle：不管触发多密集，固定间隔内至多执行一次——适合滚动、拖拽这类持续事件。

防抖与节流看着都在「少执行几次」，行为却相反：防抖关心「停没停」，节流关心「离上次够不够久」。开场那个搜索框选防抖，滚动加载选节流——方向选错，要么请求还是太密，要么响应迟钝得让人以为卡死。

亲手组合一次

从小函数到大管线

高阶函数把「做什么」从「怎么做」里拆出来，柯里化把参数分两次给，组合再把这些小函数接成一条管线。每一步都不复杂，合起来却让一段业务逻辑变成可以逐段替换、逐段测试的流水线——这才是「组合优于继承」在函数层面的样子。

「高阶函数」指接收函数作为参数、或返回一个函数的函数。它常配合纯函数（输入相同则输出相同、不改外部状态）使用，通过柯里化与偏函数把参数分开传入，再用 pipe（左到右）/ compose（右到左）组合成数据管线；once、memoize、防抖与节流则是用闭包记住状态的高阶函数。

关键代码

JavaScript
// ═══════════════════════════════════════════
// 1. 高阶函数：接收或返回函数
// ═══════════════════════════════════════════

const double = (n) => n * 2
const mapWith = (fn) => (arr) => arr.map(fn)
mapWith(double)([1, 2, 3])    // [2, 4, 6]  ← 接收函数，又返回函数
[1, 2, 3].map(double)         // [2, 4, 6]  ← map 本身也是高阶函数

// ═══════════════════════════════════════════
// 2. 纯函数与副作用
// ═══════════════════════════════════════════

const withTax = (price) => price * 1.06
withTax(100)                  // 106  ← 相同输入永远相同输出（纯函数）

let total = 0
const addImpure = (n) => { total += n }   // 改动了外部变量（有副作用）

// ═══════════════════════════════════════════
// 3. 柯里化与偏函数
// ═══════════════════════════════════════════

const applyDiscount = (rate) => (price) => price * (1 - rate)
const memberPrice = applyDiscount(0.2)     // 固定 rate，得到专用函数
memberPrice(200)              // 160
memberPrice(300)              // 240

const addTax = (rate, price) => price * (1 + rate)
const addVat = addTax.bind(null, 0.06)     // 偏函数：预填第一个参数
addVat(200)                   // 212

// ═══════════════════════════════════════════
// 4. pipe 与 compose
// ═══════════════════════════════════════════

const pipe = (...fns) => (x) => fns.reduce((v, fn) => fn(v), x)
const compose = (...fns) => (x) => fns.reduceRight((v, fn) => fn(v), x)
const format = (p) => `¥${p.toFixed(2)}`

pipe(applyDiscount(0.2), addVat, format)(200)      // '¥169.60'  ← 从左到右
compose(format, addVat, applyDiscount(0.2))(200)   // '¥169.60'  ← 从右到左

// ═══════════════════════════════════════════
// 5. 用闭包记住状态
// ═══════════════════════════════════════════

function once(fn) {
  let called = false
  let result
  return (...args) => {
    if (!called) { called = true; result = fn(...args) }
    return result
  }
}
const init = once(() => '初始化完成')
init()                        // '初始化完成'
init()                        // '初始化完成'  ← 第二次直接返回缓存，不再执行

function memoize(fn) {
  const cache = new Map()
  return (key) => {
    if (!cache.has(key)) cache.set(key, fn(key))
    return cache.get(key)
  }
}
const square = memoize((n) => n * n)
square(5)                     // 25
square(5)                     // 25  ← 命中缓存，未重新计算

// 防抖：停止触发后只执行最后这一次（适合搜索输入）
function debounce(fn, wait) {
  let timer
  return (...args) => {
    clearTimeout(timer)
    timer = setTimeout(() => fn(...args), wait)
  }
}

// 节流：固定间隔内至多执行一次（适合滚动、拖拽）
function throttle(fn, gap) {
  let last = 0
  return (...args) => {
    const now = Date.now()
    if (now - last >= gap) { last = now; fn(...args) }
  }
}
