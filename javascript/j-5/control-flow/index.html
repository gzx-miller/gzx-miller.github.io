流程控制：条件、循环与跳转

用 if/else、switch、三种循环与 continue/break 组织分支与重复，厘清 for...of 与 for...in 的区别。

开场问题：报名审核页用 for...in 遍历报名者数组，页面上打印出来的却是 '0'、'1' 这样的下标；同一份名单里用 switch 处理审核状态时漏写了 break，一条「已通过」的记录，把下面「已拒绝」的逻辑也一并执行了。

条件分支与真假值

if / else if / else 自上而下检查条件，命中第一个为真的分支，其余整段跳过。最省事的写法是把值直接丢进条件：if (score)，短，而且大部分时候看起来没错。

问题藏在「真假值」里：0、空字符串、null、undefined、NaN、false 全被判为假，用户明明填了 0 分，却和「什么都没填」走进同一个分支；顺带一提，用弱相等写条件同样危险，if (value == '') 会把 0 也判成真。它做对的是让条件短，不够的是把「值是 0」和「值不存在」压成了同一个结论。

迭代成两条习惯：条件尽量写成显式比较，如 if (score !== undefined && score >= 60)；用提前返回（guard clause）压平嵌套——先逐条挡掉不合法输入，再让主路径一路平铺下去：

  • if (!name) return '请填写姓名'
  • if (score < 60) return '未通过'
  • return '通过'

三元与多路分支

需要「二选一取个值」时，三元表达式最顺手：条件 ? 真值 : 假值，结果可直接塞进赋值或插值。88 >= 60 ? '合格' : '待定' 一行就能定档。但嵌套两三层之后，括号和冒号会迅速失去可读性，超过一层就该换回 if。

分支多于两条、且都在判断同一个值时，switch 比一串 else if 更清楚。要记住它的一条硬规则：switch 用严格相等（===）逐个比较 case，所以字符串 '1' 不会命中 case 1。另一条是穿透：每个 case 末尾若不写 break（或 return），执行会继续往下灌进下一个分支——开头那条「已通过」把「已拒绝」也跑了，正是漏了 break。穿透偶尔是故意为之（多个值共用同一段逻辑，写成 case 1: case 2:），但绝大多数情况它都是 bug。

三种循环的选择

循环有三种写法，选哪种取决于你能回答「循环什么时候停」。

  • for：次数或索引已知——初始值、条件、步进都集中在头部，最适合按下标推进的遍历。
  • while：只知道「条件成立就继续」，次数不确定，例如等一个队列清空。
  • do...while：先执行一次再判断，保证循环体至少跑一次——重试请求、输入校验这类「至少做一次」的场景才用它。

换句话说，结束条件要么是「数得清的次数」，要么是「一直成立的条件」，要么是「不管怎样先来一次」。挑中对应的那一种，循环就不容易写成死循环。

遍历值还是遍历键

两个遍历写法名字很像，取出的东西却完全不同。for...of 遍历的是可迭代对象的值——数组元素、字符串字符、Map 的 [key, value]、Set 的成员，循环变量拿到的就是值本身。它做对了「遍历和取到的内容是一回事」，正是日常最想要的效果。

而 for...in 遍历的是对象的可枚举字符串键，并且会沿原型链把继承来的可枚举属性也算进去。数组用 for...in，拿到的是 '0'、'1' 这样的字符串下标，还会带上挂在原型上的自定义属性——这就是开头打印出下标的原因。结论很干脆：要值就用 for...of；确实要看键名才用 for...in，并且最好配合 Object.hasOwn() 过滤掉继承属性；数组遍历一律用 for...of。

循环控制收尾

循环体里有两把开门的钥匙：continue 结束本轮、直接进入下一次迭代；break 结束整个循环。要注意 break 放在 switch 里时，它只跳出 switch，并不会跳出外层循环——若想一次跳出多层，可以用带标签的跳转：给外层循环起个名字 outer:，内层写 break outer。它能解决嵌套里「一次跳两层」的麻烦，但可读性差，能提前 return、或者把内外两层拆成两个函数，就别用标签。

「循环控制」continue 只跳过当前这一轮、继续下一次迭代；break 直接终止整个循环（在 switch 里则只跳出该分支）。想从嵌套循环中一次跳出指定外层，可用带标签的 break outer；能提前返回或拆分函数时，优先不用标签。

// ═══════════════════════════════════════════
// 1. if / else if / else 与真假值
// ═══════════════════════════════════════════

function grade(score) {
  if (score === undefined) return '未填写'   // 显式判断，避开 0 被当成假值
  if (score >= 90) return '优'
  else if (score >= 60) return '合格'
  else return '待定'
}
grade(0)          // '待定' —— 写成 if (score) 会在这一步误判
grade(88)         // '合格'
Boolean(0)        // false —— 所以 0 直接丢给条件会被当成没填

// ═══════════════════════════════════════════
// 2. 三元表达式与 switch
// ═══════════════════════════════════════════

const label = 88 >= 60 ? '合格' : '待定'   // '合格' —— 二选一取值

function statusOf(code) {
  switch (code) {
    case 1:
      return '待审核'
    case 2:            // 故意穿透：1 与 2 共用同一段逻辑
    case 3:
      return '处理中'
    default:
      return '已完成'
  }
}
statusOf(2)        // '处理中'
statusOf('1')      // '已完成' —— switch 用 ===，字符串 '1' 不命中数字 1

// ═══════════════════════════════════════════
// 3. for / while / do...while 的选择
// ═══════════════════════════════════════════

for (let k = 0; k < 3; k++) { }        // 次数已知：k 依次为 0、1、2

let queue = 3
while (queue > 0) { queue-- }          // 条件未知：循环结束时 queue 为 0

let visits = 0
do { visits++ } while (false)          // 结果：visits 为 1 —— 至少执行一次

// ═══════════════════════════════════════════
// 4. for...of 与 for...in
// ═══════════════════════════════════════════

const names = ['松松', '阿栗']
for (const name of names) { }          // 取到值：'松松'、'阿栗'
for (const key in names) { }           // 取到键：'0'、'1'（字符串）

const options = { limit: 20, page: 1 }
for (const key in options) { }         // 'limit'、'page'
Object.hasOwn(options, 'limit')        // true —— 过滤继承属性的标准写法

// ═══════════════════════════════════════════
// 5. continue / break / 带标签跳转
// ═══════════════════════════════════════════

const scores = [88, 45, 92, 60]
const passed = []
for (const score of scores) {
  if (score < 60) continue             // 跳过本轮，低分不进名单
  passed.push(score)
}
passed                                 // 结果：[88, 92, 60]

for (const score of scores) {
  if (score >= 90) break               // 结束整个循环
}

outer:
for (let x = 0; x < 3; x++) {
  for (let y = 0; y < 3; y++) {
    if (x + y === 2) break outer       // 一次跳出两层循环
  }
}
