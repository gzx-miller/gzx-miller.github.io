部署优化与语义缓存

掌握 LLM 应用的缓存、流式输出、Token 预算和成本控制策略。

开场问题：客服机器人上线第一天就被打爆，可翻后台日志你会发现，用户问来问去是同一件事：「怎么退款」和「如何退款」各触发了一次完整调用，「推荐 Vue3 入门课程」和「推荐 Vue3 基础教程」也各烧了一次钱。账单按请求数线性上涨，首字节越来越慢，而这两句话在语义上根本是同一个问题。

精确匹配复用条件

LLM 调用又贵又慢，而线上的问题高度重复。最直接的对策是加缓存：同样的请求，把上一次的答案直接返回。可普通缓存靠「字符串完全相等」命中——只有当用户一字不差复制了上一次的问题时才算命中。

旧办法（精确匹配缓存）把三笔成本留给了你：

  1. 命中率极低：换个标点、多一个空格、换个同义词，就是两个不同的 key，照样打模型。
  2. 明知语义相同也不敢复用：因为你手上只有「字符串相等 / 不等」这一个判据。
  3. 强行放宽又会答非所问：一旦按「字符串有点像」就命中，很容易把语义不同的问题当成同一个，返回张冠李戴的答案。

要回答的是：怎样让缓存按「语义是否相同」来判断命中，而不是按「字符是否一模一样」？

提示原文缓存键

先用最朴素的一版：拿 prompt 原文当 key，塞进一个 Map，下次来同样的 key 就直接返回。

这个方案做对了一件事：它把「重复请求复用结果」这件事真正落了地。命中就是零调用、零成本、直达返回，而且逻辑简单到不会出错——这份「先查后算」的骨架要保留。

措辞差异导致失配

  • 精确匹配下，「怎么退款」和「如何退款」是两个 key，第二句照样从头调一次模型。
  • 多一个空格、少一个标点就 miss，缓存形同虚设。
  • 不敢放宽：字符串相似并不等于语义相同，放宽阈值就可能把不同问题认成一个，返回错误答案。
  • 缓存没有过期：历史问答会长期留存，涉及用户私有数据时容易跨用户串号。

语义相似度匹配

不推翻「先查后算」，而是把判断命中的那把尺子，从「比较字符串」升级成「比较语义」。

第一步，让缓存按向量相似度命中。用嵌入模型把每句 prompt 转成向量，检索最相近的历史问题，相似度超过阈值就复用它的答案——这就是语义缓存。它认的是「这句话在说什么」，而不是「这句话怎么打出来的」，所以「怎么退款」和「如何退款」会落在很近的位置，命中同一个缓存。

第二步，把阈值当成核心旋钮来调。阈值太高，几乎命中不了，等于没做缓存；太低，又容易误命中，把不同问题认成同一个。正确做法是拿真实 query 观测相似度分布，再据此定阈值——本课演示里默认放在 0.85 附近，你可以拖动滑块直观感受命中与未命中如何在某个点翻转。

第三步，补上隔离与过期。语义缓存会长期保存历史问答，涉及用户私有数据时必须按用户隔离命名空间，并给条目设置过期时间，否则会串号、也会命中早已过时的答案。

部署上线不只是「缓存」，还要同时看好另外两件事。其一是成本与预算：用 token 预算管理配额、按任务选模型并估算单次费用，避免账单失控；其二是可靠性：对限流（429）做指数退避重试、对非可重试错误立即抛出，给长请求设超时上限，高负载时降级到更便宜的备用模型。把延迟、成本、错误率做成监控指标持续观察，再据此回头调整阈值和上限。

相似度阈值调节

延迟成本与可靠性

部署优化要同时压住三件事：延迟、成本、可靠性。语义缓存用向量相似度替代字符串相等，让「说法不同、意思相同」的重复问题复用答案；阈值按真实分布调，缓存按用户隔离并设过期。再配上 token 预算、退避重试、超时与降级，上线后才有得控。

「语义缓存」是不以字符串而以嵌入向量作为缓存键的技术：把新请求和历史问题都转成向量，用相似度阈值判断两者是否「同一个问题」，超过阈值就复用历史答案。边界：阈值必须按真实 query 的相似度分布调优——过高难命中、过低易误命中；涉及用户私有数据时必须按用户隔离并设置过期，否则会串号或命中过时答案；它省的是重复调用的成本，并不能提升单次生成的质量。

import { ChatOpenAI } from '@langchain/openai'
import { ChatPromptTemplate } from '@langchain/core/prompts'
import { StringOutputParser } from '@langchain/core/output_parsers'
import { RunnableSequence, RunnablePassthrough } from '@langchain/core/runnables'
import { OpenAIEmbeddings } from '@langchain/openai'
import { MemoryVectorStore } from 'langchain/vectorstores/memory'
import { Document } from '@langchain/core/documents'

const model = new ChatOpenAI({ model: 'gpt-4o-mini', temperature: 0 })
const parser = new StringOutputParser()

// 示例1: 简单内存缓存
const cache = new Map<string, string>()

async function getAnswerWithCache(question: string): Promise<string> {
  if (cache.has(question)) {
    console.log('缓存命中!')
    return cache.get(question)!
  }
  
  const prompt = ChatPromptTemplate.fromTemplate('回答问题: {question}')
  const chain = prompt.pipe(model).pipe(parser)
  const answer = await chain.invoke({ question })
  
  cache.set(question, answer)
  return answer
}

console.log('第一次调用（无缓存）:')
const answer1 = await getAnswerWithCache('什么是 LLM？')
console.log(answer1.slice(0, 50) + '...')

console.log('\n第二次调用（命中缓存）:')
const answer2 = await getAnswerWithCache('什么是 LLM？')
console.log(answer2.slice(0, 50) + '...')

// 示例2: 语义缓存 - 基于向量相似度
const embeddings = new OpenAIEmbeddings({ model: 'text-embedding-3-small' })
const semanticCacheStore = await MemoryVectorStore.fromDocuments([], embeddings)
const semanticCache = new Map<string, string>() // id -> answer

async function getAnswerWithSemanticCache(
  question: string,
  threshold: number = 0.9
): Promise<{ answer: string; fromCache: boolean }> {
  // 先搜索是否有相似问题
  const results = await semanticCacheStore.similaritySearchWithScore(question, 1)
  
  if (results.length > 0 && results[0][1] >= threshold) {
    const cachedDoc = results[0][0]
    const cacheKey = cachedDoc.metadata.cacheKey as string
    console.log(`语义缓存命中! (相似度: ${results[0][1].toFixed(4)})`)
    return { answer: semanticCache.get(cacheKey)!, fromCache: true }
  }
  
  // 没有命中，生成答案
  const prompt = ChatPromptTemplate.fromTemplate('回答问题: {question}')
  const chain = prompt.pipe(model).pipe(parser)
  const answer = await chain.invoke({ question })
  
  // 存入语义缓存
  const cacheKey = `cache_${Date.now()}`
  semanticCache.set(cacheKey, answer)
  await semanticCacheStore.addDocuments([
    new Document({
      pageContent: question,
      metadata: { cacheKey },
    }),
  ])
  
  return { answer, fromCache: false }
}

// 示例3: Token 预算控制
class TokenBudgetManager {
  private budget: number
  private used: number = 0
  private resetInterval: number
  private lastReset: number

  constructor(budget: number, resetIntervalMs: number = 3600000) {
    this.budget = budget
    this.resetInterval = resetIntervalMs
    this.lastReset = Date.now()
  }

  private checkReset() {
    if (Date.now() - this.lastReset > this.resetInterval) {
      this.used = 0
      this.lastReset = Date.now()
    }
  }

  canAfford(tokens: number): boolean {
    this.checkReset()
    return this.used + tokens <= this.budget
  }

  consume(tokens: number): boolean {
    this.checkReset()
    if (this.used + tokens > this.budget) {
      return false
    }
    this.used += tokens
    return true
  }

  getUsage(): { used: number; budget: number; remaining: number } {
    this.checkReset()
    return {
      used: this.used,
      budget: this.budget,
      remaining: this.budget - this.used,
    }
  }
}

// 使用 Token 预算
const budgetManager = new TokenBudgetManager(100000) // 每小时 100k token
console.log('Token 使用情况:', budgetManager.getUsage())

// 示例4: 指数退避重试
async function retryWithBackoff<T>(
  fn: () => Promise<T>,
  maxRetries: number = 3,
  baseDelay: number = 1000
): Promise<T> {
  let lastError: Error
  
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (error: any) {
      lastError = error
      
      // 只有限流错误才重试
      if (error.status !== 429 && error.code !== 'rate_limit_exceeded') {
        throw error
      }
      
      const delay = baseDelay * Math.pow(2, i)
      console.log(`限流，${delay}ms 后重试 (${i + 1}/${maxRetries})`)
      await new Promise(resolve => setTimeout(resolve, delay))
    }
  }
  
  throw lastError!
}

// 示例5: 降级策略
async function getAnswerWithFallback(question: string): Promise<string> {
  const prompt = ChatPromptTemplate.fromTemplate('回答问题: {question}')
  const advancedChain = prompt.pipe(new ChatOpenAI({ model: 'gpt-4o' })).pipe(parser)
  const basicChain = prompt.pipe(new ChatOpenAI({ model: 'gpt-4o-mini' })).pipe(parser)
  
  try {
    // 先尝试高级模型
    return await advancedChain.invoke({ question })
  } catch (error) {
    console.log('高级模型失败，降级到基础模型')
    // 降级到基础模型
    return await basicChain.invoke({ question })
  }
}

// 示例6: 请求超时控制
async function withTimeout<T>(
  promise: Promise<T>,
  timeoutMs: number
): Promise<T> {
  const timeoutPromise = new Promise<never>((_, reject) => {
    setTimeout(() => reject(new Error('请求超时')), timeoutMs)
  })
  
  return Promise.race([promise, timeoutPromise])
}

// 使用超时
try {
  const result = await withTimeout(
    model.invoke('写一篇长文'),
    10000 // 10秒超时
  )
} catch (error: any) {
  console.log('超时处理:', error.message)
}

// 示例7: 成本估算
function estimateCost(
  promptTokens: number,
  completionTokens: number,
  model: string = 'gpt-4o-mini'
): number {
  const prices: Record<string, { input: number; output: number }> = {
    'gpt-4o': { input: 0.005, output: 0.015 },
    'gpt-4o-mini': { input: 0.00015, output: 0.0006 },
    'gpt-3.5-turbo': { input: 0.0005, output: 0.0015 },
  }
  
  const price = prices[model] || prices['gpt-4o-mini']
  const inputCost = (promptTokens / 1000) * price.input
  const outputCost = (completionTokens / 1000) * price.output
  
  return inputCost + outputCost
}

// 估算成本示例
const cost = estimateCost(1000, 500, 'gpt-4o-mini')
console.log(`估算成本: $ ${cost.toFixed(6)}`)
