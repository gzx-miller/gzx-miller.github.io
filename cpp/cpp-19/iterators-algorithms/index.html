STL 迭代器与算法库

掌握迭代器的分类与用法，以及标准算法库如何在迭代器区间上工作。

开场问题：如果每个容器都得自己实现一遍 sort、find，代码会重复到失控。能不能让「算法」根本不认识「容器」，却依然能对它们操作？

朴素做法：给每个容器各写一遍算法

直觉方案是「谁需要谁实现」：数组写一份遍历找最大值，链表再写一份，动态数组再写一份。它「做对了」——逻辑直白，每份都对各自的存储结构量身定制。

但算法本身（比如「找第一个大于 x 的元素」）与数据放在数组还是链表里毫无关系。为每种容器各抄一遍，既让逻辑分散、容易改漏，也几乎无法测试和维护。算法和数据结构被绑死在一起，是这套做法最大的问题。

迭代器：算法与容器之间的桥

STL 的解法是引入迭代器：一种「像指针一样」访问元素的对象。算法不接收容器，而是接收两个迭代器表示的范围：

  • 区间写成 [first, last)，即前闭后开——包含 first，不包含 last。
  • begin() 指向第一个元素，end() 指向「尾后」位置（最后一个元素的下一个）。
  • find(v.begin(), v.end(), x)：算法只依赖迭代器的操作，压根不知道 v 是什么容器。

这样一来，同一份算法实现能作用在数组、vector、list 上——泛型编程在这里展现得最充分。

迭代器分类：算法对能力有要求

迭代器不是同一种东西，按能提供的操作分成五类，能力由弱到强：

  • 输入迭代器：只读、单向；输出迭代器：只写、单向。
  • 前向迭代器：可读写、只能前进（forward_list）。
  • 双向迭代器：可读写、能前进也能后退（list、map、set）。
  • 随机访问迭代器：还能任意步跳转、做加减比较（vector、deque、array）。

算法要求的类别必须被满足：只读算法（find、count、accumulate）只要有输入迭代器；但 std::sort 要求随机访问迭代器，所以 list 不能用它——应改用 list 自带的成员函数 sort()。

常用算法、numeric 头文件与 lambda 谓词

常用算法分成两拨：

  • <algorithm>：find（查找）、count（计数）、sort（排序，不保证稳定）、stable_sort（稳定排序）、transform（变换）、copy、replace、unique。
  • <numeric>：accumulate（累加）、inner_product 等数值算法。

用 accumulate 有个细节：初值决定累加器的类型。accumulate(begin, end, 0) 用 int 累加，若元素是浮点数，小数部分会被截断；想得到浮点结果，初值要写成 0.0。

很多算法允许传一个谓词——返回 bool 的可调用对象，用来描述「什么算符合条件的元素」。lambda 让谓词可以就地写：std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; }) 就是一次降序排序，比较规则直接写在调用点，不必另开一个命名函数。

remove-erase 惯用法与迭代器失效

有个必须记住的惯用法：std::remove 并不真的删除元素，它只是把要保留的元素往前搬、返回新的逻辑终点，容器长度并未改变。真正删除要配合容器的 erase：v.erase(std::remove(v.begin(), v.end(), x), v.end())，这就是 remove-erase 惯用法。

算法从不检查迭代器是否有效、区间是否合理，传错了就是未定义行为。尤其在算法执行过程中改动同一个容器（例如边遍历边 push_back），会让迭代器立刻失效。边界要由调用者守住。

看一遍迭代器与算法

算法不碰容器，只碰区间

迭代器与算法的分工可以浓缩成一句：容器负责存储，迭代器负责描述范围，算法只在这段范围上工作。正因为如此，算法被写一次就能服务所有容器。理解了这一分工，也就能理解为什么 sort 挑迭代器类别、为什么 remove 要配合 erase。

「迭代器」是像指针一样访问容器元素的对象，「区间」用 begin()/end() 表示前闭后开的 [first, last)；「谓词」是返回 bool 的可调用对象，常以 lambda 形式就地书写。「remove-erase 惯用法」指先由 std::remove 搬移、再由容器 erase 收缩长度，才真正删除元素。

关键代码

C++
// ═══════════════════════════════════════════
// 1. 区间与只读算法：find / count
// ═══════════════════════════════════════════

#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>
#include <numeric>
#include <string>

void findCountDemo() {
    std::vector<int> v{5, 2, 8, 1, 9, 3};
    auto it = std::find(v.begin(), v.end(), 8);        // 算法只认区间，不认识容器
    if (it != v.end())
        std::cout << std::distance(v.begin(), it) << std::endl;   // 2
    std::cout << std::count(v.begin(), v.end(), 8) << std::endl;  // 1
}

// ═══════════════════════════════════════════
// 2. sort：要求随机访问迭代器
// ═══════════════════════════════════════════

void sortDemo() {
    std::vector<int> v{5, 2, 8, 1, 9, 3};
    std::sort(v.begin(), v.end());                     // 升序，O(n log n)，不保证稳定
    for (int x : v) std::cout << x << " ";             // 1 2 3 5 8 9
    std::cout << std::endl;
    // list 只有双向迭代器，不能用 std::sort；应调用其成员函数 lst.sort()
}

// ═══════════════════════════════════════════
// 3. numeric 头文件：accumulate 累加
// ═══════════════════════════════════════════

void accumulateDemo() {
    std::vector<int> v{1, 2, 3, 4};
    int sum = std::accumulate(v.begin(), v.end(), 0);      // 初值 0 → 累加器类型 int
    std::cout << sum << std::endl;                         // 10
    // 初值写成 0.0 可让累加器为 double，避免浮点元素被截断
}

// ═══════════════════════════════════════════
// 4. transform 与 lambda 谓词
// ═══════════════════════════════════════════

void transformDemo() {
    std::vector<int> v{1, 2, 3, 4};
    std::vector<int> out(v.size());
    std::transform(v.begin(), v.end(), out.begin(),    // 一元变换
                   [](int x) { return x * x; });       // 谓词：lambda 就地写规则
    for (int x : out) std::cout << x << " ";           // 1 4 9 16
    std::cout << std::endl;

    std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });  // 降序
    std::cout << v.front() << std::endl;               // 4，最大值排在最前
}

// ═══════════════════════════════════════════
// 5. remove-erase 惯用法：删除才真正生效
// ═══════════════════════════════════════════

void removeEraseDemo() {
    std::vector<int> v{1, 2, 2, 3, 2, 4};
    auto newEnd = std::remove(v.begin(), v.end(), 2);  // 只搬移保留元素，长度不变
    v.erase(newEnd, v.end());                          // 配合 erase 收缩容器
    for (int x : v) std::cout << x << " ";             // 1 3 4
    std::cout << std::endl;
}

// ═══════════════════════════════════════════
// 6. 汇总调用
// ═══════════════════════════════════════════

int main() {
    findCountDemo();
    sortDemo();
    accumulateDemo();
    transformDemo();
    removeEraseDemo();
    return 0;
}
