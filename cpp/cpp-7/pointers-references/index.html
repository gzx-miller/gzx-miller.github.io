指针与引用：地址、解引用与别名

深入理解指针的算术运算、引用与指针的区别，以及 nullptr 和 void* 的正确使用。

开场问题：手里有一个指向数组首元素的指针 q，你写下 *(q + 1)，本以为是把地址往后挪一个字节，结果它直接读到了第二个元素——这个「加一」，加的到底是什么？

按值传参限制

你经常需要让函数去操作调用方的数据。可 C++ 默认按值传参，函数拿到的只是一份副本，在函数里改副本，原件纹丝不动。于是「怎么让函数真正操作到那个对象」成了必须回答的问题。

直觉上最省事的答案是「把对象复制一份给函数」。但这份「省事」背后压着几笔必须由人承担的账：

  • 复制本身有代价：对象越大，每次调用拷贝一次，开销随规模增长。
  • 表达不了「没有」：有些参数本来就可能不存在，纯副本无法如实描述这种「可选」。
  • 改不到「指针本身」：有时函数要换掉调用方手里那个地址，副本做不到。

所以真正要回答的是：怎样用「指向某对象」或「某对象的别名」来表达，既不复制，又能分清「必然存在」与「可能为空 / 可重定向」？

记录对象地址

最直接的做法：记下对象的位置，也就是地址。

int x = 42;
int* p = &x;
*p = 100;

p 里存的是 x 的地址，*p 解引用就拿到 x 本身，对它赋值等于直接改 x。函数只要改成收 int* p、调用时传 &x，函数里 *p = 100 就能改到原对象。

这个方案做对了一件事：它把「对象本身」和「对象的位置」分开了。传一个地址很便宜（一个指针大小），解引用之后又能直达原件，「复制太贵」和「改不到原件」两个问题一起解掉。

空指针与野指针

  • 指针可以指向「什么都没有」：int* p; 未初始化时存的是随机值，解引用就是未定义行为。
  • 用法不顺手：每次访问都得写 *p，想让「像普通变量一样直接用」就做不到。
  • 算术不直观：p + 1 加的不是一个字节，凭直觉就会算错。
  • 类型上看不出「一定非空」：函数签名 void f(int* p) 根本没说明 p 能不能是 nullptr。

引用别名机制

先补「别名」这一层，这就是引用：

int y = 5;
int& r = y;
r = 10; // y 也变成 10

r 是 y 的别名，用起来和普通变量一模一样，不用写 *。引用必须定义时初始化，之后不能改绑——所以不存在「空引用」。于是分工清晰了：需要一个必然存在的别名、且想当变量用时，用引用（函数参数首选 Type&）；需要表达「可能为空」或「函数要改指针本身」时，才用指针。

接着把指针算术说清楚。int arr[] = {10, 20, 30}; int* q = arr;（等价于 &arr[0]）。这里的 q + n 不是地址加 n 个字节，而是加 n * sizeof(int) 个字节，所以 *(q + 1) 得的是 20。这也正是 arr[i] 等价于 *(arr + i) 的原因。

再补几条必须记住的边界。第一，比较：== / != 对指向不同对象的指针是良定义的（通常为假）；但 <、<= 这类关系比较，只有两个指针指向同一数组的元素时才有意义，否则结果是未指定或实现定义的。第二，引用不是独立对象：既然它不单独占存储，就既没有「引用的引用」，也没有「指向引用的指针」——int& *p 是非法语法，想拿 r 所绑定对象的指针要写 int* p = &r;（&r 得到的正是那个对象的地址）。第三，声明别被骗：int* p, q; 里只有 p 是指针，q 是普通的 int，推荐分行声明或写成 int *p, q;。

最后把「空」和「const」补上。C++11 的 nullptr 取代了 NULL（后者往往是宏 0 或 (void*)0）：nullptr 能隐式转换成任何指针类型，却不能转成 int，从而消除了 NULL 带来的重载二义性；解引用前记得先判 if (p != nullptr)。const 则分两层：int* const p 是顶层 const，p 自己不能再改指向；const int* p 是底层 const，指向的内容不能改；两者叠加的 const int* const p 就都锁死了。

「引用不能重新绑定」这句要分清：r = 10 并不是让 r 改去指向 10，而是把 10 赋给 r 所绑定的那个对象。想「改指向」只能用指针。

解引用指针算术

地址与别名分工

指针和引用是同一件事的两副面孔：都在描述「别处的某个对象」。指针是「可以换、可以为空的地址」，引用是「装成变量、不能改绑的别名」。要改原件又不复制，用引用；要表达可选或重定向，用指针；而 p + n、p->m、const 的先后顺序，都是围绕这个地址做文章。

「解引用」指对指针使用一元 * 运算符，取得它所指向的对象本身，结果是一个左值，可以直接被赋值（*p = 100 即修改目标对象）。边界：只能对指向有效对象的指针解引用，对 nullptr、未初始化指针或已释放内存的指针解引用都是未定义行为；p->member 只是 (*p).member 的简写。

#include <iostream>

    int* p = &x;
    std::cout << *p << std::endl;
    *p = 100;
    std::cout << x << std::endl;

    r = 10;
    std::cout << x << std::endl;
