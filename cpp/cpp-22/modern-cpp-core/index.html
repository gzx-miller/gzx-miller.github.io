现代 C++ 核心特性：auto、范围 for、nullptr 与结构化绑定

掌握 auto 与 decltype、范围 for、nullptr、结构化绑定、constexpr、enum class 等现代特性。

开场问题：std::map<std::string, int>::iterator it = m.find(k); 这样的类型名又长又容易敲错，用 NULL 表示空指针还可能让重载选错版本 —— 有没有办法让编译器替我记住类型、让「空指针」真正是一个指针，顺便把遍历和取值也写得更短？

先朴素做法：显式类型、NULL、typedef 与下标循环

C++11 之前，这些事都靠手工完成，每一样都能用，但也各有代价。

  • 写全类型名：迭代器类型尤其长，改动容器就得改一串声明，转录时极易出错。
  • 用 NULL 表示空指针：它本质是宏，通常是 0 或 (void*)0，因此会与整数 0 混淆，在重载决议时可能选中期望整数的版本。
  • 用 typedef 起别名：能简化类型，但语法别扭，且无法定义模板别名。
  • 用下标循环遍历：for (int i = 0; i < n; ++i)，边界、类型容易写错，也依赖容器支持随机访问。

这些做法的共同不足是：把「本可由编译器或语言保证」的义务留给了人手 —— 类型记不住、空指针的类型不安全、别名不够灵活、边界要自己守。现代 C++ 的对应特性正是冲着这些来的。

auto 与 decltype 的推导规则

auto 用初始化表达式推导变量类型，省去冗长类型名，也保证变量类型与初始化式一致。但它的推导规则与模板参数一致，有两条必须记牢：

  • 用 auto（不带修饰）推导时，会丢弃顶层 const 和引用，并产生一次拷贝。auto a = cr;（cr 是 const int&）得到的是 int，而不是引用。
  • 要保留引用与 const，必须显式写 auto& 或 const auto&；auto&& 则是转发引用，可绑定任意值类别。

decltype 是另一种推导：decltype(名称) 直接取该名字的声明类型（保留 const 与引用）；decltype((表达式))（多加一层括号）取的是表达式类型，左值会得到引用类型。C++14 起还可用 auto 作为函数返回类型，由 return 语句推导，但所有返回语句的类型必须一致。

范围 for 与结构化绑定

范围 for 把「遍历整个容器」写成一个直观形式：for (auto& x : c)。它底层展开为对 begin() / end() 的迭代，因此对数组、标准容器、初始化列表都适用。

  • 需要修改元素时用 auto&；只读时用 const auto&，避免拷贝大对象；auto（值）会复制每个元素，通常不是本意。
  • 遍历期间不要增删元素，否则迭代器可能失效。

结构化绑定（C++17）更进一步：auto [a, b] = pair; 把聚合对象一次拆成多个具名变量，可用于 pair、tuple、结构体与数组。与范围 for 结合时特别顺手：for (const auto& [key, value] : map) 直接拿到键值对，其中用 & 可避免逐对拷贝。

nullptr、using 与 enum class

这三者各自修掉一个「语言层面的隐患」。

  • nullptr 是类型安全的空指针常量，类型为 std::nullptr_t，不会被当成整数 0，从而消除 NULL 带来的重载二义，语义也更清晰。
  • using 起别名比 typedef 可读性更好，且支持模板别名：template <typename T> using Vec = std::vector<T>;，这是 typedef 做不到的。
  • enum class 是强类型、有作用域的枚举：枚举值必须加 Color:: 前缀，不会泄漏到外层作用域，也不隐式转换成整数，需显式 static_cast，还能指定底层类型。相比裸 enum 更不容易撞名、也不易被误当数字运算。

统一初始化、initializer_list 与 constexpr

花括号初始化提供了一套统一语法：它可初始化任意对象（含容器、聚合、动态数组），并且禁止窄化转换（int i{3.14} 直接编译报错），把原先运行时才暴露的截断提前到编译期。

  • 需要注意一个优先级陷阱：当一个类既有 std::initializer_list 构造函数、又有其它构造函数时，花括号会优先匹配 initializer_list 版本。于是 std::vector<int> a(10, 20) 是「10 个值 20」，而 std::vector<int> b{10, 20} 是「两个元素 10 和 20」，含义完全不同。
  • constexpr 声明编译期的常量与函数：constexpr int area = square(4); 在编译期算好结果，既能提升运行时性能，也让结果可用于数组长度、模板参数等「必须是常量」的位置。

这些特性单看都是小便利，合起来改变的是一种书写习惯：让编译器承担记忆类型、检查类型、处理边界的工作，人只负责表达意图。

看一遍这些特性的实际写法

把重复劳动交还给编译器

这批特性共享同一条思路：凡是编译器能推出来、能检查出来的，就不要让人手去重复。类型记不住就交给 auto；空指针语义模糊就换成 nullptr；别名受限于语法就用 using；枚举容易撞名、被误当整数就用 enum class；足以在编译期确定的值就交给 constexpr。熟练之后，代码会更短，但更短的代码并没有少表达信息 —— 只是把信息交给了语言本身去表达。

「类型推导」指由初始化表达式或既有类型反推出变量类型，auto 与 decltype 的规则不同。「结构化绑定」指把一个聚合对象一次拆成多个具名变量。「窄化转换」是可能丢失信息的隐式数值转换，花括号初始化会将其拒于编译期之外。

关键代码

C++
// ═══════════════════════════════════════════
// 1. auto 与 decltype 的推导规则
// ═══════════════════════════════════════════

#include <iostream>
#include <vector>
#include <string>
#include <map>
#include <type_traits>                         // std::is_same_v

void deduceDemo() {
    int n = 0;
    const int& cr = n;
    auto a = cr;                               // auto 丢弃顶层 const 与引用 → int
    auto& b = cr;                              // 保留引用 → const int&
    decltype(cr) c = n;                        // decltype 保留引用与 const → const int&
    static_assert(std::is_same_v<decltype(a), int>);            // 说明：a 是值类型 int
    static_assert(std::is_same_v<decltype(c), const int&>);     // 说明：c 是 const int&
    std::cout << a + b + c << std::endl;       // 结果：0
}

// ═══════════════════════════════════════════
// 2. 范围 for 与结构化绑定
// ═══════════════════════════════════════════

void rangeDemo() {
    std::vector<int> nums = {1, 2, 3};
    for (auto& x : nums) {                     // 范围 for：底层用 begin/end 迭代
        x *= 2;                                // 引用遍历：就地修改元素
    }
    for (const auto& x : nums) {
        std::cout << x << " ";                 // 结果：2 4 6
    }
    std::cout << std::endl;

    std::map<std::string, int> ages = {{"Alice", 25}, {"Bob", 30}};
    for (const auto& [name, score] : ages) {   // 结构化绑定：解构 key-value
        std::cout << name << "=" << score << " ";   // 结果：Alice=25 Bob=30
    }
    std::cout << std::endl;
}

// ═══════════════════════════════════════════
// 3. nullptr、using 与 enum class
// ═══════════════════════════════════════════

using IntVec = std::vector<int>;               // using 别名，比 typedef 更清晰

enum class Color { Red, Green, Blue };         // 强类型枚举：有作用域、不隐式转 int

void typedDemo() {
    int* ptr = nullptr;                        // 类型安全的空指针，类型为 std::nullptr_t
    IntVec v = {1, 2, 3};                      // 别名可直接使用
    Color c = Color::Red;                      // 必须写 Color:: 前缀，避免作用域污染
    int code = static_cast<int>(c);            // 说明：需显式转换才能得到整数值
    std::cout << v.size() << " " << code << std::endl;   // 结果：3 0
}

// ═══════════════════════════════════════════
// 4. 统一初始化、initializer_list 与 constexpr
// ═══════════════════════════════════════════

constexpr int square(int x) { return x * x; }  // 可在编译期求值的函数

struct Point { int x; int y; };                // 聚合类型

void initDemo() {
    // int bad{3.14};                          // 编译错误：花括号初始化禁止窄化转换
    std::vector<int> a(10, 20);                // 结果：10 个元素，每个值 20
    std::vector<int> b{10, 20};                // 结果：2 个元素 10 和 20
    Point p{1, 2};                             // 聚合初始化
    constexpr int area = square(4);            // 结果：编译期算出 16
    int buf[area];                             // 说明：constexpr 结果可作数组长度
    std::cout << a.size() << " " << b.size() << " " << p.x << " " << area << std::endl;
    // 结果：10 2 1 16
}
