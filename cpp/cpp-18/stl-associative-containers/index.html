STL 容器（二）：map、set 与无序容器

掌握有序关联容器 map/set 与哈希容器 unordered_map/unordered_set 的特性与取舍。

开场问题：要用「名字 → 年龄」这种关系查数据，顺序数组得从头扫到尾；可如果还想「按名字有序遍历」，哈希表又给不了顺序。既要查得快、又要能排序，该选哪种容器？

朴素做法：平行数组或线性查找

最直接的做法是维护两个平行数组：一个存名字、一个存年龄，下标一一对应，查找时循环比对名字。它「做对了」——简单、直观、不引入额外概念。

代价是查找 O(n)，数据一多就慢；更棘手的是两个数组靠下标对齐维持关系，一旦插入或删除时忘了同步，键和值就错位了。而且想要「按名字排序遍历」，还得额外排一遍序、再重建对应关系。

map 与 set：红黑树带来的有序性

关联容器把「键」直接和「值」绑在一起。C++ 的 std::map / std::set 底层是红黑树——一种自平衡的二叉搜索树，于是：

  • 元素按键的大小有序存储，顺序遍历天然就是升序。
  • 查找、插入、删除都是 O(log n)，比线性查找快得多。
  • map 存的是键值对（value_type 是 pair<const Key, Value>），set 只存键、兼顾去重。
  • multimap / multiset 允许重复键，因此没有 operator[]。

operator[] 的插入语义：最常踩的坑

m[key] 看起来像「取值」，实际上它会插入：若键不存在，容器先插入一个值初始化的元素（int → 0、string → 空串），再返回它的引用。于是本想「读一下」，却不知不觉得往字典里塞进了一个默认值。

只想读取而不修改容器，就用两个工具：at(key) 返回引用、键不存在时抛 out_of_range；find(key) 返回迭代器、未找到返回 end()，全程不插入。operator[] 留给「确认要写入」的场景。

unordered_map 与 unordered_set：哈希表

如果不需要顺序、只追求查找速度，可以换成无序容器：std::unordered_map / std::unordered_set 基于哈希表，平均查找、插入、删除都是 O(1)，最坏会退化到 O(n)（哈希冲突严重时）。

  • 遍历顺序未指定，取决于哈希函数与桶布局，不能依赖它。
  • 负载因子（元素数 / 桶数）影响性能，可用 reserve(n) 预留、rehash(n) 强制调整桶数。
  • 键必须可哈希、可比较相等；标准类型已内置，自定义类型需要自己提供。

自定义比较与哈希

用自己的类型当键时，得替容器补上它需要的两样东西：

  • 给有序容器提供比较器（默认 std::less<Key>），满足严格弱序，比如按 id 比较。
  • 给无序容器提供哈希函数与相等比较：前者决定桶位置，后者处理冲突判断，二者必须一致——相等的东西必须哈希到同一桶。

查找与计数的分工也要清楚：find 返回迭代器、判断存在性；count 返回个数——在 map/set 里非 0 即 1，在 multimap/multiset 里可能大于 1；需要单个键的全部元素时，用 equal_range 取出 [first, last) 区间。

看一遍有序与无序关联容器

有序与无序，回答的是同一个问题的两面

关联容器的选择，本质是在「顺序」和「速度」之间做取舍：需要有序遍历或范围查询（lower_bound、upper_bound、equal_range）就选红黑树的 map/set；只需要快速命中且能给出良好哈希，就用哈希表的 unordered_ 版本。把 operator[] 的插入语义和自定义键的哈希/比较补齐，这两族容器就能稳稳地用起来。

「关联容器」按关键字存取元素；「有序关联容器」（map/set/multimap/multiset）基于红黑树，查找 O(log n) 且按键有序；「无序关联容器」（unordered_map/unordered_set）基于哈希表，平均 O(1)、顺序未指定。自定义键需要提供「比较器」或「哈希函数与相等比较」。

关键代码

C++
// ═══════════════════════════════════════════
// 1. map：红黑树有序键值、operator[] 会插入
// ═══════════════════════════════════════════

#include <iostream>
#include <map>
#include <set>
#include <unordered_map>
#include <functional>
#include <string>

void mapDemo() {
    std::map<std::string, int> ages;
    ages["Alice"] = 25;                       // 键不存在 → 先插入 {Alice, 0} 再赋值
    ages["Bob"] = 30;
    std::cout << ages.size() << std::endl;    // 2

    if (ages.find("Carol") == ages.end()) {   // find 只查，不插入
        std::cout << "no Carol" << std::endl; // 输出 no Carol
    }
    // 只读请用 at()（越界抛 out_of_range）或 find()；operator[] 会悄悄插入默认值

    for (const auto& [name, age] : ages) {    // 结构化绑定，遍历按键升序
        std::cout << name << "=" << age << " ";   // Alice=25 Bob=30
    }
    std::cout << std::endl;
}

// ═══════════════════════════════════════════
// 2. set：有序、去重的红黑树集合
// ═══════════════════════════════════════════

void setDemo() {
    std::set<int> s{5, 2, 8, 1, 2};          // 重复的 2 被丢弃
    s.insert(3);
    for (int x : s) std::cout << x << " ";   // 升序输出：1 2 3 5 8
    std::cout << std::endl;
    std::cout << s.count(2) << " " << s.count(9) << std::endl;   // 1 0
}

// ═══════════════════════════════════════════
// 3. multimap / multiset：允许重复键
// ═══════════════════════════════════════════

void multiDemo() {
    std::multiset<int> ms{1, 2, 2, 3};       // 允许重复，故没有 operator[]
    std::cout << ms.count(2) << std::endl;   // 2
    auto range = ms.equal_range(2);          // [first, last) 覆盖所有 2
    for (auto it = range.first; it != range.second; ++it)
        std::cout << *it << " ";             // 2 2
    std::cout << std::endl;
}

// ═══════════════════════════════════════════
// 4. unordered_map：哈希、平均 O(1)、顺序不定
// ═══════════════════════════════════════════

void unorderedDemo() {
    std::unordered_map<std::string, int> stock;
    stock["pen"] = 100;
    stock["book"] = 20;
    stock.reserve(16);                       // 预留桶，减少 rehash
    std::cout << stock["pen"] << std::endl;  // 100
    std::cout << stock.bucket_count() << std::endl;   // 桶数 ≥ 16
    // 遍历顺序未指定，不能假设按 pen/book 的字典序
}

// ═══════════════════════════════════════════
// 5. 自定义比较与哈希：让自定义类型可作键
// ═══════════════════════════════════════════

struct User {
    int id;
    std::string name;
};

struct UserById {                    // 有序容器所需：严格弱序比较器
    bool operator()(const User& a, const User& b) const { return a.id < b.id; }
};

struct UserHash {                    // 无序容器所需：哈希函数
    std::size_t operator()(const User& u) const {
        return std::hash<int>{}(u.id);       // 复用标准 int 哈希
    }
};

struct UserEqual {                   // 无序容器所需：相等判断，须与哈希一致
    bool operator()(const User& a, const User& b) const { return a.id == b.id; }
};

void customKeyDemo() {
    std::set<User, UserById> orderedUsers;                      // 按 id 排序、去重
    std::unordered_map<User, int, UserHash, UserEqual> table;   // 哈希 + 相等比较
    orderedUsers.insert(User{2, "Bob"});
    orderedUsers.insert(User{1, "Alice"});
    table[User{1, "Alice"}] = 90;                               // 需要 hash/equal 才能存
    std::cout << orderedUsers.begin()->name << std::endl;       // Alice（id 最小排在前）
}

// ═══════════════════════════════════════════
// 6. 汇总调用
// ═══════════════════════════════════════════

int main() {
    mapDemo();
    setDemo();
    multiDemo();
    unorderedDemo();
    customKeyDemo();
    return 0;
}
