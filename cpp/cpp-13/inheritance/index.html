继承与派生类：基类、访问控制与切片

掌握继承语法、继承方式对访问级别的影响、构造析构顺序与对象切片问题。

开场问题：已经写好了 Animal 类，现在还需要一个 Dog：它拥有 Animal 的全部数据与行为，只多出几项自己的。最直接的办法是把 Animal 的代码整段复制过来再改，可两处几乎一样的代码各自维护，改一处漏一处。有没有一种写法，既能完整复用，又能表达「Dog 是一种 Animal」？

从复制代码到继承

复制代码做对的事是：让 Dog 确实拥有 Animal 的一切。不足也很明显：两份代码没有关联，无法从关系上表达「Dog 是一种 Animal」，也无法在不改动 Dog 的前提下统一升级 Animal 的公共部分。

继承正是为了消除这层重复：让 Dog 直接复用 Animal 的成员，只声明自己新增或需要改变的部分。被继承的类叫基类（父类），继承它的叫派生类（子类）。当派生类与基类满足「派生类 is-a 基类」（Dog is-a Animal）时，继承表达的就是这种是一种关系。

继承语法与三种继承方式

继承写在类名之后：class Dog : public Animal。冒号后面就是继承方式，它决定基类成员在派生类中的访问权限如何变化，共三种：

  • public 继承：保持原权限。public 成员在派生类中仍是 public，表达 is-a 关系，是最常用的方式。
  • protected 继承：基类的 public 与 protected 成员都降为 protected，只对继续派生的类开放。
  • private 继承：基类成员全部降为 private，外部与更下游的派生类都看不见。class 的默认继承方式就是它（struct 默认是 public）。

以 public 继承为例：基类的 public 与 protected 成员在派生类里保持原样，private 成员则无论哪种继承方式都不可直接访问——派生类只能用基类提供的接口间接操作它们。

那些为派生类预留、又不希望外部直接碰的成员，正是放在 protected 里的（上一章讲过它的定位），这样派生类能直接用，外部却够不着。

构造、析构顺序与名字隐藏

构造与析构顺序是继承里最确定的一条规定：构造时先基类、后派生类，析构时先派生类、后基类，恰好相反。原因在于派生类可能依赖基类的初始化结果，得等基类就位才能动；销毁时则要先把派生层拆掉，再交给基类收尾。因此派生类构造函数必须在初始化列表里显式调用基类构造。

另一件常被误解的事是名字隐藏：派生类只要定义了与基类同名的成员，基类中所有同名成员就会被隐藏，不论参数是否相同，也不能靠重载「找回来」。想调用被隐藏的基类版本，必须用作用域限定，写成 d.Base::show() 这种形式。

对象切片与 is-a 关系

继承真正的价值在多态：通过基类指针或引用操作派生类对象，调用到派生类的行为。这里有一个陷阱值得单独说明——对象切片。

当把一个派生类对象按值赋给基类对象时，如 Animal a = dog;，发生的是「切掉派生类独有的那部分、只保留基类子对象」的复制，得到一个 纯基类对象；此后通过它调用行为，只会走基类的版本，多态失效。这就是对象切片。

  • 切片发生在按值传递或按值赋值时，因为值语义只复制「基类那一部分」。
  • 避开的方法：用指针或引用传递，如 Animal& a = dog;，被绑定的仍是完整的派生类对象，不发生切片。

is-a 关系是判断继承是否合理的准绳：只有当「派生类确实是一种基类」时，public 继承才恰当。若只是为了借用基类的实现（has-a，或纯粹的实现复用），用组合（把基类对象作为成员）往往更合适，也更不易切片。

多继承与虚基类（基础）

C++ 允许一个类同时继承多个基类，写法是逗号分隔：class Amphibian : public Land, public Water。多继承能表达「兼具多种能力」，但它会带来一个典型问题——菱形继承：若 Land 与 Water 都继承自同一个 Animal，那么 Amphibian 里会出现两份 Animal 子对象，访问 Animal 的成员就产生歧义。

解决办法是虚继承：在继承时写 class Land : virtual public Animal，让这条继承链共享唯一一份基类子对象，菱形中被共享的那个基类就叫虚基类。相应地，虚基类的初始化由最派生类负责，不能只交给中间类。若把对象切片、名字隐藏、菱形多继承放在一起看，会发现它们都是「派生类与基类的关系没有摆正」在不同层面的表现。

用「是一种」而不是「像是一种」来决定继承

继承带来的最大收益，是让基类的接口成为一纸契约：所有派生类都得遵守它，调用方则可以统一地通过基类指针或引用来使用不同的派生对象。反过来，它也带来最容易被忽视的陷阱——切片与名字隐藏。判断继承是否该用的标准始终只有一条：派生对象确实是一种基类对象；只是「实现看起来能复用」时，组合才是更稳妥的选择。

「基类 / 派生类」分别指被继承的类与继承它的类，公有继承表达 is-a 关系；「继承方式」用 public、protected、private 决定基类成员在派生类中的访问权限；「名字隐藏」指派生类的同名成员遮蔽了基类所有同名成员，需用作用域限定符访问；「对象切片」指把派生类对象按值赋给基类对象时派生部分被切掉，多态随之失效；「虚基类」是虚继承下被整条继承链共享的唯一基类子对象。

关键代码

C++
// ═══════════════════════════════════════════
// 1. 继承语法与三种继承方式
// ═══════════════════════════════════════════

#include <iostream>

class Base {
public:
    int open = 1;                          // 公有：任何继承方式下都可被外部访问（public 继承时）
protected:
    int guarded = 2;                       // 受保护：仅本类与派生类可访问
private:
    int hidden = 3;                        // 私有：派生类也不可直接访问
};

class Pub : public Base {};                // public 继承：保持原权限
class Pro : protected Base {};             // protected 继承：public 成员降为 protected
class Pri : private Base {};               // private 继承：成员全部降为 private

int main() {
    Pub p;
    std::cout << p.open << std::endl;      // 输出：1，public 继承下 open 对外可见
    return 0;
}

// ═══════════════════════════════════════════
// 2. 构造与析构顺序：基类在前，派生类在后
// ═══════════════════════════════════════════

class Animal {
public:
    Animal() { std::cout << "Animal 构造" << std::endl; }
    ~Animal() { std::cout << "Animal 析构" << std::endl; }
};

class Dog : public Animal {
public:
    Dog() : Animal() { std::cout << "Dog 构造" << std::endl; }   // 显式调用基类构造
    ~Dog() { std::cout << "Dog 析构" << std::endl; }
};

int main() {
    Dog d;   // 输出顺序：Animal 构造 → Dog 构造 → Dog 析构 → Animal 析构
    return 0;
}

// ═══════════════════════════════════════════
// 3. 名字隐藏与作用域限定
// ═══════════════════════════════════════════

class Animal {
public:
    void show() const { std::cout << "Animal::show" << std::endl; }
};

class Dog : public Animal {
public:
    void show() const {                     // 同名成员遮蔽基类所有同名成员
        std::cout << "Dog::show" << std::endl;
    }
};

int main() {
    Dog d;
    d.show();                               // 输出：Dog::show
    d.Animal::show();                       // 输出：Animal::show，作用域限定取回基类版本
    return 0;
}

// ═══════════════════════════════════════════
// 4. 对象切片：按值赋值会丢掉派生部分
// ═══════════════════════════════════════════

#include <string>

class Animal {
public:
    virtual std::string name() const { return "Animal"; }
};

class Dog : public Animal {
public:
    std::string name() const override { return "Dog"; }
};

int main() {
    Dog d;
    Animal a = d;                           // 对象切片：只复制基类子对象
    std::cout << a.name() << std::endl;     // 输出：Animal，多态失效
    Animal& ref = d;                        // 引用不切片，绑定完整的派生对象
    std::cout << ref.name() << std::endl;   // 输出：Dog，动态绑定生效
    return 0;
}

// ═══════════════════════════════════════════
// 5. 多继承与虚基类：共享唯一一份基类
// ═══════════════════════════════════════════

class Animal {
public:
    explicit Animal(int a) : age(a) {}
protected:
    int age;                                // 由虚基类 Animal 唯一持有
};

class Land : virtual public Animal {        // 虚继承：共享同一份 Animal
public:
    explicit Land(int a) : Animal(a) {}
};

class Water : virtual public Animal {
public:
    explicit Water(int a) : Animal(a) {}
};

class Amphibian : public Land, public Water {
public:
    Amphibian() : Animal(1), Land(1), Water(1) {}   // 最派生类负责初始化虚基类
    int getAge() const { return age; }              // 无歧义：整条链只有一份 age
};

int main() {
    Amphibian frog;
    std::cout << frog.getAge() << std::endl;   // 输出：1
    return 0;
}
