运算符重载：让自定义类型更自然

掌握运算符重载的规则与常见形式，让自定义类型获得与内置类型一致的写法。

开场问题：自定义的 Vector 相加，为什么不能像整数一样直接写 a + b，而非得写成长长一串 a.add(b)？有没有办法让自定义类型也「讲运算符这门语言」？

朴素做法：给每个操作起一个命名函数

最稳的起点是老老实实写函数：add() 做加法、addEqual() 累加、equals() 判等、print() 输出。这样做没有歧义，函数名把语义讲得清清楚楚。

但随着类型变多，代价浮现出来：一是调用处啰嗦，a.add(b).add(c) 读起来不是数学表达式；二是无法参与通用代码——标准库排序要求类型支持 <，容器要求支持 ==，你的命名函数它们不认识，只能被排除在外。

运算符重载：本质是把函数换个名字

C++ 的解法是允许把函数「改名」成运算符。operator+ 本质上就是一个名字特殊的函数：当编译器看到 a + b，若 a 是自定义类型，就翻译成调用 a.operator+(b)（成员形式）或 operator+(a, b)（非成员形式）。

  • 可重载的：绝大多数双目（+ - * / == < [] () …）与单目（++ -- ! * &）运算符。
  • 不可重载的：::、.、.*、?:——它们要么与语言机制绑定，要么无法用函数模拟其求值语义。
  • 不能发明新符号：只能为已有运算符赋予自定义类型的含义。

成员还是非成员（friend）：看左操作数是谁

选择实现形式，先看左操作数。若左操作数必然是自定义类型（v1 + v2），就可以写成成员函数，隐式的 this 就是左操作数；若左操作数不是自定义类型（比如 std::cout << v，左边是流对象），就只能写成非成员函数。

<<、>> 属于后者，必须是非成员。当实现需要触碰私有成员时，把非成员声明为 friend 即可获得访问权。至于 ==、+ 这类讲究对称性的运算符，也常做成非成员，好让左右两边都能参与隐式转换。

返回值与 const 正确性

运算符重载最容易出错的地方不在语法，而在返回值形态：

  • 不修改操作数的（+、-、*）：返回新对象，成员函数加 const，这样 const 对象也能用。
  • 修改左操作数的复合赋值（+=）：返回 Vector& 引用 *this，才能支持链式 a += b += c。
  • 比较运算符（==、<）：返回 bool；== 与 != 成对实现，< 要满足严格弱序，才能配合排序算法。
  • 下标 []：提供两个版本，非 const 返回可写引用，const 返回只读 const 引用。

前缀与后缀 ++：一个哑参数区分

自增有前缀 ++c 与后缀 c++ 两种写法，语义不同：前缀「先加后用」，后缀「先用后加」。C++ 用参数表区分它们：T& operator++() 是前缀，返回 *this 的引用；T operator++(int) 是后缀，那个没人接收的 int 只是占位，函数先保存旧值副本、再自增、最后返回旧副本。

顺带一提，重载 operator() 会让对象变得「可以像函数一样调用」，这类对象叫函数对象（仿函数），标准库算法大量依赖它来接收可调用对象。

看一遍自定义运算符的效果

赋予语义，而不是发明语义

运算符重载不是让你随意定义新语义，而是给某个符号绑定一个符合直觉的既有语义：+ 就该是「合起来」，< 就该是「排序依据」。守住「不改操作数者用 const、返回值/引用按语义选、== 与 < 与通用算法兼容」这几条，自定义类型才能真正融入这门运算符语言。

「运算符重载」是为自定义类型定义运算符行为的机制，写法为 operator 加符号；「成员形式」把左操作数当作隐式 this，「非成员形式」写成普通函数，必要时用 「friend」 取得私有成员访问权。重载 operator() 得到的对象叫「函数对象」（仿函数）；< 需满足的「严格弱序」是它能用于排序的前提。

关键代码

C++
// ═══════════════════════════════════════════
// 1. 函数模板：由实参推导类型
// ═══════════════════════════════════════════

#include <iostream>
#include <string>

template <typename T>
T maxValue(T a, T b) {          // T 由调用实参推导，用一次生成一份实体
    return a > b ? a : b;
}

// maxValue(3, 7);          // T = int，实例化 maxValue<int>
// maxValue(2.5, 1.5);      // T = double，实例化 maxValue<double>
// maxValue(3, 7.0);        // 推导失败：T 同时为 int 与 double → 需 maxValue<double>(3, 7.0)

// ═══════════════════════════════════════════
// 2. 类模板：使用时显式指定类型
// ═══════════════════════════════════════════

template <typename T>
class Box {
    T item_;
public:
    explicit Box(const T& item) : item_(item) {}
    const T& get() const { return item_; }
};

// Box<int> bi(42);         // 类模板参数靠显式写出，不从构造参数推导
// Box<std::string> bs("hi");

// ═══════════════════════════════════════════
// 3. 全特化：为特定类型换一套实现
// ═══════════════════════════════════════════

template <>
class Box<bool> {               // 全特化：所有参数都指定
public:
    explicit Box(bool v) : flag_(v) {}
    const char* get() const { return flag_ ? "true" : "false"; }
private:
    bool flag_;
};

// ═══════════════════════════════════════════
// 4. 类模板偏特化：只固定部分参数
// ═══════════════════════════════════════════

template <typename T, typename U>
class Pair {                    // 主模板
public:
    Pair(T a, U b) : first(a), second(b) {}
    T first; U second;
};

template <typename U>
class Pair<int, U> {            // 偏特化：只把第一个参数固定为 int
public:
    Pair(int a, U b) : first(a), second(b) {}
    int first; U second;
    int firstAsInt() const { return first; }
};

// 函数模板没有偏特化，只能用重载替代

// ═══════════════════════════════════════════
// 5. 非类型模板参数与默认模板参数
// ═══════════════════════════════════════════

template <typename T, int N>    // N 是非类型参数，必须是编译期常量
class FixedArray {
    T data_[N];
public:
    int size() const { return N; }   // 大小在编译期已确定
};

template <typename T = int>     // 默认模板参数
class Stack {
public:
    T top_;                     // Stack<> 等价于 Stack<int>
};

// ═══════════════════════════════════════════
// 6. 可变参数模板概览与实例化代价
// ═══════════════════════════════════════════

template <typename... Args>     // 可变参数模板，接受任意个数、任意类型
int countArgs(Args... args) {   // C++11 起
    return sizeof...(args);     // sizeof... 返回参数包中的参数个数
}

int main() {
    std::cout << maxValue(3, 7) << std::endl;                 // 7
    std::cout << maxValue(std::string("a"), std::string("b")) << std::endl;  // b

    Box<bool> flag(true);
    std::cout << flag.get() << std::endl;                    // true

    std::cout << countArgs(1, 2, 3) << std::endl;            // 3
    // 每用一种类型就生成一份代码，滥用会导致代码膨胀、编译变慢
    return 0;
}
