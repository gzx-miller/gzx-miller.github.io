函数模板与类模板：泛型编程基础

掌握函数模板与类模板的定义、类型推导、特化以及非类型与默认模板参数。

开场问题：max(int, int)、max(double, double)、max(string, string) 的比较逻辑一模一样，难道要为每种类型都抄一遍函数体？有没有办法只写一次，让编译器自己补出各类型版本？

朴素做法：按类型逐个函数重载

不加抽象时，只能为每种类型各写一个同名重载：int max(int, int)、double max(double, double)、string max(...)……这当然「做对了」——它是类型安全的，每个版本各自检查各自的类型。

可它不是抽象。函数体是逐字重复的；每支持一个新类型就要新增一份；更麻烦的是当实参类型不匹配时，编译器可能悄悄做隐式转换，选到一个你以为不会选的重载。重复的地方越多，一致性越难保证。

函数模板与类型推导

把「类型」本身变成参数，重复就消失了：

  • template <typename T> T maxValue(T a, T b) { return a > b ? a : b; }——这里 T 是类型参数。
  • 调用 maxValue(3, 7) 时，编译器从实参推导出 T = int，并据此生成一份函数实体，这一过程叫实例化。

推导规则值得记牢：值参数按「去掉引用、保留顶层 const」推导，引用参数保留引用与 const，多个参数推导出不同 T 时会失败。maxValue(3, 7.0) 就是典型——T 一会儿 int、一会儿 double，编译器直接报错，需要显式写 maxValue<double>(3, 7.0) 把它统一。

类模板：把类型参数化到类上

同样的思路可以套在类上。类模板用起来必须显式指定类型参数：Box<int>、Box<std::string>。成员函数定义在类外时，要重复写一遍 template <typename T> 前缀，因为模板参数的作用域不会跨定义自动延续。

一个重要的补充：类模板的成员函数只有被真正调用时才实例化。这意味着即使某个成员函数对当前类型不合法，只要不用它，这个类模板依然可以正常实例化——这是后面更高级技巧的基础。

特化与偏特化：为特定类型开小灶

模板的「一刀切」有时不适用，就可以针对特定类型替换实现：

  • 全特化：template <> class Box<bool>，为 bool 完整替换一套实现。
  • 偏特化：只固定部分参数，如 template <typename U> class Pair<int, U>。偏特化只有类模板可以。
  • 函数模板没有偏特化，遇到「只为某几类参数特事特办」的需求，直接用函数重载代替即可。

非类型参数、默认参数与代码膨胀

模板参数不一定非是类型。template <typename T, int N> 里的 N 是非类型模板参数，必须是编译期常量（整型、枚举、指针等），常用来固定数组大小。参数也可以给默认值：template <typename T = int>，于是 Stack<> 就等价于 Stack<int>。

代价要讲清：模板是「用到多少类型，就生成多少份实体」，滥用会带来代码膨胀，也让编译变慢。所以模板定义通常直接放在头文件里——编译器必须看到完整定义才能实例化，若只把定义放进 .cpp，其它翻译单元就会在链接时找不到符号。最后，template <typename... Args> 形式的可变参数模板能接受任意个参数，是元组、完美转发等能力的底座，先有个整体印象即可。

看一遍函数模板与类模板

一份代码，多种类型

泛型编程的核心动作就一个：把类型从「写死」变成「参数」。函数模板靠推导替你填类型，类模板靠显式指定，特化在必要时开小灶，非类型参数进一步把编译期常量也参数化。理解了实例化这份「编译期生成代码」的本质，模板的威力与它的编译时间、代码体积代价就都能解释了。

「函数模板」以类型参数写算法、靠实参推导出具体类型；「类模板」把类型参数化到类，使用时需显式指定。「实例化」指编译器用具体类型替换模板参数、生成真实代码的过程；「全特化」替换全部参数，「偏特化」只固定部分参数（仅类模板可用）；「非类型模板参数」是编译期常量形态的参数。

关键代码

C++
// ═══════════════════════════════════════════
// 1. 函数模板：由实参推导类型
// ═══════════════════════════════════════════

#include <iostream>
#include <string>

template <typename T>
T maxValue(T a, T b) {          // T 由调用实参推导，用一次生成一份实体
    return a > b ? a : b;
}

// maxValue(3, 7);          // T = int，实例化 maxValue<int>
// maxValue(2.5, 1.5);      // T = double，实例化 maxValue<double>
// maxValue(3, 7.0);        // 推导失败：T 同时为 int 与 double → 需 maxValue<double>(3, 7.0)

// ═══════════════════════════════════════════
// 2. 类模板：使用时显式指定类型
// ═══════════════════════════════════════════

template <typename T>
class Box {
    T item_;
public:
    explicit Box(const T& item) : item_(item) {}
    const T& get() const { return item_; }
};

// Box<int> bi(42);         // 类模板参数靠显式写出，不从构造参数推导
// Box<std::string> bs("hi");

// ═══════════════════════════════════════════
// 3. 全特化：为特定类型换一套实现
// ═══════════════════════════════════════════

template <>
class Box<bool> {               // 全特化：所有参数都指定
public:
    explicit Box(bool v) : flag_(v) {}
    const char* get() const { return flag_ ? "true" : "false"; }
private:
    bool flag_;
};

// ═══════════════════════════════════════════
// 4. 类模板偏特化：只固定部分参数
// ═══════════════════════════════════════════

template <typename T, typename U>
class Pair {                    // 主模板
public:
    Pair(T a, U b) : first(a), second(b) {}
    T first; U second;
};

template <typename U>
class Pair<int, U> {            // 偏特化：只把第一个参数固定为 int
public:
    Pair(int a, U b) : first(a), second(b) {}
    int first; U second;
    int firstAsInt() const { return first; }
};

// 函数模板没有偏特化，只能用重载替代

// ═══════════════════════════════════════════
// 5. 非类型模板参数与默认模板参数
// ═══════════════════════════════════════════

template <typename T, int N>    // N 是非类型参数，必须是编译期常量
class FixedArray {
    T data_[N];
public:
    int size() const { return N; }   // 大小在编译期已确定
};

template <typename T = int>     // 默认模板参数
class Stack {
public:
    T top_;                     // Stack<> 等价于 Stack<int>
};

// ═══════════════════════════════════════════
// 6. 可变参数模板概览与实例化代价
// ═══════════════════════════════════════════

template <typename... Args>     // 可变参数模板，接受任意个数、任意类型
int countArgs(Args... args) {   // C++11 起
    return sizeof...(args);     // sizeof... 返回参数包中的参数个数
}

int main() {
    std::cout << maxValue(3, 7) << std::endl;                 // 7
    std::cout << maxValue(std::string("a"), std::string("b")) << std::endl;  // b

    Box<bool> flag(true);
    std::cout << flag.get() << std::endl;                    // true

    std::cout << countArgs(1, 2, 3) << std::endl;            // 3
    // 每用一种类型就生成一份代码，滥用会导致代码膨胀、编译变慢
    return 0;
}
