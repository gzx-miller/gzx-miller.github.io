🌰16 · 高级渲染 约 1 分钟读完

后处理效果

用全屏四边形展示 Bloom、模糊、灰度等后处理效果。

开场问题：你把场景渲进一张纹理，再用一块全屏四边形给它做高斯模糊，画面糊得很漂亮。接着你想在模糊之上再叠一层泛光——把画面里的高光提亮、晕开。于是你在同一个片段着色器里先算出模糊色，再对着模糊色提亮。结果屏幕上是一团「糊掉的光斑」，原图里那些锐利的亮点全不见了。为什么「模糊」和「泛光」这两步单独看都对，串在一起就歪了？

画面级渲染特性

后处理和普通渲染有个根本区别：它的输入是「一整张已经画完的画面」，输出也是「一整张画面」。你不再关心场景里有什么物体，只关心这张图上的每个像素。这带来一个内生的约束——片段着色器在某一刻只能算出一个结果：它读进一张图、吐出一张图，中间过程不会自动留在任何地方。

于是「把所有效果塞进同一个片段着色器」这个老办法，账变得很难算：

  • 中间结果留不下。你在一段代码里先算模糊、再对模糊提亮，前一步的结果只是一段局部变量，没法被当成「下一张输入图」再采样一次；
  • 效果之间互相污染。「先灰度再泛光」和「先泛光再灰度」是两种不同结果，但一个着色器里只能写死一种顺序；
  • 每加一个效果，就往那个巨大的 if / else 里再插一个分支，参数越缠越乱，效果无法自由组合。

所以真正的问题不是「怎么写一个模糊」，而是：怎么让一个效果产出的画面，能被下一个效果当成输入，干净地接下去？

独立渲染通道

把每一个效果拆成独立的一遍（pass）：先把场景渲染到一张 FBO 纹理上，再用一块覆盖全屏的四边形，在片段着色器里对这张纹理做运算。一遍只做一件事——输入一张图，输出一张图。

这个方案做对了一件根本的事：它把「特效」变成了一个只管像素、不碰场景的纯函数。灰度、模糊、泛光，本质上都只是「对一整张图做某种逐像素或邻域运算」，跟场景里是球还是方块已经没关系了。

中间结果断链

  • 输出直接上屏就断了链。如果第二遍把结果直接画到屏幕，那么第三个效果就无从取用它的输出——想串联，中间结果必须落进一张能被再次采样的纹理，而不是屏幕。
  • 全屏四边形不是场景里的物体。若拿相机矩阵、投影矩阵去画它，它会被当成 3D 世界里的一块布，转开、缩远，根本盖不住整屏。
  • 逐像素运算做不出模糊。灰度只读自己那一个纹素就够了，但模糊要读「周围」——单个纹素的运算里没有「邻居」这个概念，采样点得自己偏移出去。
  • 效果越贵，采样越多。灰度采样一次就够，换成 3×3 模糊，一次片段里从 1 次涨到 9 次；把效果再叠加，成本成倍——后处理的瓶颈几乎全在这里。

全屏四边形绘制

先解决「怎么画一块盖住全屏的四边形」。它不属于场景，所以不需要任何 MVP：顶点着色器直接把顶点位置原样输出成 NDC 坐标，gl_Position = vec4(a_position, 0.0, 1.0)；UV 也不用额外传，由顶点位置换算 v_uv = a_position * 0.5 + 0.5，[−1,1] 的坐标正好映射成 [0,1] 的纹理坐标。

第一个效果最简单，灰度（逐像素）。采样一次拿到当前颜色，用亮度加权 dot(color.rgb, vec3(0.299, 0.587, 0.114)) 得到灰色，再用 mix(color.rgb, gray, u_intensity) 按强度在原色和灰度之间插值——intensity 就是那个可调的「力度」。

第二个效果开始需要邻居，高斯模糊（邻域）。对当前像素周围 3×3 共 9 个纹素各采样一次，按高斯权重（中心权重最大、四角最小）加权求和。这就是加权邻域卷积；它的副作用恰好解释了开场——模糊之后，原图里锐利的高光已经被「摊平」了，画面只剩下一团柔和的色块。

第三个效果是泛光（阈值加亮）。判断 length(color.rgb) > 0.8：只有亮度超过阈值的像素，才按强度提亮后叠回原图，于是高光周围晕出一圈光。看清它的前提——它必须去读原图里的高光，而不是读一张已经模糊过的图。

最后把三个 pass 串联成管线：让每一遍的输出不直接上屏，而是写回一张纹理，作为下一遍的输入。这一步才是开场困惑的答案——「模糊」和「泛光」各自保留自己的输出，就能按任意顺序组合；想要「先模糊再泛光」，就让泛光那遍去读原图挑高光，而不是读模糊的结果。

四条要记牢的边界：全屏四边形的顶点直接在 NDC 输出、UV 由顶点位置换算，别把相机矩阵混进去；本课的 3×3 模糊是一步近似，工程里更省的做法是把高斯拆成横向、纵向两次线性 pass，再配合降采样；成熟的泛光会先提取高亮、多次降采样模糊后再叠加，本课用「阈值判定加亮」做简化演示；后处理的开销集中在片段的纹理采样次数上，采样越多越贵，这正是移动端的主要瓶颈。

四种效果对比

多效果串联管线

后处理把「给画面加效果」这件事从场景里彻底剥了出来：先把场景渲进一张纹理，再用全屏四边形把它当成普通图片处理。一个效果是一遍，一遍的输出能喂给下一遍——所谓后处理管线，就是把一张图接一张图地传下去。

「后处理（Post-processing）」指在场景渲染完成之后，对最终画面整体做的图像处理，通常用「渲染到纹理 + 全屏四边形」实现。每个效果是一遍 pass：输入一张纹理、在片段着色器里做逐像素或邻域运算、输出一张纹理。边界与例外：全屏四边形的顶点在 NDC 直接输出、UV 由顶点位置换算；要串联效果必须把中间结果写回纹理（而非屏幕）；模糊、描边这类邻域效果需采样多个纹素，成本随采样次数上升，是移动端的主要瓶颈。

关键代码

GLSL
// ===== 场景顶点着色器 Scene Vertex Shader =====
attribute vec2 a_position;
attribute vec3 a_color;
uniform float u_time;
varying vec3 v_color;
varying vec2 v_uv;

void main() {
  v_color = a_color;
  vec2 pos = a_position;
  float s = sin(u_time + pos.x * 3.0) * 0.15;
  float c = cos(u_time * 0.7 + pos.y * 2.0) * 0.1;
  pos += vec2(s, c);
  gl_Position = vec4(pos, 0.0, 1.0);
  v_uv = a_position * 0.5 + 0.5;
}

// ===== 场景片段着色器 Scene Fragment Shader =====
precision mediump float;
varying vec3 v_color;
void main() {
  gl_FragColor = vec4(v_color, 1.0);
}

// ===== 全屏后处理顶点着色器 Post Vertex Shader =====
attribute vec2 a_position;
varying vec2 v_uv;
void main() {
  v_uv = a_position * 0.5 + 0.5;
  gl_Position = vec4(a_position, 0.0, 1.0);
}

// ===== 全屏后处理片段着色器 Post Fragment Shader（Bloom / Blur / Grayscale） =====
precision mediump float;
uniform sampler2D u_scene;
uniform int u_effect;
uniform float u_intensity;
uniform float u_time;
varying vec2 v_uv;

void main() {
  vec4 color = texture2D(u_scene, v_uv);

  if (u_effect == 0) {
    vec3 gray = vec3(dot(color.rgb, vec3(0.299, 0.587, 0.114)));
    gl_FragColor = vec4(mix(color.rgb, gray, u_intensity), 1.0);
  } else if (u_effect == 1) {
    vec3 bloomSum = vec3(0.0);
    float threshold = 0.8;
    if (length(color.rgb) > threshold) {
      bloomSum = color.rgb * u_intensity;
    }
    float s = sin(u_time) * 0.1 + 1.0;
    gl_FragColor = vec4(color.rgb + bloomSum * s, 1.0);
  } else if (u_effect == 2) {
    vec3 sum = vec3(0.0);
    float step = 0.004 * u_intensity;
    sum += texture2D(u_scene, v_uv + vec2(-step, -step)).rgb * 0.06136;
    sum += texture2D(u_scene, v_uv + vec2(-step, 0.0)).rgb * 0.24477;
    sum += texture2D(u_scene, v_uv + vec2(-step, step)).rgb * 0.06136;
    sum += texture2D(u_scene, v_uv + vec2(0.0, -step)).rgb * 0.24477;
    sum += texture2D(u_scene, v_uv).rgb * 0.38774;
    sum += texture2D(u_scene, v_uv + vec2(0.0, step)).rgb * 0.24477;
    sum += texture2D(u_scene, v_uv + vec2(step, -step)).rgb * 0.06136;
    sum += texture2D(u_scene, v_uv + vec2(step, 0.0)).rgb * 0.24477;
    sum += texture2D(u_scene, v_uv + vec2(step, step)).rgb * 0.06136;
    gl_FragColor = vec4(sum, 1.0);
  } else {
    gl_FragColor = color;
  }
}
