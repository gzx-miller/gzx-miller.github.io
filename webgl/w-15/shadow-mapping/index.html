阴影映射

展示 shadow map 的生成与 PCF 软阴影采样。

开场问题：你把球和方块摆在一个地面上，光照、高光都到位了，可它们像贴在背景上的贴纸：方块悬在半空，地面上没有任何影子，球和方块之间也互不遮挡。你把光源角度压低，满心期待拉出一道长长的投影，结果还是什么都没有。光照明明已经算了「谁朝着光」，为什么算不出「谁挡住了光」？

光照遮挡缺失

光照模型的 N·L 只回答了一个问题：这个表面朝不朝着光源。它默认光畅通无阻地照到每个表面。可真实场景里，总有东西挡在光路上——这正是画面「悬浮感」的来源。

想判断「某个点是否被挡住」，就得知道：从光源看过去，这个点前面有没有别的东西、离光源最近的那层表面在哪。在着色器里自己硬凑，账很难付：用 CPU 逐像素做射线求交，几万个像素乘以场景三角形成本直接爆炸，跑不到实时；让每个物体自己判断挡了谁，就要两两比较，无法统一处理；而单个物体的着色器里根本没有「整个场景」的全局信息。于是问题落到：怎么高效地知道，场景里每个受光点，是不是被更靠近光源的东西挡住了？

光源视角深度图

把「从光源看场景」这件事，交给 GPU 再渲染一遍。第一遍，把相机搬到光源的位置、朝向场景，照常渲染一遍，但不记录颜色，只记录深度——也就是「从光源看，每个方向离它最近的表面有多深」。这张图就是 shadow map（阴影贴图）。

这个方案做对了一件事：它用一次渲染，把「谁挡在前面」压缩成了一张可查询的深度表。原本无从下手的全局遮挡关系，变成了一次深度比较。

自阴影失真与硬边

  • 有表还得会「查」。第二遍渲染时，得知道屏幕上的某个像素，对应到光源视野里深度图的哪个位置；这个映射关系还没建立。
  • 自遮挡会让表面长满黑点。深度值有量化误差，同一个平面明明没被挡，比较时却可能被误判为「更远」，于是整片表面冒出条纹状的黑色噪点，也就是阴影粉刺（shadow acne）。
  • 边界硬得发假。直接做一次比较只能得到「是/否」两个结果，阴影边缘是锯齿状的硬边，缺少真实阴影的柔和过渡。
  • 强度不可调。要么全黑要么全亮，没法让阴影「淡淡的」，也谈不上和光照自然衔接。

光空间坐标映射

先补「怎么查」。第一遍从光源视角渲染时，顶点着色器用 uLightMVP 把网格变换到光空间，片段直接写 gl_FragCoord.z——记下的是这个点在该视角下的屏幕深度。第二遍换成相机视角渲染时，顶点着色器顺手把每个顶点的光空间坐标 vLightSpacePos 也算出来，这样片段阶段就能拿它去查表。

到了片段着色器，把光空间坐标做透视除法并映射到 [0, 1]，得到在阴影贴图上的采样坐标：projCoords = lightSpacePos.xyz / w * 0.5 + 0.5。用它采样 shadow map，就取到了「光源在这个方向看到的最浅深度」。整个流程是：

  1. Pass 1：用 uLightMVP 把网格变换到光空间，把 gl_FragCoord.z 写入深度纹理。
  2. Pass 2：正常渲染场景，顶点着色器同时计算顶点的光空间坐标 vLightSpacePos。
  3. 片段中把光空间坐标做透视除法并映射到 [0, 1]，用它采样 shadow map。
  4. 比较当前深度与采样深度判断遮挡，对周围 3×3 共 9 个纹素做 PCF 平均得到软阴影，乘强度后作用于漫反射与高光。

判断规则很直白：如果当前点的深度比阴影贴图里存的最近深度更深，说明沿这个方向有更靠近光源的东西，当前点在它后面，落进阴影。写成表达式就是 currentDepth - bias > pcfDepth。为什么要减一个 bias？因为深度值有量化误差，同一个平面在比较时可能刚好「差那么一点点」，被误判成被遮挡，于是长出粉刺。给当前深度减去一个很小的偏移量，就能把它压过去。

再补「柔化」。单点比较得到的是一刀切的硬边。把当前像素周围 3×3 共 9 个纹素各做一次比较，再把结果平均（shadow / 9.0），阴影边缘就有了渐变——这就是 PCF（Percentage Closer Filtering） 的简化版。最后把阴影乘上一个强度系数，作用在漫反射与高光上，就得到既不生硬又可控的软阴影。

三个必须权衡的点：bias 太小会留下阴影粉刺，太大则会让阴影和物体「脱开」、飘起来（peter-panning），要在两者之间取舍；shadow map 的分辨率决定阴影边缘精度，越高越清晰，但显存、带宽和采样成本同步上涨；本课的平行光用一个正交投影构成 uLightMVP，而点光源（要六面）或聚光灯需要更复杂的方法，属于进阶内容。

阴影偏移失衡

深度比较判定

阴影映射把「谁挡住了光」变成了一次「深度比较」。先从光源视角把场景的深度画下来，再从相机视角逐像素问一句：在光源看来，我是不是比记录里更远？是，就在阴影里。bias 负责堵住深度误差的缝，PCF 负责把生硬的边界揉软。

「阴影映射（Shadow Mapping）」是一种实时阴影技术，分两遍渲染：第一遍从光源视角渲染场景，把每个可见点的深度写入 shadow map；第二遍从相机视角渲染，把每个像素变换到光空间，用其深度与此处 shadow map 所记录的「离光源最近的深度」比较，若更深则说明被遮挡、处于阴影中。边界与例外：比较前要加 bias 抑制自遮挡（过大会产生阴影悬浮），边缘可用 3×3 PCF 平均柔化；平行光用正交投影构造光空间矩阵，点光源/聚光灯需六面或更深的方法。

关键代码

GLSL
// ===== 深度渲染顶点着色器 Depth Vertex Shader（Pass 1 光源视角） =====
attribute vec3 aPosition;
uniform mat4 uLightMVP;
void main() {
  gl_Position = uLightMVP * vec4(aPosition, 1.0);
}

// ===== 深度渲染片段着色器 Depth Fragment Shader（Pass 1） =====
precision mediump float;
void main() {
  gl_FragColor = vec4(gl_FragCoord.z, gl_FragCoord.z, gl_FragCoord.z, 1.0);
}

// ===== 场景顶点着色器 Scene Vertex Shader（Pass 2 相机视角） =====
attribute vec3 aPosition;
attribute vec3 aNormal;
uniform mat4 uModel;
uniform mat4 uView;
uniform mat4 uProjection;
uniform mat4 uLightMVP;
varying vec3 vNormalWorld;
varying vec3 vWorldPos;
varying vec4 vLightSpacePos;
void main() {
  vec4 wp = uModel * vec4(aPosition, 1.0);
  vWorldPos = wp.xyz;
  vNormalWorld = normalize(mat3(uModel) * aNormal);
  vLightSpacePos = uLightMVP * wp;
  gl_Position = uProjection * uView * wp;
}

// ===== 场景片段着色器 Scene Fragment Shader（Pass 2 阴影计算） =====
precision mediump float;
varying vec3 vNormalWorld;
varying vec3 vWorldPos;
varying vec4 vLightSpacePos;
uniform vec3 uAmbient;
uniform vec3 uLightDir;
uniform vec3 uViewPos;
uniform vec3 uMatColor;
uniform sampler2D uShadowMap;
uniform float uShadowBias;
uniform float uShadowIntensity;

float calcShadow(vec4 lightSpacePos) {
  vec3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
  projCoords = projCoords * 0.5 + 0.5;
  if (projCoords.z > 1.0) return 0.0;
  float currentDepth = projCoords.z;
  vec2 texelSize = 1.0 / vec2(textureSize(uShadowMap, 0));
  float shadow = 0.0;
  for (int x = -1; x <= 1; x++) {
    for (int y = -1; y <= 1; y++) {
      float pcfDepth = texture2D(uShadowMap, projCoords.xy + vec2(x, y) * texelSize).r;
      shadow += currentDepth - uShadowBias > pcfDepth ? 1.0 : 0.0;
    }
  }
  return shadow / 9.0;
}

void main() {
  vec3 N = normalize(vNormalWorld);
  vec3 L = normalize(uLightDir);
  vec3 V = normalize(uViewPos - vWorldPos);
  vec3 R = reflect(-L, N);
  float NdotL = max(dot(N, L), 0.0);
  float RdotV = max(dot(R, V), 0.0);
  float shadow = calcShadow(vLightSpacePos);
  shadow = shadow * uShadowIntensity;
  vec3 ambient = uAmbient * uMatColor;
  vec3 diffuse = uMatColor * NdotL * (1.0 - shadow);
  vec3 specular = vec3(1.0) * pow(RdotV, 24.0) * 0.4 * (1.0 - shadow);
  gl_FragColor = vec4(ambient + diffuse + specular, 1.0);
}

// ===== Shadow Map 可视化顶点着色器 Shadow Map Visual Vertex Shader =====
attribute vec2 aPosition;
attribute vec2 aUV;
varying vec2 vUV;
void main() {
  vUV = aUV;
  gl_Position = vec4(aPosition, 0.0, 1.0);
}

// ===== Shadow Map 可视化片段着色器 Shadow Map Visual Fragment Shader =====
precision mediump float;
varying vec2 vUV;
uniform sampler2D uShadowMap;
void main() {
  float depth = texture2D(uShadowMap, vUV).r;
  float gray = depth;
  gl_FragColor = vec4(gray, gray, gray, 1.0);
}
