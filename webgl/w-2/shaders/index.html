GLSL 着色器编程基础

用一个旋转三角形展示顶点着色器与片段着色器的协作与数据传递。

开场问题：你在顶点着色器里给三个顶点分别喂了红、绿、蓝，本以为画出的是三个纯色角，屏幕上却是一个内部平滑过渡的彩色渐变——你一行「过渡」的代码都没写，中间那些颜色是谁替你算出来的？

顶点颜色到像素

你想做一件很直接的事：让每个顶点各自带一种颜色，并把这份颜色一路显示到屏幕上。在 Canvas 2D 的心智模型里，一个三角形就是「一个形状」，你设一次颜色它就整体上色；可在这里，颜色是长在顶点上的，而你要看到的却是像素。

这个断层的成本必须由你承担，因为它夹在两段你必须亲手写的程序之间：

  • 顶点着色器只按顶点跑：三个顶点就执行三次，它从没见过「像素」这种东西，自然也没法在它那里决定某个像素的颜色。
  • 片段着色器不知道顶点的事：它按像素跑，却读不到逐顶点输入的 attribute——那是顶点着色器专属的入口。
  • 没人负责「搬运」：CPU 到 GPU 的数据能传，但顶点上算出的值要怎么越过这两段程序之间的鸿沟，得有个明确的通道。

于是问题落到一句话上：顶点上的数据，究竟怎么变成像素上的数据？

跨着色器传值

最朴素的尝试：既然颜色就在顶点上，那就在顶点着色器里把它「输出」出来，再让片段着色器「接收」。给同一个值取名 vColor，声明成 varying，在顶点着色器里赋成顶点自己的颜色，片段着色器里直接当成自己的输入来用。

这个方案做对了一件根本的事：它承认了顶点与像素之间需要一条显式的通道。varying 就是这条通道——名字、类型在两端对齐之后，颜色确实从顶点流到了像素，三角形也真的带上了颜色。

链接失败后果

  • 如果只在顶点着色器里声明 varying vColor，片段着色器里漏了声明或类型不一致，linkProgram 会直接失败，画面全黑。
  • 当你其实想要「整个三角形一个纯色」时，用逐顶点颜色反而做不到：中间每个像素拿到的都是三个顶点颜色混出来的值，没有任何一个像素是纯红、纯绿或纯蓝。
  • 把颜色改用一个 uniform 单色，三角形又丢掉了顶点之间的差异，变成一整块死板的颜色。
  • 就算你想在顶点着色器里算「逐像素」的效果，它每个顶点只跑一次，根本没有逐像素的上下文，算不出那种细密的变化。

两段着色器分工

不推翻这条通道，而是先把两段程序的分工说清楚，再看通道里到底发生了什么。这是理解 GLSL 的第一道坎：两个着色器执行次数不同、职责也不同。

  1. 顶点着色器对每个顶点执行一次（三个顶点就是三次），职责是「定位置」，把顶点算好后必须写入 gl_Position；本课它读入 aPosition、aColor 与 uRotation，用旋转公式算出新坐标。
  2. 顶点着色器把 aColor 赋给 varying vColor 输出——它管不了像素，只负责在顶点上把这个值交出去。
  3. 光栅化阶段（固定管线）把三角形离散成一堆片元，并在三个顶点之间对 vColor 自动做线性插值：每个像素拿到的是三个顶点颜色按它在三角形中所处位置混合出的值。
  4. 片段着色器对每个像素执行一次，读入插值后的 vColor 并写入 gl_FragColor，于是三角形内部出现了平滑渐变。

这样开场那个「颜色自己冒出来」的谜就解开了：渐变不是哪段代码画上去的，而是 varying 在光栅化阶段被自动插值的结果。顶点着色器只交出三个顶点的颜色，中间那一大片过渡色，是硬件替你补的。本课用一个随 uniform uRotation 旋转的三角形来演示这套分工——uniform 是单次绘制内所有顶点与像素共享的只读全局量，传时间、角度这类数据最合适。

两个常被忽略的点：其一，varying 必须在顶点与片段着色器里同时声明且类型一致，否则链接失败；其二，插值完全由光栅化自动完成，你不需要、也无法在着色器里手写插值——想让某个值参与渐变，让它成为 varying 即可。

想验证「渐变确实是插值带来的」，最直接的办法是对比一个平涂版：关掉颜色插值，改用 uniform 传一个单一颜色，三角形立刻变成一整块纯色。顶点数据没变，变的是「有没有让一个逐顶点量穿过那条插值通道」。

插值与纯色对比

逐顶点与逐像素

GLSL 里两段程序的分工是：顶点着色器逐顶点执行、负责定位置并写 gl_Position；片段着色器逐像素执行、负责定颜色并写 gl_FragColor。顶点想把数据交给像素，只能走 varying 这条通道，而它穿过光栅化时会被自动插值——中间那些过渡色就是这么来的。

「光栅化（Rasterization）」是固定管线里把图元离散成屏幕像素（片元）、并对跨越图元的 varying 逐片元插值的阶段。记住三个边界：插值发生在片段着色器之前、由硬件自动完成；只有逐顶点输出（varying）会被插值，uniform 与常量不参与插值、每个像素拿到的都是同一份；varying 默认按重心坐标做透视校正插值。

关键代码

GLSL
// ===== 顶点着色器 Vertex Shader =====
attribute vec2 aPosition;
attribute vec3 aColor;
varying vec3 vColor;
uniform float uRotation;
void main() {
  float c = cos(uRotation);
  float s = sin(uRotation);
  vec2 rotated = vec2(
    aPosition.x * c - aPosition.y * s,
    aPosition.x * s + aPosition.y * c
  );
  gl_Position = vec4(rotated, 0.0, 1.0);
  vColor = aColor;
}

// ===== 片段着色器 Fragment Shader（插值版 Interpolated） =====
precision mediump float;
varying vec3 vColor;
void main() {
  gl_FragColor = vec4(vColor, 1.0);
}

// ===== 片段着色器 Fragment Shader（平面版 Flat） =====
precision mediump float;
uniform vec3 uFlatColor;
void main() {
  gl_FragColor = vec4(uFlatColor, 1.0);
}
