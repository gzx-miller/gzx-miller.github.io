帧缓冲与离屏渲染

用离屏渲染展示 FBO 的创建、绑定与纹理附件。

开场问题：你画好了带光照的场景，现在想给它整体加一层「反相」滤镜。你第一反应是回每个物体的片段着色器里改：材质色取 1 减。可当效果要换成灰度、棕褐，甚至模糊时，你发现每加一种效果都得钻回十几个着色器里改一遍；而模糊这种要读「周围像素」的效果，单看某个物体的着色器根本不知道邻居画了什么。只是想给画完的画面再加一道处理，怎么就这么难？

屏幕渲染局限

到这里为止，你的渲染目标一直是屏幕。片段着色器算出的颜色直接写进屏幕的帧缓冲，画完就交出去了，你再也拿不回来、改不了。想做「全屏效果」，就必须能在整张画面画完之后，再把它整体取出来算一遍。

把效果逻辑塞进每个物体的着色器，代价藏得很深：效果代码散落到所有材质里，改一次要动 N 个地方；邻域效果（模糊、描边）需要读周围像素，逐物体的着色器拿不到画面上下文；也没法做到「先照常画好、再统一加效果」。于是问题很清楚：怎么让渲染结果先落进一个可以再次被采样的地方，而不是直接冲上屏幕？

离屏渲染目标

引入帧缓冲对象（Framebuffer Object，FBO）——一个可以切换的渲染目标。绑定它之后，draw 的输出不再进屏幕，而是进这个 FBO。但要注意：FBO 本身不存像素，它只是个「附件的挂载点」，所以还得给它挂一张颜色纹理当附件（COLOR_ATTACHMENT0）。这样第一遍把场景渲进这张纹理，就完成了「渲染到纹理（render to texture）」。

这个方案做对了一件根本的事：它把「画面」变成了可以当普通纹理再采样的数据。有了这层数据，第二遍想怎么处理都行。

深度附件缺失

  • 只挂颜色会丢遮挡。场景开了深度测试，若 FBO 没有深度附件，深度值无处存放，前后物体的遮挡关系会错乱，后面的反而盖住前面的。
  • 附件不匹配会静默失败。附件格式不对、尺寸不一致或漏挂，FBO 会处于不完整状态，此时对它的所有绘制都画不出来，而且往往不报错——不显式检查就查不出原因。
  • 忘了切回屏幕就是一片空白。如果一直绑着 FBO，第二遍的绘制又画回了离屏纹理，屏幕上什么都看不到。
  • 第二遍还得有块「画布」。要把离屏纹理铺满屏幕显示，需要一块能覆盖全屏的四边形——现在的零散几何体没法干这个。

附件配置顺序

先把 FBO 的「最小可工作配置」按顺序配齐。顺序很重要，少一步都会静默失败：

  1. 创建 FBO 并绑定，创建一张颜色纹理作为 COLOR_ATTACHMENT0 附件：用 texImage2D 分配一张 RGBA 空纹理（数据传 null），并设好 filter 与 wrap。
  2. 配齐深度附件（DEPTH_ATTACHMENT，用一个 renderbuffer），否则深度遮挡会错。
  3. 用 checkFramebufferStatus 检查完整性，只有返回 FRAMEBUFFER_COMPLETE 才算配好。
  4. 第一遍：绑定 FBO，把场景渲染到它的颜色纹理里。
  5. 第二遍：bindFramebuffer(FRAMEBUFFER, null) 切回默认帧缓冲，用一块全屏四边形采样那张纹理显示出来。

逐步解释几个关键选择。为什么颜色附件要用纹理、而不是渲染缓冲？因为纹理可以被后续采样复用——这正是「渲到纹理」的全部意义，若用渲染缓冲，这份颜色就没法再当输入来读。为什么必须查 checkFramebufferStatus？因为 FBO 完整性不满足时不会抛错，只是静默地什么都不画，不主动查就只能对着黑屏干瞪眼。

第二遍的「画布」是一块全屏四边形：顶点直接在顶点着色器里输出 NDC 坐标（gl_Position = vec4(aPosition, 0.0, 1.0)），UV 由顶点位置换算，正好覆盖整屏。它的片段着色器 texture2D 采样 FBO 纹理，再对取到的颜色做逐像素处理——原样、反相、灰度、棕褐，想加哪种就加哪种。这样一来，同一份场景只要换一个处理分支，就能得到不同效果，完全不必回去改每个物体的着色器。

三条别踩的线：FBO 不存储图像本身，它只是一组附件的挂载点，把颜色纹理挂上去，离屏结果才可被采样；切回屏幕一定要 bindFramebuffer(null)，否则会继续往离屏纹理上画；离屏纹理的尺寸通常取与屏幕分辨率一致（或按比例），第二遍映射时才不会被拉伸变形。

最后记住一点格局：这条「渲到纹理、再读回来」的通道，是后处理、阴影映射、G-Buffer、镜像水面等一大批高级技术共用的地基。本课先把最基础的一步走通：把场景画进纹理，再从纹理里把它读出来。

四种滤镜对比

可重采样纹理

当渲染目标可以自由切换，画面就不再是「一次性的输出」。FBO 把场景画进一张可再次采样的纹理，第二遍再对它做处理——全屏滤镜、后处理、阴影都建立在同一条「渲到纹理再读回」的通道上。

「帧缓冲对象（Framebuffer Object，FBO）」是一个可切换的渲染目标，允许把绘制结果写入离屏的纹理或渲染缓冲，而不直接显示到屏幕。它自身不保存图像，必须挂接附件才有意义——颜色附件常用一张 RGBA 纹理（便于后续当普通纹理采样），深度可用 renderbuffer。边界与例外：用前须 checkFramebufferStatus 确认完整（不完整会静默失败），用完须 bindFramebuffer(null) 切回屏幕；正因为颜色附件是纹理，渲染结果才能被再次采样。

// ===== 场景顶点着色器 Scene Vertex Shader =====
attribute vec3 aPosition;
attribute vec3 aNormal;
uniform mat4 uModel;
uniform mat4 uView;
uniform mat4 uProjection;
uniform mat3 uNormalMatrix;
varying vec3 vNormalWorld;
varying vec3 vWorldPos;
void main() {
  vec4 wp = uModel * vec4(aPosition, 1.0);
  vWorldPos = wp.xyz;
  vNormalWorld = normalize(uNormalMatrix * aNormal);
  gl_Position = uProjection * uView * wp;
}

// ===== 场景片段着色器 Scene Fragment Shader =====
precision mediump float;
varying vec3 vNormalWorld;
varying vec3 vWorldPos;
uniform vec3 uAmbient;
uniform vec3 uLightDir;
uniform vec3 uViewPos;
void main() {
  vec3 N = normalize(vNormalWorld);
  vec3 L = normalize(uLightDir);
  vec3 V = normalize(uViewPos - vWorldPos);
  vec3 R = reflect(-L, N);
  float NdotL = max(dot(N, L), 0.0);
  float RdotV = max(dot(R, V), 0.0);
  vec3 baseColor = vec3(0.82, 0.54, 0.26);
  vec3 ambient = uAmbient * baseColor;
  vec3 diffuse = baseColor * NdotL;
  vec3 specular = vec3(1.0) * pow(RdotV, 24.0) * 0.5;
  gl_FragColor = vec4(ambient + diffuse + specular, 1.0);
}

// ===== 全屏四边形顶点着色器 Quad Vertex Shader =====
attribute vec2 aPosition;
attribute vec2 aUV;
varying vec2 vUV;
void main() {
  vUV = aUV;
  gl_Position = vec4(aPosition, 0.0, 1.0);
}

// ===== 全屏四边形片段着色器 Quad Fragment Shader（原样 Base） =====
precision mediump float;
varying vec2 vUV;
uniform sampler2D uScene;
void main() {
  gl_FragColor = texture2D(uScene, vUV);
}

// ===== 全屏四边形片段着色器 Quad Fragment Shader（反相 Invert） =====
precision mediump float;
varying vec2 vUV;
uniform sampler2D uScene;
void main() {
  vec4 c = texture2D(uScene, vUV);
  gl_FragColor = vec4(1.0 - c.r, 1.0 - c.g, 1.0 - c.b, c.a);
}

// ===== 全屏四边形片段着色器 Quad Fragment Shader（灰度 Grayscale） =====
precision mediump float;
varying vec2 vUV;
uniform sampler2D uScene;
void main() {
  vec4 c = texture2D(uScene, vUV);
  float g = dot(c.rgb, vec3(0.299, 0.587, 0.114));
  gl_FragColor = vec4(vec3(g), c.a);
}

// ===== 全屏四边形片段着色器 Quad Fragment Shader（棕褐 Sepia） =====
precision mediump float;
varying vec2 vUV;
uniform sampler2D uScene;
void main() {
  vec4 c = texture2D(uScene, vUV);
  float r = dot(c.rgb, vec3(0.393, 0.769, 0.189));
  float g = dot(c.rgb, vec3(0.349, 0.686, 0.168));
  float b = dot(c.rgb, vec3(0.272, 0.534, 0.131));
  gl_FragColor = vec4(r, g, b, c.a);
}
