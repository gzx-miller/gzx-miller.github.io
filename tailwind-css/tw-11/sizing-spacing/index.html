尺寸约束与间距比例尺

区分 width、min/max、size、gap 与 space，并形成一致视觉节奏。

开场问题：课程卡片之间的间距，我一会儿写 mt-3、一会儿写 mb-4，页面上下翻一遍，总觉得哪一处比别处「紧一点」——这些数字到底该怎么统一？

尺寸间距数值失序

你在做一个后台的课程列表页。每行一张课程卡片，里面要放下封面图、标题、标签和价格。你打开设计稿一看，标注密密麻麻：图片宽度 320、上下留白 18px、标题和标签之间 10px、卡片之间 24px。于是你一边写一边猜，p-4、mt-3、gap-2 混着用，凭手感补齐。

单看某张卡片都没问题，可把十几张放在一起对比时，问题就暴露了：有的内部很松、有的很挤，卡片间距也忽大忽小。它们不是「不好看」，而是没有节奏。要理解这件事，得先分清两类工具：尺寸回答「盒子多大」，间距回答「留多少空」；而间距又分盒模型层面（内外边距）与布局层面（Flex/Grid 轨道间隙）。把两者混为一谈，就是间距失控的根源。

设计稿像素换算

最省事的做法，是看着设计稿逐个「翻译」成类名：留白 18px 就写 p-[18px]，间距 10px 就写 mt-[10px]。这样确实能像素级还原设计稿，单页面下甚至非常精准。

问题是它把每个数值当成孤立特例。当设计稿微调、或另一个页面也要用同一套卡片时，你无法回答「到底哪个才是标准」——因为压根没有标准，只有一堆从稿子上抄来的数字。

魔法数字泛滥

  • 视觉上「一模一样」的间距，在不同卡片里被写成不同的魔法数字，缺少统一节奏。
  • 用相邻元素的 margin 堆间距，容易出现边距叠加，实际间距比预想的大。
  • 只关心宽高、忽略边界约束，长内容一来就把布局撑破（尤其忘记 min-w-0）。
  • 固定宽度到处写死，屏幕一变窄就溢出或留一大片空白。

数值收敛到刻度

不推翻「按设计稿还原」，而是把所有数值收敛到一套设计尺度上。默认刻度以 4 为基数：1 是 4px、2 是 8px、3 是 12px、4 是 16px、6 是 24px。不必记住每个值，只需一个习惯：先想「这该是几个档位」，再从刻度里取值，而不是直接抄像素。18px 在刻度上最接近 4 或 5，选哪个取决于整体节奏。

尺寸工具按语义分三类：

语义典型类名适用场景
固定尺寸w-32、size-10头像、图标等恒定尺寸
流体尺寸w-full、w-1/2随容器伸缩的布局块
边界约束max-w-screen-md、min-h-10限制最大宽度、保证最小高度

先问一句：这个容器是固定、流体，还是受最大宽度约束？答案决定用 w-* 还是 max-w-*。size-* 是 w-* 与 h-* 的合体，方形元素用它最简洁；max-w-screen-md 这类约束让内容在宽屏上不会无限拉伸。

然后是间距的两个层面。盒子内部的留白用 p-*、盒子对外的留白用 m-*，两者都作用于盒模型。而同级元素之间的间距优先用布局层面的间隙 gap-*——它在轨道之间一次性插入等距间隔，不会像相邻 margin 那样叠加，也不会给首尾元素多出边距。space-x-* / space-y-* 则是在相邻子元素之间用选择器插边距，遇到换行或反序会露出破绽，只适合已知顺序的单行排列。

最容易忽略的坑：min-w-0。Flex 和 Grid 子项默认 min-width: auto，会按内容宽度撑开——子项里塞进一长串不换行文本时，它拒绝收缩，最终把布局顶破、产生横向溢出。给需要收缩的子项加上 min-w-0，允许它缩到比内容更窄即可。超过一半的「Flex 布局莫名溢出」，答案都在这里。

最后补两条：一是主动用好边界约束，max-w-* 限制整体最大宽度、min-h-* 保证最小可点击高度；二是负数与范围类也别乱写，像 inset-x-0、-mt-2、top-1/2，同样应从内置尺度取值，而不是随手拼 top-[47px]。

串成一条顺序：先决定容器的尺寸语义（固定 / 流体 / 受约束）→ 用统一尺度建立间距节奏 → 在长内容与窄屏下验证 min-w-0 与溢出 → 用标尺核对两处间距是否来自同一尺度。「用标尺核对」这个动作很关键：它逼你真正量一量，而不是凭感觉认为「差不多」。

刻度等级切换对照

间距与边界约束

尺寸与间距的本质，是把页面里所有「多大、留多少空」的决策，从随手填的像素，收敛到一套有语义、有刻度的系统上。容器先分清固定、流体与边界约束，同级间距优先交给 gap，并且永远别忘记 min-w-0——节奏统一了，页面自然就稳了。

「设计尺度」指一套有限、成倍数的数值刻度（默认以 4 为基数）。尺寸工具区分固定（w-32、size-10）、流体（w-full）与边界约束（max-w-screen-md、min-h-10）；间距工具区分盒模型内外的 p-*/m-*、Flex/Grid 轨道的 gap-* 与相邻子元素的 space-*。同级间距优先用 gap，并为可能溢出的子项补上 min-w-0。

HTML
<section class="mx-auto w-full max-w-5xl px-4 sm:px-6 lg:px-8">
  <div class="grid min-h-40 gap-4 p-4 md:grid-cols-3 md:gap-6">
    <article class="min-w-0 rounded-xl bg-amber-50 p-4">课程</article>
  </div>
</section>
