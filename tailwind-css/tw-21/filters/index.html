滤镜与混合模式

使用 CSS filter 和 backdrop-filter 工具类，实现模糊、亮度、对比度等滤镜效果与毛玻璃背景。

开场问题：课程封面想做成「未解锁就变灰、悬停时盖一层毛玻璃标题栏」，我以为得让设计师再出两套图，可用户上传的封面根本没法定制——这类效果真的只能靠图片资源吗？

封面降饱和与毛玻璃

你在做课程列表：封面图来自后台上传，谁也不知道会是哪张。产品给了三条视觉要求——未解锁的课程，封面整体降饱和变灰；每张卡底部压一条半透明的毛玻璃标题栏，让白字在任意封面上都读得清；鼠标悬停时封面稍微提亮、加饱和，让人有「可点」的感觉。

这三条需求看似都是「对图片做处理」，其实底层机理完全不同：变灰是对元素本身应用滤镜；毛玻璃是对元素背后的内容做模糊；而叠加出层次感还可能用到混合模式。分不清这三者，就会以为是缺图片、缺素材。

半透明遮罩与换图

最朴素的做法是改颜色：给灰掉的封面加一层半透明灰色遮罩，再让设计师针对「灰版」单独出一套图。悬停提亮就换一张调过色的图，毛玻璃就先截图做成 PNG 贴上去。

它做对的是表达了「同一张图在不同状态下要有不同观感」这个意图，在素材固定、数量很少的静态页面上也确实能跑通。但它把「视觉处理」外包给了设计资源，一旦图片来源变成用户上传，或者状态从两种变成四五种，这条路立刻走不通。

多状态资源成倍增长

  • 每个状态都要一份图片资源，状态一多资源成倍增长，维护成本失控。
  • 用户上传的图片无法逐张再加工，遮罩方案又会把原始细节一起压暗。
  • 毛玻璃是「把背景模糊掉」，普通的半透明遮罩只能变淡，透不出那种磨砂质感。
  • 图层之间的叠色关系（比如暖色叠出秋日滤镜）用纯色遮罩表达不准确。
  • 悬停提亮若换图，还会多一次资源加载，反而更卡。

元素自身滤镜清单

先把「作用于元素自身」的滤镜用起来：blur 模糊、brightness 提亮压暗、contrast 对比度、saturate 饱和度、grayscale 灰度、sepia 复古、invert 反色。多个滤镜写在同一个元素的多个类上会合并成一条 filter 声明，所以「悬停时提亮又加饱和」直接写 hover:brightness-110 hover:saturate-125 就行，互不打架。

再处理毛玻璃，它靠的是 backdrop-filter 这一族 backdrop-* 工具类：backdrop-blur-md 把元素背后的内容模糊掉。要记住一个必要条件——光有模糊是看不出来的，必须配上半透明背景色或边框，比如 bg-white/30 border border-white/40，磨砂层才有厚度感。它和 filter 的区别正在于作用对象：一个是模糊「自己」，一个是模糊「自己背后」。

注意浏览器支持：backdrop-filter 并非所有环境都支持，降级时背景会直接露出来。稳妥的做法是给这一层再配一个纯色或半透明兜底背景，保证即使在最差情况下文字依然可读。

图层叠色则交给混合模式 mix-blend-*：mix-blend-multiply 让上层和下层做正片叠底，暖色压在图片上就像加了一层统一色调的滤镜；mix-blend-screen 适合做光晕，mix-blend-overlay 适合加质感。它描述的是「这一层和它下面那层如何合成」，与滤镜、背景滤镜各管一段。

最后是取值的边界。默认档位不够用时，用任意值表达：blur-[8px]、brightness-[1.2]，方括号里写的就是真实 CSS 值，不必为了一个特殊数值去改配置。

  1. 对元素本体用 blur-* / brightness-* 等滤镜工具类，可并发叠加多个效果。
  2. 对元素背后内容用 backdrop-blur-*，配半透明背景色实现毛玻璃质感。
  3. 文字或图层叠放用 mix-blend-* 控制与背景的混合关系。
  4. 在元素面板核对 filter 与 backdrop-filter 的合成结果是否符合预期。

滤镜混合与背景滤镜

图像特效实现路径

图片特效不必依赖额外素材：作用于元素自身的用 filter（多个类合并成一条声明），作用在元素背后的用 backdrop-filter（记得配半透明背景才看得见），图层之间叠色用 mix-blend-*。默认档位不够就上任意值，同时别忘了给 backdrop 留一个降级兜底。

「filter 与 backdrop-filter」filter 作用于元素自身的渲染结果，工具类是 blur-*、brightness-*、grayscale 等；backdrop-filter 作用于元素背后的内容，工具类是 backdrop-blur-*、backdrop-brightness-* 等，必须配合半透明背景或边框才能看到毛玻璃效果。二者的合成结果不叠加混淆，可以同时使用。
