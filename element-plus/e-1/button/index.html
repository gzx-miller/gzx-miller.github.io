按钮：类型、尺寸、状态与图标

用课程操作按钮展示 ElButton 的类型、尺寸、状态和图标组合用法。

开场问题：后台列表里「保存」和「删除」长得几乎一模一样，用户手一滑就把数据删了——按钮除了文字，到底还能靠什么告诉人「这个很危险」？

操作语义视觉映射

你在做一个课程管理后台。一行里有「详情」「报名」「删除」，页面底部又有「保存」「取消」「重置」。这些按钮功能完全不同、重要程度也不同：保存是主操作、删除是危险操作、重置是次要操作。可如果它们全都长成同一个灰底矩形，用户在快速点击时只能靠读文字来分辨，而误操作的代价却由数据来承担。

这才是按钮真正要解决的问题：把「这个操作有多重要、多危险」翻译成一眼能认出的视觉信号。不用组件库的话，这个翻译得由你亲手完成——每一种语义色、每一档尺寸、加载态、禁用态、悬浮与聚焦态，都要自己写样式，还要让全站几十个按钮保持同一套语言。一旦手写样式各写各的，视觉层级立刻乱掉。

原生按钮语义承载

最省事的做法是直接用原生按钮，再挂一个类名：<button class="btn btn-primary">保存</button>。这个方案做对了一件根本的事——它用语义正确的原生元素承载操作，天生可点击、可聚焦、能被键盘回车触发，这是任何封装都不该丢掉的底线。

只要再补几个类，外观也能凑出来。当页面只有两三个按钮时，这套写法完全够用。

样式分散与状态遗漏

  • 每加一种语义色就要新增一套样式，不同人写的色值、圆角、内边距很难对齐，主次层级逐渐失控。
  • 加载态要手动加转圈动画、手动置灰、手动阻止再次点击，漏掉一步用户就能提交两次。
  • 纯图标按钮没有文字，屏幕阅读器读不出含义，无障碍全靠自觉。
  • 多个相邻按钮各自带边框，紧挨着排会叠出一条双线。

语义与外观解耦

不推翻原生按钮，而是把「语义」和「外观」拆开：你只声明这个按钮扮演什么角色，具体长什么样交给组件库统一渲染。这就是 el-button，它用 type 表达五种语义。

type语义典型场景
primary主操作提交、保存
success正向结果确认通过、启用
warning需要留意消耗积分的操作
danger危险不可逆删除、清空
info中性信息次要入口

选 type 的依据是操作语义，而不是好不好看：删除类操作一律 danger，主操作才用 primary。想让按钮更轻，用 plain 生成描边朴素样式；想要圆角用 round；只放一个图标用 circle；尺寸则由 size 提供 large、默认、small 三档。

接着补上两个状态。用 :loading 绑定一个布尔值，按钮进入加载态并显示转圈图标，最好同时给出「加载中…」这类文字提示；用 :icon 把图标组件直接挂到按钮上。当几个按钮需要成组排布时，把它们放进 el-button-group，由它负责合并相邻边框，避免叠线。

两个容易踩的坑：加载态不只是转圈，必须同时阻止重复点击，否则用户在请求返回前连点，就会重复提交；纯图标按钮（circle）完全依赖图形传达含义，务必补上 aria-label 说明，否则读屏用户听到的只是一个空按钮。

最后是层级纪律：同一个操作区里，primary 和 danger 各限一个主角，其余按钮降级为默认或 plain。整页都是 primary，等于没有主次。

按钮语义组件约定

按钮的难点从来不是「怎么画一个矩形」，而是把操作的重要与危险稳定地翻译成视觉语言。type 管语义，plain、round、circle 管形态，size 管层级，:loading 与 :icon 管状态——把语义交给组件声明，把一致性交给组件库，用户才不会点错。

「语义化按钮」指用 type 表达操作角色而非外观：primary 主操作、danger 危险操作，success、warning、info 分别对应正向、提示与中性。加载态用 :loading 进入并同时阻断重复点击；纯图标按钮必须配 aria-label；成组按钮交给 el-button-group 合并边框。

关键代码

Vue
<script setup lang="ts">
import { ref } from 'vue'
import { ElButton, ElButtonGroup, ElIcon } from 'element-plus'
import { Search, Edit, Check, Message, Delete, Star, ArrowLeft, ArrowRight } from '@element-plus/icons-vue'

const loading = ref(false)

function handleLoadingClick() {
  loading.value = true
  setTimeout(() => {
    loading.value = false
  }, 2000)
}
</script>

<template>
  <div class="demo-card">
    <h3>基础按钮</h3>
    <div class="button-row">
      <ElButton>默认按钮</ElButton>
      <ElButton type="primary">主要按钮</ElButton>
      <ElButton type="success">成功按钮</ElButton>
      <ElButton type="warning">警告按钮</ElButton>
      <ElButton type="danger">危险按钮</ElButton>
      <ElButton type="info">信息按钮</ElButton>
    </div>

    <h3>幽灵按钮</h3>
    <div class="button-row">
      <ElButton plain>朴素按钮</ElButton>
      <ElButton type="primary" plain>主要按钮</ElButton>
      <ElButton type="success" plain>成功按钮</ElButton>
      <ElButton type="warning" plain>警告按钮</ElButton>
      <ElButton type="danger" plain>危险按钮</ElButton>
    </div>

    <h3>圆角与尺寸</h3>
    <div class="button-row">
      <ElButton round>圆角按钮</ElButton>
      <ElButton type="primary" round>主要圆角</ElButton>
      <ElButton size="large">大尺寸</ElButton>
      <ElButton size="small">小尺寸</ElButton>
      <ElButton size="small" round>小圆角</ElButton>
    </div>

    <h3>图标按钮与加载态</h3>
    <div class="button-row">
      <ElButton :icon="Search" circle />
      <ElButton type="primary" :icon="Edit" circle />
      <ElButton type="success" :icon="Check" circle />
      <ElButton type="warning" :icon="Message" circle />
      <ElButton type="danger" :icon="Delete" circle />
      <ElButton type="info" :icon="Star" circle />
      <ElButton type="primary" :loading="loading" @click="handleLoadingClick">
        {{ loading ? '加载中...' : '点击加载' }}
      </ElButton>
    </div>

    <h3>按钮组</h3>
    <ElButtonGroup>
      <ElButton type="primary" :icon="ArrowLeft">上一页</ElButton>
      <ElButton type="primary">
        下一页<ElIcon class="el-icon--right"><ArrowRight /></ElIcon>
      </ElButton>
    </ElButtonGroup>
  </div>
</template>
