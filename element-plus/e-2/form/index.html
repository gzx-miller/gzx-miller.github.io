表单：数据绑定、校验与提交

用用户注册表单展示 ElForm 的双向绑定、规则校验和提交处理。

开场问题：用户在注册表单里把用户名只填了两个字、邮箱又漏了个 @，点提交却只弹出一句「请检查表单填写」——可他根本不知道，到底该改哪一项。

校验逻辑分散困境

后台里几乎每一处录入都离不开表单：新建课程要填课程名、讲师、价格，用户注册要填用户名、邮箱、角色、协议。字段一多，规则就杂——有的必填、有的限长度、有的要符合邮箱格式、有的必须勾选。用户填错的那一刻如果得不到即时、具体、落在字段旁边的提示，他只能靠猜，体验和数据质量会一起崩掉。

如果你不用组件库，这件事的代价是什么？校验逻辑会散落到每一个输入框旁边：每加一条规则就复制一段 if，每加一个字段就再补一个显示错误的元素。规则、提示、值三者各自为政，改一处牵动全身；提交时还得再遍历一遍，才能知道整体到底通没通过。

失焦校验与手写判断

最朴素的做法：在每个输入框的失焦事件里手写判断，再配一个元素显示错误文案，例如 if (username.length < 3) showError('用户名至少 3 个字符')。这个方案做对了一件关键的事——它把校验反馈放到了用户正在操作的那一刻，而不是等提交之后才一起算账。

界面与规则耦合

  • 校验规则和界面代码混在一起，新增一个字段就要再复制一整套判断与提示。
  • 错误文案的显示、定位、清除全靠手动操作，稍不注意就残留上一次的红字。
  • 提交时拿不到一个统一的「全部是否通过、具体哪一项失败」的结果。
  • 「重置表单」要逐个字段回填初始值，还要顺手擦掉所有错误状态。

模型规则与字段分离

不推翻「即时反馈」，而是把「数据」「规则」「字段」三者拆开、各归其位。这正是 el-form 的做法：

  1. 用 reactive 定义一个 form 数据对象，通过 :model 交给表单，让它成为唯一的数据来源。
  2. 把每条校验规则集中写进 rules；每个字段的 el-form-item 用 prop 关联到 model 上的同名字段，控件再用 v-model 绑定。
  3. 规则用内置的 required、min、max、type: 'email' 表达常见约束，特殊逻辑用 validator 自定义函数兜底。
  4. 通过 ref 拿到表单实例，之后统一由它执行校验、重置与定位。

trigger 决定「什么时候校验」，要和控件行为对上：输入类控件用 blur，用户填完离开时提醒；选择类控件用 change，选中那一瞬就反馈。时机不对，用户还没填完就被标红，反而添乱。

拿到实例后，三个方法覆盖了绝大部分场景：validate 做整体校验并返回是否通过，validateField 只校验指定字段，resetFields 一次性清空值并把校验状态恢复为初始。提交时的正确姿势是先 await validate()，通过后再执行业务提交；若后端返回字段级错误，再把它映射回对应的 prop 并聚焦到那一项，用户就能立刻看到问题出在哪。

两个必须记住的点：自定义 validator 里 callback() 表示通过、callback(new Error('…')) 表示失败，失败分支千万不能漏，否则校验会「静默通过」；另外，前端校验只负责即时反馈，真实提交仍然必须依赖服务端校验，绝不能把它当作安全边界。

错误信息字段定位

声明式规则与校验

表单校验的本质，是把散落的手写判断收拢成一份「声明式的规则表」：数据在 :model 里，规则在 rules 里，字段靠 prop 关联，时机由 trigger 决定。于是错误提示不再是随手拼出来的，而是组件根据规则自动算出来的——加字段只是多写一条规则，而不是多复制一段逻辑。

「表单模型校验」指用 :model 提供数据源、rules 声明规则、prop 关联字段，再由 el-form 统一执行校验的机制。实例提供 validate（整体）、validateField（局部）、resetFields（重置值与校验态）三个方法；trigger 中输入类用 blur、选择类用 change；前端校验仅供即时反馈，真实提交仍需服务端把关。

关键代码

Vue
<script setup lang="ts">
import { reactive, ref } from 'vue'
import { ElForm, ElFormItem, ElInput, ElSelect, ElOption, ElButton, ElCheckbox, ElCheckboxGroup, ElDatePicker, ElMessage } from 'element-plus'
import type { FormInstance, FormRules } from 'element-plus'

const formRef = ref<FormInstance>()
const form = reactive({
  username: '',
  email: '',
  role: '',
  skills: [] as string[],
  date: '',
  agree: false,
})

const rules: FormRules = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 3, max: 12, message: '用户名长度 3-12 个字符', trigger: 'blur' },
  ],
  email: [
    { required: true, message: '请输入邮箱', trigger: 'blur' },
    { type: 'email', message: '请输入正确的邮箱格式', trigger: 'blur' },
  ],
  role: [{ required: true, message: '请选择角色', trigger: 'change' }],
  agree: [{ validator: (_, value, callback) => {
    value ? callback() : callback(new Error('请同意用户协议'))
  }, trigger: 'change' }],
}

const skillsOptions = ['Vue3', 'TypeScript', 'Element Plus', 'Vite', 'Pinia']

function submitForm() {
  formRef.value?.validate((valid) => {
    if (valid) {
      ElMessage.success('表单提交成功！')
    } else {
      ElMessage.error('请检查表单填写')
    }
  })
}

function resetForm() {
  formRef.value?.resetFields()
}
</script>

<template>
  <div class="demo-card">
    <h3>用户注册表单</h3>
    <ElForm
      ref="formRef"
      :model="form"
      :rules="rules"
      label-width="90px"
      class="demo-form"
    >
      <ElFormItem label="用户名" prop="username">
        <ElInput v-model="form.username" placeholder="请输入用户名" clearable />
      </ElFormItem>

      <ElFormItem label="邮箱" prop="email">
        <ElInput v-model="form.email" placeholder="请输入邮箱" clearable />
      </ElFormItem>

      <ElFormItem label="角色" prop="role">
        <ElSelect v-model="form.role" placeholder="请选择角色">
          <ElOption label="前端开发" value="frontend" />
          <ElOption label="后端开发" value="backend" />
          <ElOption label="全栈开发" value="fullstack" />
          <ElOption label="产品经理" value="pm" />
        </ElSelect>
      </ElFormItem>

      <ElFormItem label="擅长技能">
        <ElCheckboxGroup v-model="form.skills">
          <ElCheckbox v-for="skill in skillsOptions" :key="skill" :value="skill">
            {{ skill }}
          </ElCheckbox>
        </ElCheckboxGroup>
      </ElFormItem>

      <ElFormItem label="注册日期" prop="date">
        <ElDatePicker
          v-model="form.date"
          type="date"
          placeholder="选择日期"
        />
      </ElFormItem>

      <ElFormItem prop="agree">
        <ElCheckbox v-model="form.agree">
          我已阅读并同意 <a href="#" @click.prevent>《用户协议》</a>
        </ElCheckbox>
      </ElFormItem>

      <ElFormItem>
        <ElButton type="primary" @click="submitForm">提交注册</ElButton>
        <ElButton @click="resetForm">重置表单</ElButton>
      </ElFormItem>
    </ElForm>
  </div>
</template>
