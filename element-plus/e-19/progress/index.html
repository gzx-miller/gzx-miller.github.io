进度条：Progress 学习进度

用课程学习进度展示 ElProgress 的线形、环形和仪表盘模式。

开场问题：课程的完成度只写了一句「已完成 55%」，用户盯着这几个字，完全感受不到自己离学完还有多远。

数字读取与换算

你在做一个学习数据看板。每门课程都有一个完成度，取值从 0 到 100。如果只把数字打印成文字，用户需要先读数字、再在脑子里换算成「大概一半」，最后还要自己比较几门课谁快谁慢——每一步都在消耗注意力。看板的意义是让人一眼看出差距，而纯文字恰恰做不到这一点。

更棘手的是，进度并不是千篇一律的。有的场景想用一条横向的条，有的想用一个圆环，有的想要仪表盘那种带刻度的弧。如果每种形态都自己造，代码会迅速膨胀，而且几种形态的视觉细节还很难对齐。

轨道与填充实现

最省事的做法：用一个 div 当轨道，里面放一个内层 div，把它的宽度设成百分比——55% 就写 width: 55%。数字一变，宽度跟着变，进度条就动起来了。

这个方案方向是对的：它把抽象的百分比翻译成了长度，让「多少」变成可以看见的东西。几条并排摆开，谁长谁短一目了然。但它只做了一条线形条，覆盖面很窄。

圆环与分段配色

  • 圆环、仪表盘得自己画，涉及 SVG 或渐变绘制，门槛不低。
  • 分段配色要自己算：低于某个阈值标红、中段标黄、快完成标绿，逻辑一多就散。
  • 粗细、尺寸这些外观参数没有统一入口，改一处要动好几处样式。
  • 异常数据没人兜底：数值传了 120 或负数，条会画出边界甚至反向。
  • 进度到 100% 之后没有任何提示，用户不知道是不是卡住了。

组件参数驱动外观

不推翻「把百分比变成可见长度」，而是把各种形态收敛到同一个组件。Element Plus 的 el-progress 用一个数字驱动外观：percentage 就是进度数值，其余属性只决定「长什么样」。

先看形态。type 可以切换线形、环形、仪表盘三种。线形适合并排比较多个任务；环形适合在卡片里突出一个数字；仪表盘则自带刻度感，适合强调「完成度」这种整体指标。

再看尺寸与粗细，这两个参数容易混，要分清楚：

  • width 控制圆形与仪表盘的整体尺寸，也就是整块画布多大。
  • stroke-width 控制进度条本身的粗细，也就是那条弧线或直线多厚。

配色的灵活性也值得说。color 支持三种写法：写一个固定颜色值、给一个按百分比分段的数组（形如「颜色加阈值」的若干段）、或者给一个函数按当前数值返回颜色。想实现「低分标红、中段标黄、高分标绿」，一段分段数组就够，不必自己写判断。

然后是两个必须自己把关的边界。第一，把 percentage 裁剪到 0 到 100 之间再传进去：接口偶尔会返回异常数据，越界的数值会让进度条绘制溢出甚至反向，看起来像渲染坏了。数据还会变化，所以要监听它动态更新，并顺势处理「已完成」和「异常」这两种终态。第二，当进度到达 100% 时要给出下一步引导，比如提示「可以继续学习下一门」，而不是让条静静地停在满格，用户还以为卡住了。

最后是信息组织。多任务场景下，与其让用户逐个去看，不如把各任务的进度汇总成一个总进度展示，一眼掌握全局。

别把 width 和 stroke-width 混着用：在仪表盘形态下，width 决定的是整块画布的尺寸，不是线的粗细；线的粗细始终归 stroke-width 管。弄反了就会得到「尺寸没变、线条莫名变粗」这类莫名其妙的效果。

四种形态同步增长

进度数值与形态

进度条把「完成了多少」从一句文字变成了看得见的长度或弧度，让比较和感知都变快。用法上记住三点：一个 percentage 驱动数值，type 决定线形、环形还是仪表盘，color 可以用固定值、分段数组或函数取色。别混淆 width 与 stroke-width，传值前裁剪到合法区间，到达终点时补上下一步引导，这条「仪表」才算真正可用。

「进度条」用 el-progress 展示完成度：percentage 是进度数值，type 切换线形 / 环形 / 仪表盘，width 控制圆形与仪表盘的整体尺寸，stroke-width 控制进度条粗细，color 支持固定颜色、按百分比分段的数组或返回颜色的函数。传入前应把 percentage 裁剪到 0 到 100 的合法区间，并在满 100% 时给出下一步引导。

Vue
<script setup lang="ts">
import { ref, computed } from 'vue'
import { ElProgress, ElButton } from 'element-plus'

const overall = ref(35)

interface CourseProgress {
  name: string
  percent: number
  color: string
}

const courses = ref<CourseProgress[]>([
  { name: 'Vue3 组合式 API', percent: 80, color: '#67c23a' },
  { name: 'TypeScript 类型体操', percent: 55, color: '#e6a23c' },
  { name: 'Nuxt 全栈开发', percent: 20, color: '#409eff' },
  { name: '前端性能优化', percent: 0, color: '#f56c6c' },
])

const avgPercent = computed(() =>
  Math.round(courses.value.reduce((sum, c) => sum + c.percent, 0) / courses.value.length),
)

function simulateStudy() {
  courses.value.forEach(c => {
    c.percent = Math.min(c.percent + Math.floor(Math.random() * 15 + 5), 100)
  })
  overall.value = avgPercent.value
}

function resetAll() {
  courses.value.forEach(c => { c.percent = 0 })
  overall.value = 0
}
</script>

<template>
  <div class="demo-card">
    <p class="demo-kicker">学习数据看板</p>
    <h3>课程完成进度</h3>

    <div style="display: flex; align-items: center; gap: 24px; margin-bottom: 16px">
      <ElProgress type="dashboard" :percentage="overall" :width="100" />
      <div>
        <p style="margin: 0">总体完成度</p>
        <strong style="font-size: 1.5em">{{ overall }}%</strong>
      </div>
    </div>

    <div v-for="c in courses" :key="c.name" style="margin-bottom: 8px">
      <p style="margin: 0 0 4px">{{ c.name }}</p>
      <ElProgress :percentage="c.percent" :color="c.color" :stroke-width="14" />
    </div>

    <div class="button-row" style="margin-top: 12px">
      <ElButton type="primary" @click="simulateStudy">模拟学习推进</ElButton>
      <ElButton @click="resetAll">重置进度</ElButton>
    </div>
  </div>
</template>
