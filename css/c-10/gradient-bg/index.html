渐变与背景

用课程卡片背景理解 linear / radial / conic-gradient 的语法与色标控制。

开场问题：卡片背景只是一层橙色渐变，可设计师每调一次色值，我就得重新导出一张图、替换资源、再压一遍体积——明明只是两个颜色之间的一段过渡。

渐变背景切图

你在给课程卡片做一层从暖橙到明黄的背景。设计稿里它是平滑过渡的颜色，你顺手把它导出成 PNG 用 background-image 引了进来。第一次没问题，但配色方案一改，你就得回到设计工具重出图；要做深色模式，又得再备一套；窗口一大，图片还得面对缩放带来的模糊与体积。

代价在于：把一个"算得出来的东西"固化成了"必须切图才有的资源"。颜色、角度、过渡方向，全都是可以用参数描述的规律，可一旦变成位图，就失去了随主题、随尺寸、随变量变化的能力。渐变色本身，其实是一种用规则生成图像的机制。

导出图片方案

最朴素的做法：继续用导出的渐变图片，写进 background 里。

这个方案做对了一件事：它能精确还原任意设计稿效果。不管过渡多复杂、叠加多少光泽，导出的图片都能一五一十地呈现，控制力是最强的。

资源重导代价

  • 改一个色值就要重新导出、重新压缩、重新替换，一条龙的重活只为两个颜色。
  • 要为不同倍率屏幕准备多套图，高清设备下体积和清晰度难以两全。
  • 元素尺寸变化时位图会被拉伸，过渡带糊掉或出现色阶。
  • 它无法参与主题变量，深色模式只能再备一张图。

规则生成图像

不推翻「用图片做背景」，而是换一种图片来源：渐变色属于 CSS 的 <image> 类型——它是一张由规则算出来的图，可以直接写进 background，无需任何文件。

线性渐变 linear-gradient 沿一条直线方向过渡：linear-gradient(135deg, #e8590c, #d9480f)，第一个参数是角度或方向关键字。注意 0deg 是垂直向上，并随角度顺时针旋转，所以 90deg 指向右；也可以用 to right、to bottom 这类关键字表达方向。

径向渐变 radial-gradient 从中心沿半径向外辐射：radial-gradient(circle at center, #fff4e6, #e8590c)，形状取 circle 或 ellipse，at 后面指明中心位置。锥形渐变 conic-gradient 则绕中心沿角度扫过：conic-gradient(from 0deg, #e8590c, #ffd43b, #e8590c)，from 指定起始角度。

三者适用的场景差别很大，对照着记最清楚。

函数过渡规律适用场景
linear-gradient沿直线方向过渡按钮、卡片底色、遮罩
radial-gradient从中心向外辐射光晕、聚光灯、圆形氛围
conic-gradient绕中心沿角度扫过色轮、进度环、仪表盘

再往深一层，色标还可以带位置：linear-gradient(to right, #e8590c 0%, #ff922b 50%, #ffd43b 100%) 精确控制每段颜色落在哪。当相邻两个色标位置相同时，中间就没有过渡空间，会形成一条硬边——利用这点可以做出条纹色块。多个渐变用逗号叠加就成多重背景，先写的位于上层，例如 linear-gradient(135deg, rgba(232,89,12,0.8), transparent), radial-gradient(circle at top right, #ffd43b, transparent)；再配上 background-size，甚至能用渐变拼出重复图案。

落到实际界面里，渐变的用法很集中：卡片和按钮用一层线性渐变做底色，图片上盖一层 linear-gradient(180deg, transparent, rgba(0,0,0,0.6)) 做文字遮罩，色轮与进度环交给锥形渐变，光晕和聚光效果则用径向渐变。这些都统一走 background 简写，颜色、图片、重复、位置、尺寸一条声明写完：background: #fff url('bg.png') no-repeat center / cover；渐变也能像图片一样写进这个简写里，与背景图自由组合。

别把渐变当动画：渐变的动画与重绘开销很大，大面积渐变在动效里尤其吃力。需要动起来的大面积背景，优先考虑静态图或用合成层友好的属性替代，而不是让浏览器每帧重算整张渐变的每个像素。

三种渐变对照

背景规则与色标

渐变把「背景图」从需要切图的资源，变回了一条可描述的规则：线性沿方向、径向向外辐射、锥形绕圈扫过，色标控制颜色落点，逗号叠加出多重背景。改色只是改一个值，还能随主题与尺寸自由变化——为一层渐变单独切图的时代可以结束了。挑函数时先问它沿哪条路径过渡，方向对了，剩下的只是继续调色标。

「CSS 渐变」渐变色属于 CSS 的 <image> 类型，是可由规则生成的图像：linear-gradient 沿方向过渡（0deg 向上、顺时针旋转），radial-gradient 从中心向外辐射，conic-gradient 绕中心沿角度扫过。色标可带位置，相邻色标位置相同即形成硬边；多个渐变用逗号叠加时先写的在上层。

关键代码

CSS
/* 线性渐变：沿直线方向过渡 */
.gradient-linear {
  background: linear-gradient(135deg, #e8590c, #d9480f);
  /* 角度 + 起始色 + 结束色 */
}

/* 线性渐变：多个色标 */
.gradient-multi {
  background: linear-gradient(
    to right,
    #e8590c 0%,
    #ff922b 50%,
    #ffd43b 100%
  );
}

/* 线性渐变：硬边（色标位置相同） */
.gradient-stripes {
  background: linear-gradient(
    to bottom,
    #e8590c 0%,
    #e8590c 50%,
    #fff4e6 50%,
    #fff4e6 100%
  );
}

/* 径向渐变：从中心向外辐射 */
.gradient-radial {
  background: radial-gradient(circle at center, #fff4e6, #e8590c);
  /* 形状 + 位置 + 色标 */
}

/* 锥形渐变：围绕中心旋转 */
.gradient-conic {
  background: conic-gradient(from 0deg, #e8590c, #ffd43b, #e8590c);
}

/* 多重渐变叠加 */
.gradient-multi-layer {
  background:
    linear-gradient(135deg, rgba(232,89,12,0.8), transparent),
    radial-gradient(circle at top right, #ffd43b, transparent);
}

/* 渐变 + background-size 实现图案 */
.gradient-pattern {
  background: linear-gradient(45deg, #e8590c 25%, transparent 25%) 0 0 / 20px 20px,
              linear-gradient(-45deg, #e8590c 25%, transparent 25%) 0 0 / 20px 20px;
}

/* background 属性简写 */
.bg-full {
  background: #fff url('bg.png') no-repeat center / cover;
  /* 颜色 图片 重复 位置 / 尺寸 */
}
