定位机制

理解 static / relative / absolute / fixed / sticky 的偏移基准与文档流行为。

开场问题：我给商品卡片的「热卖」角标写了 position: absolute; top: 0; right: 0，结果角标没待在卡片角上，反而飞到了整个页面的右上角——它到底相对谁在定位？

多场景定位需求

同一个页面里还有别的需求：顶部导航要在滚动时一直吸在视口顶端；右下角要有一个悬浮的客服按钮；卡片里的角标要牢牢贴住卡片右上角。这三件事看起来都是「挪个位置」，但要求并不一样——有的要跟着页面滚，有的滚动到某处才吸住，有的只能待在父级内部。

代价是元素会「乱飞」并且挤乱邻居：偏移基准没搞清，写下的 top/left 就会以你意想不到的参照物生效；而一旦元素脱离文档流不再占位，后面的兄弟会紧接着往上挤，原本对齐的版面瞬间错位。更烦的是「吸顶失效」这类问题，往往改来改去找不到原因。

这三个需求的差别，其实落在两个问题上：元素偏移时以谁为原点，偏移之后它还算不算「原来那个位置」。把这两问想清楚，五种定位的选用就是水到渠成的事。

负边距位移方案

最朴素的做法：用负的 margin 或 transform: translate 把元素硬挪过去。比如角标就用 margin-top: -8px; margin-left: -8px 往外拉一点。

它做对了「位移可以不影响布局」这一层：transform 只改变绘制位置，不改变元素占的空间，做微调时非常省心。

裁剪与基准局限

  • 往外挪会被父容器的 overflow: hidden 裁掉，或者把父容器撑出滚动条。
  • 基准是「元素自己原来的位置」：卡片一旦换了位置，写死的偏移量就全错了。
  • 做不到「跟随视口固定」，也做不到「滚动到某处才吸住」。
  • 复杂场景下（角标贴父级右上角、弹层居中）没法用位移简单表达。

偏移与脱离文档流

不推翻「位移」，而是用 position 一次说清两件事：偏移的参考系是谁，以及它是否脱离文档流。五种取值各有分工：

  • static：默认值，正常文档流，top/right/bottom/left 一律不生效。
  • relative：相对自身原来的位置偏移，但仍保留原来的占位，邻居不会受影响。它更大的用途，是给子级的 absolute 提供一个参考框。
  • absolute：脱离文档流、不占空间，相对最近的非 static 祖先定位。
  • fixed：脱离文档流，相对视口固定，页面怎么滚它都不动，适合吸顶导航和悬浮按钮。
  • sticky：越过阈值之前保留原位、像普通元素一样跟着滚；越过阈值后像 fixed 一样吸住，特别适合吸附式表头。
取值是否脱离文档流参考基准
static不脱离无（默认，偏移不生效）
relative不脱离自身原位置
absolute脱离最近的非 static 祖先
fixed脱离视口
sticky不脱离（滚动时转为固定效果）滚动祖先 + 阈值

拿着这张表回看开场：角标飞走的根因，是卡片本身没有建立参考系。absolute 必须依托一个非 static 的祖先，否则它会一路向上找到视口，于是角标就跑到了页面右上角。正确写法是给卡片加一句 position: relative，角标立刻回到卡片角上。

日常最常用的一对组合就是「父 relative、子 absolute」：父元素本身往往不需要移动，只是把 position: relative 当作一个「定位锚点」挂在那里，让子元素的 top/right 有了参照物。养成习惯——要放角标、遮罩、关闭按钮时，先给容器补上这句锚点。

还有一个容易被忽略的副作用：position 一旦不是 static，元素就获得了参与 z-index 比较的资格，也就是说定位往往和「谁压住谁」绑在一起。吸顶导航给一个 z-index: 100，就是为了在滚上去时压住下面的内容。层级问题的完整规则在 C_17，这里先记住「定位会打开层级比较的大门」就够了。

两个常见坑：其一，sticky 必须同时给出 top/bottom/left/right 中的至少一个，只写 position: sticky 是不会生效的；而且它在父容器的高度用尽之后会随容器滚出视口，并非常久吸顶。其二，fixed 默认相对视口，但如果祖先带有 transform、filter 这类属性，它会被当作包含块而不再是视口——这也是弹层偶尔「位置突然不对」的原因。

五种定位对照

基准与占位差异

定位要同时回答两个问题：相对谁偏移，以及是否还占原来的位置。relative 保留占位、absolute 脱离流并找最近的非 static 祖先、fixed 认准视口、sticky 到阈值才吸住——把参考系和占位这两条理清，元素乱飞与吸顶失效就都有了答案。

「定位」由 position 决定偏移参考系与是否脱离文档流：static 不定位；relative 相对自身原位置偏移且保留占位；absolute 脱离文档流、相对最近的非 static 祖先定位；fixed 脱离文档流、相对视口固定；sticky 越过阈值前保留原位、越过阈值后吸住（须给定 top/left 等）。注意祖先的 transform/filter 会改变 fixed 的包含块。

关键代码

CSS
/* static：默认定位，正常文档流 */
.static-box {
  position: static;
  /* top/right/bottom/left 不生效 */
}

/* relative：相对自身原位置偏移 */
.relative-box {
  position: relative;
  top: 10px;
  left: 20px;
  /* 相对原位置向下 10px，向右 20px */
  /* 仍占据原文档流位置 */
}

/* absolute：相对最近的非 static 祖先定位 */
.absolute-box {
  position: absolute;
  top: 0;
  right: 0;
  /* 相对于最近定位祖先的右上角 */
  /* 脱离文档流，不占空间 */
}

/* 父容器设置 relative 作为定位参考 */
.parent-relative {
  position: relative;
}

/* fixed：相对于视口定位 */
.fixed-header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  /* 固定在视口顶部 */
  /* 脱离文档流 */
  z-index: 1000;
}

/* sticky：滚动时切换 fixed */
.sticky-nav {
  position: sticky;
  top: 0;
  /* 滚动到顶部时吸顶 */
  /* 必须指定 top/left 等才生效 */
  background: #fff;
}
