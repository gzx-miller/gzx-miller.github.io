Flexbox 弹性布局

用课程卡片列表理解主轴、交叉轴对齐与弹性伸缩。

开场问题：我想让卡片里的文字垂直居中，写了 vertical-align: middle，浏览器一点反应都没有——为什么这个「居中」不管用？

卡片列表对齐需求

你在排一份课程卡片列表：左边一张封面图、右边标题与简介，需要图撑满卡片高度、标题贴顶、底部一行「查看详情」贴右，卡片之间还要均匀留缝、放不下时自动换行。用传统写法拼了半天，卡片之间总有几像素对不齐的空白缝，怎么都消不干净。

代价是布局全靠 hack 维持：每个间距都要手算百分比，一改文案长度整个排列就乱；想调整卡片顺序，只能去动 HTML。这类「一行或一列里的排列问题」几乎每个页面都会遇到，值得有一套专门的模型。

更本质地说，这类需求都属于「一维排列」：元素沿着一根线依次摆开，只是在线上的对齐方式、间距、伸缩比例不同。传统方案没有为这根线提供统一的抽象，于是每种对齐都要各找各的办法，才有了拼凑感。

行内块水平排列

最朴素的做法：让子元素 display: inline-block，父级用 text-align: center 控制水平位置，间距靠 margin 一个个加。

它做对了「把元素当成排列单位」这件事：子项并排了，水平对齐也有了。当只有两三个元素、位置也简单时，这套写法完全能跑。

空白字符与垂直居中

  • inline-block 之间会多出空隙：HTML 里换行产生的空白字符被当成了内容，卡片之间凭空多几像素缝。
  • 垂直居中做不到：text-align 只管水平方向，vertical-align 是给行内元素对齐基线的，管不了盒子在容器里的上下位置。
  • 剩余空间要手算：想让三个卡片均分宽度，得自己算 calc 百分比，内容一变又要重算。
  • 顺序调整只能挪 DOM，视觉顺序和结构顺序被绑死。
  • 换行、间距、对齐各管各的，稍微复杂一点就开始互相打架。

弹性布局轴向模型

不推翻「并排排列」，而是换一套有明确轴向的模型：给容器写 display: flex，它的直接子元素立刻变成「flex 项目」。关键在于它引入了两条轴——主轴由 flex-direction 决定，默认 row 是横向排列，改成 column 就变纵向。

有了两条轴，对齐就分成了各司其职的两件事：justify-content 管主轴，取值 flex-start、center、space-between、space-around、space-evenly；align-items 管交叉轴，取值 flex-start、center、stretch（默认，撑满）、baseline。开场那个垂直居中，在默认 row 下用的正是 align-items: center——它是交叉轴的事，不该指望 justify-content。

最容易踩的一坑：两轴不可混用。主轴对齐没反应时，先回头检查 flex-direction——方向一旦从 row 改成 column，主轴的语义和 justify-content 的作用方向就互换了，原来「水平居中」的写法会变成「垂直居中」。

接着补齐换行与间距：空间不够想换行就加 flex-wrap: wrap；项目间距用 gap，一行就够，而且不会像 margin 那样在首尾留出多余的空隙。

换行之后还会多出一个对齐维度。项目一旦折成多行，align-content 决定的是「这些行整体」在交叉轴上的分布，而 align-items 管的是「每一行内部」的项目对齐——不换行时前者的作用看不出来，一换行就容易把两者搞混。

再往下是剩余空间的分配。flex: 1 是 flex-grow: 1; flex-shrink: 1; flex-basis: 0% 的简写，给多个子项都写上，它们就会均分剩余空间；反过来 flex: 0 0 auto 表示不伸也不缩，尺寸由内容决定。最后是顺序：order 数值越小越靠前，它只改视觉顺序，不动 DOM，这也是它相对挪 HTML 的优势。

分配空间时还有个细节值得先记住：flex-basis 是项目在分配之前的「基准尺寸」，写成 0% 表示不按内容宽、一切从零开始再均分；这正是 flex: 1 能把宽度分得那么整齐的原因。如果写成 flex: 1 1 auto，基准变成了内容宽度，分出来的结果就会因文字长短而参差不齐。

一句话分工：主轴方向的事（靠哪边、怎么分）交给 justify-content 与 flex，交叉轴方向的事（多高、怎么对）交给 align-items 与 align-content，间距统一交给 gap。

还要把分工说清楚：Flexbox 是一维布局，处理一行或一列内部的排列与分配；页面级的二维骨架（同时要管行和管列）应该交给 Grid。

两轴对齐对照

主轴与交叉轴

Flexbox 用「一根主轴、一根交叉轴」把排列讲清楚了：主轴对齐交给 justify-content，交叉轴对齐交给 align-items，空间不足用 flex-wrap 换行、gap 留缝，剩余空间用 flex: 1 分配。垂直居中、等分宽度、均匀间距这些曾经要靠 hack 的事，现在各归各位。

「Flexbox」是一维布局模型：主轴由 flex-direction 决定（row/column），交叉轴垂直于主轴；justify-content 负责主轴对齐，align-items 负责交叉轴对齐，二者不可混用；flex-wrap 决定超宽是否换行，gap 设项目间距，order 调整显示顺序。flex: 1 即 flex-grow:1; flex-shrink:1; flex-basis:0%，用于均分剩余空间。

关键代码

CSS
/* Flex 容器：启用弹性布局 */
.flex-container {
  display: flex;
  gap: 12px;
}

/* 主轴对齐方式 */
.justify-center {
  justify-content: center;
  /* 主轴居中 */
}
.justify-between {
  justify-content: space-between;
  /* 两端对齐，中间均匀分布 */
}
.justify-around {
  justify-content: space-around;
  /* 每个项目两侧间距相等 */
}

/* 交叉轴对齐方式 */
.align-center {
  align-items: center;
  /* 交叉轴居中 */
}
.align-stretch {
  align-items: stretch;
  /* 拉伸填满容器高度（默认） */
}
.align-baseline {
  align-items: baseline;
  /* 基线对齐 */
}

/* 换行设置 */
.flex-wrap {
  flex-wrap: wrap;
  /* 空间不足时换行 */
}

/* Flex 项目：弹性增长 */
.flex-grow {
  flex-grow: 1;
  /* 平分剩余空间 */
}

/* 改变排列顺序 */
.order-first {
  order: -1;
  /* 排在最前面 */
}

/* 简写：flex: grow shrink basis */
.flex-1 {
  flex: 1 1 0%;
  /* 常用简写：可伸缩 */
}
