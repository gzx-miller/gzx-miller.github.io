Grid 二维网格布局

用课程仪表盘理解列轨道定义、gap 与 grid-template-areas 区域布局。

开场问题：后台仪表盘要「页头横跨整宽、左边固定侧栏、右边内容自适应、页脚压底」，我用 flex 横排竖排套了三层，侧栏和内容的高度却怎么也对不齐——为什么？

后台骨架分区需求

你在搭一个课程运营后台的骨架：顶部一条页头，下面左边是导航侧栏、右边是内容区，最底下一行页脚。页头要横跨整宽，侧栏又要从页头下面一直延伸到页脚上面——这是一个「同时要管行、又要管列」的结构，可横跨和纵跨两件事，恰好是单方向模型最难表达的。

代价是骨架会被表达方式反过来绑架：套得越深，层级越多，每个断点都要重排一遍嵌套关系；改一处结构要动好几层容器，可读性和可维护性都随之下滑。

关键差异在于：flex 的排列是「顺着一个方向流下去」，而仪表盘这种结构需要的是「先把版面切成格子，再把元素放进去」。前者描述过程，后者描述结果——这就是为什么二维布局需要另一个模型。

浮动与弹性拼接

用 flex 硬拼：外层横排，装下侧栏和主区；主区里再竖排，装下页头、内容、页脚。或者更老派一点，用 float 把侧栏浮起来、给内容留出边距。

它做对了「先分区、再排列」这个大方向：先把页面切成几块，再逐块排列。当结构只有简单的头尾两段式时，这套写法是够用的。

一维模型表达局限

  • 行列交叉的需求表达不了：页头要横跨两列、侧栏要纵跨两行，一维模型里没有「跨」这个概念。
  • 层级被迫加深：为了拼出二维效果，容器要一层套一层，结构越复杂嵌套越深。
  • 对齐是间接的：想让左右两块的基线或是高度对齐，只能靠额外的属性去凑。
  • 响应式要重排嵌套：每换一次断点，可能连容器层级都要重写。
  • 浮动的老写法还要清浮动，父容器包不住子元素时就出问题。

网格布局二维模型

不推翻「分区排列」，而是换一个天然二维的模型：display: grid。它直接承认行和列同时存在，用 grid-template-columns 和 grid-template-rows 定义轨道，也就是一条条行线和列线划出的格子。

轨道里的宽度有个专有单位 fr，表示「剩余可用空间的一份」。它能和固定像素混用：200px 1fr 200px 就是左右各锁死 200px、中间吃掉全部剩余。repeat(3, 1fr) 把重复的轨道写简，minmax(120px, 1fr) 给一列同时设下限与弹性上限，而 repeat(auto-fill, minmax(120px, 1fr)) 会让列数随容器宽度自动增减——这已经是一种不用写媒体查询的响应式了。轨道之间留缝用 gap，一次设定横向纵向的间距。

轨道定好之后，并非所有格子都要你亲手画。当你用 grid-area 把元素放到显式轨道之外时，浏览器会自动生成新的行或列来接住它，这部分叫隐式网格，grid-auto-rows 可以规定这些自动行的高度。理解了这一点，就不会奇怪「我明明只定义了三列，第四列为什么会自己冒出来」。

真正解决开场那个「横跨又纵跨」的，是区域命名布局：

grid-template-areas 里写上 "header header"、"sidebar main"、"footer footer" 三行，就相当于把骨架画了出来——同一个名字横着占两格就是横跨。子元素只要写 grid-area: header 就自动归位，页头自然横跨整宽、侧栏自然纵跨页头与页脚之间。好处是骨架的这几行字符串一眼可读，改结构只改这几行，不用再去挪嵌套。

如果不想命名，也可以用网格线定位：grid-column: 1 / 3 表示从第 1 条列线跨到第 3 条列线，即占两列；grid-row: span 2 表示向下跨两行。

与 Flexbox 的分工：Grid 负责页面级的二维骨架，Flexbox 负责组件内部的一维排列。用 fr 混搭固定像素前，先想清楚哪些维度该随窗口伸缩、哪些该锁死——这一点想清楚了，轨道怎么写就是顺理成章的事。

Grid 同样能管对齐。justify-items 控制项目在格子内的水平位置，align-items 控制垂直位置，两者都设在容器上；只想调某一个项目时，就写在项目自己身上。它们的默认值是 stretch，所以格子里的元素往往会被拉满——这也是为什么有时「明明没设宽度，卡片却铺满了整格」。

列轨道与区域对照

行列并重布局能力

Grid 把「同时控制行和列」变成了第一等公民：用轨道定义格子尺寸，用 fr 分配空间、minmax 与 auto-fill 做自适应，用区域命名把页面骨架写成可读的图形。遇到横跨纵跨的二维结构，就不必再用一层层 flex 去凑了。

「Grid」是二维布局模型：grid-template-columns/rows 定义轨道，fr 分配可用空间比例，repeat() 简化重复，minmax() 设上下限，repeat(auto-fill, minmax(120px, 1fr)) 让列数随宽度自动增减；grid-template-areas 用命名区域语义化描述页面骨架，子元素以 grid-area 归位。二维整体布局交给 Grid，一维的组件内部仍用 Flexbox。

关键代码

CSS
/* Grid 容器：启用网格布局 */
.grid-container {
  display: grid;
  gap: 16px;
}

/* 定义列轨道 */
.grid-cols-3 {
  grid-template-columns: 1fr 1fr 1fr;
  /* 三等分列 */
}
.grid-cols-auto {
  grid-template-columns: repeat(3, minmax(100px, 1fr));
  /* 每列最小 100px，最大平分 */
}

/* 定义行轨道 */
.grid-rows-2 {
  grid-template-rows: auto 1fr;
  /* 第一行自适应，第二行占剩余 */
}

/* 区域命名布局 */
.grid-areas {
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.grid-areas .header { grid-area: header; }
.grid-areas .sidebar { grid-area: sidebar; }
.grid-areas .main { grid-area: main; }
.grid-areas .footer { grid-area: footer; }

/* 网格线放置项目 */
.item-span {
  grid-column: 1 / 3;
  /* 从第 1 列线到第 3 列线（跨 2 列） */
  grid-row: span 2;
  /* 跨 2 行 */
}

/* 自动填充 */
.grid-auto-fill {
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  /* 自动填充，每列至少 200px */
}
