CSS 变量（自定义属性）

用暖/冷主题与间距滑块理解自定义属性的声明、读取、继承与运行时更新。

开场问题：产品临时要加一个「夜间主题」，我打开样式表才发现主色 #e8590c 被写死在十几个选择器里——难道只能一个一个搜着替换，还得祈祷没有漏掉？

色值重复书写

你想做一件很小的事：把站点的品牌色从橙色换成蓝色。听起来是改一个值，可真正动手时会发现，同一个色值散落在按钮、徽标、边框、卡片底色等几十个地方，字面量到处复制。颜色如此，间距、圆角、字号也一样——它们本该是一套「设计令牌」，却在代码里被拆成了无数份互相独立的副本。

代价很清楚：改色要全局搜索替换，而替换并不认识语义，它会把不该动的地方一起改掉；更麻烦的是主题切换。用户点一下「夜间模式」，你要的是同一套 DOM 换一套颜色，可静态样式表里根本没有一个可以现场改写颜色的入口。不引入某种「变量」机制，这件事就只能靠重发一份新 CSS 来硬扛。

预处理器变量

最省事的做法：用预处理器变量。$primary: #e8590c; 声明一次，处处引用，编译后替换成真正的颜色值。

这个方案确实做对了一件事：把散落的字面量收敛成了单一来源。改一处，所有引用同步变化，编译产物里仍然是干净的颜色，没有运行时开销。对「值固定、只在构建期确定」的场景，它完全够用。

编译期替换局限

  • 预处理器变量在编译期就被替换掉了，运行时的 JavaScript 既读不到、也改不了它。
  • 想在用户点击时切换主题，只能重新编译、再发布一份新 CSS，做不到「同一页面即时换肤」。
  • 第三方组件内部的样式无法被你自己的编译变量覆盖，主题色对它们失效。
  • 变量值的变化不能驱动任何运行时计算，比如「根据当前间距再推算别的尺寸」就无从谈起。

运行时自定义属性

不推翻「集中定义」这个思路，只换一种承载方式：别把颜色当成编译期写死的字面量，而是把它当成一个运行时可读写的 CSS 属性——这就是自定义属性，也就是常说的 CSS 变量。声明用 --name，读取用 var(--name, fallback)。

它和普通属性一样参与层叠与继承。定义在 :root 上，全站可用；在 .card 里重新声明 --card-padding: 20px，就只有这个元素及其后代读到新值——这正好是「作用域内的主题覆盖」。于是局部微调不必污染全局，主题切换也不必动到任何选择器。

最关键的一点是：它是运行时可写的。执行 element.style.setProperty('--primary-color', '#000')，所有读取该变量的属性立刻重算，整套配色无需重编译、无需新 CSS 就切换了过去。这正是编译期变量给不了的能力。

  • 备用值只在变量未定义或无效时生效：color: var(--text-color, #333)。
  • 可与 calc 组合，把令牌和计算绑在一起：--col-width: calc((100% - var(--gutter) * 2) / var(--cols))。
  • 命名用语义而非外观：写 --color-primary 而不是 --blue，换主题时语义不变，代码也不用跟着改。

它之所以能被 JavaScript 随意读写，是因为浏览器把它当成真正的属性对待——变量名、作用域、继承关系，全都遵循和 color、padding 一样的层叠规则。这也带来一个实用的调试习惯：主题「没生效」时，先在开发者工具里查看某个元素上变量解析后的实际值，再顺着继承链往上找是哪一层把值覆盖了，比在几十条规则里猜要快得多。把色板、间距、圆角这些设计令牌集中在 :root，正是为了让所有组件共享同一份来源。

把四种基本用法摆在一起对照，更容易记住各自的职责。

用法写法要点
声明--name: value;以两个连字符开头，值是任意合法 CSS 值
读取var(--name, fallback)备用值仅在未定义或无效时生效
JS 访问element.style.setProperty('--name', val)运行时改写，立即驱动重算
继承随普通属性向下继承局部重声明即作用域覆盖
一个容易踩的坑：自定义属性不能直接参与动画插值——浏览器不知道 #e8590c 到 #1971c2 之间该怎么过渡。想让主题色平滑变化，要把它读进具体属性或 calc() 里再动：color: var(--text-color) 这样的属性值本身才是可插值的对象。

主题与间距联动

设计令牌运行时化

CSS 变量把「设计令牌」从编译期的静态副本，变成了运行时可以被读取、继承与改写的属性。定义在 :root 就全局共享，局部重声明就作用域覆盖，style.setProperty() 一改就整套生效——主题切换、间距微调这些过去要重发 CSS 的事，现在都收敛成了改一个值。

「CSS 变量（自定义属性）」以 --name 声明、var(--name, fallback) 读取，与普通属性一样参与层叠和继承。它可在运行时被 element.style.setProperty() 改写，从而驱动整套主题切换；定义在 :root 全局可用，局部重声明即作用域覆盖，备用值只在变量未定义或无效时生效。

关键代码

CSS
/* 在 :root 声明全局变量 */
:root {
  --primary-color: #e8590c;
  --primary-light: #fff4e6;
  --border-color: #ffd8a8;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --font-size-base: 14px;
  --border-radius: 6px;
}

/* 读取变量：var(变量名, 备用值) */
.btn {
  background: var(--primary-color);
  color: #fff;
  padding: var(--spacing-sm) var(--spacing-md);
  border-radius: var(--border-radius);
  border: none;
  cursor: pointer;
}

/* 局部变量：只在当前选择器及后代生效 */
.card {
  --card-padding: 20px;
  padding: var(--card-padding);
  border: 1px solid var(--border-color);
}

/* 备用值：变量不存在时使用 */
.text {
  color: var(--text-color, #333);
  /* --text-color 未定义时用 #333 */
}

/* 主题切换示例：冷色主题 */
.theme-cool {
  --primary-color: #1971c2;
  --primary-light: #e7f5ff;
  --border-color: #a5d8ff;
}

/* 计算中使用变量 */
.layout {
  --gutter: 16px;
  --cols: 3;
  --col-width: calc((100% - var(--gutter) * 2) / var(--cols));
}

/* JavaScript 动态修改变量 */
/* element.style.setProperty('--primary-color', '#000'); */
