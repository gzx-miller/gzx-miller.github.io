形状与裁剪

用封面裁剪理解 clip-path 的几何形状与 mask 的透明度遮罩。

开场问题：想把产品封面裁成六边形，可 border-radius 只能做圆角；想让它底部自然渐隐融入背景，圆角更是彻底没辙——把元素切成任意形状，到底该用哪个属性？

多种形状裁剪

你在做一个展示页：卡片封面要做成斜切的六边形，标签要做成三角形小尖角，图片底部还要从实到透明地渐隐下去。三件事看起来都在「改形状」，可你越写越发现，它们其实在问两个不同的问题——一是「哪些像素可见」，二是「可见的像素有多不透明」。

不掌握这两者的分工，你会陷入「用边框拼三角形、用定位盖住多余部分」的老套路：代码难懂、内容装不进去、换个尺寸就崩。更糟的是，你以为裁掉的部分就真的不存在了，可它只是「看不见」而已。

圆角方案写法

最朴素的做法：圆角和圆形交给 border-radius。头像写 border-radius: 50% 就是正圆，卡片写 border-radius: 12px 就是圆角。配合 overflow: hidden，连里面的内容也会被裁到圆角以内。

这个方案做对了一件重要的事：裁剪不改变布局尺寸。元素在文档流里占的位置分毫未动，只是四角被削圆了。这个「保留布局、只改可见」的思路，正是后面一切裁剪的基础。

硬边裁剪局限

  • 它只会圆角，做不出三角形、六边形、斜切边这类直边或折线形状。
  • 它只能给出「硬边」——边缘要么完全可见，要么完全不可见，实现不了从实到透明的渐隐。
  • 想用「透明边框拼三角形」的老技巧画尖角，得到的是一块空色块，塞不进图片或文字。
  • 面对「按一张图的透明度决定可见性」这种诉求，它连门都摸不到。

几何图形裁剪

不推翻「保留布局、只改可见」，而是把裁剪形状从「圆角一种」扩展成任意几何图形。这就是 clip-path：给它一个形状，它就按这个形状把元素的可渲染区域裁出来。常用的形状各有各的写法：

  • circle(50% at center)：半径 50%、圆心居中的圆。
  • ellipse(50% 40% at 50% 50%)：水平半径 50%、垂直半径 40% 的椭圆。
  • polygon(50% 0%, 0% 100%, 100% 100%)：按顶点坐标列表围出的多边形，三个顶点就是三角形。
  • inset(10px round 8px)：向内缩进 10px 再带 8px 圆角，正好覆盖圆角矩形场景。

六边形只需要把六个顶点按顺序列出来，例如 polygon(25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50%)。这里藏着一个必须先想清楚的性质：顶点坐标基于元素自身的百分比，所以元素放大缩小时，形状会跟着等比例缩放，而不是固定在某个像素位置。

两个必须记住的坑：其一，clip-path 会创建新的层叠上下文，它内部元素的 z-index 从此被隔离在这一层里比较；其二，被裁掉的区域虽然不可见，却无法接收点击事件——如果你把一个按钮裁小，露在外面的那部分才是真正可点的热区。

顺带一个收益：clip-path 可以参与 transition 做形状动效，比如悬停时圆从 10% 扩到 50%。但形状补间有个前提——两个形状的顶点数量与顺序必须一致，否则浏览器无法一一对应，动画会直接跳变。

现在回到「按透明度渐隐」这个需求。clip-path 只回答「可见或不可见」，答不了「半透明」，所以需要另一位主角：mask。它不读几何图形，而是读一张图像或一段渐变的透明通道——越不透明的地方越可见，越透明的地方越隐去。用 mask: linear-gradient(to bottom, black 0%, transparent 100%)，就能让元素顶部实、底部渐隐；换成 radial-gradient，则是中心实、边缘渐隐。

mask 现在已获主流浏览器无前缀支持，-webkit-mask 只作为旧版 Safari 的兼容写法保留。把四个常被混用的属性并排一看，分工就清楚了：

属性裁剪依据能否半透明是否保留布局空间
border-radius圆角几何否是
overflow: hidden内容盒边界否是（滚动/溢出被截断）
clip-path任意几何形状否（硬边）是
mask图像的透明通道是（可渐隐）是

一句话收束：要几何外形，用 clip-path；要透明度渐隐，用 mask。两者都保留布局空间，所以放心：无论怎么裁，元素在页面里占的位置都不会变。

形状与渐隐对照

裁剪与遮罩分工

裁剪的本质是「保留布局、只改可见」。clip-path 用 circle / ellipse / polygon / inset 把元素切成任意几何形状，代价是会新建层叠上下文、且被裁区域不可交互；mask 则按透明度通道做渐隐。坐标基于百分比，形状会随尺寸缩放。

「裁剪路径」指用 clip-path 以 circle / ellipse / polygon / inset / path 等几何形状，把元素的可渲染区域裁成非矩形：它保留布局空间，只裁剪可见与可交互的部分，被裁区域之外的点击不可达，同时会创建新的层叠上下文。与它互补的 mask 依据图片或渐变的 alpha 通道决定可见性，从而按透明度渐隐；两者都能配合 transition 做动效。

关键代码

CSS
/* clip-path：圆形裁剪 */
.clip-circle {
  clip-path: circle(50% at center);
  /* 半径 50%，中心为圆心 */
}

/* clip-path：椭圆裁剪 */
.clip-ellipse {
  clip-path: ellipse(50% 40% at 50% 50%);
  /* 水平半径 50%，垂直半径 40% */
}

/* clip-path：多边形裁剪（三角形） */
.clip-triangle {
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
  /* 顶点坐标列表 */
}

/* clip-path：多边形裁剪（六边形） */
.clip-hexagon {
  clip-path: polygon(25% 0%, 75% 0%, 100% 50%, 75% 100%, 25% 100%, 0% 50%);
}

/* clip-path：圆角矩形（inset） */
.clip-inset {
  clip-path: inset(10px round 8px);
  /* 四周内边距 + 圆角 */
}

/* 动画 clip-path */
.clip-anim {
  clip-path: circle(10% at center);
  transition: clip-path 0.5s ease;
}
.clip-anim:hover {
  clip-path: circle(50% at center);
}

/* mask 遮罩：用图像/渐变的透明度决定可见性 */
.mask-gradient {
  -webkit-mask: linear-gradient(to bottom, black 0%, transparent 100%);
  mask: linear-gradient(to bottom, black 0%, transparent 100%);
  /* 顶部不透明，底部渐隐 */
}

/* mask：径向渐变遮罩 */
.mask-radial {
  -webkit-mask: radial-gradient(circle, black 60%, transparent 100%);
  mask: radial-gradient(circle, black 60%, transparent 100%);
  /* 中心显示，边缘渐隐 */
}

/* 注意：clip-path 裁剪区域无法接收点击事件 */
/* mask 需要 -webkit-mask 前缀兼容 Safari */
