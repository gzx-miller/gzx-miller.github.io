sass:math 与单位安全计算

计算网格列宽，掌握 math.div、舍入和单位兼容边界。

开场问题：算栅格列宽写下 $col: 1000px / 3，编译报错；改用 math.div(1000px, 3) 通过了，可换成百分比 math.div(100%, 3) 又不对——问题到底出在除法语法，还是百分比根本不能这么算？

栅格列宽计算

你要做一个可配置的栅格：容器 1000px、3 列、列间距 16px，理想的单列宽就是 (1000px − 16px × 2) / 3。你希望列数和间距都是变量，改一个数就能重算全部，于是很自然地把这条公式写进 Sass，盼着编译期就把结果算好。

结果编译器先拦住了斜杠除法，改写成函数后，又被「百分比」这一项难住。这不只是语法问题——它逼你想清楚一件事：哪些数学是编译期就能算完的，哪些必须留给浏览器运行时。分不清这条界线，你要么算错，要么把本可静态计算的数字变成散落各处的魔法值。

手算写死数值

最朴素的两种办法：一是把结果手算出来写死，比如 width: 322.666px；二是凭直觉手写系数，既然整宽对应 100%，那三分之一列就是 33.333%。

它们都做对了同一件事：把「列宽」当成一个可以被表达式描述的结果，而不是碰运气调出来的数。只要列数不变，两种写法都能跑起来。

参数变更数值失效

  • 写死 322.666px 后，间距一改数字全废，容器尺寸一变更是无从下手。
  • 手写 33.333% 时忘了减去列间距，列与列直接挤在一起。
  • 斜杠除法语义已经弃用，$a / $b 现在不再稳定地代表除法，写法必须升级。
  • 百分比、vw、env()、var() 这些值在编译期根本不存在，Sass 无从计算。
  • 浮点结果不加处理就直接输出，会出现 33.3333333333% 这种长尾。

求值时机拆分

不推翻「用表达式算列宽」，而是按求值时机把计算拆成两半。第一半是编译期就确定的量——固定长度、纯数字，交给 sass:math 用明确的函数算清楚，其中除法统一写 math.div，不再用斜杠。第二半是依赖浏览器运行上下文的量——100%、vw、env()、var()，它们要等页面真正渲染时才知道值，Sass 不能也不该替它们求值，应当原样保留成 CSS calc() 表达式。

这两半还能安全地混用：calc() 里可以放 Sass 变量，编译时变量被替换成字面量，剩下的运算交给浏览器。而 sass:math 提供了一整套数字工具：math.div 做明确的除法、math.pow 求幂、math.round / math.ceil / math.floor 负责舍入、math.min / math.max 取最值、math.compatible 检查单位是否可换算。把魔法数字换成这些函数，公式的意图才真正留在代码里。

落到栅格这个场景，可以按下面的顺序实现：

  1. 在函数入口用 @error 校验输入约束，例如列数必须为正整数。
  2. 用 math.div 执行明确的除法，替代已弃用的斜杠写法。
  3. 编译期无法确定的部分（如百分比关系）保留成 calc()，交给浏览器求值。
  4. 把常用换算沉淀成函数，避免在业务样式中散落魔法数字。

举例来说，减去间距的部分是纯长度运算，可以在编译期算完；而「占容器几分之几」这种相对关系必须留在 calc() 中。把两者写在一起，Sass 负责前半段，浏览器负责后半段，各自的职责清晰分明，列数一改也不用重算任何系数。

两个容易忽略的边界：浮点结果要依据 CSS 的真实需要决定是否舍入，别让长尾小数进入产物；百分比与单位的换算规则以 sass:math 文档为准，不要凭直觉手写转换系数——直觉算出来的数，往往就是布局在极端尺寸下错位的原因。

编译与运行时分野

设计数学的可靠做法，是先分清「编译期算得出」和「只有运行时才算得出」。前者用 sass:math 明确求值，除法一律写 math.div；后者保留成 calc() 交给浏览器。把这条界线划清楚，公式既不会被写死，也不会在错误的地方求值。

「sass:math」是 Sass 的数字运算模块，提供 math.div（明确除法，替代已弃用的斜杠）、math.pow、math.round / math.ceil / math.floor、math.min / math.max 与单位检查 math.compatible。Sass 只能处理编译期已知的量，100%、vw、env()、var() 等运行时值应保留为 calc()，其中可混用 Sass 变量，编译后变量被替换为字面量。

关键代码

SCSS
@use "sass:math";

@function column-width($container, $columns, $gap) {
  @if $columns < 1 { @error "$columns 必须大于 0"; }
  @return math.div($container - $gap * ($columns - 1), $columns);
}

.card { width: column-width(1000px, 3, 16px); }
// 需要浏览器上下文时保留 calc(100% - 2rem)，不要提前求值。
