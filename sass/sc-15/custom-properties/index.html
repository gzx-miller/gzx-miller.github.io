CSS 自定义属性与 Sass 插值

把编译期令牌写入运行时 CSS 变量，并正确保留字符串。

开场问题：我想让用户能实时换主题色，于是写下 :root { --brand: $brand; }，结果页面一点颜色都没变，浏览器像是把这条声明当成了无效值——为什么 Sass 变量放进自定义属性里就「失灵」了？

变量与自定义属性

你手里有两套颜色命名方式：一套是 Sass 变量 $brand，在编译期求值、编译完就从产物里消失；另一套是 CSS 自定义属性 var(--brand)，浏览器认识它，能参与级联与继承，也能被脚本随时改写。

可业务的诉求是分裂的：「品牌色、间距」这类设计令牌希望编译期就固定下来；而「用户切主题、跟随系统深色、从本地存储读回用户偏好」这些必须在浏览器运行时才决定。Sass 变量天生做不到后者——它不会留在 CSS 里，JS 根本看不见它。

不用自定义属性的代价同样清楚：要么放弃运行时切换，每换一次主题就重新编译一次 Sass；要么把品牌色硬编码进 JavaScript，让同一个色值在样式和脚本两处各维护一份，改一处忘一处。

直接手写CSS变量

最朴素的做法：干脆不用 Sass 变量，直接在样式里手写 CSS 变量。

:root { --brand: #c45125; } .button { background: var(--brand); }

这个方案做对了最关键的一件事：运行时体系是对的。浏览器认识 var()，变量能继承、能级联、能被 element.style.setProperty 覆盖，不需要重新编译，主题切换立刻生效。

色值双来源分叉

  • 品牌色如今有两个来源：Sass 里的 $brand 和 CSS 里的 #c45125，改一处忘一处，色值悄悄分叉。
  • 设计令牌一多起来，把它们一个个手抄进 :root 既枯燥又容易抄错。
  • 想让 Sass 的计算结果——比如 color.scale 派生出的深色——也变成运行时变量，纯手写 CSS 根本表达不了这层计算。

插值写入自定义属性

关键的一步是让 Sass 去「写」这些自定义属性。但要注意一个坑：自定义属性的值在 Sass 眼里是任意 CSS 文本，默认会原样输出，不会替你求值。所以写 Sass 值进去时必须用插值 #{$brand}，把它显式地求出来：

:root { --brand: #{$brand}; } .button { background: var(--brand); color: var(--brand); }

这样品牌色只有一个来源 $brand，编译后自动落到 :root，而浏览器仍然可以在运行时改写它。派生色同理——先算出来，再插值进变量。

第二个坑来自字符串。如果被插值的值是带引号的字符串（最典型的是字体栈 "Inter", sans-serif），插值会把引号剥掉，得到没有引号的 Inter, sans-serif，声明可能因此失效。这时用 meta.inspect() 保留它的字面表示：

--font-stack: #{meta.inspect($font-stack)};

接着理清运行时那一侧：浏览器通过级联、继承或脚本改变量值。在 :root 上声明的是全局默认值；在组件作用域内重声明同名变量，就能做局部主题覆盖，不必牵动全局。主题切换只改值、不需要重新编译 Sass，这正是把令牌写进自定义属性的意义。

两个容易忽略的细节：自定义属性名大小写敏感，--Main 与 --main 是两个不同的变量；此外，插值通常会移除字符串引号，凡是依赖引号的声明都要用 meta.inspect 兜底。

回到最初那个问题，整条链路其实已经把它回答了：Sass 变量在编译期被求值后就从产物里消失，它根本进不了浏览器的运行时环境；而自定义属性的值会被原样保留进 CSS，所以必须由你亲手用插值把 Sass 的结果写进去。分不清这两者，就会一次次写出 --brand: $brand; 这种「看着对、编译后无效」的声明。

最后别忘验证：用浏览器开发者工具查看该自定义属性在运行时的最终值——它经过级联与覆盖之后是什么，只有元素检查器能告诉你，编译产物里看到的只是初始值。

改色免重新编译

编译期与运行时接力

Sass 变量和 CSS 自定义属性各守一段：前者在编译期定义令牌、参与计算，后者在运行时承载主题、参与级联。让两者接力的方式就是插值——把 Sass 值显式写进自定义属性；遇到带引号的字符串再用 meta.inspect 保住表示。分清「编译期常量」与「运行时变量」，这套协作才不会互相打架。

「CSS 自定义属性」是运行时可读写的 CSS 变量，参与级联与继承、能被脚本覆盖，而 Sass 变量只存在于编译期。把 Sass 值写进自定义属性必须用插值 #{$brand}；带引号字符串要用 meta.inspect() 保留引号，否则会被剥掉导致声明失效。变量名大小写敏感，主题切换只改值、无需重新编译。

关键代码

SCSS
@use "sass:meta";

$brand: #c45125;
$font-stack: "Noto Serif SC", serif;

:root {
  --brand: #{$brand};
  --font-display: #{meta.inspect($font-stack)};
}

.title { color: var(--brand); font-family: var(--font-display); }
// 自定义属性在浏览器运行时继承、级联并可被 JavaScript 更新。
