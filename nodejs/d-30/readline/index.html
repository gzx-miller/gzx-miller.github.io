readline 交互式输入

使用 readline 模块实现逐行读取和交互式命令行工具。

开场问题：你写了个小脚本，直接监听 process.stdin.on('data')，想一回合一回合地问用户；可用户一次粘贴了三行，回调一下子给你一大坨；换个环境把输入用管道灌进来，它又只给你半行。按「数据块」读，怎么就读不出「一行」？

字节流与行切分

你要做一个命令行工具：先问名字、再问年龄、最后确认，然后打印结果。输入来自终端，本质是字节流——用户敲一下、粘贴一段、或者用管道灌进来，到达的节奏和大小都不由你控制。

直接监听 data 事件，等于自己接手了所有麻烦：拿到的是一块块字节，不是行，一行可能分两次到、一次也可能来三行；要自己找换行、缓存残留、处理编码，还容易在边界上出错；要逐行处理大文件时，先 readFile 再按行切会把整份内容塞进内存；交互结束后终端状态和资源的恢复也容易漏。

问题落到一句话：怎样把「按块到达的字节流」变成「一行一行的事件」，并且把「提问—等待回答」这种异步流转表达清楚？

行事件回调接口

用 node:readline：readline.createInterface({ input, output }) 拿到一个接口对象，监听它的 'line' 事件，每凑齐一整行就触发一次回调，参数就是这一行的字符串。

这个方案做对了一件省心的事：它把「按块到达的字节流」翻译成「按行触发的事件」。分片、残留、换行判定、编码，这些原本要你自己扛的细节，全被收进接口内部；你只管对「一行」做业务处理。

回调嵌套与资源释放

  • 'line' 事件是推给你的：当一问依赖上一答时，只能在回调里再套一层回调，几步下来就成了回调金字塔。
  • 忘记调 rl.close()，接口不释放、进程迟迟不退出——因为 stdin 还活着，事件循环还有东西可等。
  • 要逐行处理大文件时，若先 readFile 再按行切，整份文件会常驻内存，文件一大就地爆；正确做法是把 createReadStream() 交给接口当输入。
  • 用户按下 Ctrl+C（SIGINT）时如果什么都不做，可能留下半截状态，终端也没被正确恢复。
  • 多选、输入校验、动态提示这类交互，用 'line' 一个个手写会迅速膨胀，越写越难维护。

提问原语与顺序化

先补上「提问」这个原语，因为交互式 CLI 的核心就是「打印提示、暂停等输入、收到一行后继续」。rl.question('请输入名字: ', callback) 一步到位：它打印提示、挂起等待，用户回车后把这一行交给回调。用提问串起四步，结构是这样的：

  1. 调 rl.question('请输入名字: ', ...)，等到答案，进入它的回调。
  2. 在回调里再调 rl.question('请输入年龄: ', ...)。
  3. 继续嵌套 rl.question('请选择语言: ', ...)。
  4. 最内层再问「确认提交？」，然后打印结果并 rl.close()。

四步就是四层嵌套，问题一眼可见：每多问一句就多一层缩进，「先做 A、拿到结果再做 B」的顺序被折进了回调里。于是补上现代写法：node:readline/promises 提供了 Promise 版接口，const name = await rl.question('名字: ')，把嵌套拉平成一条顺序执行的 async 函数。同样的四步，从四层嵌套变成四行顺序代码，可读性差别很大。

接着补流式处理大文件这条支线。readline 之所以被单独抽出来，是因为它面对的从来不只是终端：把 fs.createReadStream('big.log') 作为 input，'line' 事件就会随着文件被读入而逐行触发，任一时刻只有有限内容在内存里，多大的文件都不会撑爆。同一套「按行」的接口，既能驱动交互，又能扫大文件——这正是它的价值所在。

最后是收尾，别省。用 try ... finally 保证无论中间是否出错都调 rl.close()，让进程能干净退出；给 SIGINT 挂一个处理，在用户中断时把终端状态和资源恢复好；而当交互复杂到需要多选、校验、动态提示时，不必自己硬造，交给 inquirer 或 prompts 这类封装，readline 作为底层能力继续在它们下面工作。

四点提醒：readline 是处理流的低级 API，复杂交互推荐用 inquirer / prompts；交互结束务必 rl.close()，否则进程不退出；逐行处理大文件要用 createReadStream 当输入、按需消费，别整份读入内存；处理 SIGINT，保证终端状态与资源被正确恢复。

四步问答推进节奏

通用按行消费接口

readline 解决的是「把输入流按行消费」这件事：它把字节块翻译成一行一行的事件，于是同一套接口既能驱动「提问—等待回答」的交互式 CLI，也能流式扫过大文件。再配上 Promise 版接口把嵌套拉平、用 close 与 SIGINT 做好收尾，一个稳的 CLI 就成型了。

「标准输入（stdin）」指进程的标准输入流，可以是交互终端，也可以是被重定向的管道或文件。边界与例外：当它是终端（TTY）时，readline 会回显输入并显示提示符；一旦被重定向成管道或文件，它就不再是 TTY，逐行消费照常但交互行为不同；终端宽度、Ctrl+C（SIGINT）等行为也都依赖 TTY，处理时要按是否终端分别对待。

// 逐行读取大文件（内存高效）
function readFileLineByLine(filePath) {
  const rl = readline.createInterface({
    input: fs.createReadStream(filePath),
    crlfDelay: Infinity // 识别 \r\n 作为行结束
  })

  let lineCount = 0

  rl.on('line', (line) => {
    lineCount++
    console.log(`第 ${lineCount} 行: ${line}`)

    // 可以在需要时暂停

    // }
  })

  rl.on('close', () => {
    console.log(`文件读取完毕，共 ${lineCount} 行`)
  })

  return rl
}

// 创建交互式界面
function createInteractiveInterface() {
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    prompt: '> ',          // 提示符
    historySize: 100,      // 历史记录大小
    removeHistoryDuplicates: true
  })

  // 显示提示符
  rl.prompt()

  // 处理每行输入
  rl.on('line', (input) => {
    input = input.trim()

    switch (input.toLowerCase()) {
      case 'help':
        console.log('可用命令: help, hello, date, exit')
        break

      case 'hello':
        console.log('你好！欢迎使用交互式程序')
        break

      case 'date':
        console.log('当前时间:', new Date().toLocaleString())
        break

      case 'exit':
      case 'quit':
        console.log('再见！')
        rl.close()
        break

      default:
        console.log(`未知命令: ${input}`)
        console.log('输入 help 查看帮助')
    }

    rl.prompt()
  })

  rl.on('close', () => {
    console.log('\n程序退出')
    process.exit(0)
  })

  return rl
}

// 简单的提问函数
function askQuestion(question) {
  return new Promise((resolve) => {
    const rl = readline.createInterface({
      input: process.stdin,
      output: process.stdout
    })

    rl.question(question, (answer) => {
      rl.close()
      resolve(answer)
    })
  })
}

// 使用
async function askDemo() {
  const name = await askQuestion('你叫什么名字？')
  const age = await askQuestion('你多大了？')
  console.log(`你好，${name}！你今年 ${age} 岁。`)
}

// ───────── 密码输入（不回显） ─────────

function askPassword(question = '请输入密码: ') {
  return new Promise((resolve) => {
    const rl = readline.createInterface({
      input: process.stdin,
      output: process.stdout
    })

    // 方法1：用 silent 模式
    rl._writeToOutput = function _writeToOutput(stringToWrite) {
      // 只显示提示，不显示输入
      if (stringToWrite === question) {
        rl.output.write(question)
      }
    }

    rl.question(question, (password) => {
      rl.close()
      console.log() // 换行
      resolve(password)
    })
  })
}

// 更简单的方法（Node 15+）
function askPasswordV2(question = '请输入密码: ') {
  return new Promise((resolve) => {
    const rl = readline.createInterface({
      input: process.stdin,
      output: process.stdout
    })

    // 监听 keypress
    const stdin = process.stdin
    let password = ''

    process.stdout.write(question)

    stdin.setRawMode(true)
    stdin.resume()
    stdin.setEncoding('utf-8')

    const onData = (char) => {
      if (char === '\n' || char === '\r') {
        // 回车结束
        stdin.removeListener('data', onData)
        stdin.setRawMode(false)
        rl.close()
        console.log()
        resolve(password)
      } else if (char === '\u0003') {
        // Ctrl+C
        stdin.removeListener('data', onData)
        stdin.setRawMode(false)
        rl.close()
        process.exit()
      } else if (char === '\b' || char === '\u007f') {
        // 退格
        if (password.length > 0) {
          password = password.slice(0, -1)
          process.stdout.write('\b \b') // 删除一个字符
        }
      } else {
        // 普通字符
        password += char
        process.stdout.write('*') // 显示星号
      }
    }

    stdin.on('data', onData)
  })
}

async function interactiveForm() {
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  })

  const question = (q) => new Promise(resolve => rl.question(q, resolve))

  console.log('=== 用户注册 ===')

  const username = await question('用户名: ')
  const email = await question('邮箱: ')
  const password = await askPasswordV2('密码: ')

  console.log('\n=== 注册信息确认 ===')
  console.log(`用户名: ${username}`)
  console.log(`邮箱: ${email}`)
  console.log(`密码: ${'*'.repeat(password.length)}`)

  const confirm = await question('\n确认注册？(y/n): ')

  if (confirm.toLowerCase() === 'y' || confirm.toLowerCase() === 'yes') {
    console.log('注册成功！')
  } else {
    console.log('已取消注册')
  }

  rl.close()
}

function createShellWithCompletion() {
  const commands = ['help', 'hello', 'date', 'exit', 'quit', 'clear', 'history']

  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    prompt: '$ ',
    completer: (line) => {
      const hits = commands.filter(c => c.startsWith(line))
      return [hits.length ? hits : commands, line]
    }
  })

  rl.prompt()

  rl.on('line', (line) => {
    const cmd = line.trim().toLowerCase()

    if (cmd === 'exit' || cmd === 'quit') {
      rl.close()
      return
    }

    if (cmd === 'clear') {
      console.clear()
      rl.prompt()
      return
    }

    if (cmd === 'history') {
      rl.history.forEach((h, i) => {
        console.log(`  ${i + 1}: ${h}`)
      })
      rl.prompt()
      return
    }

    console.log(`执行命令: ${cmd}`)
    rl.prompt()
  })

  return rl
}
