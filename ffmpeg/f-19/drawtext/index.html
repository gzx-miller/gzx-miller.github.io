文字叠加与动态字幕（Drawtext）

使用 drawtext 滤镜在视频上添加动态文字，实现标题、台标、跑马灯、时间码显示等效果。

开场问题：你照着教程给视频加文字水印，命令一个字没改，回车却报 No such filter: 'drawtext'；好不容易换上带 libfreetype 的版本跑通了，中文又全部变成了一个个方块。

视频文字叠加需求

你想要的其实很常规：在视频上压一行标题、加一个台标、角落滚动一条公告，或者把当前时间码显示出来。旧办法各有各的别扭——用剪辑软件手动敲字，遇到成百上千个文件就废了，参数也没法脚本化；事先把文字做成 PNG 水印再用 overlay 叠上去，文字一改就得重做图，像实时时间码这种每帧都变的字，更是根本做不出来。

这些方案背后藏着三笔成本：文字要显示出来得依赖字体，而字体又依赖运行时的渲染库；命令里文本内容和滤镜语法共用冒号，一不小心就把参数拆错；动态文字必须靠表达式逐帧求值，写死了就只能是静态的。

所以要回答的是：怎么让 FFmpeg 直接在画面上画字，既能显示中文，又能随着时间变化？

文字滤镜基本写法

最基本的写法是在一条滤镜里把文字和位置交代清楚：ffmpeg -i input.mp4 -vf "drawtext=text='Hello World':x=10:y=10:fontsize=24:fontcolor=white" output.mp4。

它做对了一件本质的事：把「文字」当成一个逐帧渲染的滤镜，跟着每一帧画面一起绘出来。不需要外部素材、不需要剪辑软件，也就意味着它可以被写进脚本、批量套用。前提是这份 FFmpeg 在编译时启用了 libfreetype，并且有可用的字体。

字形缺失与转义限制

  • 编译时没带 libfreetype，滤镜根本不存在，直接报 No such filter: 'drawtext'。
  • 不指定 fontfile，默认字体的字库里没有中文字形，于是「你好」被画成一串方块。
  • 文本里的冒号、百分号在滤镜语法里有特殊含义，text='a:b' 会被当成参数分隔符拆错位置。
  • 像 %{pts\:hms} 这样的占位符，里面那个冒号本身也要转义，写漏一个就解析失败。
  • 命令在 shell 里已经过一层转义，滤镜里还有一层，两层叠起来，报错信息往往只指向「语法错误」，很难定位。
  • 把跑马灯、时间码的值写死是不行的——它们必须随帧变化。

字体与转义补齐

不推翻这条命令，而是按「先让它显示对，再让它动起来」的顺序，一层层补。

第一层解决「字体」。显式指定一个含中文字形的字体文件：fontfile=/Windows/Fonts/msyh.ttc（macOS、Linux 换成本机对应路径）。字体一给，方块立刻变成正常汉字。

第二层解决「转义地狱」。与其在命令行里和冒号、百分号反复搏斗，不如把要显示的文字写进一个 UTF-8 文本文件，再用 textfile=text.txt 引进来。文字里的标点统统不用转义，长文本、含冒号的文本都应该走这条路。

第三层补「定位」。x、y 支持表达式，而且能用上画面的宽高 w/h 和文字的宽高 tw/th：贴右下角写 x=w-tw-10:y=h-th-10，水平居中写 x=(w-tw)/2。位置的算法交给表达式，换分辨率也不用改。

第四层补「动态」。把参数写成逐帧求值的表达式，用上内置变量 t（当前秒数）和 n（帧号）：跑马灯 x=w-t*20 让文字随时间从右向左移；时间码 text='%{pts\:hms}' 显示成时:分:秒；帧号 text='Frame: %{n}' 直接打出第几帧。

第五层补「时段控制」。用 enable 指定文字只在某段时间出现，或者用 alpha 表达式做淡入，例如 alpha='if(lt(t,3),t/3,1)' 让标题在前三秒从透明渐显。

最后补「可读性」。给文字加描边 bordercolor/borderw，或者加背景框 boxcolor/boxborderw，这样不论压在亮画面还是暗画面上，字都看得清。

调试口诀：先简化文本。命令失败时，先把 text 里的冒号、百分号、反斜杠统统去掉，用一句纯字母试跑；确认链路通了，再逐段把特殊字符加回来。另外务必确认 fontfile 的路径真实存在——文件找不到时，报错不会直说是字体问题。

三类叠加写法对照

逐帧渲染滤镜机制

drawtext 的本质是「一个逐帧在画面上渲染文字的滤镜」。把它用顺只需三件事：给它一个含所需字形的字体文件；文本复杂就改用 textfile 绕开转义；要动起来就用逐帧求值的表达式，而不是写死数值。

「滤镜表达式」指 drawtext 的 x/y/text/alpha 等参数可以写成在每一帧求值的表达式，可用变量包括 t（秒）、n（帧号）、w/h（画面宽高）、tw/th（文字宽高）。边界：不是所有滤镜都逐帧求值，有些默认只算一次、需要 eval=frame 才每帧重算；表达式里的逗号、冒号在 shell 与滤镜两层都要转义。

关键代码

BASH
# 添加静态文字
ffmpeg -i input.mp4 -vf "drawtext=text='Hello World':x=10:y=10:fontsize=24:fontcolor=white" output.mp4

# 指定中文字体（Windows）
ffmpeg -i input.mp4 -vf "drawtext=fontfile=/Windows/Fonts/msyh.ttc:text='你好':x=10:y=10:fontsize=24:fontcolor=white" output.mp4

# 右下角水印 + 边框
ffmpeg -i input.mp4 -vf "drawtext=text='Watermark':x=w-tw-10:y=h-th-10:fontsize=20:fontcolor=white:bordercolor=black:borderw=2" output.mp4

# 显示时间码（HH:MM:SS）
ffmpeg -i input.mp4 -vf "drawtext=text='%{pts\:hms}':x=10:y=10:fontsize=20:fontcolor=white" output.mp4

# 跑马灯（从右向左滚动）
ffmpeg -i input.mp4 -vf "drawtext=text='Breaking News':x=w-t*20:y=H/2:fontsize=32:fontcolor=white" output.mp4

# 文字淡入（前 3 秒）
ffmpeg -i input.mp4 -vf "drawtext=text='Title':x=10:y=10:fontsize=32:fontcolor=white:alpha='if(lt(t,3),t/3,1)'" output.mp4
