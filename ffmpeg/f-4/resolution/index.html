分辨率调整与缩放滤镜

使用 scale 滤镜调整视频分辨率，掌握等比缩放、指定缩放、填充与裁剪等常见场景。

开场问题：你把一个 1080×1920 的竖屏视频缩到 720 高，按「自动算另一维」的写法写了 scale=-1:720，FFmpeg 却报错说宽度不能被 2 整除；把 -1 改成 -2 立刻就过了。同样表示「自动」，这两个数字差在哪？

宽高比与奇偶约束

不同设备要不同分辨率，缩放的诉求本身很直接。但「目标尺寸」从来不是一个孤立数字，它牵动两件事：一是保持原始的宽高比，否则画面会被拉伸变形；二是满足编码器对尺寸的奇偶约束，否则直接报错。

手工对付这两件事的成本很容易被低估：源是 1920×1080，要缩到高 720，你得自己算出宽是 720 × 1920 ÷ 1080 = 1280，还得确认它是偶数；换一个源、宽高比变了，整套数字又得重算。更常见的是把一组写死的宽高套到所有源上，遇到宽高比不同的素材就必然变形。所以真正的问题是：怎么在不手算、不变形的前提下，把视频缩到想要的分辨率？

双维尺寸直写

最直接的写法是两个尺寸都写死：ffmpeg -i input.mp4 -vf scale=1280:720 output.mp4。这是 scale 滤镜的基础语法 scale=width:height。

它做对了一件事：目标尺寸完全可控。你要 1280×720，就精确得到 1280×720，没有任何含糊。只要源本身就是 16:9，这条命令既准又省事。

画面拉伸与失真

  • 源不是 16:9 时，它把画面硬生生拉到 1280×720，人脸被压扁、圆形变椭圆。
  • 只想要「高 720、宽随便」时，宽度还得自己算，换一个源就要重算一次。
  • 手算出来的某一维可能是 1279 这样的奇数，编码器立刻报 width not divisible by 2。
  • 想「完整放进 1080×1080 又不裁掉任何内容」时，它只有拉伸这一条路，做不到适配。

自动推算另一维

不推翻它，而是把其中一维交给 FFmpeg，让它顺着原宽高比反推。写法是 scale=-1:720——负值表示「按原宽高比自动算这一维」。这样宽度不用手算，也不会变形。

但 -1 还会算出一个奇数。根子在色度二次采样：像 yuv420p 这类常用像素格式，色度信息是按 2×2 的块存的，所以画面宽高必须为偶数，否则编码器拒绝。把 -1 换成 -2，就是在「自动反推」的基础上再把结果取整到偶数，一步解决报错。所以等比缩放推荐一律用 -2。

再往下，会遇到「源宽高比和目标区域真的不一样」的场景——比如把竖屏塞进横屏播放区。这时要的是「在目标矩形内保持比例、又不放大」，用 force_original_aspect_ratio=decrease 让画面先缩进矩形里，再用 pad 把剩余部分补成黑边，得到「完整但不填满」的效果：

scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2

如果反过来想要「填满矩形、允许裁掉一些」，就把 decrease 换成 increase，再配合 crop 裁边。至于放大场景（小分辨率变大），可以顺手把算法从默认换成 flags=lanczos，画质会更好一些。

两条要记住的边界：上采样（把低分辨率放大）只会让画面更糊，并不能凭空补出细节，应尽量避免；scale 里若写出奇数尺寸会被编码器直接拒绝，宽高都要保持偶数，或用 -2 自动取偶。

参数联动与预览

等比缩放与取偶

缩放的关键不在「填一个尺寸」，而在「要不要保比例、要不要满足偶数」。只指定一维时用 -2 让 FFmpeg 自动取偶，比例不符时用 force_original_aspect_ratio 加补边或裁切，你就不用再手算，也不会变形或报错。

「色度二次采样」指为节省带宽，把颜色（色度）信息以比亮度更低的采样率存储的做法，常见形式有 yuv420p、yuv422p。边界与例外：受它影响，4:2:0 通常要求宽高都为偶数、4:2:2 只要求宽为偶数，这也是等比缩放推荐写 -2（而非 -1）的原因——-2 会把自动反推的结果取整到偶数。若换成不降采样的 yuv444p，这一约束就基本消失。

关键代码

BASH
# 缩放到 720p（保持宽高比，-2 确保偶数）
ffmpeg -i input.mp4 -vf scale=-2:720 output.mp4

# 指定宽度，高度自动
ffmpeg -i input.mp4 -vf scale=1280:-2 output.mp4

# 强制指定分辨率（可能变形）
ffmpeg -i input.mp4 -vf scale=1280:720 output.mp4

# 适配目标尺寸并添加黑边（不裁剪不变形）
ffmpeg -i input.mp4 -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2" output.mp4

# 使用 lanczos 算法缩放（放大时质量更好）
ffmpeg -i input.mp4 -vf scale=1920:1080:flags=lanczos output.mp4
