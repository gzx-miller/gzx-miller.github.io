事件处理：合成事件与处理器模式

用课程搜索和表单提交演示合成事件对象、preventDefault 与事件处理器设计。

开场问题：搜索框里填好关键词，你按下回车「提交一下」，页面却整个闪了一下重新加载，列表被清空、刚才的筛选也没了——只是提交一个表单，浏览器凭什么把整页都重来一遍？

表单默认提交行为

你在做一个纯前端驱动的搜索：输入关键词、点「提交」，结果区域随之更新。可真实跑起来，第一次提交就把你打回原形——页面刷新回到初始状态。这是 form 提交的浏览器默认行为：它本来就要导航到一个新地址，在单页应用里，等于把整个界面带走了。

顺着往下想，你会发现还有几件事需要被统一。事件本身的信息（是谁触发的、触发类型是什么、目标元素是哪个）在不同浏览器里字段名和取值并不完全一致；给页面上成百上千个可交互元素逐一挂监听器、再逐一清理，是一笔持续要人看管的开销；一旦事件处理器里还要访问组件状态，绑定 this 的麻烦又会冒出来。这些成本原本都得由写业务的人承担。

于是问题清楚了：如何可靠地拿到一份统一的事件信息、拿到后能干净地阻止默认行为，同时不必为每个元素手工挂事件？

阻止默认提交行为

最直接的一步是在提交处理器里拦下默认行为：function handleSubmit(e) { e.preventDefault(); /* 自己驱动界面更新 */ }，把刷新这件事从浏览器手里拿走，交给业务逻辑。

这个方案确实做对了一件事：它抓住了问题的核心——表单提交的默认动作是可以被「拒绝」的，一旦拦住，后续就完全由组件状态说了算。同时你也能从事件对象里读出 type、target 这些基本信息。

原生事件字段差异

  • 直接面向原生事件时，字段是按浏览器各异的：判断目标元素有的用 target、有的得退到 srcElement，按键信息在 keyCode 与 key 之间也不统一，你得自己写兼容分支。
  • 类组件里把方法直接当处理器用，this 会是 undefined，必须记得在构造函数里 bind，漏一次就在运行时炸。
  • 监听器要自己挂、自己清：组件卸载时忘掉一次，就是内存泄漏，或者对已卸载组件更新。
  • 若要给列表里每一个元素分别 addEventListener，元素一多，绑定与回收的开销都随规模增长。

合成事件统一封装

不推翻「事件处理器 + 阻止默认」，而是给事件包一层统一的外壳。React 提供合成事件对象（SyntheticEvent），它是浏览器原生事件的跨浏览器封装：你在处理器里拿到的 event，type、target、key 等字段都按统一接口给出，不必再写兼容分支；真要触达原生对象时用 event.nativeEvent，但大多数场景合成事件已经够用。

  1. 点击与输入：通过合成事件对象读取事件类型和触发目标，例如 event.type、event.target.tagName、event.target.value。
  2. 表单提交：在 onSubmit 里调用 preventDefault() 阻止浏览器刷新，改由提交处理器驱动状态更新。
  3. 键盘事件：用 event.key === 'Enter' 这类判断过滤特定按键，比如回车才记录一次搜索。
  4. 核对来源：把 event.type 与 event.target 打出来，确认事件确实来自你预期的元素。

分发方式也一并变了。从 React 17 起，事件不再是挂到 document 上，而是委托到 React 根容器统一分发：你写在 JSX 上的 onClick、onChange 只是声明「这里关心这个事件」，真正的监听器由 React 在根节点统一管理，所以不必担心为大量元素逐个绑定。又因为函数组件用闭包直接访问状态，处理器里读写 state 天然就是最新的，this 绑定的历史包袱也不用再背。

两个常见误会：早期 React 会对事件对象做「池化」复用，读取前要调用 persist()——这一点早已取消，如今在异步回调里读 event 字段是安全的，不必再 persist；另外，把表单包进 form、按钮设成 type="submit"，默认提交行为依然存在，想不刷新就必须自己 preventDefault()。

浏览器差异与合成事件

事件处理的要害有两处：一是别让表单的默认提交把页面带走，preventDefault() 把主动权交回组件；二是别自己跟浏览器差异和监听器生命周期较劲，用 React 的合成事件统一读取、交给根容器统一分发。处理器越短越好，复杂的逻辑拆成独立函数。

「合成事件（SyntheticEvent）」是 React 对浏览器原生事件的跨浏览器封装对象，统一了 type、target、key 等字段，并负责事件委托（React 17 起挂载到根容器而非 document）。边界与例外：出于性能的「事件池」机制已废除，无需再调用 persist()，异步读取字段也安全；需要原生对象时用 event.nativeEvent，但多数场景用不到。

import { useState } from 'react'
import { createRoot } from 'react-dom/client'

function EventDemo() {
  const [clickLog, setClickLog] = useState([])

  function handleClick(event) {
    setClickLog((prev) => [...prev, `点击类型：${event.type}，目标：${event.target.tagName}`])
  }

  function handleInputChange(event) {
    setClickLog((prev) => [...prev, `输入值：${event.target.value}`])
  }

  function handleKeyDown(event) {
    if (event.key === 'Enter') {
      setClickLog((prev) => [...prev, `按下 Enter：${event.target.value}`])
    }
  }

  return (
    <section className="panel">
      <strong>合成事件捕获</strong>
      <p className="muted">React 合成事件是浏览器原生事件的跨浏览器封装。</p>
      <div className="field">
        <label>课程搜索</label>
        <input placeholder="输入后按 Enter" onChange={handleInputChange} onKeyDown={handleKeyDown} />
      </div>
      <button onClick={handleClick}>点击记录事件</button>
      <div style={{ marginTop: '8px' }}>
        {clickLog.length > 0
          ? <ul>{clickLog.slice(-5).map((log, i) => <li key={i} className="muted">{log}</li>)}</ul>
          : <p className="muted">尚无事件记录。</p>
        }
      </div>
    </section>
  )
}

function PreventDefaultDemo() {
  const [submitted, setSubmitted] = useState(false)

  function handleSubmit(event) {
    event.preventDefault()
    setSubmitted(true)
    setTimeout(() => setSubmitted(false), 2000)
  }

  return (
    <section className="panel">
      <strong>阻止默认行为</strong>
      <p className="muted">表单提交需要 preventDefault 阻止浏览器刷新。</p>
      <form onSubmit={handleSubmit}>
        <div className="field">
          <label>课程名称</label>
          <input placeholder="输入课程名" />
        </div>
        <button type="submit">提交</button>
      </form>
      {submitted && <p className="success">表单已提交，页面未刷新！</p>}
    </section>
  )
}

function App() {
  const [tab, setTab] = useState('basic')

  return (
    <main className="app">
      <header>
        <p className="kicker">事件处理</p>
        <h3>合成事件与处理器模式</h3>
      </header>
      <div className="toolbar">
        <button className={tab === 'basic' ? '' : 'secondary'} onClick={() => setTab('basic')}>基础事件</button>
        <button className={tab === 'prevent' ? '' : 'secondary'} onClick={() => setTab('prevent')}>阻止默认</button>
      </div>
      {tab === 'basic' ? <EventDemo /> : <PreventDefaultDemo />}
    </main>
  )
}

createRoot(document.getElementById('root')).render(<App />)
