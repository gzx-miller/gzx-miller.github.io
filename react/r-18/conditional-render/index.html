条件渲染：逻辑与、三元表达式与提前返回

用课程列表与详情切换演示 &&、三元运算符和提前返回三种条件渲染方式。

开场问题：折扣区一直用 {count && <Discount />} 控制，跑了大半年都好好的；直到某次活动把 count 设成了 0，页面角落凭空多出一个孤零零的「0」——条件明明是假的，这个 0 究竟是谁渲染上去的？

条件渲染表达式化

你在给课程页加一块折扣提示：有时展示、有时不展示。React 里偏偏没有 v-if 这类模板指令，JSX 本身只是 JavaScript 的语法糖，所以「显不显示」这件事，最后必须落成一个普通的 JS 表达式。而 JSX 又会把表达式求出来的值直接当作要渲染的内容——这一点是理解后面所有坑的钥匙。

旧的写法往往带来两笔隐藏成本。其一，if/else 是语句而不是表达式，没法直接塞进 JSX，于是你要么把整块结构复制两份、要么把布局拆得七零八落。其二，页面上一堆「可选内容」如果各写各的开关，很快就会演变成到处是布尔 prop 和一串嵌套条件，读起来像在解谜。

于是问题清楚了：没有模板指令的情况下，用什么样的表达式写条件分支，既能让写法统一，又不会让不该显示的东西漏出来？

逻辑与返回规则

最省事的一招是逻辑与：{showDiscount && <Discount />}。左边为真，就返回并渲染右边那个元素；左边为假，整个表达式就等于左边这个假值，而 React 会忽略 false、null、undefined，于是什么都不渲染。

这个方案确实做对了一件事：它证明了条件渲染根本不需要新语法，一个 && 就能表达「满足才显示」。只要左侧真的是布尔，它既简洁又直观。

假值忽略与零值渲染

  • 当左侧是数字 0 时，{0 && <Discount />} 求值为 0，而 0 并不在那三个被忽略的值里，于是页面上实打实渲染出一个「0」——正是开场那一幕。
  • 同理，左侧是空字符串时会渲染出一个空文本节点，可能在布局里撑出一段看不见的间隙。
  • 多个分支用三元硬套，会写成 a ? <A /> : b ? <B /> : c ? <C /> : null 这样的嵌套链，读两遍才能对上号。
  • if/else 是语句，直接放进 JSX 会报错，只能被迫在外面先算好变量，或复制整段结构。

布尔判据显式转换

先给 && 补一条判据：左侧必须是真正的布尔。「数量」这类可能为 0 的值，要么显式写成 {count > 0 && ...}，要么干脆改用别的写法——问题从来不是 && 错，而是你把一个「数值」当成「真假」用了。

接着补上「二选一」这一层。当两条分支都要出现、且彼此对立，用三元运算符最清楚：{selected ? <CourseDetail /> : <CourseList />}，一眼能看出「有选中看详情、没选中看列表」。

再补上「分支在组件内部」这一层。如果某个分支之后剩下的逻辑还很多，写在 JSX 里的三元会越缩越深，这时更合适的是提前返回：在组件函数体最前面写一句 if (!course) return null，把无效情况就地处理掉，后面就是一条平坦的主干，再也不用为每段 JSX 套一层条件。

  1. 折扣区域用 && 控制：showDiscount 为 false 时不渲染任何内容。
  2. selected 用三元运算符在课程列表与详情之间二选一渲染。
  3. CourseDetail 内部用提前返回：没传课程时直接 return null。
  4. 把条件改成可能为 0 的数值，亲自验证渲染结果里冒出来的那个 0。

最后收一下结构：分支一多、或多个条件彼此互斥，就把它们拆成独立的子组件，让每个组件只负责一种形态，而不是把一长串三元堆在一个函数里。用哪种写法由可读性决定，本来就没有唯一的标准答案。

三种条件渲染对照

显示逻辑交给表达式

条件渲染的本质，是把「显不显示」交给一个 JS 表达式：&& 用于「满足才显示」，三元用于「二选一」，分支留在组件内部且后面还长时就提前返回。写的时候盯紧一件事——表达式求出来的值会被真的渲染出来，所以别让 0 这种假值混进「不渲染」的位置。

「提前返回（Early Return）」指在组件函数体的开头用 if 处理掉无效或特殊情形并直接 return（常配 return null 表示不渲染任何内容），使其后的 JSX 保持单一主干。边界与例外：它只能写在组件函数体里，无法嵌进某一段 JSX 的中间；return null 只是渲染为空，组件仍会挂载并执行其中的 Hook。

关键代码

JSX
import { useState } from 'react'
import { createRoot } from 'react-dom/client'

function CourseDetail({ course, onClose }) {
  if (!course) return null

  return (
    <section className="panel">
      <strong>{course.title}</strong>
      <p className="muted">难度：{course.level} · 时长：{course.duration}</p>
      <p className="muted">{course.description}</p>
      <button className="secondary" onClick={onClose}>返回列表</button>
    </section>
  )
}

function CourseList({ courses, onSelect }) {
  return (
    <div className="grid">
      {courses.map((course) => (
        <button key={course.id} className="secondary" onClick={() => onSelect(course)}>
          {course.title}
        </button>
      ))}
    </div>
  )
}

function App() {
  const courses = [
    { id: 1, title: 'React 条件渲染', level: '基础', duration: '2h', description: '掌握逻辑与、三元表达式和提前返回三种条件渲染方式。' },
    { id: 2, title: 'Hooks 深入', level: '进阶', duration: '3h', description: '理解 Hooks 规则、闭包陷阱和自定义 Hook 设计。' },
    { id: 3, title: '并发模式实战', level: '高级', duration: '4h', description: '用 Transition 和 DeferredValue 优化用户交互体验。' },
  ]

  const [selected, setSelected] = useState(null)
  const [showDiscount, setShowDiscount] = useState(false)

  return (
    <main className="app">
      <header>
        <p className="kicker">条件渲染</p>
        <h3>逻辑与、三元表达式与提前返回</h3>
      </header>
      <div className="toolbar">
        <button className="secondary" onClick={() => setShowDiscount((v) => !v)}>
          {showDiscount ? '隐藏折扣' : '显示折扣'}
        </button>
      </div>
      {showDiscount && (
        <div className="panel" style={{ background: '#fff4dd' }}>
          <strong>秋季特惠</strong>
          <p className="muted">所有课程限时八折，逻辑与 (&&) 控制此区域显示。</p>
        </div>
      )}
      {selected
        ? <CourseDetail course={selected} onClose={() => setSelected(null)} />
        : <CourseList courses={courses} onSelect={setSelected} />
      }
      <p className="muted">
        {selected ? '当前使用提前返回模式展示详情。' : '未选择课程时展示列表，选择后切换为详情。三元运算符控制两种视图。'}
      </p>
    </main>
  )
}

createRoot(document.getElementById('root')).render(<App />)
