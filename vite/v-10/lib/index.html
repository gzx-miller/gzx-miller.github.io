库模式

使用 Vite 构建可发布的 npm 包，同时输出 ESM/UMD/CJS 格式。

开场问题：你发布了一个 Vue 组件库。同事装进项目后，组件能显示但交互全乱——点按钮没反应。排查半天才发现：页面上同时加载了两份 Vue，一份是他的应用自带的，一份是你的库打包进去的。

消费环境未知

你要写一个「给别人用」的库，而别人的环境是未知的：有人用 Vite/webpack 按 ESM 引入，有人直接在 HTML 里挂 CDN 的 <script>，还有人在 Node 里 require。同时，一个 Vue 组件库有个绝不能踩的雷——Vue 不能被你自己打进库里，否则使用方的应用和你的库各带一份 Vue，两套响应式系统互不认识，交互就会像开头那样全部错乱。

若照搬打包应用的方式去构建库，人要付出的隐藏成本是：产物格式单一，只有一种引用方式能用；框架依赖被整份打进去，制造多实例；类型声明与包入口字段要人手工对齐，漏一个使用者就报错。于是问题变成：怎么一次构建同时产出多种模块格式，并把框架依赖留给使用方提供？

应用式产物局限

最直接的想法：像打包应用一样构建，产出一个 bundle 发出去。

这个方案做对了一件事：库的代码确实被收敛成了可发布的文件，能装进任意项目里被引用。

产物格式单一

  • 格式单一：产物若是 CJS，CDN 的 <script> 用不了；若是 UMD，Node 的 require 又要绕。使用者被格式绑死。
  • 框架重复：vue 被打进库产物，使用方自己也有一份，页面上出现两个 Vue 实例，响应式与插件注册全部错乱。
  • UMD 全局名没映射：库内部 import 'vue'，打到 UMD 里得去全局找一个叫 Vue 的变量，不告诉它名字就报 Vue is not defined。
  • 类型与入口对不上：有产物却没有 .d.ts，或 package.json 的入口字段指向不存在的文件，使用者一装就红。

多格式并行输出

先补「一次输出多种格式」。Vite 的 build.lib 让你一次构建产出多种模块格式，用 formats 列出 ['es', 'cjs', 'umd']，用 fileName 按格式生成文件名。三种格式各有归属：ESM 给现代打包器按需引入，UMD 给 CDN 的 <script> 直接用，CJS 给 Node 的 require。一份源码，三种消费方式。

接着补「把框架外部化」。要解决多实例，就得告诉 Rollup：vue 不要打进来，交给使用方提供。这就是 rollupOptions.external，把 vue 填进去它就不再进入产物；UMD 场景下还要配 output.globals，把库里的模块名 vue 映射成全局变量 Vue，否则 CDN 引用时会报 Vue is not defined。映射关系就是「模块名 → 全局变量名」。

再补「告诉使用方这是依赖，而不是塞给他」。产物的入口字段要写清楚，让构建工具知道去哪找不同格式，并声明框架由使用方提供：用 package.json 的 module 指向 ESM 产物、main 指向 CJS/UMD，用 exports 的条件映射分别对应 import / require / types；再用 peerDependencies 声明 vue，从声明层面杜绝多实例。

最后补「类型声明与 CSS」。类型声明 Rollup 不会自动生成，要用 vite-plugin-dts 生成 .d.ts，并保证 exports 的 types 指向它；而库里的 CSS 会被单独产出一个文件，需要使用者手动引入，例如 import 'my-lib/dist/style.css'——这一条一定要写进文档，否则使用者会看到一堆没有样式的组件。

两条必守的线：框架依赖要用 external 加 peerDependencies 双保险，绝不能打进产物，否则使用方页面会出现两份 Vue；库的 CSS 不会随 JS 自动生效，必须由使用方手动引入，务必写进文档。

发布字段与格式

外部化依赖处理

库模式做的事，是让一份源码适配所有消费环境：用 build.lib 一次输出 ESM / UMD / CJS 三种格式，用 external 加 globals 把框架依赖让给使用方，用 package.json 的入口字段与 peerDependencies 把「从哪引、谁提供依赖」交代清楚。库不是应用，它的产物要服务于你见不到的使用者。

「外部化（external）」指打包时把某个依赖排除出产物、交由使用方提供；UMD 场景再配合 output.globals 把模块名映射为全局变量，避免同一依赖被打包多份。边界：external 只保证「不打包」，并不保证运行时能找到——使用方必须自行安装并正确引入；框架类依赖还应同时在 peerDependencies 里声明。

关键代码

TypeScript
// vite.config.ts - 库模式配置
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'node:path'

export default defineConfig({
  plugins: [vue()],
  build: {
    lib: {
      // 入口文件
      entry: resolve(__dirname, 'src/index.ts'),
      
      // 包名（UMD 格式需要）
      name: 'MyLibrary',
      
      // 输出格式
      formats: ['es', 'cjs', 'umd'],
      
      // 输出文件名
      fileName: (format) => `my-library.${format}.js`
    },
    
    rollupOptions: {
      // 外部化依赖（不打包进产物）
      external: ['vue', 'vue-router'],
      
      output: {
        // UMD 格式下的全局变量映射
        globals: {
          vue: 'Vue',
          'vue-router': 'VueRouter'
        }
      }
    }
  }
})

// 库入口文件示例 (src/index.ts)
// ====================

// 导出组件
export { default as Button } from './components/Button.vue'
export { default as Input } from './components/Input.vue'

// 导出 composable
export { useCounter } from './composables/useCounter'
export { useForm } from './composables/useForm'

// 导出工具函数
export { formatDate, debounce } from './utils'

// 导出类型
export type { ButtonProps, InputProps } from './types'

// ====================
// package.json 配置
// ====================

// {

//   "version": "1.0.0",
//   "type": "module",
//   // ESM 入口
//   "module": "./dist/my-library.es.js",
//   // CJS 入口
//   "main": "./dist/my-library.cjs.js",
//   // 类型声明入口
//   "types": "./dist/index.d.ts",
//   // 导出映射
//   "exports": {
//     ".": {
//       "import": "./dist/my-library.es.js",
//       "require": "./dist/my-library.cjs.js",
//       "types": "./dist/index.d.ts"
//     }
//   },
//   // peer dependencies
//   "peerDependencies": {
//     "vue": "^3.0.0"
//   },
//   // 文件发布到 npm
//   "files": ["dist"]
// }

// ====================
// 生成类型声明（配合 vite-plugin-dts）
// ====================

import dts from 'vite-plugin-dts'

export default defineConfig({
  plugins: [
    vue(),
    dts({
      // 输出目录
      outDir: 'dist',
      // 是否插入类型入口
      insertTypesEntry: true,
      // 包含的文件
      include: ['src/**/*.ts', 'src/**/*.vue']
    })
  ],
  build: {
    lib: {
      entry: 'src/index.ts',
      name: 'MyLibrary',
      formats: ['es', 'cjs']
    }
  }
})
