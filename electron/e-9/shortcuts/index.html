全局快捷键与菜单快捷键

注册 globalShortcut 全局快捷键（应用未聚焦也能触发）与菜单 accelerator，掌握冲突检查与退出时的资源释放。

开场问题：你给应用做了个"按 Ctrl+Shift+K 唤起窗口"的功能，用 globalShortcut.register 注册。上线后有人反馈按了没反应——那个组合被输入法抢先占用了，而 register 返回的 false 你根本没看；更糟的是，有人退出应用后这个键在别的软件里也失灵了，只能重启电脑。

未聚焦唤起需求

你希望应用不在前台时也能被一个按键唤起——比如全局截图、快速记一笔。但渲染进程里能监听的只有 keydown，而它只在窗口聚焦时收到事件：用户一切到别的软件，你的按键监听就是死的。

想让"未聚焦也响应"就得去系统层注册按键，这里有三笔隐藏成本：跨平台没有统一的自建接口，各系统的全局钩子 API 完全不同，自己写等于维护三套；键位是全局共享资源，你占了别的应用就用不了，不检测冲突就会静默失败、或者霸占别人的常用键；注册了就必须释放，忘了注销，应用退出后那条按键绑定还留在系统里，别的软件按这个键也没反应，用户只能重启。

所以要问的是：怎样让按键在应用未聚焦时也能触发，并且不抢占、不残留？

系统级按键注册

最直接的写法是在主进程里调 globalShortcut.register('CommandOrControl+Shift+K', callback)，放在 app.whenReady() 之后注册。

这个方案做对了一件事：它拿到的是系统级的按键监听，应用不在前台也能被触发。CommandOrControl 前缀还能自动跨平台——macOS 上是 ⌘、其他系统是 Ctrl。

键位冲突与重复注册

  • 不看 register 的返回值：键位被别的应用占用时返回 false，回调根本不触发，而你毫不知情，用户按了没反应只能来投诉。
  • 不检测是否已注册：同一个键位注册两次，第二次静默失败或覆盖，行为变得不确定。
  • 退出时不注销：应用关了，系统里的按键绑定还在，别的软件按这个键也没反应，直到重启电脑。
  • 在渲染进程里注册：keydown 只在窗口聚焦时触发，切走就失效——想要"全局"却写错了地方。
  • 用系统保留键（如 Ctrl+Alt+Delete）：操作系统自己占用，永远注册不上。
  • 回调里直接操作某个窗口变量：用户切走期间窗口可能已被关闭，回调触发时操作的是已销毁的窗口。

注册校验与退出注销

第一步，注册前检查、注册后校验。先用 globalShortcut.isRegistered(accel) 看这个键是否已被占用，再调 register 并用它的布尔返回值确认是否成功；一旦失败，就给用户一个降级提示（换个键、或告知"该键已被占用"），绝不强行覆盖别人的键位。

第二步，确认注册地点。globalShortcut 只能在主进程使用；如果键位要由用户界面触发注册，就经 preload + IPC 把键位传给主进程去注册，触发时主进程再决定是直接执行动作、还是把事件回传渲染进程。

第三步，退出时务必释放。在 will-quit 里调用 globalShortcut.unregisterAll()（或逐个 unregister）。这是硬性要求——不释放，残留的系统级绑定会一直占着那个键。

第四步，把两种快捷键分清楚，这是本课最容易混的地方：

  1. 菜单 accelerator：写在 MenuItem 上，由菜单系统自动注册，会显示在菜单里，只在应用聚焦（菜单栏可见）时生效。
  2. 全局快捷键 globalShortcut：系统级，应用未聚焦也能触发，不显示在任何界面上，需要你自己管生命周期（注册、检查、注销）。
  3. 同一个功能不要两处都绑：既写 accelerator 又用 globalShortcut 注册同一个键，会互相冲突。

最后补可配置与健壮性。把用户的键位存进配置，启动时统一注册；改键时先注销旧绑定、再注册新绑定；回调里操作窗口前先确认它仍然存在（必要时重建），不要假设用户切走的这段时间里窗口一直可用。

别混淆这两者：accelerator 只在应用聚焦时生效，需要"未聚焦也响应"就必须用 globalShortcut；而全局快捷键是系统级资源，注册失败时应给出降级提示，而不是强行抢占。

快捷键勾选触发

全局注册归属边界

要让按键在应用未聚焦时也生效，就得用主进程的 globalShortcut：注册前用 isRegistered 查冲突、用返回值确认成败，退出时在 will-quit 里 unregisterAll 释放。它和菜单上的 accelerator 是两回事——前者是系统级资源、要自己管生命周期，后者交给菜单系统、只在聚焦时生效。

「accelerator（加速度键）」是写在 MenuItem 上、用来声明快捷键的字符串，如 CmdOrCtrl+Shift+K；用 CmdOrCtrl 前缀即可跨平台，菜单系统会自动注册并把它显示在菜单项右侧。它的边界是只在应用聚焦时生效、也不等于全局快捷键；若要应用未聚焦也响应，必须另用 globalShortcut 注册，且不要让两者绑定同一个键位。

// ========== 1. 全局快捷键 main.js ==========
const { app, BrowserWindow, globalShortcut, Menu } = require('electron')
const path = require('path')

// 注册全局快捷键
function registerGlobalShortcuts() {
  // 注册单个快捷键
  const ret = globalShortcut.register('CommandOrControl+Alt+K', () => {
    console.log('用户按下了 Ctrl+Alt+K')
    // 显示/隐藏窗口
    toggleWindow()
  })

  if (!ret) {
    console.log('快捷键注册失败（可能被其他应用占用）')
  }

  // 检查快捷键是否注册成功
  console.log('快捷键已注册:', globalShortcut.isRegistered('CommandOrControl+Alt+K'))

  // 注册媒体快捷键
  globalShortcut.register('MediaPlayPause', () => {
    console.log('播放/暂停')
  })

  globalShortcut.register('MediaNextTrack', () => {
    console.log('下一首')
  })

  globalShortcut.register('MediaPreviousTrack', () => {
    console.log('上一首')
  })
}

// 切换窗口显示/隐藏
let mainWindow = null
function toggleWindow() {
  if (!mainWindow) return

  if (mainWindow.isVisible()) {
    mainWindow.hide()
  } else {
    mainWindow.show()
    mainWindow.focus()
  }
}

// ========== 2. 注销快捷键 ==========
function unregisterShortcuts() {
  // 注销单个快捷键
  globalShortcut.unregister('CommandOrControl+Alt+K')

  // 注销所有快捷键
  globalShortcut.unregisterAll()
}

// 应用退出时必须注销
app.on('will-quit', () => {
  unregisterShortcuts()
})

// ========== 3. 菜单快捷键（accelerator） ==========
// 菜单快捷键不需要手动注册，定义在 MenuItem 中即可
function createMenuWithShortcuts() {
  const template = [
    {
      label: '文件',
      submenu: [
        {
          label: '新建',
          accelerator: 'CmdOrCtrl+N',
          click: () => {
            console.log('新建文件')
          }
        },
        {
          label: '打开',
          accelerator: 'CmdOrCtrl+O',
          click: () => {}
        },
        {
          label: '保存',
          accelerator: 'CmdOrCtrl+S',
          click: () => {}
        },
        {
          label: '另存为',
          accelerator: 'CmdOrCtrl+Shift+S',
          click: () => {}
        }
      ]
    },
    {
      label: '编辑',
      submenu: [
        { role: 'undo', accelerator: 'CmdOrCtrl+Z' },
        { role: 'redo', accelerator: 'CmdOrCtrl+Shift+Z' },
        { type: 'separator' },
        { role: 'cut' },
        { role: 'copy' },
        { role: 'paste' }
      ]
    },
    {
      label: '视图',
      submenu: [
        {
          label: '刷新',
          accelerator: 'F5',
          click: () => {
            if (mainWindow) {
              mainWindow.webContents.reload()
            }
          }
        },
        {
          label: '开发者工具',
          accelerator: 'F12',
          // 或 accelerator: 'CmdOrCtrl+Shift+I',
          click: () => {
            if (mainWindow) {
              mainWindow.webContents.toggleDevTools()
            }
          }
        },
        {
          label: '全屏',
          accelerator: 'F11',
          click: () => {
            if (mainWindow) {
              mainWindow.setFullScreen(!mainWindow.isFullScreen())
            }
          }
        }
      ]
    }
  ]

  const menu = Menu.buildFromTemplate(template)
  Menu.setApplicationMenu(menu)
}

// ========== 7. 快捷键冲突处理 ==========
function safeRegister(accelerator, callback) {
  // 先检查是否已被注册
  if (globalShortcut.isRegistered(accelerator)) {
    console.warn(`快捷键 ${accelerator} 已被占用`)
    return false
  }

  const success = globalShortcut.register(accelerator, callback)
  if (!success) {
    console.error(`注册快捷键失败: ${accelerator}`)
  }
  return success
}
