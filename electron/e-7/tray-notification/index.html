系统托盘与通知

创建系统托盘图标并挂上菜单，通过 click/右键交互切换窗口显示，实现后台常驻。

开场问题：你在函数里写下 const tray = new Tray(icon)，刚启动时托盘区确实出现了图标；可过一会儿它自己就消失了，程序没崩、控制台也没有任何报错——一个"常驻"图标怎么会自己溜走？

后台常驻入口需求

你想做一个能待在后台的应用：用户点了窗口右上角的 ×，程序不退出，而是缩进系统托盘区，需要时再从那里唤回来。可如果没有这个常驻入口，用户一关窗就彻底找不到应用了——任务栏里没了、桌面也看不见，只剩一个还在占内存、占端口的"幽灵进程"，只能去任务管理器把它杀掉。

想在托盘区放个图标，自己动手会有三笔隐藏成本：图标不是画上去就完事，它得由系统托管、随时可点击，还要在深浅色主题下都看得清；关闭语义必须拆开，"关掉窗口"和"退出应用"是两件事，混在一起要么关不掉、要么误退出丢掉未保存的数据；点击行为要区分左右键，左键通常切换窗口显隐，右键要弹出菜单，做成一样用户就懵了。

所以要问的是：怎样在系统层面放一个受管理的常驻入口，既能随时唤回窗口，又能把"关窗"和"退出"这两件性质完全不同的事讲清楚？

托盘实例与菜单挂载

最朴素的写法是用 new Tray(icon) 创建托盘，再用 setToolTip 设悬停提示、用 setContextMenu 挂上右键菜单。

这个方案做对了一件事：它给了应用一个由操作系统托管的常驻入口。窗口可以藏起来，入口还在；而这一切都在主进程完成，因为托盘是系统资源，渲染进程根本碰不到它。

图标回收与引用失效

  • 把 Tray 实例存在函数局部变量里：函数返回后没有任何强引用，图标被垃圾回收，悄无声息地消失，还不报错。
  • 图标随便传一张 256×256 的彩色 PNG：在只有十几像素的托盘区被压得模糊；macOS 上不用黑白模板图，深色菜单栏里几乎看不见。
  • 只监听 click 切换显隐：Windows 上左键和右键都被算作点击，用户想右键看菜单，窗口却被切没了。
  • 关窗时无脑 preventDefault() 加 hide()：用户从系统层面关窗、或系统注销时也无法退出，应用"关不掉"。
  • 没提供任何"退出"入口：用户想正常退出只能去杀进程。

模块级引用与退出语义

先补最要命的一条——让引用活着。把 Tray 提升为模块级的全局变量持有（而不是函数里的局部变量），这样它才不会被垃圾回收；这也是官方文档反复强调的"必须保持对 Tray 的引用"。

第二步挂上右键菜单：tray.setContextMenu(Menu.buildFromTemplate([...]))，放"显示主窗口 / 隐藏主窗口 / 设置 / 退出"几项。菜单模板和上一课同源，只是挂在托盘上；"退出"这一项要调用 app.quit()。

第三步拆开关闭语义，这是托盘应用最核心的一步：

  1. 维护一个 isQuitting 标志，从托盘的"退出"菜单进入时先把它置为 true。
  2. 拦截窗口的 close：如果 isQuitting 为真，就放行，让窗口真正关闭、应用真正退出。
  3. 否则 event.preventDefault() 并 win.hide()，把窗口藏进托盘。
  4. 顺手弹一条 Notification 告诉用户"程序仍在托盘继续运行"，免得他以为应用被关掉了。

第四步补点击行为：单击 click 用 mainWindow.isVisible() 判断后切换显隐，双击 double-click 则显示并聚焦。macOS 上单击通常只弹菜单，双击行为按平台适配即可。

最后补平台细节。macOS 的托盘图标建议用黑白模板图像（并准备 @2x 版本），系统会自动适配深浅色；纯托盘应用还可以用 app.dock.hide() 隐藏 Dock 图标，再用 setBadge 显示未读角标。通知要在 app.whenReady() 之后再弹。

一个后果常被忽略：一旦拦截了 close，window-all-closed 就不再等于"用户想退出"了——窗口全被藏起来，事件根本不会触发。也就是说，退出意图只能由显式的"退出"菜单项来传递；忘了给这个入口，用户就会觉得应用"关不掉"。

常驻应用三项职责

托盘应用要同时管好三件事：让 Tray 实例被全局持有、别被 GC 回收；用 setContextMenu 把菜单挂上去、用 click 切换窗口显隐；并把"关窗"和"退出"彻底分开——普通关闭只隐藏，只有显式的"退出"才走 app.quit()。这三条立住，后台常驻才真的可用。

「模板图像（template image）」是 macOS 上的一种特殊图标：你提供一张纯黑白（带透明通道）的图并标记为模板，系统会据此在浅色与深色菜单栏中自动反色，让它始终清晰。它的边界是只对 macOS 有意义——Windows 与 Linux 请用普通彩色 PNG，并按 16×16 与 32×32（@2x）两档准备尺寸，否则会被拉伸失真。

// ========== 1. 系统托盘 main.js ==========
const { app, BrowserWindow, Tray, Menu, Notification, nativeImage } = require('electron')
const path = require('path')

let tray = null
let mainWindow = null

// 创建系统托盘
function createTray() {
  // 托盘图标（推荐使用 16x16 和 32x32 的 PNG）
  const iconPath = path.join(__dirname, 'assets/tray-icon.png')
  const trayIcon = nativeImage.createFromPath(iconPath)

  tray = new Tray(trayIcon)

  // 设置托盘提示文字
  tray.setToolTip('我的 Electron 应用')

  // 设置托盘菜单
  const contextMenu = Menu.buildFromTemplate([
    {
      label: '显示主窗口',
      click: () => {
        if (mainWindow) {
          mainWindow.show()
          mainWindow.focus()
        }
      }
    },
    {
      label: '隐藏主窗口',
      click: () => {
        if (mainWindow) {
          mainWindow.hide()
        }
      }
    },
    { type: 'separator' },
    {
      label: '设置',
      click: () => {
        console.log('打开设置')
      }
    },
    { type: 'separator' },
    {
      label: '退出',
      click: () => {
        app.quit()
      }
    }
  ])

  tray.setContextMenu(contextMenu)

  // 单击托盘图标事件
  tray.on('click', () => {
    if (mainWindow) {
      if (mainWindow.isVisible()) {
        mainWindow.hide()
      } else {
        mainWindow.show()
      }
    }
  })

  // 双击托盘图标事件
  tray.on('double-click', () => {
    if (mainWindow) {
      mainWindow.show()
      mainWindow.focus()
    }
  })

  // 右键点击（通常显示上下文菜单，Electron 已自动处理）
  tray.on('right-click', () => {
    tray.popUpContextMenu()
  })
}

// ========== 2. 更新托盘图标 ==========
function updateTrayIcon(hasNotification) {
  if (!tray) return

  const iconName = hasNotification ? 'tray-icon-unread.png' : 'tray-icon.png'
  const iconPath = path.join(__dirname, 'assets', iconName)
  tray.setImage(nativeImage.createFromPath(iconPath))
}

// ========== 3. 系统通知 ==========
// 简单通知
function showNotification(title, body) {
  const notification = new Notification({
    title: title,
    body: body,
    // 图标
    icon: path.join(__dirname, 'assets/notification-icon.png'),
    // 声音（macOS）
    silent: false,
    // 超时时间
    timeoutType: 'default' // 'default' 或 'never'
  })

  notification.show()

  // 通知被点击
  notification.on('click', () => {
    console.log('通知被点击')
    if (mainWindow) {
      mainWindow.show()
      mainWindow.focus()
    }
  })

  // 通知关闭
  notification.on('close', () => {
    console.log('通知已关闭')
  })

  // 通知操作按钮（仅部分平台支持）
  // notification.on('action', (event, index) => {
  //   console.log('点击了操作按钮:', index)
  // })
}

// 通知示例
function showDownloadComplete() {
  showNotification(
    '下载完成',
    '文件已经下载完成，点击查看'
  )

// ========== 4. 完整的托盘应用模式 ==========
// 关闭窗口时最小化到托盘，而不是退出
function createMainWindow() {
  const win = new BrowserWindow({
    width: 800,
    height: 600,
    show: false, // 初始不显示，等 ready-to-show
    webPreferences: {
      preload: path.join(__dirname, 'preload.js'),
      contextIsolation: true
    }
  })

  win.loadFile('index.html')

  // 准备好再显示
  win.once('ready-to-show', () => {
    win.show()
  })

  // 窗口关闭时隐藏到托盘（不退出应用）
  win.on('close', (event) => {
    // 如果是用户主动退出应用（通过托盘菜单退出），则真的关闭
    if (app.isQuiting) {
      return
    }

    // 否则隐藏到托盘
    event.preventDefault()
    win.hide()

    // 显示通知告知用户
    showNotification('应用已最小化', '程序在系统托盘中继续运行')
  })

  return win
}

// 自定义退出方法
function quitApp() {
  app.isQuiting = true
  app.quit()
}

// ========== 5. macOS Dock 图标隐藏 ==========
// 纯托盘应用可以隐藏 Dock 图标
function setupDock() {
  if (process.platform === 'darwin') {
    // 隐藏 Dock 图标
    app.dock.hide()

    // 或者显示 Dock 图标
    // app.dock.show()

    // 设置 Dock 菜单
    const dockMenu = Menu.buildFromTemplate([
      {
        label: '新窗口',
        click: () => {}
      }
    ])
    app.dock.setMenu(dockMenu)

    // 设置 Dock 图标徽章（数字角标）
    app.dock.setBadge('5')

    // 弹跳 Dock 图标
    // app.dock.bounce('critical') // 一直弹直到点击
    // app.dock.bounce('informational') // 弹一下
  }
}

// ========== 6. Windows 任务栏气球通知 ==========
// Windows 上 Tray 也可以显示气球提示
function showTrayBalloon() {
  if (tray && process.platform === 'win32') {
    tray.displayBalloon({
      title: '通知标题',
      content: '这是气球通知内容',
      icon: path.join(__dirname, 'assets/tray-icon.png'),
      noSound: false,
      respectQuietTime: false
    })

    // 气球被点击
    tray.on('balloon-click', () => {
      console.log('气球通知被点击')
    })
  }
}
