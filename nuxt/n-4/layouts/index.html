布局系统：Layout 与 definePageMeta

掌握 layouts/ 目录创建布局模板，页面通过 definePageMeta 指定布局。

开场问题：你给二十个页面都加了同一根顶部导航，于是把那段 header 复制了二十遍。产品说 logo 要换，你就得改二十个文件。可换到隔壁那个 Nuxt 项目，同样的导航只存在于一个文件里，页面文件里连它的影子都看不到——页面自己没写的东西，是怎么出现在页面上的？

共享外壳复制代价

一组页面往往要共享同一段外壳：顶部导航栏、侧边菜单、页脚。这层结构和具体页面无关，却要出现在每一个页面上。

旧办法的代价一个比一个明显。在每个页面里直接复制外壳，改一处就得改 N 处，迟早漏改；把外壳抽成组件、在每页 import 后再包起来，省了复制，可每个页面都得记得包，漏一个就少了导航；干脆在 App.vue 里统一包住所有页面，省心是省心了，但所有页面被迫共用同一套壳，官网和后台想用不同外壳就没了办法。于是问题凝成一句：怎么让共享外壳只写一次，又能让不同页面各自选用不同的外壳？

外壳抽成布局组件

最省事的做法：把外壳做成一个 <Layout> 组件，页面 import 进来，用自己的内容把它包住。

这个方案做对了一件核心的事：外壳逻辑只有一份，真正被复用了。导航要改，改组件一处即可。要挑刺的话，问题出在「每页都得手工包」——壳与页面的关系，仍然由每个页面自己建立和维护。

逐页包裹漏写风险

  • 每个页面都要记得把内容包进 <Layout>，漏写一个页面，它就没了导航。
  • 想给某个页面换一种壳，得改它的 import 和标签，逐页修改。
  • 外壳标签和页面内容挤在同一个文件里，页面本身的职责被外壳稀释，读起来更累。
  • 没有任何地方能「声明式」地一句话说清：这个页面该用哪种外壳。

布局一等概念化

不推翻「把壳抽出来复用」，而是把「壳」提升为框架里的一等概念——布局。页面不再自己包裹，而是把「用哪个壳」声明出去，剩下的交给框架拼接。

  1. 在 layouts/ 下建布局文件，内部用一个 <slot /> 标出「页面内容放在这里」的位置。
  2. layouts/default.vue 是默认布局：页面不指定时自动使用它，所以什么都不写也照样有壳。
  3. 页面用 definePageMeta({ layout: 'custom' }) 选择布局——这是一句声明，不是一次包裹，页面里从此不再出现任何外壳标签。
  4. 渲染时框架把页面内容填进布局的 <slot />，两者合成最终页面。

这也就解开了开场的疑问：页面上之所以看得见导航，是因为导航写在布局里，页面只是被填进了布局预留的那个位置。你切换布局不同的页面时会发现一件有意思的事：布局外壳保持不动，只有 slot 里的内容被替换——因为更换的只是被填进去的部分。

还有一个容易混淆的地方要分清：<slot /> 与 <NuxtPage /> 职责完全不同。<slot /> 是布局留给自己的插槽，用来接收页面内容；而 <NuxtPage /> 用来呈现当前匹配到的路由页面，通常写在 App.vue 里决定「页面渲染在哪个位置」。一个是「把内容放进来」，另一个是「把匹配的页面挂上去」。

SSR 下布局在服务端也会渲染：布局组件在服务端就会执行，因此直接在布局里访问 window 会报错。需要用到浏览器 API 的逻辑，放到 onMounted 里，等组件在客户端挂载后再做。另外，只想在客户端使用的布局，用 .client 后缀命名（如 custom.client.vue）即可声明。

双布局代码对照

插槽与页面分工

布局把「共享外壳」从每个页面里搬了出来，只保留一份，并让页面用 definePageMeta 声明选用哪一个。<slot /> 负责把页面内容嵌进外壳的位置，默认布局 default.vue 负责兜底——于是「多页面共享结构」和「不同页面用不同外壳」这两件事，第一次可以同时成立。

「布局（Layout）」是包裹页面内容的壳组件：layouts/default.vue 是未指定时的默认布局，内部用 <slot /> 接收页面内容；页面通过 definePageMeta({ layout: 'custom' }) 选择布局，渲染时页面内容被填入 slot。它的边界是——<slot /> 承载页面内容而与呈现路由页面的 <NuxtPage /> 职责不同；SSR 下布局会在服务端渲染，访问 window 会报错，须放到 onMounted；仅客户端的布局用 .client 后缀命名。

关键代码

Vue
<script setup lang="ts">
import { ref } from 'vue'

const currentLayout = ref<'default' | 'custom'>('default')

const layouts = [
  { name: 'default', file: 'layouts/default.vue', desc: '默认布局，包含 NuxtPage 插槽' },
  { name: 'custom', file: 'layouts/custom.vue', desc: '自定义布局，如带侧边栏的后台' },
]

const pageMetaCode = `// 在页面组件中指定布局
definePageMeta({
  layout: 'custom'
})`

const defaultLayoutCode = `<!-- layouts/default.vue -->
<template>
  <div class="layout">
    <header>网站导航栏</header>
    <main><slot /></main>
    <footer>底部信息</footer>
  </div>
</template>`

const customLayoutCode = `<!-- layouts/custom.vue -->
<template>
  <div class="layout">
    <aside>侧边菜单</aside>
    <main><slot /></main>
  </div>
</template>`
</script>

<template>
  <div class="demo-card">
    <h3>布局系统：Layout 与 definePageMeta</h3>

    <div style="display:flex;gap:8px;margin-bottom:12px;">
      <button :class="{ active: currentLayout === 'default' }" @click="currentLayout='default'">Default 布局</button>
      <button :class="{ active: currentLayout === 'custom' }" @click="currentLayout='custom'">Custom 布局</button>
    </div>

    <div style="display:flex;gap:16px;">
      <div style="flex:1;">
        <h4>布局预览</h4>
        <div class="layout-preview" v-if="currentLayout === 'default'">
          <div class="layout-header">🌐 导航栏 (Header)</div>
          <div class="layout-body">
            <div class="layout-slot">📂 页面内容 <code><slot /></code></div>
          </div>
          <div class="layout-footer">📝 底部 (Footer)</div>
        </div>
        <div class="layout-preview" v-else>
          <div class="layout-sidebar">📋 侧边菜单 (Sidebar)</div>
          <div class="layout-body" style="flex:1;">
            <div class="layout-slot">📂 页面内容 <code><slot /></code></div>
          </div>
        </div>
      </div>

      <div style="flex:1;">
        <h4>布局代码</h4>
        <pre class="code-block" v-if="currentLayout === 'default'">{{ defaultLayoutCode }}</pre>
        <pre class="code-block" v-else>{{ customLayoutCode }}</pre>

        <h4 style="margin-top:8px;">页面指定布局</h4>
        <pre class="code-block">{{ pageMetaCode }}</pre>
      </div>
    </div>

    <div style="margin-top:10px;font-size:13px;color:#666;">
      💡 布局通过 <code><slot /></code> 接收页面内容；页面通过 <code>definePageMeta({ layout })</code> 选择布局；不指定则使用 default。
    </div>
  </div>
</template>
