组件自动导入

理解 components/、composables/、utils/ 的自动导入机制与组件命名规则。

开场问题：你在模板里写了 <Button />，整个文件里却没有一行 import。接着你把组件文件从 components/Button.vue 挪进 components/base/Button.vue，文件没改名、内容也没改，可模板里的标签却必须跟着改成 <BaseButton />——没人写 import，也没人改标签，这个名字究竟是谁替你定的？

重复导入语句噪声

组件一旦多起来，「每个用到的地方都 import 一次」就成了纯粹的重复劳动。你真正想表达的是「这里用一个按钮」，而不是「请从某个相对路径把按钮文件拉进来」。

手写 import 的成本随组件数增长：文件顶部一长串 import 成了噪声，路径一深就容易写错，删组件时还常常忘了清理。退一步用全局注册（app.component）能免掉 import，但代价是所有组件都被塞进主包，首屏体积跟着上涨，命名还可能互相冲突。自己写构建插件来做自动注册也行，但要额外维护扫描范围、命名规则和类型声明。于是问题变成：能不能把「import 组件」这件重复劳动交给构建工具，同时还保住按需加载？

组件全局注册方案

最省事的做法：干脆把所有组件全局注册一遍，模板里就再也不用 import 了，写起来最顺手。

这个方案做对了一件表面的事：它确实消灭了组件顶部的 import 噪声。但它换来的代价并不小，而且恰好丢掉了一件很重要的东西——按需加载。

包体膨胀与重名覆盖

  • 全局注册等于所有组件都进主包，用不到的也被打包，首屏体积白白变胖。
  • 全局命名空间没有隔离，两个组件重名就会互相覆盖，且不会报错。
  • 深层目录仍要手写注册语句，体力活并没有真正消除。
  • 得自己维护一份注册清单，新增组件忘了注册就用不了，编辑器也给不出提示。

按需插入导入语句

不推翻「免 import」这个诉求，而是换一种实现方式：把自动导入做成「用到时才插入 import」，而不是「一次性全部注册」。前者既有免手写的手感，又天然保住按需加载。

  1. 构建时扫描约定目录，为 Vue / Nuxt 内置 API、组件、composable 与工具函数批量生成自动导入声明，落到 .nuxt/ 下的类型声明文件里。
  2. 模板里直接写 <ComponentName />，框架自动插入对应的 import 语句。
  3. 脚本里，composables/ 下以 use 开头的函数、utils/ 下的具名导出，直接调用即可，无需手写 import。
  4. 生成的声明文件同时供编辑器读取，因此免 import 的同时仍然有智能提示和类型检查。

这里有个必须记住的命名规则：components/ 下的组件是按路径前缀命名的。放在根目录的 MyButton.vue 就叫 <MyButton />；每往下一层目录，就给名字加上这层目录的前缀——components/base/Input.vue 对应 <BaseInput />，components/admin/Table.vue 对应 <AdminTable />。这正是开场那件事的答案：目录本身也是组件名字的一部分，你换了目录，名字自然跟着变。

想扩大扫描范围，用 imports.dirs 把自定义目录加进来即可；默认覆盖 .vue、.ts、.js 这类可编译文件。要注意的是，自动导入并非没有边界——约定目录之外的文件不会被自动导入，那些地方仍得老老实实写 import。

当心前缀命名出意外：组件文件名与所在目录名重复时（例如 components/admin/Admin.vue），前缀拼接出来的名字会出乎你的预料。稳妥的做法是保持一文件一组件、短名清晰，别让文件名和目录名撞车。

五类自动导入来源

构建期扫描约定目录

自动导入的核心不是「全局注册」，而是「用到时才插入 import」：构建时扫描约定目录生成声明，写代码时省掉 import，打包时又只带上真正用到的部分。记住两条边界——只有约定目录会被扫描，组件名还会带上目录前缀——就能把免 import 的便利稳稳用住。

「自动导入」指构建期扫描约定目录，为 Vue / Nuxt 内置 API、组件、composable 与工具函数生成导入声明（落在 .nuxt/ 下），使用时再自动插入 import。它的边界是：仅在 components/、composables/、utils/ 等约定目录生效，约定之外的文件必须显式 import；组件按路径前缀命名（base/Input.vue → <BaseInput />），且它是按需插入 import 而非运行时全局注册。

import { ref, computed } from 'vue'

type ImportSource = 'vue' | 'nuxt' | 'component' | 'composable' | 'util'

const selected = ref<ImportSource>('vue')

const importMap: Record<ImportSource, { title: string; items: { name: string; desc: string }[] }> = {
  vue: {
    title: 'Vue 自动导入',
    items: [
      { name: 'ref', desc: '创建响应式引用' },

      { name: 'nextTick', desc: '等待 DOM 更新' },
      { name: 'toRef / toRefs', desc: '转换响应式引用' },
    ],
  },
  nuxt: {
    title: 'Nuxt 自动导入',
    items: [
      { name: 'useFetch', desc: '数据获取（自动 key）' },
      { name: 'useAsyncData', desc: '异步数据管理' },

      { name: 'useHead', desc: '管理页面 head' },

      { name: 'useRouter', desc: '获取路由器实例' },
      { name: 'navigateTo', desc: '编程式导航' },
      { name: 'useRuntimeConfig', desc: '读取运行时配置' },
      { name: 'useAppConfig', desc: '读取应用配置' },
    ],
  },
  component: {
    title: '组件自动导入',
    items: [
      { name: 'components/MyButton.vue', desc: '模板中直接用 <MyButton />' },
      { name: 'components/UserCard.vue', desc: '模板中直接用 <UserCard />' },
      { name: 'components/base/Input.vue', desc: '前缀命名 <BaseInput />' },
      { name: 'components/admin/Table.vue', desc: '路径前缀 <AdminTable />' },
    ],
  },
  composable: {
    title: 'Composables 自动导入',
    items: [
      { name: 'composables/useCart.ts', desc: '导出 useCart，全局可用' },

    title: '工具函数自动导入',

      { name: 'utils/format.ts', desc: '导出 formatDate，全局可用' },

      { name: 'utils/helper.ts', desc: '导出 debounce，全局可用' },
    ],
  },
}

const current = computed(() => importMap[selected.value])
</script>

<template>
  <div class="demo-card">
    <h3>自动导入：无需手动 import</h3>

      <button v-for="(val, key) in importMap" :key="key"

              @click="selected = key as ImportSource">
        {{ val.title }}
      </button>
    </div>

    </div>
  </div>
