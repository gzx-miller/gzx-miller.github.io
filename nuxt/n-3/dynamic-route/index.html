动态路由与路由参数

深入理解动态路由参数 [id] 和 catch-all [...slug] 的匹配规则与参数获取方式。

开场问题：课程详情页的地址是 /courses/3，你在页面里写 if (route.params.id === 3) 判断「这是第三门课」，它却从来不成立；你再写 route.params.id + 1，本以为得到 4，结果拼出了字符串 '31'。地址栏里那个明明是数字的 3，取出来到底变成了什么？

数据驱动详情页

一个课程详情页要服务无数条数据。如果每条数据都得对应一个自己的页面文件，产品让你上十门课，你就得新建十个文件——数据量一涨，文件数跟着线性膨胀，显然不可维护。你真正需要的，是一个文件按「路径的形状」匹配一整类 URL，并把其中会变的那一段作为参数接出来。

旧的替代方案各有代价。用查询串 /course?id=3，一个文件确实够用，但 URL 只表达了「某个页面带了个参数」，像 /docs/guide/installation 这样的层级关系无从体现，对搜索引擎和分享链接也不友好；自己动手解析路径字符串、写正则去匹配，不但容易写错，还等于在框架的路由匹配之外又维护了一套平行逻辑，两边容易打架。于是问题落到一句：怎么让一个文件接住一整类 URL，并把变动的那一段干净地交出来？

查询串参数传递

最省事的做法：用查询串。写一个 pages/course.vue，所有数据都走 /course?id=3，组件里用 useRoute().query.id 把参数取出来。

这个方案做对了一件重要的事：它把「变动的那一部分」从页面里抽了出来，变成了参数，于是同一个文件能服务所有 id。但它把资源地址退化成了「一个固定页面加一串参数」，URL 不再表达「这就是第 3 号资源的地址」。

语义表达与层级缺失

  • /course?id=3 语义弱，搜索引擎与分享卡片都读不出这是一个具体资源的地址。
  • 表达不了层级：/docs/guide/installation 这种多段路径，查询串完全无能为力。
  • ?id= 缺失时页面照样匹配成功，得自己在组件里判空，否则拿到 undefined。
  • 想在「访问之前」就校验参数是否合法，查询串方案没有一个自然的挂载点。

动态段方括号语法

不推翻「把变动部分抽成参数」，而是让路径本身来承载这个参数——用方括号把文件名的某一段标成可变段。分三步补齐。

先看单段参数。pages/courses/[id].vue 匹配 /courses/ 下的一个路径段，组件里用 useRoute().params.id 取值。这里立刻撞上开场那个坑：参数值始终是字符串。地址里写的是 3，取出来的是 '3'，所以 === 3 恒为 false，而 '3' + 1 会按字符串拼接成 '31'。要参与数值运算，必须先 Number() 转换，并判掉 NaN——像 /courses/abc 这样的非法段转出来正是 NaN，不处理就会带着脏值往下走。

再补多段路径。pages/docs/[...slug].vue 匹配余下的全部路径段：访问 /docs/guide/installation，得到的是 params.slug，而它的类型和单参数不一样——单参数是一个字符串，catch-all 则是一个字符串数组，这里是 ['guide', 'installation']，这一点最容易记混。它的匹配优先级低于更具体的静态与动态路由，所以它天然承担「前面都没命中的收尾路径」。

最后补校验。在页面的 definePageMeta 里写一个 validate 函数，对参数做格式检查，返回 false 就让这次匹配失效、把请求转交错误处理（例如落到 404）。要留意的是，validate 在服务端渲染与客户端导航上都会执行，两端的逻辑必须写一致，否则同一地址在两种场景下会给出不同结果。

把这条链路串起来就是：地址命中文件 → 从 params 取值（记得转类型）→ 用数据渲染页面。开场那两个怪现象，答案都在第一步——URL 里的一切，到了 params 里都是字符串。

同一路径别写两份：不要让 [id].vue 和 [id]/index.vue 同时存在——二者的路由是等价的，框架里只会有一份生效，容易让人搞不清到底走的哪个文件。先统一约定，再动手写页面。

单段参数与多段捕获

参数值恒为字符串

动态路由把「一类地址」和「一个文件」对应了起来：方括号标出可变的那一段，命中后从 params 取值。要带走的关键判断只有一条——参数值永远是字符串，参与数值运算前先转换；而单段参数给字符串、catch-all 给数组，这个差别决定了你该怎么消费它。

「动态路由参数」指由文件名方括号声明的可变路径段：[id].vue 匹配单个路径段，route.params.id 取到字符串；[...slug].vue 匹配余下全部路径段，route.params.slug 取到字符串数组。它的边界是取值恒为字符串（运算前需 Number() 并处理 NaN），且可用 definePageMeta 的 validate 校验参数、在不合法时返回 false 转交错误处理。

关键代码

Vue
<script setup lang="ts">
import { ref, computed } from 'vue'

const currentPath = ref('/courses/3')
const courses = [
  { id: 1, name: 'Vue3 入门', price: 99 },
  { id: 2, name: 'Nuxt 实战', price: 129 },
  { id: 3, name: 'TypeScript 进阶', price: 149 },
  { id: 4, name: 'Pinia 状态管理', price: 79 },
]

const matchResult = computed(() => {
  const match = currentPath.value.match(/^\/courses\/(\d+)$/)
  if (!match) return { matched: false, params: null, course: null }
  const id = Number(match[1])
  const course = courses.find(c => c.id === id)
  return { matched: true, params: { id }, course: course ?? null }
})

const catchAllPath = ref('/docs/guide/installation')
const catchAllResult = computed(() => {
  const match = catchAllPath.value.match(/^\/docs\/(.*)$/)
  if (!match) return { matched: false, slug: null, segments: [] }
  const slug = match[1]
  return { matched: true, slug, segments: slug.split('/') }
})
</script>

<template>
  <div class="demo-card">
    <h3>动态路由与路由参数</h3>

    <div style="display:flex;gap:16px;">
      <div style="flex:1;">
        <h4>动态参数 <code>[id].vue</code></h4>
        <p>模拟路径：<code>/courses/:id</code></p>
        <input v-model="currentPath" placeholder="/courses/3" style="width:100%;margin-bottom:8px;" />
        <div class="result-box">
          <p>匹配：{{ matchResult.matched ? '✅ 是' : '❌ 否' }}</p>
          <p v-if="matchResult.matched">参数 <code>id</code> = {{ matchResult.params?.id }}</p>
          <p v-if="matchResult.course">课程：{{ matchResult.course.name }}（¥{{ matchResult.course.price }}）</p>
          <p v-if="matchResult.matched && !matchResult.course" style="color:#c62828;">⚠ 未找到 id={{ matchResult.params?.id }} 的课程</p>
        </div>
      </div>

      <div style="flex:1;">
        <h4>Catch-all <code>[...slug].vue</code></h4>
        <p>模拟路径：<code>/docs/:slug(.*)*</code></p>
        <input v-model="catchAllPath" placeholder="/docs/guide/installation" style="width:100%;margin-bottom:8px;" />
        <div class="result-box">
          <p>匹配：{{ catchAllResult.matched ? '✅ 是' : '❌ 否' }}</p>
          <p v-if="catchAllResult.matched">slug = <code>{{ catchAllResult.slug }}</code></p>
          <p v-if="catchAllResult.segments.length">路径段：{{ catchAllResult.segments.join(' → ') }}</p>
        </div>
      </div>
    </div>

    <div style="margin-top:12px;padding:10px;background:#fff8f0;border-radius:6px;">
      <strong>代码示例：</strong>
      <pre style="font-size:12px;margin:4px 0;">// pages/courses/[id].vue
const route = useRoute()
const id = route.params.id  // 字符串类型

// pages/docs/[...slug].vue
const slug = route.params.slug  // 字符串数组</pre>
    </div>
  </div>
</template>
