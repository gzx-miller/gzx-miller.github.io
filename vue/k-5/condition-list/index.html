条件与列表渲染：v-if、v-show、v-for、key

用任务看板展示条件渲染、显示切换和列表身份维护。

开场问题：列表头部插入一条新任务之后，第二条任务的复选框自己勾上了——我什么都没点，状态怎么会串到别人身上？

列表渲染与数据驱动

做一个学习任务看板：一列任务，每条显示标题和一个「已完成 / 进行中」的样子；上面有一个开关，控制是否显示已完成的任务。看起来就是「一个数组铺开成一组列表项」这么简单。

但只要这个列表开始增删和排序，问题就会冒出来：新插入的一项为什么让旧项的输入内容错位？切来切去之后，为什么已经隐藏的任务又闪了一下？要回答这些，得先弄清楚两件事——节点是被保留还是被重建，以及框架凭什么认出「这还是同一条数据」。

数组下标作为键

最省事的做法：对每一项都用条件判断控制显示，隐藏时靠切换样式或干脆重排数组；列表项则沿用数组下标当作身份。

这个方案做对了一件基础的事：它承认「列表内容由数据决定」，显示与隐藏也都由状态推导出来，没有手动去创建节点。在列表从不增删、只做整段渲染的场景里，它跑得很好。

销毁重建与身份错位

  • 用条件判断控制显隐时，条件为假会真的销毁节点，切回来重新创建——组件内部状态、输入内容、动画进度全部丢失。
  • 用数组下标当身份，在头部插入一项后，所有项的身份整体后移，框架会认为「第一项变成了原来的第一项的位置」，于是复用出错误的状态。
  • 下标不能代表数据身份，一旦发生排序，勾选、展开、播放这些基于实例的状态会集体错位。
  • 把条件判断和循环写在同一个元素上时，条件判断优先级更高，会先于循环求值，循环变量根本还没生成。

惰性渲染与节点保留

先分清两种「隐藏」，它们的代价完全不同。

v-if 是惰性渲染：条件为假时它根本不创建节点，节点是真的不存在；代价是每次切换都要经历一次真实的创建与销毁，切换有开销。v-show 则相反，它始终创建节点，只切换 display 样式：首次渲染开销更高，但切换成本极低。

于是选择标准就出来了：频繁显示隐藏、DOM 又比较简单时，用 v-show 更合适；真正需要销毁和重建内容时才用 v-if——比如权限区域、或者本身很昂贵的组件，你确实希望它不出现时就不要存在。

再解决身份问题。列表渲染的关键不在循环本身，而在 key：它是列表项的身份标识。靠它，diff 算法才能在列表增删排序时复用正确的 DOM 与组件实例，避免状态错位。所以 key 必须稳定且能代表数据身份——用数据自己的 id 最稳妥，不要用数组下标去表示会增删排序的数据：下标描述的是「位置」，而你要表达的是「这是同一条任务」。

一条硬规则：v-if 与 v-for 不要写在同一个元素上。当两者同时出现时，v-if 的优先级更高，会在循环变量还不存在时先求值，导致拿不到当前项；正确做法是把条件移到外层容器包住循环，或在循环内部对每一项单独判断。

把这些拼回看板这个例子：任务数组是唯一的数据来源，模板只负责把它展示出来；「是否显示已完成」用开关状态控制可见性；每一条用任务自己的 id 作 key，于是无论怎么增删排序，身份都稳定。此时在列表头部插入一项，用元素面板就能确认：旧节点被复用，而不是整段重建。

  1. 任务数组作为单一数据来源，模板只负责把它展示出来。
  2. 勾选开关改变显示状态，已完成任务通过 v-show 控制可见性。
  3. 每个任务使用 id 作为 key，保证列表更新时身份稳定。
  4. 在列表头部插入一项，用元素面板确认旧节点被复用而非全部重建。

显隐切换对照

渲染分支与键机制

条件渲染决定「节点要不要存在」，列表渲染决定「一组节点怎么复用」，而 key 是把两者串起来的身份线。记住三条就够了：频繁显隐用 v-show，需要真正销毁重建才用 v-if；key 用稳定的数据标识而不是下标；v-if 与 v-for 别写在同一元素上。

「列表身份」由 key 承担：它是列表项的稳定标识，让 diff 算法在增删排序时复用正确的 DOM 与组件实例，避免状态错位。v-if 是惰性渲染（条件为假不创建节点，切换有开销），v-show 始终创建、只切 display（首渲染贵、切换便宜）；key 不要用数组下标，v-if 与 v-for 也不要写在同一元素上。

<script setup lang="ts">
import { ref } from 'vue'

const showDone = ref(true)
const tasks = ref([
  { id: 1, title: '搭建 Vue3 项目', done: true },
  { id: 2, title: '学习 v-for 的 key', done: false },
  { id: 3, title: '整理条件渲染笔记', done: true },
])
</script>

<template>
  <div class="demo-card">
    <h3>学习任务看板</h3>
    <label><input v-model="showDone" type="checkbox" /> 显示已完成</label>
    <ul>
      <li v-for="task in tasks" v-show="showDone || !task.done" :key="task.id">
        <span v-if="task.done">已完成</span>
        <span v-else>进行中</span>
        {{ task.title }}
      </li>
    </ul>
  </div>
</template>
