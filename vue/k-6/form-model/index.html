表单处理：v-model、修饰符、基础校验

用活动报名表展示双向绑定、输入清洗和提交条件控制。

开场问题：用户在输入框里打字，我并没有写任何赋值语句，代码里那个变量怎么就跟着变了？

表单输入与按钮联动

做一个活动报名表：姓名、邮箱两个输入框，外加一个「同意接收课程通知」的勾选框；三项都填齐之后，「提交报名」按钮才可点，否则置灰，并给出一句提示告诉用户还差什么。

表单的本质是用户输入如何进入业务状态，并驱动按钮、提示这些反馈同步更新。看起来简单，但输入框有自己的行为——它保存着用户敲进去的字符，也保存着光标位置。麻烦在于，这份「界面上的事实」和「代码里的事实」默认是两份，需要有人把它们接起来。

事件监听与手动赋值

最直接的做法：每个输入框都绑一个 @input 监听，回调里从事件对象上取出当前值，手动赋值给对应的变量；勾选框再单独绑一次。哪个字段要联动，就再补一段更新逻辑。

这个方案做对了两件事：它承认「控件的变化是一类事件」，也承认「业务状态是唯一源头」。把值搬进变量之后，校验、提交都能基于同一份数据来做，思路是对的。

样板膨胀与维护代价

  • 字段一多，样板代码成倍增长，每个控件都要写一遍「取事件对象、读值、赋值」。
  • 漏绑一个监听，那个字段就永远停在初始值，界面上看着正常，提交时才发现是空的。
  • 用户输入的首尾空格会原样进入状态，导致「看起来填了、实际校验不过」这类诡异现象。
  • 输入框给出的值默认是字符串，数字字段需要额外转换，转换逻辑散落在每个回调里。
  • 校验判断散在各处，提交按钮的启用条件与提示文案容易各写一套，互相不一致。

双向绑定与语法糖

把「取事件、读值、赋值」这三步收成一句声明，这就是 v-model。它并不是新机制，而是一个语法糖：对文本输入而言，它展开成「把状态绑到 value 属性」加「监听 input 事件」，从而把表单控件与响应式状态连接成双向关系——状态变，输入框显示跟着变；用户输入，状态跟着变。样板代码就此消失，剩下的是「这个字段对应哪个状态」这条唯一信息。

接着处理「输入细节」。空格、类型、触发时机这些事每个项目都会遇到，与其在每个回调里重复，不如在同步之前统一处理，这就是修饰符：

  • .trim 在同步前去掉首尾空格，从源头避免「看起来填了」的假象。
  • .number 把输入结果按数字处理，省去手写转换。
  • .lazy 改变同步时机，从「每次输入」变成「失焦或回车」，减少高频更新。

然后是状态的组织方式。表单字段往往属于同一个业务对象，把它们收进一个 reactive 对象，比散落成好几个独立变量更便于组织，提交时也能整体取用。

最后是校验。直觉做法是在提交时写一串判断，但更贴合响应式的做法是用 computed 表达校验结论：把所有规则写进一段派生计算，得出「是否可提交」，按钮的禁用状态与提示文案都读同一个结果。这样校验逻辑只有一处，输入一变，按钮和提示自动跟进，不会出现按钮亮了却提示「请补全信息」这种自相矛盾。

两条不能省的原则：前端校验的价值在于即时反馈，真实提交仍然必须依赖服务端校验，二者缺一不可；另外不要只用「禁用按钮」表达错误——用户看到灰按钮并不知道差在哪，必要时应给出明确提示。字段较多时，可以先把校验规则集中定义，再交给 computed 汇总结果。
  1. 用户填写姓名、邮箱并勾选同意项。
  2. v-model.trim 把输入同步到表单状态，同时去掉首尾空格。
  3. 用一个 computed 计算「是否可以提交」，按钮状态与提示文案都读它。
  4. 提交后清空表单，验证双向绑定的状态同步复位。

输入通路与修饰符

表单处理的核心是把「界面上的输入」和「代码里的状态」接成一条双向通路：v-model 负责连接，修饰符负责在同步前清洗输入细节，reactive 把同属一个业务对象的字段组织起来，computed 把校验收成唯一结论。前端只管即时反馈，最终的正确性仍然交给服务端把关。

「双向绑定」指 v-model，它本质是「绑定值 + 事件监听」的语法糖：对文本输入展开为 value 绑定与 input 事件处理，把表单控件与响应式状态连成双向关系。修饰符 .trim、.number、.lazy 在同步前处理常见输入细节；校验用 computed 表达，让提交按钮状态与提示文案随输入自动更新，且服务端校验始终不可省略。

Vue
<script setup lang="ts">
import { computed, reactive } from 'vue'

const form = reactive({
  name: '',
  email: '',
  agree: false,
})

const canSubmit = computed(() => form.name.trim().length >= 2 && form.email.includes('@') && form.agree)
</script>

<template>
  <form class="demo-card" @submit.prevent>
    <h3>活动报名表</h3>
    <input v-model.trim="form.name" placeholder="姓名，至少 2 个字符" />
    <input v-model.trim="form.email" placeholder="邮箱" />
    <label><input v-model="form.agree" type="checkbox" /> 同意接收课程通知</label>
    <button :disabled="!canSubmit">提交报名</button>
    <p>{{ canSubmit ? '表单可以提交' : '请补全信息' }}</p>
  </form>
</template>
