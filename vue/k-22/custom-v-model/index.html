自定义 v-model：组件级双向绑定

用评分选择器展示组件级 v-model 的实现：modelValue、命名 model 和修饰符。

开场问题：我封装的评分选择器，父组件想用 v-model 像原生输入框一样直接双向绑定，可子组件改了值以后，怎么让父级知道并且同步过去？

评分选择器组件

你做了一个评分选择器组件：五颗星，点一下就选中对应分数，旁边还有一个标题输入框。现在父组件想这样用它——v-model="rating"，拿到和原生输入框一模一样的体验：值传下去、改完自动传上来。可原生控件那套「value 加 input」的绑定是浏览器给的，你自己写的组件并没有这层魔法。

所以你要回答的是：一个自定义组件，怎么把自己伪装成原生表单控件那样的双向绑定，让父级不必关心内部究竟是怎么传值的，也不必为每个组件记一套新的读写规则。

手动搭建双向回路

最朴素的写法是手动搭一条回路：子组件接收一个 value 属性作为当前值，用户点击星星时不直接改它，而是 emit 一个事件把新值抛出去；父组件监听这个事件、更新自己的状态，再把新值通过属性传回来。

这个方案做对了最关键的一件事：它守住了单向数据流。属性只读、值靠事件上行，父子之间的数据流向清晰可追，不会出现「不知道是谁改的」这种失控局面。这也是所有双向绑定最终都要落回的地基。

但要注意，这条回路你每写一个组件就要搭一次，名字还得自己定。当页面里同时有十几个需要双向绑定的自定义控件时，光是「记住每个组件用的是哪个属性名、哪个事件名」就足以让人头疼，更别说代码评审时很难一眼看出父子之间到底是怎么传值的。

双向回路与样板

  • 每做一个双向绑定的组件，都要手写一遍「属性 + 事件 + 父级更新」，样板代码反复出现。
  • 组件里若有两个都需要双向绑定的值（比如评分和标题），光靠一个约定的属性名区分不开。
  • 父级想加 .trim 这类修饰符时，子组件拿不到「用了什么修饰符」这一信息，没法做对应处理。

组件级双向绑定

不推翻「属性 + 事件」，而是给这套回路一个统一的语法糖。组件级 v-model 的本质，就是 modelValue 属性加上 update:modelValue 事件的语法糖：v-model="rating" 等价于 :modelValue="rating"，再配上 @update:modelValue。子组件接收 modelValue，修改时用 emit 抛出 update:modelValue 通知父级，剩下的交给 Vue。

第二个问题是「多个值」。既然默认绑定的名字是 modelValue，那再要一个就可以给它起名：v-model:title 对应子组件的 title 属性和 update:title 事件。一个组件因此可以同时挂多个 v-model，例如 v-model="data" 与 v-model:title="name" 并存，互不干扰。

第三个问题是修饰符。当父级写 v-model:title.trim，子组件会收到一个 modelModifiers 对象，里面标记了 trim 为 true。组件据此自行决定如何清洗输入——修饰符的处理逻辑在组件内部完成，并不会改变父级的绑定行为。

把三点合起来看，会发现这套设计其实一直在做「约定」：约定默认名字、约定事件名格式、约定修饰符对象的挂载位置。约定越统一，父级使用组件就越像使用原生控件，不必为每个组件重新记一套输入输出的名字。这也是 v-model 相比手写属性与事件最大的价值——它把「怎么通信」这件琐碎事，变成了一个所有组件通用的词汇。

迁移别踩坑：Vue3 的组件 v-model 默认绑定名是 modelValue，而 Vue2 是 value，从 Vue2 迁移时这里最容易漏改。另外，新代码如果要支持组件级 v-model，可以优先用 defineModel 宏，它能把这套属性与事件的样板收敛成一行声明。

同步回传父级

属性事件命名约定

自定义 v-model 并不神秘，它只是把「属性向下传、事件向上抛」这条单向回路约定成了固定名字：默认用 modelValue，需要多个就加命名，需要修饰符就用 modelModifiers 在组件内处理。理解了这层语法糖，你就既能让组件像原生控件一样好用，又不会破坏单向数据流的清晰——组件越多，这套统一约定的收益就越明显。

「组件级 v-model」是 modelValue 属性与 update:modelValue 事件的语法糖；命名 model（如 v-model:title）使用对应名称的属性与 update: 事件；modelModifiers 让组件内部感知并处理 .trim 这类修饰符。注意 Vue3 默认名是 modelValue（Vue2 为 value），新代码可用 defineModel 宏替代手写样板。

关键代码

Vue
<script setup lang="ts">
// ---- 子组件：评分选择器 ----
// 组件 v-model 的核心：modelValue prop + update:modelValue emit
const props = defineProps<{
  modelValue: number      // v-model 绑定的值
  title: string           // v-model:title 绑定的值
  titleModifiers?: { trim?: boolean }  // v-model:title 的修饰符
}>()

const emit = defineEmits<{
  'update:modelValue': [value: number]
  'update:title': [value: string]
}>()

const stars = [1, 2, 3, 4, 5]

function selectRating(n: number) {
  emit('update:modelValue', n)
}

function handleTitleInput(e: Event) {
  let val = (e.target as HTMLInputElement).value
  // modelModifiers 允许组件内部处理修饰符逻辑
  if (props.titleModifiers?.trim) {
    val = val.trim()
  }
  emit('update:title', val)
}
</script>
