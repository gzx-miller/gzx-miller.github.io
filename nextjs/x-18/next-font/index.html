next/font 字体优化

用 next/font 自托管字体，消除布局抖动，避免第三方 CDN 请求。

开场问题：引用了外部字体之后，页面加载时文字先「隐身」了一小会儿，接着整段排版往下一跳才稳定；更奇怪的是，合规同事还来问——用户打开网页，IP 是不是发到境外去了？

全站字体替换

你在做课程站，想要中英混排的正文看起来更规整，于是给全站换了一套字体。做法很常见：在页面模板顶部加一行指向字体 CDN 的 <link>，再在 CSS 里写上字体族名。本地看着挺好，问题全在上线后才冒出来。

这里面藏着一串连锁反应：字体文件不在你自己手里，用户浏览器要先去第三方服务器取；文件没到之前，浏览器要么先不显示文字等着，要么先用系统兜底字体顶上、字体到了再换回来。而换字体的那一刻，字宽和行高都会变，整块文字跟着重新排版，于是页面抖了一下。这就解释了为什么「只是换个字体」会同时影响速度、稳定性和隐私。

外链字体引入

最省事的做法就是那行外部链接：把字体服务商的地址贴进页面，剩下交给浏览器。它确实解决了最表面的诉求——页面文字用上了想要的字体，而且不用你维护任何字体文件。

这一点没有错：字体是设计的一部分，该用就得用。问题在于，把字体来源、加载时机、加载失败的表现全部外包出去，等于把三个不可控因素一起引进了页面。

第三方字体风险

  • 用户的浏览器直接连第三方字体服务器，IP 与访问行为会外泄，隐私合规上容易被质疑。
  • 境外 CDN 在本地网络下可能很慢甚至超时，字体迟迟不到，文字就一直「隐身」。
  • 字体未就绪时先隐藏文字会造成短暂空白（FOIT），先用兜底字体再切换（FOUT）则会让排版抖一下。
  • 字体文件体积不小，尤其中文字体动辄几 MB；全量加载会明显拖慢首屏。
  • 从第三方动态提供的字体，加载完还可能引发版本与缓存的不确定，问题难复现。

字体自托管方案

思路不是「不用字体」，而是把字体搬回自己家里、把加载过程管起来。这就是 next/font 要解决的事：它在构建时下载字体文件并随应用一起自托管，用户浏览器只会向你的站点请求字体，不再有第三方请求。

它提供两个入口：next/font/google 用于加载字体服务商上的字体，next/font/local 用于加载你自己项目里的字体文件。两者用法一致，都返回一个对象，你把它挂到根布局上，整棵组件树都能用。

挂载方式推荐用 variable：它会生成一个 CSS 变量（例如 --font-inter），你在根布局的 html 上引用，再在全局样式里用 var(...) 组合成字体族。这样做的好处是字体与类名解耦：以后想整体换字体，只改变量的值，不用逐页改动。

接着处理那一下抖动。两点最关键：

  1. 用 display: 'swap'。它让文字先用兜底字体立即显示，等真字体到位再平滑切换，避免出现「一片空白」的 FOIT。其余取值里 'block' 会短暂隐藏文本，'optional' 则更偏向放弃晚到的字体。
  2. 靠自托管的尺寸校正消除偏移。因为兜底字体与目标字体的字符宽高并不一致，直接换会抖动；自托管方案会为字体附上校正信息，让两者在版式上尽量对齐，切换时几乎看不出跳动。

最后是瘦身。中文字体很大，别指望全量加载。用 subsets 只加载需要的字符子集，用 weight 只声明真正用到的字重。常见折中是「拉丁子集 + 系统中文字体兜底」，把最重的部分交给系统已有的字体。如果公司有自研字体或第三方授权字体，用 next/font/local 配合对应的字体文件即可。

一个容易忽略的好处：字体在构建时就被下载下来并自托管，运行时不向字体服务商发起任何请求，隐私更友好；同时构建产物里已包含字体文件，部署上线后不会再受第三方可用性影响。

挂载与样式引用

来源与加载控制

字体优化的核心是「把控制权收回来」：来源自托管，加载时机用 display 说清楚，切换偏移靠尺寸校正抹平，体积靠子集与字重压下去。隐私、速度、稳定这三件事，其实都指向同一个动作——让字体成为你自己构建产物的一部分。

「字体自托管」next/font 在构建时下载字体并随应用一起部署，运行时不再向第三方 CDN 请求，配合尺寸校正消除换字体时的布局抖动；支持 next/font/google 与 next/font/local，用 variable 生成 CSS 变量便于全局引用，display: 'swap' 先用兜底字体显示，subsets 与 weight 控制体积。

关键代码

JSX
// Google Fonts - 自动自托管
// app/layout.tsx
import './globals.css'
import { Inter, Noto_Sans_SC } from 'next/font/google'

// 加载 Inter 字体
const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
})

// 加载思源黑体
const notoSansSC = Noto_Sans_SC({
  subsets: ['latin'],
  weight: ['400', '500', '700'],
  display: 'swap',
  variable: '--font-noto-sans-sc',
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="zh-CN" className={`${inter.variable} ${notoSansSC.variable}`}>
      <body>{children}</body>
    </html>
  )
}

// ============================================

// 在 CSS 中使用
/* app/globals.css */
// :root {
//   --font-inter: 'Inter', sans-serif;
//   --font-noto-sans-sc: 'Noto Sans SC', sans-serif;
// }
//
// body {
//   font-family: var(--font-inter), var(--font-noto-sans-sc), sans-serif;
// }

// ============================================

// 本地字体 - next/font/local
// app/layout.tsx
import './globals.css'
import localFont from 'next/font/local'

// 加载本地字体文件
const myFont = localFont({
  src: [
    {
      path: './fonts/MyFont-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: './fonts/MyFont-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
  ],
  display: 'swap',
  variable: '--font-my',
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="zh-CN" className={myFont.variable}>
      <body>{children}</body>
    </html>
  )
}

// ============================================

// 在组件中使用字体类名
import { Roboto } from 'next/font/google'

const roboto = Roboto({
  weight: ['400', '700'],
  subsets: ['latin'],
})

export default function Page() {
  return (
    <div className={roboto.className}>
      <h1>使用 Roboto 字体</h1>
      <p>这段文字使用 Roboto 字体渲染</p>
    </div>
  )
}

// ============================================

// display 选项说明：
// - 'swap'（推荐）：先用 fallback 字体，加载完再切换
// - 'auto'：浏览器默认行为
// - 'block'：短暂隐藏文本（FOIT）
// - 'fallback'：极短隐藏期，然后 swap
// - 'optional'：极短隐藏期，加载失败用 fallback

// ============================================

// 预加载子集
// subsets 可以减小字体文件体积
import { Noto_Sans_SC } from 'next/font/google'

const notoSans = Noto_Sans_SC({
  subsets: ['latin'], // 只加载拉丁字符子集
  weight: ['400', '700'],
  display: 'swap',
})
