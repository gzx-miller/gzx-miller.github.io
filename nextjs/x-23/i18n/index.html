国际化 i18n

用 App Router 的 [lang] 动态路由 + middleware 语言检测实现多语言站点。

开场问题：产品要做中英日三语，一开始我在浏览器里读语言偏好、运行时切换文案，结果搜索引擎抓到的永远只有中文，用户分享出去的链接也全是中文标题。

浏览器判断语言

多语言站点看起来只是「把文字换成另一种语言」，做起来却处处别扭。你先想到的自然是：在浏览器里判断用户用什么语言，然后切换对应文案。本地测试没问题，一到线上就暴露了两个问题——搜不到，分享不对。

原因在于，语言不只是显示出来的文字，还是地址的一部分。如果中英日是同一份地址，只是运行时换文案，那搜索引擎和分享抓取看到的永远是初始那一版；而如果每种语言都有各自的地址，那么每种语言都能被单独收录、单独分享。这个判断决定了整个方案的走向。

客户端状态记语言

最直接的做法是用一个客户端状态记录当前语言，在运行时把文案替换掉。切换语言只是改一下这个状态，页面不跳转，看起来非常顺滑。

它确实解决了「展示」这一层：用户能在页面上看到自己的语言，切换也没有刷新感。但「展示」只是多语言的一半，另一半是「可达」——别人能不能通过一个地址拿到特定语言的版本。

单地址收录缺陷

  • 所有语言共用一条地址，搜索引擎无法区分，收录不到其他语言版本。
  • 分享出去永远是最初那一版的标题，接收者看到的语言未必是他想要的。
  • 首屏要等脚本跑起来才知道该显示哪种语言，用户会先看到默认语言再被替换，视觉上闪一下。
  • 所有语言的文案都被打进同一份产物，即使只访问一种语言也要下载全部。
  • 用户切换后一旦刷新或从外部重新进入，语言又回到默认值。

语言前缀路由

改成「语言进地址」的方案：用动态路由为每种语言生成独立地址，语言前缀成为路径的第一段。每种语言各有一条自己的地址，于是每种语言都能被单独收录、单独分享，也让服务端在渲染时就知道该输出哪种语言。

第一步是集中定义语言配置：声明支持哪些语言、默认是哪一种，并据此推导出语言的类型。这份配置会被目录、检测逻辑和切换组件共同引用，避免各处写死同一个语言列表。

第二步是把文案拆成按语言组织的字典文件，用异步加载的方式按需取用。这样访问中文时不会把日文也下载一遍；字典越拆越细，首屏加载的文案就越少。取字典的模块应标记为仅在服务端使用，避免被误带进客户端产物。

第三步是在语言动态段下的布局里，用预生成函数把所有语言都提前生成为静态页面，并让文档的语言属性跟随当前语言；同时用动态元信息，为每种语言给出对应的标题。

第四步是自动检测。光有地址还不够——用户不会主动去输入「斜杠英文」。用中间件在请求进入前做一次判断：如果地址里没带语言前缀，就依次从用户凭据、再从请求头里的语言偏好中推断语言，然后重定向到带前缀的地址；如果已经带了前缀，就原样放行。检测有优先级很重要：用户的显式选择（存在凭据里）应当优先于浏览器的语言偏好。

最后是用户主动切换。在客户端组件里读取当前路径，把第一段语言前缀替换成新语言再跳转，用户就能在语言之间自由切换，而且地址会跟着变，刷新也不会丢。

两个实现细节：语言前缀是动态路径段，所以中间件的匹配范围要排除接口路径与静态资源，否则接口请求会被误当成缺语言前缀而被重定向，前端拿到的就不是数据而是跳转；另外除了自建方案，社区里也有封装好的多语言库可以直接用，但无论用哪种，独立地址、按需字典、服务端可感知语言这三点都不能省。

前缀字典与检测

地址内嵌语言

国际化的关键决定只有一个：让语言成为地址的一部分。地址里带语言，服务端渲染时就知道该输出什么，搜索引擎与分享抓取也能拿到正确的版本；字典按语言拆分按需加载，检测交给中间件，切换交给客户端。展示之外的部分补齐了，多语言才算真的做完。

「语言前缀路由」用动态路径段为每种语言生成独立地址，使每种语言都能被单独收录与分享，并让服务端在渲染时即知晓语言；字典按语言拆分、按需加载以控制体积，中间件依据凭据与请求头自动检测并重定向到对应语言前缀。中间件的匹配范围需排除接口与静态资源，避免请求被误重定向。

// i18n/get-dictionary.ts - 字典加载
import 'server-only'
import type { Locale } from './config'

const dictionaries = {
  zh: () => import('./dictionaries/zh.json').then(m => m.default),
  en: () => import('./dictionaries/en.json').then(m => m.default),
  ja: () => import('./dictionaries/ja.json').then(m => m.default),
}

export const getDictionary = async (locale: Locale) => {
  return dictionaries[locale]?.() ?? dictionaries.zh()
}

// app/[lang]/layout.tsx - 布局
import type { Metadata } from 'next'

export default function RootLayout({

// 动态 metadata
export async function generateMetadata({
  params,
}: {
  params: { lang: string }
}): Promise<Metadata> {
  const titles: Record<string, string> = {
    zh: '我的网站',
    en: 'My Website',

    title: titles[params.lang] || titles.zh,

}

// app/[lang]/components/LanguageSwitcher.tsx
'use client'

import { usePathname, useRouter } from 'next/navigation'
import { i18n } from '@/i18n/config'

export function LanguageSwitcher() {
  const router = useRouter()
  const pathname = usePathname()

  function handleChange(e: React.ChangeEvent<HTMLSelectElement>) {
    const newLang = e.target.value
    // 替换路径中的语言前缀
    const segments = pathname.split('/')
    segments[1] = newLang
    router.push(segments.join('/'))
  }

  return (
    <select onChange={handleChange} defaultValue={pathname.split('/')[1]}>
      {i18n.locales.map(locale => (
        <option key={locale} value={locale}>
          {locale === 'zh' ? '中文' : locale === 'en' ? 'English' : '日本語'}
        </option>
      ))}
    </select>
  )
}

// middleware.ts - 自动语言检测
import { NextResponse, type NextRequest } from 'next/server'
import { i18n } from './i18n/config'

function getLocale(request: NextRequest): string {
  // 从 cookie 读取
  const cookieLocale = request.cookies.get('locale')?.value
  if (cookieLocale && i18n.locales.includes(cookieLocale as any)) {
    return cookieLocale
  }

  // 从 Accept-Language 检测
  const acceptLanguage = request.headers.get('accept-language')
  if (acceptLanguage) {
    const preferred = acceptLanguage.split(',')[0].slice(0, 2)
    if (i18n.locales.includes(preferred as any)) {
      return preferred
    }
  }

  return i18n.defaultLocale
}

export function middleware(request: NextRequest) {
  const pathname = request.nextUrl.pathname

  // 检查路径是否已有 locale
  const pathnameIsMissingLocale = i18n.locales.every(
    locale => !pathname.startsWith(`/${locale}`) && pathname !== `/${locale}`
  )

  if (pathnameIsMissingLocale) {
    const locale = getLocale(request)
    return NextResponse.redirect(
      new URL(`/${locale}${pathname === '/' ? '' : pathname}`, request.url)
    )
  }

  return NextResponse.next()
}
