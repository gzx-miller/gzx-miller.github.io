Streaming 与 Suspense 流式渲染

用 Suspense 边界实现流式渲染，让慢组件不阻塞首屏，渐进式展示内容。

开场问题：仪表盘上顶部标题和几个统计数字早就该出来了，可整页就是白屏不动，非要等最慢的那个图表接口返回才一起显示——为什么快的部分要被慢的拖住，不能先给用户看点东西？

快慢模块共存

一个页面里往往混着快慢悬殊的模块。头部标题几乎瞬间就绪，统计数字查一次数据库就能回来，而营收图表可能要调很慢的第三方接口。如果服务端坚持「把数据拿齐再一起发给浏览器」，那么整页的首屏时间就被最慢的那一环决定：快的部分明明能马上用，却只能陪着一起等。

矛盾在于：服务端渲染天然是「先算完、再输出 HTML」的线性流程，而各部分的就绪时间并不一致。要让用户尽早看到内容，就得允许 HTML 分批地、按到达顺序送到浏览器，而不是攒成一大块。问题是，怎么在代码里表达「这一块可以先等、那一块先发」？

整页等待策略

最小的一步，是承认「数据必须等」，于是整页一起 await 完再返回。它做对了一件事——实现简单、结果确定，页面要么完整出现，要么干脆还没出现，不会出现半成品。

但代价是把所有模块绑成同一根时间线：一个慢请求就会堵住整页，用户面对的是长时间白屏，而不是「先看到框架、再逐块填满」。

最慢模块拖累

  • 首屏被最慢的组件拖住，快组件只能陪跑，用户等待体感很差。
  • 没有「部分已就绪」的表达，无法先给用户一个骨架。
  • 页面级 loading.tsx 只覆盖整条路由的等待，粒度太粗，管不了页面内部的慢模块。
  • 多个互不依赖的数据块仍按串行等待，浪费并行的时间。

流式渲染改造

不推翻「服务端渲染」，而是把输出方式从「一次性」改为流式（Streaming）：服务端把已渲染的 HTML 分块发出去，浏览器边收边渲染。用户因此能很早看到骨架与已就绪的内容，慢的部分准备好再补上。

用来划分「哪一块可以先等」的工具，是 React 的 <Suspense> 边界。把慢的异步组件用 <Suspense> 包起来并给一个 fallback：渲染到这里时，若该组件的数据还没回来，就先把 fallback（通常是一个骨架屏）发出去，继续渲染后面的内容；等数据就绪，再把真正的 HTML 流式替换进去。

  1. 把快速组件直接渲染，它会出现在最早的一批 HTML 里。
  2. 把慢组件用 <Suspense fallback={骨架屏}> 包裹。
  3. 服务端遇到该边界时，先输出 fallback，不在这里阻塞。
  4. 慢组件数据 resolve 后，把真实内容流式发送并替换掉骨架。

这套机制能成立，前提是慢组件本身是异步的 Server Component，内部用 await 取数据。服务端渲染遇到未就绪的异步组件时要「先跳过、稍后回来补」，只有异步组件才提供了可被挂起、等待后继续的机会。

路由级的整页加载则用 loading.tsx：它相当于路由级 <Suspense>，会自动包裹同目录的 page，导航时自动显示其中的加载界面，不必手动写一层 <Suspense>。页面外层的等待用它，页面内部的慢模块用显式边界，两者各管一层。

更实用的是多个边界并行。把图表、统计、订单三个互不依赖的数据块各自用 <Suspense> 包一层，它们会独立加载、互不阻塞：谁先准备好谁先显示，用户不必等三个都到齐。这也是流式渲染收益最明显的场景。

手段作用范围
<Suspense fallback>页面内部某个慢组件或数据块
loading.tsx整条路由，导航时自动显示
多个 <Suspense>各数据块并行加载、互不阻塞
一个直接收益：把慢组件用 <Suspense> 隔离，让快速部分优先输出，能明显改善 LCP（最大内容绘制）等指标——用户更早看到主要内容，而不是盯着白屏。
边界粒度要拿捏：拆分应按数据依赖来划，而不是越细越好。把一整段内容切成一堆极小的 <Suspense>，会产生大量小分块，增加调度与替换开销，反而拖慢。合理做法是把「同一份数据驱动的区域」放进一个边界。

骨架占位与替换

分块输出与边界

流式渲染这一课，核心是让服务端「分块输出」而不是「攒完再发」：用 <Suspense> 边界把慢组件隔离出去，先返回 fallback，数据就绪后再流式替换。路由级的等待用 loading.tsx，页面内的慢模块用显式边界，多个边界并行还能让各区块各显各的。

「Streaming 与 Suspense」中 Streaming 指服务端把渲染好的 HTML 分块发送给浏览器、让其边收边渲染；<Suspense> 是划分边界的工具：慢的异步 Server Component 被包裹后，服务端先返回 fallback（骨架屏），数据 resolve 后再流式替换成真实内容。loading.tsx 是路由级 Suspense 的语法糖，会自动包裹同目录的 page。流式依赖异步 Server Component 配合 await；边界粒度应按数据依赖划分，过细会产生大量小块、增加调度开销。

关键代码

JSX
// app/page.tsx - 使用 Suspense 包裹慢组件
import { Suspense } from 'react'
import { FastContent } from './FastContent'
import { SlowContent } from './SlowContent'
import { LoadingSkeleton } from './LoadingSkeleton'

export default function HomePage() {
  return (
    <div>
      {/* 快组件直接渲染，立即显示 */}
      <FastContent />

      {/* 慢组件用 Suspense 包裹，先显示 fallback */}
      <Suspense fallback={<LoadingSkeleton />}>
        <SlowContent />
      </Suspense>
    </div>
  )
}

// app/FastContent.tsx - 快速组件
async function getQuickData() {
  // 模拟快速请求
  await new Promise(resolve => setTimeout(resolve, 100))
  return { message: '快速加载完成' }
}

export async function FastContent() {
  const data = await getQuickData()
  return <div className="fast">{data.message}</div>
}

// ============================================

// app/SlowContent.tsx - 慢速组件
async function getSlowData() {
  // 模拟慢请求
  await new Promise(resolve => setTimeout(resolve, 3000))
  return { items: ['项目 A', '项目 B', '项目 C'] }
}

export async function SlowContent() {
  const data = await getSlowData()
  return (
    <div className="slow">
      <h2>慢速数据</h2>
      <ul>
        {data.items.map((item, i) => (
          <li key={i}>{item}</li>
        ))}
      </ul>
    </div>
  )
}

// ============================================

// app/LoadingSkeleton.tsx - 骨架屏
export function LoadingSkeleton() {
  return (
    <div className="skeleton">
      <div className="skeleton-title" />
      <div className="skeleton-line" />
      <div className="skeleton-line" />
      <div className="skeleton-line short" />
    </div>
  )
}

// app/dashboard/loading.tsx
// 自动包裹 page.tsx，导航时显示
export default function DashboardLoading() {
  return (
    <div className="loading-container">
      <div className="spinner" />
      <p>加载仪表盘数据...</p>

// 多个 Suspense 并行流式渲染
// app/dashboard/page.tsx
import { Suspense } from 'react'
import { RevenueChart } from './RevenueChart'
import { UserStats } from './UserStats'
import { RecentOrders } from './RecentOrders'

export default function DashboardPage() {
  return (
    <div className="dashboard-grid">
      <Suspense fallback={<div>加载图表...</div>}>
        <RevenueChart />
      </Suspense>

      <Suspense fallback={<div>加载统计...</div>}>
        <UserStats />
      </Suspense>

      <Suspense fallback={<div>加载订单...</div>}>
        <RecentOrders />
      </Suspense>
    </div>
  )
}

// 三个组件独立加载，互不阻塞
