向量与数字照片

认识向量把「像不像」变成可计算的坐标与距离，先亲历概念再理解维度的意义。

开场问题：计算机只认识数字，它怎么知道「猫」和「老虎」比「猫」和「金鱼」更像？

计算机识别猫与老虎

假设你在写一个程序，希望它能回答「猫、老虎、金鱼——哪两个更像」。你脱口而出「猫和老虎」，理由是「都是猫科、长得像」。但问题来了：计算机不懂「猫科」、不懂「长得像」，它只认识数字。你没法把一只猫塞进 CPU，只能给它数字。那么，如果只允许用数字描述一只动物，你打算怎么描述？

先给动物打体型分

最省事的做法：给每种动物打一个「体型分」（0 到 1）。金鱼 0.02、猫 0.25、狗 0.45、鳄鱼 0.50、老虎 0.90。瞬间，「像不像」变成了可计算的东西——两个数的差越小就越像：距离(猫,老虎)＝|0.25−0.90|＝0.65，而距离(猫,金鱼)＝|0.25−0.02|＝0.23。虽然结论反了，但这个方案做对了一件大事：把「比较两个事物」变成了「比较两个数字」，这个思想要保留。

单个数字丢失特征

  • 在一个数字的世界里，狗和鳄鱼成了「天造地设的一对」——只因为它们差 0.05，体重差不多。
  • 把一只动物压成一个数时，丢掉了太多信息：性格、习性、危险程度全没了。

再加一维体型凶猛

不推翻「用数字描述」，给每只动物两个数 (体型, 凶猛)，一个当横坐标、一个当纵坐标，从数轴升级到平面。狗和鳄鱼在横轴上仍贴着，但「凶猛」这一轴把它们狠狠拉开（距离从约 0.05 变成约 0.70）。

关键的一步出现了：你把一只动物写成了一组有顺序的数字——狗 = [0.45, 0.20]。这组数字，数学上就叫向量。数字的个数叫维度，刚造的是 2 维向量。同一个向量有三副面孔，说的是同一件事：它是一列数字（计算机看到的）、平面上一个点（画出来的）、从原点指向那个点的一支箭头（最好用的视角）。

再往下：体型和凶猛都接近的猫和狐狸怎么区分？再加一维「是否家养」；会飞的和会游的？再加。每发现一种区分不开，就加一个维度。3 个数是空间里的点，4 个、100 个数画不出来，但数学不在乎——距离照样算、相似照样比。GPT 一类大模型里每个词就是一个上万维的向量（GPT-3 用了 12288 维），没人指定「体型」「凶猛」，这些维度是模型自己从海量文本里学出来的，但思想和你今天发明的完全一样。

向量如数字照片

向量，就是给事物拍的一张「数字照片」：用一组有顺序的数字捕捉特征，于是「像不像」这种模糊的直觉，第一次变成了可以计算的距离。

「向量」是指一组有顺序的数字（如 [0.45, 0.20]），其中数字的个数叫维度。它有「一列数字 = 空间中的点 = 从原点出发的箭头」三副面孔；两个向量离得越近，代表的事物越像，即相似度 = 距离。

关键代码

PYTHON
# 用一组有顺序的数字（向量）把事物变成可计算的距离
cat    = [0.25, 0.80]      # (体型, 凶猛)
tiger  = [0.90, 0.95]
goldfish = [0.02, 0.30]

def dist(a, b):            # 欧几里得距离：算两个向量差多“远”
    return sum((x - y) ** 2 for x, y in zip(a, b)) ** 0.5

print(dist(cat, tiger))    # 0.66 —— 猫与老虎“像”
print(dist(cat, goldfish)) # 0.55 —— 猫与金鱼“不像”
# 维度不足就再加一维，直到能把想区分的事物全部拉开
