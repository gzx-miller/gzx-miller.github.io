前馈模型与稀疏灾难

前馈语言模型把最近 N 个词的词向量拼接后送入全连接网络预测下一个词；相近的词向量带来相近的输入，从而对未见过的词组举一反三、绕开 N-gram 的稀疏灾难，但仍受固定上下文窗口限制。

开场问题：N-gram 的稀疏灾难是怎么被绕开的？

N-gram遇到新搭配

用 N=3 试试「科学家发现了一颗围绕黑洞运转的 ___」，N-gram 要查「围绕黑洞运转」后面最常跟什么词——结果是个尴尬的 0 次。「黑洞」本就是冷僻词，「围绕黑洞运转的」这个完整组合普通文本里压根没出现过。查不到就只能回退：砍前文看「运转的 ___」甚至「的 ___」，可「的」后面最常见的是「人」「树」「东西」这类万金油词——于是它一本正经地补出「围绕黑洞运转的树」。病根：N-gram 眼里每个词都是孤立的符号，即便语料里「围绕恒星运转的行星」出现过一万次，对这条空白记录也帮不上忙——它毫无推断能力。

词向量拼接过网络

把上一课的文字向量拼进来，2003 年 Bengio 的办法朴素得惊人，就三步：

  1. 查向量：把最近的 N 个词，各自换成它的词向量（一串数字）；
  2. 拼起来：把这几串数字首尾相接，拼成一长串，作为神经网络的输入；
  3. 过网络：送进一个神经网络，输出词表里每个词「该是下一个词」的概率。

关键的转折在第 1 步：神经网络的输入从今往后是数字、不再是符号。而这个「神经网络」不是新东西，正是卷二积木的组合：过「Wx + b 加激活函数」、最后用 Softmax 压成概率；真实的下一个词是标准答案，用交叉熵算预测有多离谱、再靠反向传播把误差摊回每个权重连同词向量一起微调。

迭代手算一遍前向

简化到能手算的尺寸：上下文取 2 个词（「围绕」+ 待定词，先用「恒星」）、词向量只要 2 维（第 1 维叫「天文性」）、候选只留「行星 / 雨伞」。查表：围绕 = [0.10, 0.20]、恒星 = [0.90, 0.15]，拼成 [0.10, 0.20, 0.90, 0.15]。隐藏层放一个「天文语境探测器」，只盯天文性那维，做 tanh(wx+b)（权重 1.5、偏置 −0.8）：h = tanh(1.5×0.90 − 0.8) ≈ 0.50。输出层让「行星」分数 = 2.5h、「雨伞」固定为 0，再用 Softmax 挤概率：e^1.25/(e^1.25+e^0) ≈ 78% 是「行星」。一串数字经「拼接 → 一次加权 + tanh → softmax」，就成了有理有据的预测。

见证举一反三

回到难住 N-gram 的「黑洞」。假设训练里「围绕黑洞」从没出现过，但词向量让「黑洞」和「恒星」挨得极近：恒星 = [0.90, 0.15] vs 黑洞 = [0.85, 0.20]。同一台机器重算：h = tanh(1.5×0.85 − 0.8) ≈ 0.44 → 行星 ≈ 75%。78% vs 75%——几乎一模一样。道理很朴素：黑洞的向量和恒星只差一点点，拼出的输入就只差一点点，隐藏层是连续函数、输入差一点输出也只差一点。于是哪怕「围绕黑洞」从未出现过，网络照样稳猜「行星」。而换成「香蕉」（向量差得远），输出立刻翻盘成「雨伞」——这正是 N-gram 怎么也做不到的泛化。

上下文窗口被钉死

但两者仍有共同死结：上下文窗口是固定大小的。N 通常只设 3~5——窗口变大、拼接输入变长、网络变大，训练成本飙升而回报越来越小。看这句：「那只从小被遗弃在废弃工厂里、因长期挨饿而格外暴躁的流浪犬，今天终于被好心人收留了，它＿＿＿」——要填最后一个词得读懂整段故事，但 FFNN 只看得见最后几个词「它＿＿＿」，前面一长串铺垫全被挡在窗口外面。想要模型记住更早的内容，就要引入能保留历史记忆的结构——那是下一课的故事。

相近向量带来相近预测

FFNN 语言模型 = 词向量 + 神经网络：把最近 N 个词的向量拼成一长串，送进全连接网络预测下一个词。关键进步是相近的词向量 → 相近的输入 → 相近的预测，于是能对没见过的组合举一反三、绕开 N-gram 的稀疏灾难；遗留问题是上下文窗口仍固定，看不到更远处。

「前馈神经网络语言模型（FFNN-LM）」是指把最近 N 个词的词向量拼接后送入全连接神经网络预测下一个词的模型，利用相近词向量带来相近输入，从而对语料中没出现过的词组也具备推断能力（泛化），绕开了 N-gram 的稀疏性，但仍受固定上下文窗口的限制。

关键代码

PYTHON
import numpy as np

def relu(x): return np.maximum(0, x)

# 前馈语言模型：窗口里的词先查向量，拼接后送入全连接
emb = { "猫":[0.1, 0.9], "猎狗":[0.3, 0.7], "老虎":[0.8, 0.8] }
window = [emb["猫"], emb["猎狗"]]
x = np.concatenate(window)                # 两个词向量拼成一串
W1, W2 = np.random.randn(8, 4), np.random.randn(4, 8)
h   = relu(W1 @ x)                        # 相近输入 -> 相近输出
logits = W2 @ h

# 没见过的“猫 猎狗”因为和训练过的词向量相近，也能推对，
# 从而绕开 N-gram 的稀疏灾难 —— 这是词向量带来的泛化
