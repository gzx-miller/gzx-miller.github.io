梯度与蒙眼下山

从「蒙眼下山」出发，经导数、偏导数与方向导数，把最陡的下山方向打包成梯度向量 ∇L；沿其反方向更新参数即梯度下降，正是神经网络训练的核心引擎。

开场问题：蒙着眼睛站在山坡上，怎么走到山谷最低点？

蒙眼下山摸到谷底

你被蒙上眼睛，独自站在一片连绵起伏的山坡上，任务是走到山谷的最低点。你看不见远处地形，唯一能依靠的是脚底下的触感——往四周探一探，就能感觉哪边是下坡、坡有多陡。几乎是本能地，每个人都会这么走：探一圈、找出脚下最陡的下坡方向，朝那个方向迈一小步，站定再探、再迈，重复。只要每步都朝「当前最陡的下坡」走，迟早走到四面都是上坡的谷底。这个朴素到极点的办法，就是神经网络训练的核心思想。接下来要做的事只有一件：把「用脚感受坡度」翻译成计算机能算的数学，依此经过导数、偏导数、方向导数，最后总结梯度。

最小方案导数与斜率

先把问题简化到极致：把山的走势抽象成平面上的一条曲线，上帝视角一眼能定位谷底；可身处山中的人看不到全局，只能在脚下往左、右各探一点点，凭升降判断方向——而升降正由该点的斜率决定。斜率正→往右边是上坡、往左边是下坡；斜率负→往右是下坡。

麻烦在于：直线的斜率好算（任取两点「竖直上升÷水平移动」），可曲线每点陡峭程度都不同，没有统一的「上升÷移动」。数学专门造了工具——导数。办法很自然：在曲线上取两点，连接它们的割线斜率是这一小段的平均斜率；让第二点不断滑回自身（Δx→0 取极限），割线越转越贴近在哪一点才轻轻擦过的切线，切线斜率就是那一点的精确斜率。用抛物线 h(x)=(x−4)² 实跑：求导得 h′(x)=2(x−4)，在 x=1 处 h′(1)=−6。符号是负→往右下降；大小是 6→坡很陡。一句话：沿导数的反方向走，就是下坡。

发现不足一维太理想

  • 真实的山坡是二维地面，可以往东西（x）走，也可以往南北（y）走，高度同时取决于两个坐标。
  • 你真正想知道的不是「沿东西」或「沿南北」的坡度，而是「随便朝哪个方向迈步的坡度」——尤其是最陡的那个方向。

梯度打包最陡方向

偏导数：山其实是二维的

很自然的想法是分两次量：南北按住只动东西，量出东西方向坡度；再东西按住只动南北。这两个「只动一个方向、其余按住不动」量出的坡度叫偏导数（用圆头 ∂ 写）。∂h/∂x 就是只动东西时的坡度，∂h/∂y 是只动南北时的。对碗形函数 h(x,y)=(x−4)²+(y−2)²：∂h/∂x=2(x−4)、∂h/∂y=2(y−2)。

方向导数：朝任意方向看坡度

沿任意方向 u 迈步的坡度叫方向导数。神奇的是不需要对每个方向重新实测——把两个偏导数拼成一个向量，任意方向的坡度就等于它和方向 u 的点积：Duh = (∂h/∂x)·u₁ + (∂h/∂y)·u₂。点积是投影：坡度向量投影到方向 u 上，什么时候投影最长？当 u 和它方向完全一致的时候。深藏的关键直觉是——最陡的方向，就是那个「坡度向量」自己指的方向。

梯度：最陡方向，打包成一个向量

把所有偏导数排成一个向量，就叫梯度，记作 ∇h。它有两个极其有用的几何含义：方向指向上升最快（坡最陡）的方向，大小就是那个最陡方向上的坡度。在 (1,5) 处 ∇h = (−6,+6)，指向爬升最快的「西偏北」；我们要下山，就走它的反方向「东偏南」。于是「蒙眼下山」的每一步变成一个干净公式：

xnew ← x − α∇h，减号＝朝梯度反方向走，α 是步长。不断重复就把你一步步带向谷底，它有个正式名字：梯度下降（Gradient Descent）。

从山坡到神经网络

换回 AI：神经网络训练就是一次蒙眼下山，只是换了名字——山的海拔高度对应模型的损失，你站的位置坐标对应模型的所有参数，脚下最陡的下坡方向就是梯度的反方向。唯一区别是维度：山坡只有 x、y 两个坐标，大模型有上千亿个参数。损失对每个参数都有偏导数，打包成梯度 ∇L，再同时更新所有参数 w ← w − α∇L(w)——一次更新把上千亿参数全部朝「损失更小」的方向推一步，这就是神经网络训练的核心引擎。

梯度反方向走向谷底

梯度就是「蒙眼下山时脚底感受到的最陡方向」的数学版本。一维时它是导数；多维时先对每根轴求偏导数，任意方向坡度由方向导数给出；而最陡方向就是把这些偏导数打包成的向量——梯度 ∇L。沿其反方向更新参数，正是整个神经网络训练的核心机制。

「梯度」是指把所有偏导数装进一个向量 ∇h = (∂h/∂x, ∂h/∂y) 得到的对象：它指向上升最快的方向，大小为该方向上的坡度；要下山（最小化损失）就沿它的反方向更新参数 w ← w − α∇L，即梯度下降。

关键代码

PYTHON
import numpy as np

# 梯度：把所有偏导数装进一个向量，指向“最陡上升”方向
def f(w1, w2):                  # 损失曲面，比如一个碗
    return (w1 - 3) ** 2 + (w2 + 2) ** 2

def grad(w1, w2, h=1e-3):       # 数值求导近似
    g1 = (f(w1 + h, w2) - f(w1 - h, w2)) / (2 * h)
    g2 = (f(w1, w2 + h) - f(w1, w2 - h)) / (2 * h)
    return np.array([g1, g2])

w = np.array([0.0, 0.0])
alpha = 0.1                      # 学习率：一步迈多大
for _ in range(60):              # 沿负梯度方向迭代下山
    w = w - alpha * grad(*w)
print(w)                         # ≈ [3., -2.] 山谷最低点
