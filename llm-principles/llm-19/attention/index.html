注意力机制与看向何处

注意力让每个词用自己的 Query 查所有词的 Key 打分、softmax 归一成权重，再按权重混合各词的 Value，词义随上下文而变；缩放因子 √d_k 防止 softmax 饱和，且全句并行、任意距离一次直达。

开场问题：「它太累了」——「它」指谁？让每个词自己决定该看向哪里

注意力回头看机制

读两句几乎一样的话：「小猫没有过马路，因为它太累了。」和「…因为它太堵了。」两个「它」指的东西完全不同：第一句指小猫，第二句指马路。你几乎是无意识就分辨出来了——读到「它」时，你的目光回头扫了一眼前文，只在「小猫」和「马路」之间挑了一个，其余的字几乎被忽略。这个「回头看、且看得有轻有重」的动作就是人类的注意力，问题是：怎么让神经网络也学会这个动作？

旧方案的局限：RNN / LSTM 从左到右逐词读入，把读过的一切不断压缩进一个固定大小的向量里，像滚雪球装进一只「行李箱」——句子越长，越早装进去的东西越容易被压变形。等网络读到「它」时，「小猫」已是五步前的记忆。LSTM 的阀门缓解了遗忘，却没解决根本问题：所有历史共用一条固定宽度的门缝。

按分值混合所有词

激进一点：根本不压缩，所有词的向量都原样留在桌面上，「它」需要谁就直接去看谁。新方案只有三步：

  1. 打分：「它」想知道每个词和自己的相关度。两个向量的点积越大越相关，就让「它」的向量和每个词的向量分别做点积，得到一排分数。
  2. 变成权重：分数有正有负不好直接用，用 softmax 把这一排分数变成加起来等于 1 的比例，比如「小猫 62%、马路 9%、累 13%」。
  3. 按比例混合：用这些百分比对所有词的向量加权求和，得到一个主要由小猫构成、掺了一点「累」的「它」——指代问题就这样被算了出来。

发现不足一词顾两头

直接拿词向量互相点积藏着毛病：一个词「想找什么」和「能提供什么」是两回事。「它」是代词，想找的是「前文某个具体事物」；而它能供给别的词的信息只是「这里有个代词」。一个向量身兼两职会互相打架。

迭代一三角色QKV

修补的办法也很小：别用原始向量直接对话，让每个词先通过三个可学习的线性变换矩阵 W_Q, W_K, W_V，生成三个「分身」，就像在图书馆里：

  • Q（查询单）「我在找：前文里一个具体事物」
  • K（书脊标签）「我这里有：一只动物、名词、主语」
  • V（书的内容）「真正被取走混合的信息本体」

于是打分规则修正为：用「它」的 Q 去点积每个词的 K，权重算好后混合的是每个词的 V。三个矩阵都是训练学出来的——「该注意什么」这件事本身，是模型自己学会的。

迭代二从词到整句

这套动作只照顾了「它」一个词，真实的句子里每个词都得回头看一遍。与其逐个循环，不如把「对所有词各做一遍」用矩阵一次写完——把每个词的 q、k、v 从上到下摞成矩阵 Q、K、V，整套流程就坍缩成一个式子，正是 2017 年 Google 论文《Attention Is All You Need》的核心（Scaled Dot-Product Attention）：

Attention(Q, K, V) = softmax(QKᵀ / √d_k) V，四步：QKᵀ 打分 → ÷√d_k 降温 → softmax 归一成权重 → 乘 V 混合。

每一行的作用（以「它」这一行为例）：

  1. 打分 QKᵀ：一次把所有词对所有词的分数打出来，第 i 行第 j 格即「第 i 个词该看第 j 个词多少」。
  2. 降温 ÷√d_k：论文里 d_k=64 维点积数值很容易累积很大，喂进 softmax 会「饱和」，注意力变成非黑即白、梯度几乎为零。统一除以 √64=8，把分数缩回温和范围。
  3. 归一 softmax：对每一行做 softmax，变成加起来等于 1 的权重表。
  4. 混合 ×V：拿权重取各词的 V 加权相加。前三步只是算出「该看谁」的计划，这一步才把信息真的搬进词里。

这个设计有两个「免费赠品」：所有词的回头看是同时发生的（矩阵一乘全算完，不用排队）；「小猫」距「它」5 个词还是 500 个词都是一次直达，不存在传着传着丢了的问题——行李箱被彻底扔掉了。

迭代三代入数字手算

把向量缩到 2 维落地验算。三个分身设计成「第 1 维是动物味、第 2 维是疲惫味」：小猫 q=[0.3,0.3], k=[1.2,0], v=[1.0,0]，累 q=[0.2,1.5], k=[0,1.0], v=[0,1.0]，它 q=[2.0,0.2], k=[0.1,0], v=[0.5,0.5]。只算「它」这一行：

  1. 打分：它·小猫 = 2.4，它·累 = 0.2，它·它 = 0.2。「它」的查询几乎和「小猫」的 key 同向，点积远甩后面两个。
  2. 降温 ÷√2≈1.41：1.70、0.14、0.14。
  3. softmax：小猫 ≈ 70.3%、累 ≈ 14.8%、它 ≈ 14.8%，和为 100%。
  4. 混合：out = 0.703×[1.0,0] + 0.148×[0,1.0] + 0.148×[0.5,0.5] = [0.78, 0.22]。
「它」原本是个空洞的代词（从词表查出的固定向量，与上下文无关），经过这轮注意力变成 [0.78, 0.22]——0.78 的动物味 + 0.22 的疲惫味，模型算出了「这个『它』≈ 一只（有点累的）小猫」。这个装好料的新向量会顶替原向量继续往上走。把 2 维换回 64 维、把「只算一行」换成「n 行一起算」，就是真实 Transformer 每层都在做的事。

按匹配度分配目光

注意力机制就是让每个词带着自己的问题（Q）去查所有词的标签（K），按匹配程度分配目光，再把对应的内容（V）按比例混合成自己的新含义——理解一个词不再依赖一条会遗忘的传话链。本课要点：注意力权重（点积打分 + softmax 归一）；Q/K/V 三个可学习矩阵生成的分身；缩放因子 √d_k 防止 softmax 饱和；以及全句并行、任意距离一步直达这两个免费赠品。

「注意力机制（Attention）」是指让每个词通过查询 Q 与所有词的键 K 点积打分、softmax 归一成权重，再按权重混合各词的值 V，从而让每个词都得到「该看谁、看多少」且随上下文而变的向量表示；其缩放点积形式 softmax(QKᵀ/√d_k)V 是 Transformer 和大语言模型的基石。

import numpy as np
def softmax_logits(z):
    e = np.exp(z - np.max(z)); return e / e.sum()

# 注意力：每个词用自己的 Query 查所有词 Key 打分，
# softmax 归一后按权重去混合 Value
def attention(Q, K, V, dk):
    scores = Q @ K.T / np.sqrt(dk)      # (词 x 词) 相关度，除以 sqrt(dk) 防方差爆
    weights = softmax_logits(scores)
    return weights @ V                   # 加权混合，得上下文相关的表示

# “它太累了”的“它”回头看上下文里出现过的那只猫，
# 词义不再固定，而是随上下文而变 —— 这就是注意力
