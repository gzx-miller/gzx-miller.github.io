模型蒸馏与知识传授

蒸馏让学生模型学习教师模型输出的概率分布（软标签）而非只抄正确结论；软标签里藏着「暗知识」（错误项的相对高下），靠升温 T 放大，损失 = α·KL(贴近教师) + (1−α)·交叉熵(对照真答案)。

开场问题：大模型再快也是大——它能把自己一身本事「教」给一个小得多的模型吗？软标签里藏着什么「暗知识」？

大模型教导小模型

我们已经能造出 GPT-4 级别的庞然大物——会写论文、读合同、解数学。可它太贵：每生成 1000 个 token 约 0.03 美元，一家中型公司用它扛全部客服对话，一年 API 账单轻松上百万美元。而一个 7B 小模型在单张消费级显卡（16GB 显存）上就能跑，成本是前者的几百分之一，却笨得多。分岔就在眼前：能不能把大模型的本事「教」给一个小模型？

硬标签丢掉的那层讲究

一个自然的想法是：用大模型给一堆问题生成标准答案，再拿这批数据训小模型。可它漏了最关键的东西。考「法国的首都？A. 巴黎 B. 伦敦 C. 罗马 D. 柏林」，有两种讲法：硬标签只传一个比特「选 A」；而软标签给完整概率分布「A 99.6%、B 0.25%、C 0.09%、D 0.05%」——它还顺带告诉你：错误项里伦敦比罗马、柏林更像个首都。这层「错得有讲究」的信息，硬标签里完全没有。这就是 Hinton 2014 年提出的知识蒸馏：让学生模型去模仿教师模型的输出分布，而不只是抄那个正确答案。学生学的是教师的「判断纹理」，不只是结论。Hinton 把这层信息称作「暗知识」（dark knowledge）。

教师太自信黑盒无分布

可这里有个麻烦：

  • 教师太自信了——原始分布常 99.6% 全压在正确答案上，错误项小到 0.05%，暗知识淹在小数点后好几位，学生几乎看不见。
  • 黑盒 vs 白盒：经典「分布蒸馏」要求拿得到教师每一步、整个词表上的概率分布，只有在你自己拥有教师模型（白盒）时才行；而大多数人只能通过 API 调 GPT-4，它只吐文本不吐内部分布。

升温让暗知识浮现

让暗知识浮出来的开关，是第 11 课那位老朋友温度 T：softmax 之前把每个分数都除以 T，T 越大分布越「软」。拿教师打分 [8, 2, 1, 0.5] 手算：在 T=1（原始）下 softmax 得 [99.6%, 0.25%, 0.09%, 0.05%]，暗知识被压没了；在 T=4（除以 4 再 softmax）下得到 [64%, 14%, 11%, 10%]——巴黎仍最高，但「伦敦 14% > 罗马 11% > 柏林 10%」的相对纹理清清楚楚露了出来。升温不改变谁高谁低，却把被压扁的差距拉开成学生看得见的信号。于是蒸馏时学生同时背两个目标：既要像升温软化后的教师，也要答对真答案，损失 L = α·KL(贴近教师) + (1−α)·交叉熵(对照真答案)，α 常取 0.5~0.9、以软标签为主。值得一提：这一课三件工具没一件是新的——软标签是 softmax 的概率分布、温度 T 是调软硬的旋钮、KL 散度是量「两个分布差多远」的尺子，整门课的零件在此会师。

现实里因此分出两条路。白盒·分布蒸馏：教师每步给出完整概率分布，学生用 KL 对齐，信息最全但要求拥有教师内部。黑盒·序列蒸馏（API 时代主流）：教师只给生成的文本/推理链，学生当普通 SFT 训，一个 API 就够。第二条路看着「只学了硬答案」，可一旦教师够强、数据够多够好，效果惊人——尤其 2024 年起火热的推理蒸馏：让 DeepSeek-R1、o1 这类会一步步思考的强教师把完整思维链写出来，小模型照这些「解题过程」训，竟把「慢慢想」的本事也学个八九分。

学生模仿判断纹理

蒸馏让小模型学大模型的输出分布而非只抄正确答案。软标签藏着暗知识（错误项的相对高低），靠温度 T 升温才看得见；损失 = α·KL(贴近教师) + (1−α)·交叉熵(对照真答案)。白盒可做分布蒸馏、黑盒（API）只能做序列蒸馏，后者正撑起今天的推理蒸馏热潮。工业界早已用开——DistilBERT 把 BERT 蒸到 60% 大小保留约 97% 性能，Phi 只有 3.8B 却多项基准压过更大的模型，DeepSeek-R1-Distill 把推理蒸进 7B/14B。

「知识蒸馏（distillation）」是指让学生模型去模仿教师模型输出的概率分布（软标签）而非仅正确答案的过程；软标签里藏着「暗知识」——类别之间的相对关系，可通过提高 softmax 的温度 T 将其放大，损失常用「贴近教师分布的 KL 项 + 对照真答案的交叉熵项」组合。

PYTHON
import numpy as np

# 蒸馏：让“学生”小模型去学“教师”大模型输出的概率分布
# 温度 T 把分布“升温”，让软化标签含有更多暗知识，
# 即非正确答案之间的相对高下也被当作“软标签”传给学生
def softmax_t(logits, T):
    e = np.exp(np.array(logits) / T - np.max(np.array(logits) / T))
    return e / e.sum()

# 损失 = alpha*KL(学生(T=T) vs 教师(T=T)) + (1-alpha)*交叉熵(学生T=1 vs 硬标签)
# 局限：学生通常翻不过教师，蒸馏补的是“压缩部署”，不是超越
