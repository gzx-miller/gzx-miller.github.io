原理串讲到Transformer

把 30 课串成一条线——每一代技术，都是来解上一代那个死结的。

开场问题：学了这么多细节，怎么把它们重新串成一条线？——每一代技术，都是来解上一代死结的。

学过零件串成项链

这一课不引入任何新概念，只做一件事：把已学过的所有零件串成一条项链。串这条线只需记住一个叙事母题：语言难在哪，每一代技术就在补哪一刀。语言的难可归成三句话——模型必须处理顺序（「我打你」和「你打我」字一样、意思反）；一个词的意思取决于上下文（「苹果」是水果还是公司得看语境）；能组成的句子近乎稀疏，再大的语料也只见过其中极小一撮。接下来每一站都是一次「上一代留下一个死结 → 这一代解开它 → 又冒出新的死结」。

N-gram 只会数数

N-gram 是最朴素的起点：只会数数。它赌一条朴素假设（马尔可夫假设）：下一个词只跟前面紧挨着的几个词有关。用的时候把语料里的搭配频率数出来即可——接「今天天气很 ___」，数「很」后面跟过什么（好 38%、冷 21%……），赌概率最高的那个。这招在短搭配上意外好用，撑起了手机输入法几十年。但它有两道硬伤：一是稀疏（词表五万，3-gram 组合就约 5万³ 种，没见过的组合频率为 0、被判「不可能」）；二是记性短（只回头瞄两三个词，够不着跨越几十个词的线索）。它还有个根：把每个词当成孤立的符号。

每代短板逐层暴露

顺着「上一代死结」的线索，每一代的缺陷逐步暴露：

  • N-gram 把「猫」和「小猫」当成毫无关系的两个符号（符号孤立）。
  • 即便换成神经网络，固定窗口也看不到更早的上下文，长依赖抓不住。
  • 该有记忆循环了，可梯度沿时间连乘、几十步后衰减到几乎为零（梯度消失，记不远），还必须串行处理、无法并行。

词向量补到Transformer

词向量：先补「符号孤立」。把每个词变成一组数字（几百维向量），让意思相近的词向量也相近、余弦相似度高。这些数字靠「近朱者赤」的假设训练出来——一个词的意思由它常出现的上下文决定，让模型反复做完形填空，「猫」和「小猫」总出现在相似语境，就被挤到相邻位置。最惊艳的是连词间关系都被编码成向量方向，国王 − 男人 + 女人 ≈ 女王，语义第一次有了坐标。但它只是「零件」，而且是静态的——区分不了水果和公司的两个「苹果」。

神经网络语言模型：用词向量绕开稀疏。把前几个词的向量拼接起来过几层网络，最后用 Softmax 吐出「下一个词」的概率分布。飞跃在泛化：N-gram 见过「我吃苹果」、碰到「我吃梨」就傻眼，而 NNLM 知道「苹果」「梨」向量很近，本事能自动迁移过去，稀疏的诅咒就此绕开。但它还留着固定窗口的旧疾，一次只能吃前面 N 个词。

RNN：给网络装上记忆，砸开固定窗口。逐词阅读、边读边记，把「这个词 + 上一刻的记忆」揉成新记忆（隐藏状态）传给下一步，理论上能携带任意长的历史，且整条序列共用同一套权重。可惜记忆每走一步就被整体重写、早期信息一路被冲淡（梯度消失），记性其实传不远，而且天生串行，GPU 上万核心只能干瞪眼。

LSTM：给记忆装阀门。给记忆装上三道 0~1 的阀门（遗忘门丢多少旧记忆、输入门写多少新信息、输出门读出多少），外加一条「细胞状态」像传送带一样贯穿始终——信息几乎原封不动地从头滑到尾，只在阀门处被有选择地增删，重要信息能守住几十步。这条「记忆高速路」与残差连接的「梯度高速路」是同一个灵魂——给信息留一条少受干扰的直通道。但最硬的墙纹丝不动：依然要按顺序逐词处理、无法并行，模型规模卡在天花板。

Transformer：扔掉循环，让所有词同时开口。让每个词直接「查询」句中所有词：拿自己的 Query 与所有词的 Key 比对算出注意力权重，再按权重把大家的 Value 汇总。这一下解决两件大事——任意两个词一步直达、长依赖不再衰减；更致命的是计算可以完全并行，本质就是几个大矩阵相乘，正好喂饱 GPU 上万核心。并行解锁了规模，而规模本身就带来能力，参数从亿级冲到千亿万亿。把多头注意力、FFN、残差与层归一化拼成块、叠几十上百层，配上分词器与「预训练 → 监督微调 → RLHF」，就长成了 ChatGPT。它也留下新麻烦：让每个词看所有词，代价是 O(n²)，正是前沿仍在攻打的难题之一。

问题解药与新问题链

按这条链记住一句话：N-gram 数数 → 但稀疏、记性短、符号孤立；词向量 给词义坐标 → 但静态且只是零件；神经语言模型 靠泛化绕开稀疏 → 但窗口固定；RNN 循环记忆破窗口 → 但梯度消失、必须串行；LSTM 门控让记忆传远 → 但仍然串行；Transformer 注意力换来并行与规模 → 但 O(n²) 仍待优化。每一代都是一条「问题 → 解药 → 新问题」不断咬合的链，而这条链到 Transformer 并没有停——它留下的死结，正被今天的研究者解开。

「每一代技术都是来解上一代死结的」是指整部 NLP 演变史可以用一条不断咬合的链来理解：N-gram（数数）→ 词向量（语义）→ 神经语言模型（泛化）→ RNN（记忆）→ LSTM（记得久）→ Transformer（并行与规模），每一代都解决上一代留下的问题、又制造出下一个新问题。
