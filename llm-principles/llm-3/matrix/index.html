矩阵与多组变换

矩阵把多组权重排成一张表，矩阵乘向量本质是「每行与输入做点积」、同时算多个加权求和；维度规则「内层匹配、外层定维」决定了神经网络每层的输入输出形态。

开场问题：神经网络的每一层都在做「把一组数字变成另一组数字」的变换——这个操作用什么数学对象来表示？

加权求和写法啰嗦

先把数学放一边。你盘下一家奶茶店，菜单上有 3 款招牌饮品，每款按自己的配方用到 4 种原料——茶叶、牛奶、糖、珍珠。比如珍珠奶茶＝2 茶＋1 奶＋0 糖＋3 珍珠。今天 4 种原料价格是 x₁、x₂、x₃、x₄，你想立刻算出每款饮品的成本是多少？答案很简单：把配方当权重，做加权求和。三款饮品就是三条加权求和——而现实中可能是几百款产品、上百种原料，神经网络里更是几百万个权重。把每条公式分开写太啰嗦了。

最小方案配方表

把所有配方里的份数排成一张矩形表格，叫做矩阵。这张表是 3×4：3 行＝3 款饮品的配方，4 列＝4 种原料。矩阵用 m × n 描述大小：m 行、n 列。记住这个画面：一行一份配方，一列一种原料——后面所有矩阵运算都能退回这张表来理解。

矩阵乘向量逐行点积

假设今日原料价是「茶 1 元、奶 2 元、糖 1 元、珍珠 0 元」，写成列向量 x = [1,2,1,0]。矩阵乘法 Wx 的意思是：用 W 的每一行（配方）和 x（价格）做点积，结果拼成成本向量。一行 ①：2×1＋1×2＋0×1＋3×0＝4；行 ②、③ 同理，得到 y = [4, 9, 4]——珍珠奶茶 4 元、奶霸布丁 9 元、古早甜茶 4 元，一次矩阵乘法整张菜单一起算完。这正是矩阵的用处：把「同时做很多组加权求和」压成一个动作。神经网络每一层做的就是这一个动作，只是配方表大得多。

发现不足维度需匹配

  • W 有 n 列，x 就必须是 n 维，否则点积无从对齐——维度不符就完全无法计算。
  • 输出维度由 W 的行数 m 决定，即「从几维变到几维」由此确定。

迭代维度规则

矩阵乘法的核心规则只有一条，记住形状就够了：W(m×n) × x(n维) = y(m维)。内层维度必须相等，外层维度决定结果。这个「从几维变到几维」的性质，是下一课《线性变换》的核心：矩阵不只是计算工具，它在几何上代表一次空间变换——旋转、缩放、压缩或拉伸。

矩阵排列多组权重

矩阵把多组权重整齐排列：每行是一组系数，每列对应一个输入。矩阵乘向量就是每行与 x 做点积，m 行产生 m 个结果。

「矩阵」是指一张 m×n 的数字表格（m 行 n 列），把多组系数整理成一个对象。矩阵乘向量 Wx 本质是「每行与 x 做点积」，即同时算多个加权求和；维度规则为「内层匹配、外层决定结果」，把 n 维输入变成 m 维输出。

关键代码

PYTHON
import numpy as np

# 矩阵就是“多组权重”排成的一张表；Wx 即每行与 x 做点积
W = np.array([[0.2, 0.8],     # 第 1 个输出神经元：0.2*[0] + 0.8*[1]
              [0.9, 0.1],     # 第 2 个输出神经元
              [0.5, 0.5]])    # 第 3 个输出神经元
x = np.array([3, 1])          # 输入向量

out = W @ x
print(out)        # [1.4 2.8 2.0]
# 维度规则：矩阵列数 = 输入维，矩阵行数 = 输出维，内层匹配外层定
