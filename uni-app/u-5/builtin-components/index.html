🌰9 · 内置组件 约 1 分钟读完

内置组件 view/text/image/button/input

认识 uni-app 跨端基础组件，理解不能用 div/span 的原因，以及 image 必须设定宽高的细节。

开场问题：你把一段在 Vue 里写好的页面原样复制进 uni-app：<div> 做布局、<span> 放文字、<img> 放头像。H5 预览一切正常，切到微信小程序，整页内容塌成了一个小点——div 在小程序里根本不认识。

小程序视图层自绘

你想让同一套页面喂给小程序渲染，而小程序并不是浏览器：它没有文档流、没有 HTML 标签体系，视图层是自绘的。HTML 标签对它来说只是些不认识的字符串。

继续用 HTML 标签的代价很具体：div、span、img 只在 H5 生效，小程序里不渲染，布局当场崩掉；浏览器原生的 input、button 三端默认样式与行为都不一致，要分别写覆盖样式；再加上图片不给尺寸时各端默认表现不同，最容易把布局撑破。于是问题收成一句：既然不能直接用 HTML 标签，一套跨端 UI 到底该用什么来搭？

容器文本组件对应

最朴素的做法：按"块级 / 行内"给出一一对应——用 <view> 替代 <div>，用 <text> 替代 <span>。

这个方案做对了一件事：它给出了最小可用的"容器 + 文本"两种单元，页面骨架能搭起来，数据也能照常绑上去——跨端的起点就此立住。

图像按钮输入缺位

  • 光有 view、text 不够用：图片、按钮、输入框都还没有对应物，img 在小程序里不识别，头像直接不显示。
  • 只给图片一个 URL 而不管尺寸时，小程序按默认 320px × 240px 渲染，一张小头像也能把整行撑开。
  • text 并非"什么都能装"：它只渲染内部的文本与嵌套的 text，塞进去的其它节点会被丢弃；段落级文本的正确做法是外层用 view、内部按需嵌套 text。
  • 各端 button 自带不同的默认外观，样式写死在一端，换一端就变形。

跨端基础组件清单

不推翻"用容器和文本搭页面"，而是把每一类元素都补上平台级等价物，凑齐一组跨端基础组件：

  1. view：块级容器，承担布局（对应 div）。
  2. text：行内文本，可嵌套、可复制、能正确换行（对应 span）。
  3. image：图片（对应 img），默认尺寸 320px × 240px，必须显式设定宽高，或用 mode 控制缩放。
  4. button：按钮，用 size / type / loading 等属性控制形态。
  5. input：输入框，type 支持 text / number / digit / password 等场景值。

这里要理解"为什么必须换"：这组内置组件会被编译到各端的原生等价物——小程序端映射到原生组件，H5 端映射到 div、span、img 这些标签。H5 虽然顺带也认识 div，但为了跨端一致，统一写内置组件，才不会出现"某端正常、某端塌掉"的分裂。

再补图片的适配细节：image 用 mode 控制裁剪与缩放，常见值有 aspectFit（等比完整显示，可能留白）、aspectFill（等比裁剪填满）、widthFix（宽度固定、高度自适应）。选对 mode，配合显式尺寸，图片才不会撑破或变形。

三条必须记住的边界：H5 端兼容 div 只是"顺带"，小程序端不识别，跨端务必用内置组件；image 不设宽高时在小程序里按 320px × 240px 渲染，务必显式设定；input 的 type 要按场景选，收数字就用 number 或 digit，别一律默认 text。

组件定位与数据绑定

内置组件职责划分

uni-app 用一套内置组件替代了 HTML 标签：view 管布局、text 管文本、image 管图片、button 与 input 管表单交互。它们不是"HTML 的别名"，而是会被编译到各端原生等价物的抽象层——记住这一点，就不会再写只在小程序里塌掉的页面。

「mode（图片缩放模式）」image 组件上控制裁剪与缩放方式的属性，常见值有 aspectFit（等比完整显示）、aspectFill（等比裁剪填满）、widthFix（宽固定、高自适应）。要记住的边界：它只决定图片在给定尺寸里的填充方式，不会替你补上尺寸——宽高仍要显式设定；各端对个别 mode 的支持也略有差异，源图尺寸过小放大后会模糊。

关键代码

Vue
<template>
  <view class="card">
    <!-- view：块级容器，替代 div -->
    <view class="head">
      <!-- image：图片，需显式设置尺寸，mode 控制裁剪等比 -->
      <image class="cover" src="/static/cover.png" mode="aspectFill" />
      <!-- text：行内文本，可嵌套、可 selectable 选中复制 -->
      <text class="name" selectable>Vue3 组合式 API 实战</text>
    </view>

    <!-- input：输入框，type 控制键盘类型 -->
    <input class="field" type="text" v-model="mobile" placeholder="输入手机号" />

    <!-- button：按钮，size / type / loading 控制形态 -->
    <button size="mini" type="primary" :loading="submitting" @tap="join">立即报名</button>
  </view>
</template>

<script>
export default {
  data() {
    return { mobile: '', submitting: false }
  },
  methods: {
    join() {
      uni.showToast({ title: '报名成功', icon: 'success' })
    },
  },
}
</script>
