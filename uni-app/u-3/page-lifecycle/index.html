页面生命周期 onLoad 与 onShow

理解 onLoad、onShow、onReady、onHide、onUnload 的触发时机，用它编排数据拉取与缓存刷新。

开场问题：你在 onLoad 里拉了一次课程列表。用户点进详情、又返回列表页，看到的还是刚才那份旧数据——你明明把刷新写在"页面加载"里，可返回时它一次都没再执行。

返回列表刷新时机

场景很常见：列表页进详情页，返回时希望列表是最新的。你在 Vue 里习惯把初始化写进 onMounted，把它当成"页面加载时执行一次"；可小程序没有 activated 那套路由钩子，页面也不是"每次显示都重新挂载"。

于是要求变得矛盾：只在首次拉一次，返回时数据就陈旧；每次可见都重新拉，来回切换又变成请求风暴；而定时器、事件监听只在挂载时建、却没有合适的销毁时机，用着用着就积成了内存泄漏。所以真正要问的是：一个页面从创建到销毁，哪些时刻注定只发生一次、哪些时刻会反复发生，初始化、刷新和清理该怎么分别安放？

初始化写入挂载钩子

最朴素的办法：把初始化写进 Vue 的 onMounted，把它当成"页面加载时执行一次"。

这个方案做对了一件事：首次进入页面时确实完成了初始化，请求发出去了，数据也渲染出来了，单次打开的场景完全够用。

挂载钩子触发局限

  • onMounted 只代表"组件首次挂载"——从后台或其他页面返回时不会再触发，列表永远停在第一次拉到的数据上。
  • 它区分不了"页面被切走（隐藏）"和"页面被销毁"：小程序里切走并不销毁，回到前台时组件根本不会重新挂载。
  • onMounted 触发时首帧未必渲染完成，这时去量节点尺寸，可能只拿到 0。
  • 没有与"离开"对称的时机，定时器、事件监听无处清理，来回几次就越积越多。

两套生命周期并存

不推翻"初始化只做一次"的判断，而是把"页面"这个对象的完整一生拆成几个明确的时刻。uni-app 的页面生命周期继承自小程序模型，和 Vue 自身的生命周期并存——各管一摊，谁适合做什么就交给谁。

  1. onLoad：页面首次创建时触发一次，用来读取路由参数、做一次性初始化。
  2. onShow：每次页面进入前台都触发，首次紧跟在 onLoad 之后，从后台或其他页面返回时还会再来——适合刷新可能变化的数据。
  3. onReady：页面首次渲染完成后触发，此时访问节点尺寸、初始化依赖真实渲染的第三方库才可靠。
  4. onHide：页面切走但未销毁，用来暂停轮询、计时这类后台行为。
  5. onUnload：页面销毁，用来清理定时器与事件监听。

拿着这套时刻表回头看开场就通了：首次进入的序列是 onLoad → onShow → onReady；用户返回列表页时，页面并没有重新创建，触发的是 onShow 而不是 onLoad，onMounted 更是不会再出现。所以刷新要放进 onShow，一次性初始化才留给 onLoad。

这些生命周期用组合式写法时，从 @dcloudio/uni-app 导入即可（它的写法细节下一课还会展开）；注意它们和 vue 自带的 onMounted、onUnmounted 是两套东西，不要互相替代。

几个容易混淆的边界：onShow 在 onLoad 之后以及从后台返回时都会执行，别把"只该做一次"的初始化塞进它；不要在 onLoad 里做依赖 DOM 的操作，那时页面还没渲染；onHide 是"暂时隐藏、可能还会回来"，onUnload 才是"销毁、不再回来"，清理逻辑要放在后者。下拉刷新、触底加载是另外两个页面事件（对应 onPullDownRefresh / onReachBottom），别和这几个混为一谈。

生命周期时刻划分

页面生命周期的价值，是把"页面的一生"切成几个可命名的时刻：创建只一次、每次可见都一次、渲染完成一次、隐藏与销毁各一次。把一次性初始化交给 onLoad、把刷新交给 onShow、把渲染后操作交给 onReady、把清理交给 onUnload，数据陈旧和资源泄漏就同时解决了。

「onReady」页面首次渲染完成后触发的生命周期，只触发一次；此时才适合访问节点尺寸、初始化依赖真实渲染的第三方库。要记住的边界：它只对应首帧，后续数据更新不会再次触发；需要访问 DOM 的操作必须等到它，而不是放在 onLoad 里。

关键代码

Vue
<script>
export default {
  data() {
    return { courseId: '', course: null }
  },

  onLoad(options) {
    // 页面首次创建：只执行一次，读取路由参数并做一次性初始化
    this.courseId = options.id
    this.fetchCourse()
  },

  onShow() {
    // 每次回到前台（含首次显示）都执行：刷新可能变化的数据
    this.refreshProgress()
  },

  onReady() {
    // 首次渲染完成：可安全访问 DOM 节点或初始化第三方 SDK
    this.initChart()
  },

  onHide() {
    // 页面被切走但未销毁：暂停轮询、倒计时等
    this.pauseCountdown()
  },

  onUnload() {
    // 页面销毁：清理定时器、事件监听，避免内存泄漏
    this.clearTimers()
  },

  methods: {
    fetchCourse() {},
    refreshProgress() {},
    initChart() {},
    pauseCountdown() {},
    clearTimers() {},
  },
}
</script>
