WAT 文本格式与二进制对照

用可读的 WAT 文本对照每条指令的二进制操作码，建立"文本即图纸"的映射。

开场问题：你手上只有一个编译好的 math.wasm，想把里面那个常量 10 改成 20。可你没有源码，文件又是一长串十六进制——到底该改哪个字节，改完又怎么知道没把它改坏？

字节与文本互译

你要在「机器看的字节」和「人看的文字」之间来回翻译：既要读懂一份二进制里写了什么，也要能让手改的结果重新变回合法模块。

旧办法是拿肉身直接读十六进制，成本有三：操作码全是数字，人脑记不住哪条对应哪条指令；在文本里改一行，二进制里可能牵动一整段的长度前缀；改完无法验证，只能丢给引擎看它报不报错。

反编译为文本

最朴素的做法：用 wasm2wat 把 .wasm 反编译成可读文本，看懂它、在文本上改，再用 wat2wasm 编译回二进制。

这个方案做对了最关键的一件事：文本和二进制是同一件事的两面，可以互相翻译。你不再需要拿眼睛去啃字节，而是先在「图纸」上想清楚，再让它自动落成字节。

行数与字节错位

  • 一行 WAT 可能对应好几个字节（local.get $a 是 20 00 两个字节），按行数根本对不齐。
  • 不认识操作码，就没法在二进制里手工定位、修改某条指令。
  • 反编译出来的文本是「结构等价」而非「逐字相同」，和原作者手写的写法可能不一样。
  • 段的长度是字节数：你插入一条指令，就要同步改正长度前缀，改错一位整段作废。

映射表分层对应

不推翻「翻译」，而是把翻译拆成一张映射表，一层层对上。第一层，模块头和根节点对应：文本最外层的 (module ...)，对应二进制的魔数加版本 00 61 73 6d 01 00 00 00。文本换了行、加了缩进、写了注释，二进制一个字节都不多——注释和空白不占任何空间。

第二层，函数签名落在类型段。文本里 (func $add (param i32 i32) (result i32) ...) 声明了签名，二进制里对应 01 07 01 60 02 7f 7f 01 7f：60 表示这是一个函数类型，02 表示两个参数，7f 正是 i32 的类型码，末尾的 7f 则是返回值类型。

第三层，指令与操作码一一对应：local.get 是 0x20，后面紧跟一个字节的局部索引（$a 是 00、$b 是 01）；i32.add 是 0x6a；函数体的 end 是 0x0b。只要对着操作码表，你就能在二进制里精确定位一条指令。

第四层，导出段 0x07 把内部函数挂上一个对外名字。文本里的 (export "add" (func $add)) 编译后是 07 08 01 03 61 64 64 00 00，其中 61 64 64 正是字符 a d d 的 ASCII——原来字符串在二进制里就是一个个字节。

  1. 先看 (func ...) 的签名，确认参数与返回类型。
  2. 再顺着函数体逐条读指令，把指令名翻译成对应的操作码。
  3. 遇到 export 就回到导出段，看它把哪个索引挂成了什么名字。
调试任何来路不明的 .wasm，第一件事都是 wasm2wat 反编译出来读一遍——文本即图纸，看懂了图纸再决定动不动字节。

指令字节高亮

文本与字节等价

WAT 是可读文本，二进制是它的紧凑编码，两者一一对应。wat2wasm 向下编译、wasm2wat 向上还原；指令名对应固定操作码（local.get=0x20、i32.add=0x6a、end=0x0b），函数名落到导出段，签名落到类型段。拿到一份二进制，先用文本还原成图纸，再决定动不动它。

「操作码（opcode）」指二进制里表示某条指令的那个字节，如 local.get=0x20、i32.add=0x6a、end=0x0b；WAT 里的指令名与操作码一一对应，操作码之后还会跟它的立即数（如 local.get 后面的局部索引 00）。边界：注释、空白、缩进不占任何字节；一行 WAT 可能对应多个字节，反过来一条指令也可能横跨多字节，所以对账不能按行数来数。

关键代码

WAT
;; WAT 文本格式与二进制一一对应，wat2wasm 可编译成 .wasm
;; 每条指令都有固定操作码：local.get=0x20, i32.add=0x6a, end=0x0b
(module
  ;; 类型段：(i32, i32) -> i32
  (func $add (param $a i32) (param $b i32) (result i32)
    local.get $a  ;; 20 00 取第 0 个参数入栈
    local.get $b  ;; 20 01 取第 1 个参数入栈
    i32.add       ;; 6a   弹出栈顶两数相加，结果入栈
  )               ;; 0b   end 函数体结束
  (export "add" (func $add)) ;; 07 ... 导出段
)
