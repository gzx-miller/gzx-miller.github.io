线性内存读写

用货架可视化展示内存字节视图，体验 store8/load8 读写。

开场问题：你在 JS 里改了一个数组的第 3 个元素，然后把它交给 Wasm 的函数处理。处理完你发现，Wasm 读到的正是你刚改过的值；你又回头在 JS 里改一次，Wasm 立刻也能看到。两个人、两份代码，凭什么共享同一份数据，而且不需要来回拷贝？

序列化拷贝开销

你想让宿主和模块交换可变数据——图片像素、字符串字节、数组。最自然的做法是每次调用都序列化一份传过去，但成本有三：大数组每调用一次就拷贝一遍，来回两趟；拷贝出的副本在两边各改各的，最后对不上；没有一个「可写的地址」概念，模块没法原地修改数据。

于是问题变成：能不能给模块一块双方都能直接读写、且不用拷贝的存储？

线性内存寻址

最朴素的做法：让模块持有一块自己的连续字节数组，JS 通过地址去读写它。这块内存叫线性内存，从地址 0 开始按字节连续编号。store8(addr, val) 在地址 addr 写一个字节，load8(addr) 从 addr 读一个字节。

这个方案做对了一件事：模块有了一块可以用整数地址直接访问的连续存储，数据不再需要拆成一个个参数传进传出。

字节序与越界

  • 只有地址还不够——JS 怎么找到这块内存？它不能凭空访问模块内部。
  • 一个字节装不下一个 i32，多字节的值该怎么摆、按什么顺序。
  • 读写越界（比如写到第 65536 个字节之外）会怎样，会不会把宿主搞崩？
  • 数据变多、内存不够用了，能长大吗？

导出内存与视图

不推翻「字节数组」，而是把这块内存和 JS 连起来。第一层，解决「JS 怎么访问」。模块用 (memory (export "memory") 1) 声明一块内存并把它导出；JS 实例化后拿到 instance.exports.memory，它的 buffer 属性是一个 ArrayBuffer。用 new Uint8Array(memory.buffer) 建一个视图，就能像看普通数组一样逐个看字节。这一步是共享的关键：JS 和 Wasm 看的是同一个 buffer，不是副本，所以 JS 写完 Wasm 立刻能读到。

第二层，解决「多大」。内存按页分配，1 页 = 64KiB = 65536 字节，(memory 1) 就是 1 页。这也解释了为什么地址范围是 0 到 65535。

第三层，解决「多个字节怎么放」。load/store 有不同宽度：i32.store8 只写 1 个字节，不带宽度后缀的 i32.store 写 4 个字节，i32.load 读 4 个字节。同一段字节用不同宽度去读会得到不同的数；所有多字节的值都按小端序摆放，低位字节在低地址。

第四层，越界。访问当前页数之外的地址会触发 RuntimeError（trap），而不是安静地写坏别处——这正是 Wasm「天然防缓冲区溢出」的来源：越界会当场停下，不会破坏宿主进程。

最后补上增长。内存可以按页增长（memory.grow），但要记住：一旦增长，引擎会换一块新的 ArrayBuffer，你之前用 new Uint8Array(memory.buffer) 建的那个视图就失效了，必须重新创建——这是最常见的踩坑点。

Wasm 侧只能通过 load / store 指令访问线性内存，JS 侧则通过导出的 memory.buffer 摸到同一块存储，两边看到的是同一份数据，不存在「传进去」这个动作。

内存分页与增长

线性内存是一块从地址 0 连续编号的字节数组，按页增长（1 页 = 64KiB）。模块内只能经 load/store 访问它，宿主 JS 则通过导出的 memory.buffer 访问同一块存储，因此双方共享而非拷贝。越界读写触发 RuntimeError，多字节小端排列，内存一旦增长，旧的 JS 视图就会失效。

「线性内存（linear memory）」指 Wasm 模块持有的一块从地址 0 连续编号的字节数组，按页分配与增长（1 页 = 64KiB = 65536 字节）；模块内只能用 load/store 指令访问，宿主 JS 通过导出的 memory.buffer 取得同一块 ArrayBuffer，因此两边共享而非拷贝。边界：越界读写触发 RuntimeError（不破坏宿主进程）；多字节值采用小端序；内存增长后 buffer 被替换，旧的类型化数组视图失效，必须重建。

关键代码

WAT
;; 线性内存：一块连续字节数组，地址从 0 编号
;; 1 页 = 64KiB；JS 与 Wasm 通过 memory.buffer 共享同一块存储
(module
  (memory (export "memory") 1)

  ;; store8(off, val)：写一个字节
  (func $store8 (param $off i32) (param $val i32)
    local.get $off
    local.get $val
    i32.store8
  )

  ;; load8(off)：读一个字节
  (func $load8 (param $off i32) (result i32)
    local.get $off
    i32.load8_u
  )

  ;; sum(ptr, n)：从 ptr 累加 n 个 i32
  (func $sum (param $ptr i32) (param $n i32) (result i32)
    (local $end i32)
    (local $acc i32)
    ;; end = ptr + n * 4（i32 对齐到 4 字节）
    local.get $ptr
    local.get $n
    i32.const 4
    i32.mul
    i32.add
    local.set $end
    i32.const 0
    local.set $acc
    block $done
      loop $loop
        local.get $ptr
        local.get $end
        i32.ge_u
        br_if $done
        local.get $acc
        local.get $ptr
        i32.load offset=0
        i32.add
        local.set $acc
        local.get $ptr
        i32.const 4
        i32.add
        local.set $ptr
        br $loop
      end
    end
    local.get $acc
  )

  (export "store8" (func $store8))
  (export "load8" (func $load8))
  (export "sum" (func $sum))
)
