函数定义与局部变量

用购物车结算函数 sum 剖析参数、局部变量与循环累加。

开场问题：你给购物车写了一个 Wasm 函数 sum，签名明明声明返回 i32，调用后却拿到一个跟总价毫无关系的数——像是数组的个数。代码逐行看着没错，问题到底出在哪几个槽位上？

名称与索引差异

你想把「算一段商品总价」封装成一个可复用的函数。在 JS 里这件事很轻松：参数和局部变量都靠名字，编译器替你管理它们在内存里放哪。可 Wasm 是贴近机器码的栈式目标，函数一被调用，它需要一套固定、可索引的存储布局——参数要按位置落进确定的槽，函数体里临时用的中间值也要有槽可放。

如果不用这些槽，把所有中间结果都留在操作数栈上会怎样？代价有两个，而且都很硬：栈只能后进先出，你在循环里想回头取一个早先算好的值，就得靠 dup 和反复调整顺序来「记住」它，稍不留神就把栈搞乱；更糟的是栈上的数没有名字，读代码时根本不知道此刻栈顶那个数代表「结束地址」还是「累加器」。所以真正的问题是：函数调用时，参数和临时变量该落在哪里、又怎样被稳定地取回来？

本地槽位编号

给函数一块按索引编号的本地槽位：参数先占靠前的槽，局部变量接着占后面的槽，用 local.get <索引> 读、local.set <索引> 写。于是 sum(ptr, n) 里 ptr 是 0 号槽、n 是 1 号槽，后面再加两个局部变量。

这个方案做对了一件事：它把「操作数栈上转瞬即逝的临时值」提升成了「有编号、可随时取回的本地存储」。你在函数的任何位置都能按索引重新拿到一个值，不必再小心翼翼地维护栈顺序。

索引空间共用

  • 参数和局部变量共享同一个索引空间，很容易数错：ptr 是 0、n 是 1，第一个局部变量其实是 2 号，不是一个独立的「1 号局部」。
  • 光有索引没有名字，local.get 2 读代码时完全不知道它是什么。
  • 如果函数体最后留在栈顶的值类型，和签名声明的 result 对不上，整个模块校验就会失败。
  • 局部变量只活在这次调用里，函数一返回就没了，不能指望它跨调用保留状态。

参数局部命名

先补「编号与命名」。WAT 允许给参数和局部变量起名字： (func $sum (param $ptr i32) (param $n i32) (result i32) (local $end i32) (local $acc i32) …)。 编号规则是参数在前、局部变量在后、从 0 连续排：$ptr=0、$n=1、$end=2、$acc=3。源码里写名字、机器码里用索引，只要记住这个排序，就不会取错槽。

再补「拿什么变量算一段循环」。用局部变量 $end 记录结束地址：ptr + n * 4——因为数组里每个 i32 占 4 字节，n 个元素就跨 n * 4 字节。再用 $acc 作累加器，先 local.set 成 0。

接着补「怎么循环」。Wasm 没有 for，用 (block $exit (loop $loop … )) 表达：每轮开头先比 $ptr 与 $end，若 $ptr >= $end 就 br_if $exit 跳出；否则把 $acc + i32.load($ptr) 写回 $acc，再把 $ptr 加 4，最后 br $loop 回到循环开头。累加与指针推进这两件事合起来，正好走完整个数组。

最后补「怎么把结果交出去」。函数体收尾时把 local.get $acc 留在操作数栈顶，函数以 0x0b（即 end）结束，栈顶那个值就是返回值。要记住一条硬规则：返回值类型必须与签名里声明的 result 一致，声明 i32 却留了个 f64 在栈顶，校验器会直接拒绝这个模块。

一个最容易踩的坑：参数与局部变量共用同一个索引空间，序号是「参数在前、局部变量在后」连着数的。此外 local.get / local.set 的取值类型必须和槽位声明的类型匹配，拿 i32 的指令去取一个 f64 的槽，同样会被拒绝。

槽空间与栈帧

Wasm 函数由签名、参数、局部变量和指令体组成，参数与局部变量共用一个从 0 开始连续编号的本地槽空间。调用时这些槽在栈帧里分配，函数体用 local.get / local.set 按索引读写，而返回值就是函数体留在操作数栈上的那个值——它的类型必须与签名声明的 result 一致。

「局部索引空间（local index space）」指每个 Wasm 函数持有的一组从 0 连续编号的本地槽位，参数占前几个槽，局部变量紧接其后，用 local.get / local.set 按索引（或 WAT 里的名字）读写。边界：索引顺序是「参数在前、局部变量在后」；取数指令的类型必须与槽位声明一致；局部变量在调用时分配于栈帧、返回即回收；函数体以 end 收尾，栈顶留下的返回值类型必须匹配签名里的 result。

关键代码

WAT
;; 函数定义与局部变量：参数与局部变量共享"函数局部索引空间"
;; local.get/set 按索引访问；局部变量在函数栈帧上分配，调用后回收
(module
  (memory (export "memory") 1)

  ;; sum(ptr, n)：购物车结算，把 ptr 起始的 n 个价格累加
  (func $sum (param $ptr i32) (param $n i32) (result i32)
    (local $end i32)  ;; 局部变量 0：结束地址
    (local $acc i32)  ;; 局部变量 1：累加器
    local.get $ptr
    local.get $n
    i32.const 4
    i32.mul
    i32.add
    local.set $end
    i32.const 0
    local.set $acc
    block $done
      loop $loop
        local.get $ptr
        local.get $end
        i32.ge_u
        br_if $done
        local.get $acc
        local.get $ptr
        i32.load offset=0
        i32.add
        local.set $acc
        local.get $ptr
        i32.const 4
        i32.add
        local.set $ptr
        br $loop
      end
    end
    local.get $acc   ;; 函数结束时栈顶值作为返回值
  )

  (export "sum" (func $sum))
)
