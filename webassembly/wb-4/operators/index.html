运算指令集

以折扣计算场景体验整数、位运算与浮点指令，理解栈式运算。

开场问题：你读一段 WAT，函数体只有三行：local.get $a、local.get $b、i32.add。没有赋值，没有 a + b 这样的表达式，也没有一行写着「结果存到哪」。可它就是算出了两数之和——这些值从哪来，算完又去了哪？

无变量运算形式

你要看懂（或写出）一段 WAT 的运算。别的语言里，表达式自带中间结果的名字，你能一眼追踪每一步；Wasm 不这么写。旧办法是「把它当普通算式照抄」，成本有三：找不到中间值存在哪，读起来像断了链；分不清二元指令的左右操作数（a、b 谁被减）；不知道除零、移位越界这些边界会发生什么。

问题由此落到：不写中间变量的指令序列，凭什么能算出结果？

栈式求值方式

最朴素的做法：把函数体当成按顺序执行的一串命令，每读一条，就在脑子里维护一个「栈」。local.get $a 把 a 压上去；local.get $b 把 b 压上去；i32.add 弹掉栈顶两个、把和压回去。

这个方案做对了一件事：用一个隐式的栈代替了所有中间变量，指令序列本身就是计算过程，不需要给每一步起名字。

操作数顺序与除零

  • 二元指令的操作数顺序固定：local.get $a local.get $b i32.sub 得到的是 a - b，先压栈的作左操作数，写反结果就错。
  • 除零没有定义：i32.div_s 遇到除数为 0 会触发运行时陷阱（RuntimeError），不是返回 0 也不是 NaN。
  • 整除向零取整：-7 / 2 得到 -3，不是数学上向下取整的 -4。
  • 移位量越界不报错：i32.shl 会把移位数按位宽取模（等价于 shift & 31），得到看似奇怪但完全确定的结果。
  • 整数与浮点是两套独立指令，i32.add 和 f32.add 操作码不同，混用会让验证失败。

求值规则推演

不推翻「栈」，而是把它的规则说清，并逐条推演。规则只有两条：指令从栈顶取操作数，把结果压回栈顶；函数返回时以当前栈顶值为结果。

用这个规则推一遍 (a + b) * c 怎么编：压 a、压 b，i32.add（栈顶变成 a + b），再压 c，最后 i32.mul。你会发现运算符出现的顺序，就是计算的顺序——不需要括号，也不需要给中间结果起名。

  1. i32.const 10 把常量 10 压栈。
  2. i32.const 4 再压一个 4，此时栈顶是 4、下面是 10。
  3. i32.mul 弹出两个、相乘，把 40 压回栈顶。
  4. 函数以 end 收尾，栈顶的 40 作为返回值。

补上「供给源」这一步：有两类指令专门往栈里放值，短小但关键——i32.const 压常量，local.get 从函数局部空间取值压栈。没有它们，栈永远是空的。

再补指令的分族。整数族（i32.* / i64.*）与浮点族（f32.* / f64.*）各有自己的操作码：i32.add 是 0x6a、i32.mul 是 0x6c、i32.div_s 是 0x6d、i32.xor 是 0x73、i32.shl 是 0x74，而 f32.add 是 0x92——浮点指令是独立命名空间，不会和整数混用。

别忘了比较指令也在这套体系里。i32.lt_s、i64.gt_u 这类指令同样消费两个操作数，但压回的不是原类型，而是一个 i32 的 0 或 1，充当布尔结果。

最后记住两条边界：一是运算指令不直接访问内存，要碰内存必须走显式的 load / store；二是除零会 trap、位移量会被取模，这些不是 bug，而是规范写死的确定行为。

读完就记住这两条：操作数的左右顺序由压栈顺序决定，i32.sub 尤其容易写反；i32.div_s 除零触发 RuntimeError，而位移量超过位宽不报错、只会按位宽取模。

五种运算指令对比

栈顶取值规则

Wasm 的运算指令作用在一个显式的操作数栈上：常量与局部值压栈，运算符从栈顶弹出所需操作数、把结果压回，函数返回栈顶值。运算符的出现顺序就是计算顺序，整数族与浮点族各自独立；除零 trap、位移取模、指令不直接碰内存，是必须记住的三条边界。

「操作数栈」指 Wasm 指令执行时操作的隐式栈——i32.const、local.get 等把值压入，运算符从栈顶弹出固定数量的操作数、把结果压回，函数返回时取栈顶值。边界：二元指令先压入者作左操作数（i32.sub 顺序写反结果就错）；i32.div_s 除零触发 RuntimeError、且向零取整；i32.shl 等移位指令对移位数按位宽取模。

关键代码

WAT
;; 运算指令集：Wasm 指令操作一个显式栈
;; local.get 压栈，运算符从栈顶弹操作数、压回结果
(module
  (func $mul (param $a i32) (param $b i32) (result i32)
    local.get $a
    local.get $b
    i32.mul)             ;; 0x6c
  (func $div (param $a i32) (param $b i32) (result i32)
    local.get $a
    local.get $b
    i32.div_s)           ;; 0x6d 整除，商向零取整
  (func $xor (param $a i32) (param $b i32) (result i32)
    local.get $a
    local.get $b
    i32.xor)             ;; 0x73 异或
  (func $shl (param $a i32) (param $b i32) (result i32)
    local.get $a
    local.get $b
    i32.shl)             ;; 0x74 左移，移位数需小于 32
  (func $fadd (param $a f32) (param $b f32) (result f32)
    local.get $a
    local.get $b
    f32.add)             ;; 0x92 浮点指令独立命名空间

  (export "mul" (func $mul))
  (export "div" (func $div))
  (export "xor" (func $xor))
  (export "shl" (func $shl))
  (export "fadd" (func $fadd))
)
