字符串与格式化

从「字符串不可变」出发，掌握索引切片、f-string 格式化、常用方法与文本/字节的转换。

开场问题：想把一段字符串的第一个字母改成大写，写了 s[0] = 'H'，结果直接抛 TypeError。明明只是改一个字符，为什么 Python 不让你改？

先看最朴素的做法

字符串是日常里最常用的类型：拼接、取片段、判断开头、去掉空格。写起来顺手，"a" + "b" 直接得到 "ab"，"abc"[1] 直接得到 "b"，完全没有门槛。

但一旦想「修改」它，就会撞墙。s = "Hello" 之后写 s[0] = "h" 会报错，因为字符串是不可变对象——它没有「修改某个位置」的能力，任何看起来像修改的操作，其实都是造出一个新字符串。要真正理解它，得从这条性质出发。

不可变意味着什么

列表（list）可以 lst[0] = 9 就地改，字符串不行。你可以这样理解：字符串一旦创建，内容就被冻结，s[0] = "h" 这条赋值根本没有对应的底层操作。

想改一个字符，正确做法是拼出一个新串：s = "h" + s[1:]，或者用 s.replace("H", "h")。这些方法都返回新的字符串，原对象不动。所以判断两个字符串是否相同，用 == 比内容，别指望用 is 比身份。

索引、切片与负步长

字符串支持基于位置的访问，规则和列表一致：

  • 索引从 0 开始，负数从末尾数：s[0] 是首个字符，s[-1] 是末个字符。
  • 切片 s[start:stop:step] 从 start 取到 stop（不含 stop），可以省略任一参数。
  • 步长为负就从右往左走，s[::-1] 是反转字符串的最简洁写法。

切片的边界会被自动裁剪，不会越界报错：s[0:100] 最多取到串尾，s[100:] 得到空串。这种「宽松」是刻意设计的，让切片比手动循环下标安全得多。

f-string：把值排进文本

拼接字符串最容易写出又长又乱的 "name=" + name + ", age=" + str(age)。f-string 把表达式直接写进文本：f"{name} = {age}"，既简洁又不容易漏掉转换。

在 {} 里加个冒号，就能控制格式：

  • 对齐与宽度：{v:>6} 右对齐占 6 格、{v:<6} 左对齐、{v:^6} 居中，常用于对齐表格输出。
  • 精度：{v:.2f} 保留两位小数，{n:04d} 把整数补零到 4 位（如 0042）。

常用方法与转义、多行

围绕字符串有一组高频方法，它们都不改变原串，只返回结果：

  • split() 按分隔符切分，不带参数时按连续空白切并丢掉空串；join() 是它的逆操作，"-".join(parts)。
  • strip() 去掉首尾空白，replace(a, b) 替换，find() 找子串位置，startswith() / endswith() 判断前后缀。

文本里要表示引号、换行这类特殊字符，用转义序列 \n、\t、\\、\'；要跨多行书写长文本，用三引号 """..."""，换行会被原样保留。

str 与 bytes

字符串是文本，而 bytes 是字节序列。文本要落盘或走网络，必须先按某种编码（常见是 utf-8）编成字节："栗子".encode("utf-8") 得到 b'\xe6\xa0\x97\xe5\xad\x90'；读回来时再用 .decode("utf-8") 还原。

两者的界限要划清：str 面向人类、按字符处理；bytes 面向机器、按字节处理。编码不匹配就会抛 UnicodeDecodeError，这也是处理外部数据时最常见的一类错误。

看一遍字符串的行为

一句话收敛

字符串的一切行为都可以从「不可变」推出来：任何「修改」都返回新对象，因此要拼接或替换出新串，比较内容用 ==。它支持基于位置的索引与切片，s[::-1] 是反转的惯用写法；f-string 负责把值排进文本并控制对齐与精度；文本与字节之间靠 encode / decode 跨越。把这四点记住，拼接、格式化、文本处理就都有了统一的解释。

「字符串不可变」指字符串对象创建后内容不能就地修改，所有看似修改的操作都返回新字符串。边界与例外：切片和索引只读取、不修改；要和字节序列互转需显式 encode / decode；拼接大量分片时，用 join 比反复 + 更高效。

PYTHON
# ═══════════════════════════════════════════
# 1. 引号与转义
# ═══════════════════════════════════════════

print('It\'s ok')          # 结果：It's ok，转义单引号
print("line1\nline2")      # 结果：两行文本，\n 是换行
print("tab\there")         # 结果：tab 与 here 之间有制表符

# ═══════════════════════════════════════════
# 2. f-string 的对齐与精度
# ═══════════════════════════════════════════

name, score = "Ada", 3.14159
print(f"[{name:>6}]")      # 结果：[   Ada]，右对齐宽 6
print(f"[{name:<6}]")      # 结果：[Ada   ]，左对齐宽 6
print(f"{score:.2f}")      # 结果：3.14，保留两位小数
print(f"{42:04d}")         # 结果：0042，整数补零到 4 位
print(f"{name} = {score:.2f}")  # 结果：Ada = 3.14

# ═══════════════════════════════════════════
# 3. 索引与切片（负索引、正负步长）
# ═══════════════════════════════════════════

s = "abcdef"
print(s[0], s[-1])         # 结果：a f，负索引取末字符
print(s[1:4])              # 结果：bcd，不含 stop
print(s[:3], s[3:])        # 结果：abc def
print(s[::2])              # 结果：ace，步长 2
print(s[::-1])             # 结果：fedcba，负步长反转

# ═══════════════════════════════════════════
# 4. split 与 join
# ═══════════════════════════════════════════

csv = "a,b,c"
parts = csv.split(",")     # 结果：['a', 'b', 'c']
print("-".join(parts))     # 结果：a-b-c
print("a b  c".split())    # 结果：['a', 'b', 'c']，按连续空白切分

# ═══════════════════════════════════════════
# 5. strip / replace / startswith
# ═══════════════════════════════════════════

raw = "  hi  "
print(raw.strip())                     # 结果：hi，去掉首尾空白
print("aXbXc".replace("X", "-"))       # 结果：a-b-c
print("hello".startswith("he"))        # 结果：True
print("hello".find("l"))               # 结果：2，返回首次出现的位置

# ═══════════════════════════════════════════
# 6. 三引号多行
# ═══════════════════════════════════════════

text = """第一行
第二行"""
print(text.count("\n") + 1)  # 结果：2，跨两行

# ═══════════════════════════════════════════
# 7. str 与 bytes（encode / decode）
# ═══════════════════════════════════════════

data = "栗子".encode("utf-8")
print(type(data))            # 结果：<class 'bytes'>
print(data)                  # 结果：b'\xe6\xa0\x97\xe5\xad\x90'
print(data.decode("utf-8"))  # 结果：栗子，还原回文本
