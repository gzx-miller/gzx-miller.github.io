函数、参数与作用域

掌握返回值规则、位置/默认/关键字/变参四层参数写法、调用处解包，以及 LEGB 作用域查找。

开场问题：写了一个 def add_item(item, box=[])，接着连续调用 add_item('栗子') 两次。本以为每次都拿到只装一个元素的新列表，第二次返回的列表里却躺着两个 '栗子'。明明没传 box，这个元素是从哪冒出来的？

先看最朴素的做法

一段逻辑要被用上好几次时，最省事的办法是把它抄成 def：把重复的几行收进一个名字，调用处只写一行 greet('小明')。这样改动集中在定义里一处，调用处干净，读起来也像在念一句自然语言。

函数一旦变多，新的问题紧跟着出现：调用时到底该按顺序塞几个值？哪些可以省略？想额外塞点别的东西怎么办？这些都要落到参数与返回值的设计上。先弄清楚返回值，再往参数上叠能力。

返回值：没写 return 就返回 None

Python 不要求函数声明返回类型，return 本身也是可选的。理解返回值只需记住三条规则：

  • 函数体里一次 return 都没执行到，调用结果就是 None。
  • 只写 return（后面没表达式），返回的同样是 None，常用于提前结束。
  • return a, b 看着像返回两个值，其实返回的是一个元组 (a, b)，正好可以用 low, high = min_max(data) 解包。

把「多返回值」理解成「返回一个元组」，很多困惑就消散了：它和单个值没有本质区别，只是元组可以被解包而已。

参数的四层写法

一个形参列表可以从左到右叠出四种能力，顺序基本固定：

  1. 位置参数：最普通的形式，实参按先后顺序一一对应。
  2. 默认参数：写作 def f(x=1)，调用时省略就取默认值，必须排在不带默认值的位置参数之后。
  3. 关键字参数：调用时写作 f(x=5)，按名字赋值，顺序随意、可读性更好。
  4. 变参：*args 把多余的位置实参收进一个元组，**kwargs 把多余的关键字实参收进一个字典。

*args 与 **kwargs 里的名字（args、kwargs）只是习惯叫法，写作 *hobbies、**extra 完全等价，真正起作用的是那两个星号。函数签名里，带 * 的参数之后还允许出现仅限关键字的参数，调用时只能按名字传入。

调用处解包：星号的反向用法

星号在函数定义处是「收集」，在调用处则是「拆开」。手里已经有一个列表或字典时，不想一个个手动写出来，就直接解包：

  • f(*items)：把列表或元组里的每个元素当成一个位置实参依次传入。
  • f(**options)：把字典里的每个键值对当成一个关键字实参传入。

两个方向合起来看就清楚了：定义处让函数接住不定数量的实参，调用处让容器展开成一份实参清单，两者是同一枚硬币的两面。

作用域与名字查找的 LEGB 顺序

函数体里用到一个名字时，Python 按LEGB四层依次查找：先 Local（当前函数的局部变量），再 Enclosing（外层嵌套函数的局部变量），然后 Global（模块级全局变量），最后 Builtins（内置名字，如 len、print）。找到就停下，全找不到才抛 NameError。

默认情况下，函数体里对名字赋值只影响局部作用域。想把结果写回外层，要用 global 声明绑定到模块级名字，用 nonlocal 声明绑定到外层嵌套函数的名字。二者要注意：声明只是「把赋值指向已有名字」，并不会凭空创建。

可变默认参数陷阱与一等对象

回到开场那个诡异现象。默认值 [] 属于参数对象本身，在函数定义时就被创建了一次，于是所有没传 box 的调用都在往同一个列表里追加——它当然会跨调用累积。修复方式是用不可变的 None 作占位，进入函数后再按需新建列表。

另一件事值得早点建立：在 Python 里函数是一等对象。它能被赋给名字、放进列表、当作实参传给别的函数，也能作为返回值。正因为如此，才可能出现「接收函数、返回新函数」的装饰器，才有无名的小函数 lambda x: x * 2。把它当普通对象看待，后面闭包、装饰器、回调会顺很多。

常见误区：把可变对象（[]、{}、set()）直接写成默认值，是新手最常踩的坑之一。只要默认值可被就地修改，就优先写成 None 再在函数体内初始化。

看一遍参数绑定与默认值陷阱

一句话收敛

def 把逻辑收进一个名字，返回值默认是 None、多个值其实是元组；参数从左到右可叠位置、默认、关键字与 *args/**kwargs，调用处再用星号反向解包。函数体里的名字按 LEGB 查找，用 global/nonlocal 才能写回外层。最后，函数本身是一等对象——这一条是理解装饰器与闭包的起点。

「一等对象」指函数与整数、字符串一样是普通对象：可赋值、可作参数、可作返回值、可存放在容器里。边界与例外：把函数当作对象传递时要留意闭包捕获的是变量引用而非当时的取值；可变默认参数属于定义时共享的对象，不是每次调用新建的。

关键代码

PYTHON
# ════════════════════════════════════════════
# 1. def 定义函数与返回值
# ════════════════════════════════════════════

def no_return():
    pass                              # 没有 return，结果默认是 None

print(no_return())                    # 结果：None


def min_max(numbers):
    return min(numbers), max(numbers)  # 逗号分隔其实返回一个元组

pair = min_max([3, 1, 4, 1, 5])
print(pair)                           # 结果：(1, 5)
low, high = min_max([3, 1, 4])        # 元组可直接解包成两个名字
print(low, high)                      # 结果：1 4


# ════════════════════════════════════════════
# 2. 默认参数与关键字参数
# ════════════════════════════════════════════

def greet(name, greeting="你好"):        # greeting 是默认参数，必须排在必填参数之后
    return f"{greeting}，{name}"

print(greet("小明"))                     # 结果：你好，小明
print(greet("小明", "早上好"))           # 结果：早上好，小明（位置传参）
print(greet("小明", greeting="嗨"))      # 结果：嗨，小明（关键字传参，顺序随意）


# ════════════════════════════════════════════
# 3. *args 与 **kwargs 收集变参
# ════════════════════════════════════════════

def report(title, *tags, **meta):        # *tags 收位置实参，**meta 收关键字实参
    print("标题:", title)
    print("标签:", tags)                 # 说明：tags 是元组
    print("附加:", meta)                 # 说明：meta 是字典

report("周报", "前端", "复盘", author="小明", week=42)
# 结果：标题: 周报 / 标签: ('前端', '复盘') / 附加: {'author': '小明', 'week': 42}


# ════════════════════════════════════════════
# 4. 调用处解包：星号的反向用法
# ════════════════════════════════════════════

args = ["小明", "晚上好"]
kwargs = {"name": "小红", "greeting": "早安"}

print(greet(*args))                   # 结果：晚上好，小明（列表展开成位置实参）
print(greet(**kwargs))                # 结果：早安，小红（字典展开成关键字实参）


# ════════════════════════════════════════════
# 5. LEGB 作用域查找
# ════════════════════════════════════════════

level = "模块级"                        # Global：模块作用域的名字

def outer():
    level = "外层"                      # Enclosing：外层函数的局部名字

    def inner():
        level = "内层"                  # Local：内层函数的局部名字
        return level                    # 按 LEGB，就近先拿到"内层"

    return inner()

print(outer())                        # 结果：内层
print(level)                          # 结果：模块级（未改动全局名字）


# ════════════════════════════════════════════
# 6. 可变默认参数陷阱
# ════════════════════════════════════════════

def add_bad(item, box=[]):            # 默认值 [] 只在定义时创建一次
    box.append(item)
    return box

print(add_bad("栗子"))                # 结果：['栗子']
print(add_bad("橡果"))                # 结果：['栗子', '橡果']，跨调用累积了


def add_ok(item, box=None):           # 用 None 占位，进入函数后再新建列表
    if box is None:
        box = []
    box.append(item)
    return box

print(add_ok("栗子"))                 # 结果：['栗子']
print(add_ok("橡果"))                 # 结果：['橡果']，每次都独立


# ════════════════════════════════════════════
# 7. lambda 与函数是一等对象
# ════════════════════════════════════════════

double = lambda x: x * 2              # lambda 是匿名的单表达式函数
print(double(21))                     # 结果：42

numbers = [3, 1, 2]
print(sorted(numbers, key=lambda n: -n))  # 结果：[3, 2, 1]（函数作为参数传入）
