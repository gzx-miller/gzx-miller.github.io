闭包与装饰器

从「函数是一等对象」与闭包出发，理解装饰器的本质、functools.wraps 与带参数的装饰器。

开场问题：想在 my_func() 前后各打一行日志，又不想钻进函数体里改代码，就在它上面写了一行 @log_decorator。奇怪的是，之后再调用 my_func()，打印日志的却是另一段从没亲手调用的代码。这中间到底发生了什么？

先看最朴素的做法

给一批函数都加上日志、计时或权限检查，最直接的做法是钻进每个函数体，在开头结尾各插一段代码。一开始能跑，但函数一多就失控：同样的样板被复制了几十遍，将来想把日志格式改一处，得改几十处，还容易漏。

更麻烦的是，日志、计时这类需求和函数真正的业务逻辑并没有关系。把它们混在业务代码里，等于让每段逻辑都被杂事缠住，读起来也分不清哪句是干什么的。于是自然想：能不能把这段额外动作抽出来，套在函数外面，而函数本身一个字都不用改？

函数是一等对象

要让「套在外面」成为可能，前提是函数能被当作普通对象传来传去。Python 恰好如此：函数可以赋给变量、放进列表、作为实参传给别的函数，也能当作返回值送出去。既然函数能当参数接收、又能当结果返回，那么写一个「接收函数、返回新函数」的函数，逻辑上就完全说得通了。

这个「接收一个函数、返回另一个函数」的东西，就是装饰器的骨架。它不是语法魔法，只是把「函数作为参数与返回值」这件事用到了极致。

闭包：内层函数记住外层变量

装饰器返回的新函数，往往是在另一个函数内部定义的。这种「定义在函数内部的函数」加上「它引用了外层函数的变量」，就是闭包。即便外层函数早已返回，内层函数依然能读到那些变量——因为 Python 把那部分环境一起保存了下来。

拿计时来说：外壳函数负责在调用前后记时间，真正的原函数被闭包记在内部，等到被调用时才执行。日志在哪、原函数是谁，都被内层函数牢牢记住。

装饰器本质：接收函数，返回新函数

@log_decorator 这行语法糖，等价于在定义完函数后立刻写一句 my_func = log_decorator(my_func)。也就是说，装饰器在被装饰函数定义时就已经执行了一次，用返回值顶替了原来的名字。此后你调用 my_func()，调到的其实是被包好的新函数。

  1. 定义 my_func。
  2. @log_decorator 触发：把 my_func 交给装饰器，拿回一个 wrapper。
  3. 名字 my_func 被重新绑定到这个 wrapper。
  4. 调用 my_func() 时，先跑的其实是 wrapper，它在内部再调用原始函数。

functools.wraps 与带参数的装饰器

直接用上面的写法有个瑕疵：wrapper 会覆盖掉原函数的名字、文档字符串等元信息，调试和自省时看到的全是 wrapper。解决办法是在 wrapper 上加一个 @functools.wraps(func)，它把原函数的这些信息复制回来。

当装饰器本身还需要配置项（例如「重复几次」「缓存多大」）时，就要再加一层嵌套：最外层收配置参数并返回真正的 decorator，decorator 收函数并返回 wrapper。写成 @repeat(2) 时，先算 repeat(2) 得到一个装饰器，再用它去装饰函数。三层各司其职，少了任何一层都会漏掉一个阶段。

多装饰器叠加与常见用途

同一函数上可以叠多个装饰器，书写顺序贴近函数，但执行顺序是从下往上的：最靠近函数的那个先包裹，最上面的最后包裹。于是调用时，最外层先进入、最内层最后进入。

  • 日志：记录调用与返回，或在异常时留下现场。
  • 计时：测量耗时，用于性能排查。
  • 缓存：用 functools.lru_cache 记住计算结果，避免重复计算。
  • 权限校验：调用前检查身份，不通过就提前拒绝。

这些场景的共同点是：都属于「包裹在业务之外、每个函数都差不多」的横切关注点，正好由装饰器统一收口。

看一遍装饰器的包裹过程

一句话收敛

装饰器的地基是「函数是一等对象」与「闭包」：内层函数记住外层变量，外层函数返回内层函数。@ 只是把 f = deco(f) 写得更顺眼的语法糖。需要配置时再加一层嵌套，用 functools.wraps 保住原函数元信息，叠加时从下往上包裹。日志、计时、缓存、鉴权这类横切逻辑，正适合交给它。

「闭包」指一个内层函数连同它所引用的外层变量环境一起被保存下来，外层函数返回后内层函数仍能访问那些变量。边界与例外：闭包捕获的是变量本身而非当时的快照，若外层变量随后被修改，内层函数看到的是最新值；这也提醒在循环中创建闭包时要留意绑定时机。

关键代码

PYTHON
# ════════════════════════════════════════════
# 1. 闭包：内层函数记住外层变量
# ════════════════════════════════════════════

def make_multiplier(factor):
    def multiply(number):
        return number * factor      # 说明：multiply 记住了外层变量 factor
    return multiply                 # 说明：返回的是函数对象，不是调用结果

double = make_multiplier(2)
print(double(21))                   # 结果：42

triple = make_multiplier(3)
print(triple(21))                   # 结果：63，每次调用都生成独立闭包


# ════════════════════════════════════════════
# 2. 手写一个计时装饰器
# ════════════════════════════════════════════

import time

def timer(func):
    def wrapper(*args, **kwargs):   # 说明：*args/**kwargs 让包装层支持任意签名
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} 耗时 {elapsed:.6f} 秒")
        return result
    return wrapper

@timer
def sum_to(n):
    return sum(range(n + 1))

print(sum_to(100000))               # 结果：5000050000，并打印一行耗时


# ════════════════════════════════════════════
# 3. functools.wraps 保住元信息
# ════════════════════════════════════════════

import functools

def logged(func):
    @functools.wraps(func)          # 说明：把原函数的名字与文档复制到 wrapper
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logged
def hello(name):
    """向某人问好。"""
    return f"你好，{name}"

hello("小明")                        # 结果：先打印"调用 hello"，再返回字符串
print(hello.__name__)               # 结果：hello（没有 wraps 的话会是 wrapper）


# ════════════════════════════════════════════
# 4. 带参数的装饰器（三层嵌套）
# ════════════════════════════════════════════

def repeat(n):                      # 第 1 层：接收配置参数
    def decorator(func):            # 第 2 层：接收被装饰的函数
        @functools.wraps(func)
        def wrapper(*args, **kwargs):   # 第 3 层：真正执行
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def cheer():
    print("加油")

cheer()                             # 结果：连续打印三次"加油"


# ════════════════════════════════════════════
# 5. 多个装饰器叠加：从下往上包裹
# ════════════════════════════════════════════

def bold(func):
    def wrapper(*args, **kwargs):
        return f"[{func(*args, **kwargs)}]"
    return wrapper

def star(func):
    def wrapper(*args, **kwargs):
        return f"*{func(*args, **kwargs)}*"
    return wrapper

@bold                               # 最外层，最后包裹
@star                               # 靠近函数，先包裹
def word():
    return "嗨"

print(word())                       # 结果：[ *嗨* ]，先加星号再加方括号


# ════════════════════════════════════════════
# 6. functools.lru_cache 缓存结果
# ════════════════════════════════════════════

@functools.lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)  # 说明：相同参数直接命中缓存

print(fib(30))                      # 结果：832040，重复子问题不再重算
print(fib.cache_info().hits)        # 结果：缓存命中次数（远大于递归次数）
