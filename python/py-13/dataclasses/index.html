数据类与类型注解

用 @dataclass 消除手写的 __init__ / __repr__ / __eq__ 样板，掌握默认值、工厂与 frozen。

开场问题：定义了一个课程类，只声明了 title: str = '未命名' 和 hours: int = 12 两行字段，却在上方加了一行 @dataclass。之后 repr(course) 能打出完整内容、course == other 也能按字段相等——可你从没写过 __init__、__repr__、__eq__。这些方法是谁替你写的？

先看最朴素的做法

要存一门课程的数据，手写一个类是最直接的：在 __init__ 里把每个字段逐一赋值，再顺手写个 __repr__ 方便调试打印。字段就两三个时，抄一遍也就过去了。

但字段一多，这份「样板」就显出笨重：__init__ 里十几行赋值几乎是把字段名重复三遍（参数、属性、值），__repr__ 又是类似的一长串，想按内容比较还得再写 __eq__。更糟的是，加一个字段就得同步改这几处，漏掉一个就出 bug。这些代码毫无技术含量，却占据了类的绝大部分篇幅。

@dataclass：自动生成 __init__/__repr__/__eq__

@dataclass 专门用来消除这份样板。只要在类上标一行装饰器，并把字段写成带类型注解的类属性，装饰器就会在幕后替你生成三件套：

  • __init__：按字段声明顺序接收参数并赋值。
  • __repr__：形如 Course(title='...', hours=12)，调试时一目了然。
  • __eq__：按字段内容逐一比较，两个字段相同的对象就相等。

于是类体里只剩下「有哪些字段」这一件事，意图被表达得干净利落。源码变短了，可读性反而变高了。

字段默认值与 field(default_factory=...)

字段可以直接给默认值，写法就是普通的赋值：hours: int = 12，省略该参数时用它。注意顺序规则：有默认值的字段必须排在没有默认值的字段之后，否则会有「后面的必填参数无法跳过」的矛盾，装饰器会直接报错。

当默认值是可变对象（列表、字典）时，不能写成 tags: list = []。回顾函数默认参数那一课：可变默认值会在定义时创建一次、被所有实例共享。正确做法是改用 field(default_factory=list)，让每次构造对象时当场调用这个工厂生成一份新对象，从而彼此独立。

frozen：让实例不可变

数据类常常用来表示「不该被随意改动」的取值对象，比如坐标、配置、金额。给装饰器加上参数 @dataclass(frozen=True)，生成的实例就变成只读：构造完成后任何 course.title = ... 的赋值都会抛 FrozenInstanceError。

不可变带来的好处是可预测：对象一旦建好就不会被篡改，可以放心地当字典键、放进集合，也便于在并发场景里共享。代价是「修改」得换成「构造一个新对象」，这在不少数据流风格里反倒更清晰。

字段顺序规则与类型注解

数据类的字段靠类体里的变量注解识别：只要写了 name: str 这样的注解，它就被认作一个字段。这带来几条实用规则：

  1. 没有默认值的字段写在前，有默认值的写在后。
  2. 不写注解的普通类属性不会被当作字段，因此不会进 __init__。
  3. 顺序即 __init__ 的位置参数顺序，也即 __repr__ 的展示顺序。

顺带一提，注解本身在运行期不做强制校验，它的价值在于配合编辑器和静态检查工具，在写代码阶段就发现字段类型不一致。数据类恰好把「声明式的字段定义」和「类型注解」这两件事捆在了一起。

典型使用场景

数据类适合表达「主要用来装数据、少有复杂行为」的东西：

  • 配置项、数据模型、传输对象——字段多、样板多，收益最大。
  • 函数返回值用一个小对象承载，比裸元组更可读。
  • 配合 asdict() 快速转成字典，便于序列化或打印。
  • 需要不可变语义时，用 frozen=True 一档搞定。

反之，若一个类有大量自定义行为、复杂的状态转换，手写类往往更合适——数据类不是万能模板，它擅长的是把「数据形状」表达清楚。

看一遍手写类与数据类的对照

一句话收敛

数据类用一行 @dataclass 换掉了手写的 __init__、__repr__、__eq__ 样板，字段以带注解的类属性声明。默认值要留意顺序规则，可变的默认值改用 field(default_factory=...)。frozen=True 提供不可变语义，asdict() 便于转字典。它最擅长表达「以装数据为主」的对象，让字段形状一目了然。

「数据类」指用 @dataclass 装饰、以带类型注解的类属性声明字段，并由装饰器自动生成 __init__、__repr__、__eq__ 等方法的类。边界与例外：可变字段的默认值必须用 field(default_factory=...) 提供；字段顺序受「有默认值的字段须在后」约束，违反会直接报错。

关键代码

PYTHON
# ════════════════════════════════════════════
# 1. 手写类 vs @dataclass
# ════════════════════════════════════════════

class CoursePlain:                    # 手写：字段一多，样板就成倍增长
    def __init__(self, title, hours):
        self.title = title
        self.hours = hours

    def __repr__(self):
        return f"CoursePlain({self.title!r}, {self.hours})"

    def __eq__(self, other):
        return (self.title, self.hours) == (other.title, other.hours)

from dataclasses import dataclass, field, asdict

@dataclass                            # 自动生成 __init__ / __repr__ / __eq__
class Course:
    title: str = "未命名"
    hours: int = 12

print(Course("Python 入门", 12))       # 结果：Course(title='Python 入门', hours=12)
print(Course("A", 1) == Course("A", 1))   # 结果：True，按字段内容比较


# ════════════════════════════════════════════
# 2. 默认值与 field(default_factory=...)
# ════════════════════════════════════════════

@dataclass
class Cart:
    owner: str
    items: list = field(default_factory=list)   # 说明：每次构造各自新建列表

c1, c2 = Cart("小明"), Cart("小红")
c1.items.append("栗子")
print(c1.items)                        # 结果：['栗子']
print(c2.items)                        # 结果：[]，两件购物车互不共享


# ════════════════════════════════════════════
# 3. frozen 让实例不可变
# ════════════════════════════════════════════

@dataclass(frozen=True)
class Point:
    x: int
    y: int

p = Point(3, 4)
print(p)                               # 结果：Point(x=3, y=4)
try:
    p.x = 10                           # frozen 实例禁止赋值
except Exception as error:
    print(type(error).__name__)        # 结果：FrozenInstanceError


# ════════════════════════════════════════════
# 4. field 精细控制字段
# ════════════════════════════════════════════

@dataclass
class Account:
    name: str
    balance: float = field(default=0.0, repr=False)   # 不参与 __repr__ 展示
    tags: list = field(default_factory=list, repr=False, compare=False)  # 不参与相等比较

account = Account("小明", 100)
print(account)                         # 结果：Account(name='小明')，balance 与 tags 被隐藏
print(account == Account("小明", 100))  # 结果：True，tags 不参与比较


# ════════════════════════════════════════════
# 5. asdict 转为普通字典
# ════════════════════════════════════════════

course = Course("Vue3 实战", 20)
print(asdict(course))                  # 结果：{'title': 'Vue3 实战', 'hours': 20}


# ════════════════════════════════════════════
# 6. 配合类型注解的函数
# ════════════════════════════════════════════

def total_hours(courses: list[Course]) -> int:   # 注解表达意图，运行期不强制
    return sum(course.hours for course in courses)

print(total_hours([Course("A", 12), Course("B", 8)]))   # 结果：20
