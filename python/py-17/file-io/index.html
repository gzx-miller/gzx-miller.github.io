文件读写与路径操作

掌握文件打开模式、显式编码、with 上下文管理器、大文件读取，以及 pathlib 路径操作。

开场问题：你用 'w' 模式打开文件、写入几行、程序正常结束，可再去读时内容是空的；而把 'w' 改成 'a'，同样的代码却把旧内容也留住了。同样都是「写」，'w' 和 'a' 到底差在哪里？

先看最朴素的做法

读写文件最直接的方式，是 open() 拿到文件对象，再调它的方法： 

f = open('data.txt', 'w')
f.write('hello\n')
f.close()

这段代码能跑，写法也短。但它埋着两个隐患：一是忘了 close() 就会丢数据——写操作先进缓冲区，只有关闭（或显式 flush）才落盘，程序异常退出时缓冲区可能来不及写；二是没有指定编码，读写时的默认编码随平台不同，同一份文件在 Windows 与 Linux 之间来回搬，中文就可能变成乱码或者直接抛 UnicodeDecodeError。

模式决定「打开时就发生什么」

开场问题的答案藏在模式里。模式不只是「能不能写」，它决定了打开文件的那一刻对文件做了什么：

  • 'r'：只读。文件必须已存在，否则抛 FileNotFoundError。
  • 'w'：只写，且一打开就把文件清零（truncate）。文件不存在则新建。这就是「写完再读是空的」的原因——旧内容在打开瞬间就被抹掉了。
  • 'a'：追加，指针停在末尾，原内容保留；文件不存在则新建。
  • 'r+'：可读可写，指针在开头，且不清空原内容（写多少覆盖多少）。

想要「保留旧内容」，就必须用 'a' 而不是 'w'；想把每次运行的结果都攒起来，也应当用追加。选错模式，是文件内容莫名消失的头号原因。

编码：显式写死，别赌默认值

处理文本文件时，永远显式指定 encoding='utf-8'。Python 的默认编码取决于运行环境（某些系统上不是 utf-8），省略它等于把「文件能否正确读出」交给运气。写一个参数的成本，换取跨平台一致，非常划算。二进制文件（图片、压缩包）则用 'rb' / 'wb'，此时不涉及编码。

`with`：让关闭这件事不再靠自觉

与其记得手动 close()，不如用上下文管理器 with 把资源生命周期圈起来： 

with open('data.txt', 'r', encoding='utf-8') as f:
    text = f.read()
# 离开 with 代码块时，f 已被自动关闭

with 的价值在于无论代码块里是否抛异常，退出时都会执行关闭。漏写 close()、异常导致提前跳出这些情况，它都替你兜住了。凡是「打开后需要释放」的资源（文件、网络连接、锁），都该用 with。

怎么读：read、readline 与逐行迭代

读有三种粒度：read() 一次读入全部内容返回一个字符串；readline() 每次读一行；readlines() 读成「一行的列表」。对小文件，read() 最省事。

大文件不要 read()：对上百 MB 的日志，read() 会把整份内容都塞进内存。正确做法是直接迭代文件对象——for line in f: 逐行读取，内存占用恒定，几乎总是优于 readlines()。

用 pathlib 做路径操作

拼路径别再用字符串 +，那会在 Windows 的反斜杠上翻车。标准库的 pathlib.Path 把路径当对象处理：

  • 拼接：Path('data') / '2024' / 'log.txt'，用 / 运算符，自动适配分隔符。
  • 拆解：.name、.stem、.suffix、.parent 分别取文件名、主干、后缀、父目录。
  • 判断与遍历：.exists() 是否存在，.iterdir() 遍历目录，.glob('*.csv') 按模式匹配。
  • 读写捷径：.read_text(encoding='utf-8')、.write_text(text, encoding='utf-8')，省去显式 open。

文件不存在时会发生什么

用 'r' 打开一个不存在的文件，会抛 FileNotFoundError。这不是坏事——它把问题明确定位在「文件这一层」，而不是让错误渗到后续逻辑。需要容错时，可以先用 Path.exists() 判断，或者用 try / except FileNotFoundError 捕获并给出友好提示。别用「先判断再打开」当作唯一方案，因为两步之间文件仍可能被删除，捕获异常才是最稳的。

看一遍模式、with 与 pathlib

一句话收敛

文件读写要同时管好三件事：模式决定打开时的行为（'w' 清零、'a' 追加）、编码必须显式写成 utf-8、关闭交给 with 自动完成；读取大文件用逐行迭代而非 read()；路径操作交给 pathlib.Path 而不是字符串拼接。

「上下文管理器」指支持 with 语法、能保证进入和退出时各执行一次固定动作的对象（文件对象、锁等），退出动作在异常时也照样执行。边界与例外：'w' 会在打开时清空文件，与是否写入无关；编码未指定时依赖平台默认值；read() 会把整个文件读入内存，大文件应改用逐行迭代。

关键代码

PYTHON
# ═══════════════════════════════════════════
# 1. with 读写：显式编码 + 自动关闭
# ═══════════════════════════════════════════

import tempfile
from pathlib import Path

tmp_dir = tempfile.TemporaryDirectory()      # 用临时目录，脚本可安全反复运行
file_path = Path(tmp_dir.name) / "data.txt"

with open(file_path, "w", encoding="utf-8") as f:   # 'w' 会清空原有内容
    f.write("第一行\n第二行\n")
print(file_path.exists())                     # 结果：True

with open(file_path, "r", encoding="utf-8") as f:
    text = f.read()                           # 一次读入全部内容
print(repr(text))                             # 结果：'第一行\n第二行\n'
print(f.closed)                               # 结果：True，离开 with 已自动关闭

# ═══════════════════════════════════════════
# 2. 追加模式：保留旧内容
# ═══════════════════════════════════════════

with open(file_path, "a", encoding="utf-8") as f:   # 'a' 指针在末尾，不清空
    f.write("第三行\n")

print(file_path.read_text(encoding="utf-8").count("\n"))   # 结果：3

# ═══════════════════════════════════════════
# 3. 按行迭代：大文件也不吃内存
# ═══════════════════════════════════════════

with open(file_path, "r", encoding="utf-8") as f:
    for index, line in enumerate(f, start=1):  # 直接迭代文件对象，逐行读
        print(index, line.strip())             # 结果：依次打印 3 行内容

# ═══════════════════════════════════════════
# 4. pathlib：用 / 拼路径，拆解各部分
# ═══════════════════════════════════════════

p = Path("reports") / "2024" / "data.csv"      # / 运算符适配不同平台分隔符
print(p.name)                                  # 结果：data.csv
print(p.stem)                                  # 结果：data
print(p.suffix)                                # 结果：.csv
print(p.parent)                                # 结果：reports/2024
print(p.with_suffix(".txt"))                   # 结果：reports/2024/data.txt

# ═══════════════════════════════════════════
# 5. 文件不存在时的处理
# ═══════════════════════════════════════════

missing = file_path.parent / "missing.txt"
print(missing.exists())                        # 结果：False

try:
    open(missing, "r", encoding="utf-8")       # 只读打开不存在的文件
except FileNotFoundError as error:
    print("捕获 FileNotFoundError:", error.filename)   # 结果：文件路径

tmp_dir.cleanup()                              # 清理临时目录
