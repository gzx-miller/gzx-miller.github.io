继承、多态与魔法方法

掌握继承与 super()、方法解析顺序 MRO、多态与鸭子类型，以及常用魔法方法的作用。

开场问题：给 Dog 和 Cat 都写了各自的 speak 方法，然后用一个循环 for a in animals: a.speak() 统一调用。代码里没有任何 if 判断 a 到底是狗还是猫，可每个对象偏偏都叫出了正确的声音。是谁替这段循环做了分类？

先看最朴素的做法

一开始，每种动物各写一个类，各自实现自己的 speak，互不相干。能跑，但共同的部分没法复用：名字、觅食、休息这些逻辑，狗、猫、鸟身上几乎一模一样，却要被各抄一份。改动一处，得记得改所有类。

也可以反过来，用一个类加一大堆 if：if type == 'dog': ... elif type == 'cat': ...。这正是要摆脱的老路——每加一种新动物，就得回来改这个类的判断分支，类越写越臃肿，牵一发而动全身。

继承与 super()

继承把「共有的部分」提到父类，把「各自的差异」留在子类。写法是 class Dog(Animal)，表示 Dog 继承 Animal。父类里定义一次 speak 的通用版本，子类按需重写。没有重写的方法，子类对象可以直接沿用父类的实现。

super() 的作用是「拿到父类的方法」，常用来在重写时先复用父类原版、再补充差异。比如狗在通用叫声之上补一声「汪汪」，写成 return super().speak() + "汪汪"，就避免了把父类的逻辑再抄一遍。

方法解析顺序 MRO

一个类可能同时继承多个父类，属性或方法该去哪找？Python 用方法解析顺序（MRO）定下一条固定的查找链。对多数情况，记住直觉就够：先子类自己，再按 MRO 依次往上找父类，沿途遇到第一个定义就采用。

MRO 之所以存在，是为了在多继承下仍保证查找不重复、不歧义。想亲眼确认顺序，可以对类调用 SomeClass.__mro__ 或 SomeClass.mro()，它会把查找链依次列出来。理解它的意义不在于背规则，而在于遇到多继承的怪行为时，能用它去解释。

多态与鸭子类型

多态说的是：不管对象的真实类型是什么，只要它们提供了同名的方法，调用方就能用同一句代码统一处理。这正解释了开场那个循环——它不关心 a 是谁，只管对它喊 speak()，各对象用自己的实现响应。

更松弛的说法叫鸭子类型：「像鸭子一样叫、像鸭子一样走，那它就可以当鸭子用」。Python 不看对象的类是谁，只看它有没有需要的方法。于是两个毫无继承关系的类，只要都实现了 speak，也能被同一段代码平等对待。

魔术方法：让对象贴合语言习惯

魔术方法是名字被双下划线包住、由解释器在特定时机自动调用的方法。它们让自定义对象看起来像内建类型：

  • __init__：创建对象时初始化。
  • __str__：print 或 str() 时调用，面向使用者。
  • __repr__：repr() 时调用，面向开发者，理想情况下能用来重建对象。
  • __eq__：== 比较时调用，默认按身份比较，重写后可按内容比较。
  • __len__：len() 时调用，让对象具备「长度」。
  • __add__：+ 运算时调用，让对象支持相加。

重写好这几个，自定义对象就能自然地融入 print、比较、求和这些惯用写法，而不用额外记住一堆自定义方法名。

何时避免继承滥用

继承很顺手，但并非越多越好。它把子类永久绑在父类上：父类一改，所有子类都受牵连。若两个类只是「用到对方的一部分能力」而非「是一种」，用组合（把另一个对象作为属性持有）往往更稳。判断标准很朴素：真的是「is-a」关系才继承，只是「has-a」或「用得到」就组合。

常见误区：为了复用几行代码而强行造继承，会把无关的类捆在一起。层级一深，方法到底从哪来就变得难追；优先用组合，只在确属类型关系时才继承。

看一遍继承、多态与魔法方法

一句话收敛

继承把共性上提、差异下放，super() 让重写能复用父类原版，MRO 决定多继承下的查找顺序。多态与鸭子类型让同一句调用由不同对象各自响应，调用方无需判断类型。魔术方法则让自定义对象贴合 print、比较、长度、相加这些语言习惯。最后，继承只用在真正的「是一种」关系上，其余场合优先组合。

「多态」指不同类的对象对同一方法调用作出各自的响应，调用方只依赖方法名、不依赖具体类型。边界与例外：Python 靠鸭子类型实现多态，只要对象具备所需方法即可参与；这也意味着方法名或签名不匹配时，错误要到运行时才会暴露。

关键代码

PYTHON
# ════════════════════════════════════════════
# 1. 单继承与 super()
# ════════════════════════════════════════════

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):                    # Dog 继承 Animal
    def speak(self):
        return super().speak() + "汪汪"   # 说明：先复用父类行为，再补充差异

print(Animal("生物").speak())          # 结果：...
print(Dog("旺财").speak())             # 结果：...汪汪


# ════════════════════════════════════════════
# 2. 重写方法与多态
# ════════════════════════════════════════════

class Cat(Animal):
    def speak(self):                  # 重写父类的 speak
        return "喵~"

animals = [Animal("生物"), Dog("旺财"), Cat("咪咪")]
for animal in animals:
    print(animal.name, animal.speak())
# 结果：生物 ... / 旺财 ...汪汪 / 咪咪 喵~，同一句调用各自响应


# ════════════════════════════════════════════
# 3. __str__ 与 __repr__
# ════════════════════════════════════════════

class Course:
    def __init__(self, title, hours):
        self.title = title
        self.hours = hours

    def __str__(self):                # print / str() 时调用，面向使用者
        return f"{self.title} ({self.hours}h)"

    def __repr__(self):               # 面向开发者，尽量能重建对象
        return f"Course({self.title!r}, {self.hours})"

c = Course("Python 入门", 12)
print(str(c))                         # 结果：Python 入门 (12h)
print(repr(c))                         # 结果：Course('Python 入门', 12)


# ════════════════════════════════════════════
# 4. __eq__：按内容比较而非身份
# ════════════════════════════════════════════

class Course2:
    def __init__(self, title, hours):
        self.title, self.hours = title, hours

    def __eq__(self, other):          # 重写后 == 比较字段内容
        if not isinstance(other, Course2):
            return NotImplemented
        return (self.title, self.hours) == (other.title, other.hours)

x = Course2("Python 入门", 12)
y = Course2("Python 入门", 12)
print(x == y)                          # 结果：True（默认情况下会是 False）


# ════════════════════════════════════════════
# 5. __len__ 与 __add__
# ════════════════════════════════════════════

class Basket:
    def __init__(self, items):
        self.items = list(items)

    def __len__(self):                 # 让对象支持 len()
        return len(self.items)

    def __add__(self, other):          # 让对象支持 + 合并
        return Basket(self.items + other.items)

basket = Basket(["栗子", "橡果"])
print(len(basket))                     # 结果：2
merged = basket + Basket(["松果"])
print(len(merged), merged.items)       # 结果：3 ['栗子', '橡果', '松果']


# ════════════════════════════════════════════
# 6. MRO：多继承下的方法查找顺序
# ════════════════════════════════════════════

class A:
    def who(self):
        return "A"

class B(A):
    def who(self):
        return "B"                     # 说明：子类自己先被找到

class C(B):
    pass

print(C().who())                       # 结果：B（先子类，再沿 MRO 上溯）
print([cls.__name__ for cls in C.__mro__])   # 结果：['C', 'B', 'A', 'object']
