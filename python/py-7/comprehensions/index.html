推导式与迭代协议

掌握列表、字典、集合推导式与生成器表达式，并理解它们共同依赖的迭代协议。

开场问题：写下一个生成器 gen = (x * x for x in range(5))，先 next(gen) 取了一个值，再用 list(gen) 转成列表——本以为会拿到五个数，结果只剩四个。前面那个值去哪了？

先看最朴素的做法

「把列表里每个元素平方」「只保留偶数」这类需求，最直接的写法是先建一个空列表，再用 for 逐项 append：result = []、for、if、append，四行起步。它清晰，但样板代码占了一大半。

推导式（comprehension）把这套模板压缩成一行 [x * x for x in data if x % 2 == 0]，语义不变、代码更短。但短不等于总是好——什么时候该用、什么时候该退回循环，是这一章要划清的边界。

列表推导式与条件过滤

列表推导式的基本骨架是 [表达式 for 变量 in 可迭代对象]：对每个元素计算 表达式，收集成一个新列表。在末尾加 if 就是过滤：[x for x in data if x % 2 == 0] 只保留偶数。

它适合「输入序列、输出序列」的转换；但要注意它总是新建列表，不像 sort() 那样就地修改。在需要保留原序列时，这正是想要的行为。

嵌套推导

推导式里可以放两层 for，书写顺序和嵌套循环一致，从左到右、外层到内层：[(x, y) for x in range(2) for y in range(2)] 生成坐标的笛卡尔积。

但两层以上时，一行会迅速变难读。判断标准是「一眼能不能看懂」：若需要停顿拆解，回退到显式循环往往更清楚。

字典推导与集合推导

把外面的方括号换掉，就得到另外两种容器：

  • 字典推导式用 {键表达式: 值表达式 for ...}：{w: len(w) for w in words} 生成「单词到长度」的映射。
  • 集合推导式用 {表达式 for ...}：{x % 3 for x in range(6)} 自动去重。

注意 {} 里只有一个表达式就是集合，写成 键: 值 才是字典。空集合要写 set()，{} 是空字典。

生成器表达式：惰性求值

把方括号换成圆括号，得到的不是容器，而是生成器表达式：(x * x for x in data)。它不立刻算出全部结果，而是每调用一次 next() 才算一个——用到才计算，这叫惰性求值。

好处是省内存，适合流式处理大序列；代价是它只能遍历一次，走过就没了，也不能用下标或 len()。需要反复使用或随机访问时，应先 list() 把它物化成列表。开头那个「少了一个值」的疑问，答案就在这里：已 next 取走的元素不会再出现。

可读性边界与迭代协议

推导式不是越长越好。当它塞进多个条件、多层嵌套，或要产生副作用时，可读性会断崖式下降，这时应果断退回普通 for 循环。一条经验线：一行读下来若需要停顿才能看懂，就别用推导式。

更底层地看，for 之所以能遍历各种对象，是因为迭代协议：对象实现 __iter__ 返回一个迭代器，迭代器实现 __next__ 逐个给出元素，耗尽后抛 StopIteration。你也可以手动走这套协议：it = iter(seq)，再反复 next(it)。推导式、生成器、for，全都建立在这套协议之上。

常见误区：把生成器表达式当列表反复使用（第二次遍历会得到空结果）；或在推导式里做复杂的副作用。前者应先用 list() 物化，后者该改用普通循环。

看一遍推导式的写法

一句话收敛

推导式是「输入序列、输出序列」转换的紧凑写法：列表、字典、集合各有自己的括号形态，末尾加 if 做过滤，多层 for 表达嵌套。生成器表达式改用圆括号，惰性求值、省内存，但只能遍历一次。逻辑变复杂或需要副作用时，普通 for 循环更清楚。它们能工作，靠的都是同一套迭代协议：__iter__ 给出迭代器，__next__ 逐个产出、耗尽时抛 StopIteration。

「迭代协议」指对象实现 __iter__ 返回迭代器、迭代器实现 __next__ 逐个产出元素并在耗尽时抛 StopIteration 的约定，for、推导式与生成器都建立在它之上。边界与例外：生成器是「一次性」迭代器，遍历完即耗尽；而列表这类可迭代对象每次 iter() 都能得到全新的迭代器，因而可以反复遍历。

关键代码

PYTHON
# ═══════════════════════════════════════════
# 1. 列表推导式
# ═══════════════════════════════════════════

squares = [x * x for x in range(6)]
print(squares)             # 结果：[0, 1, 4, 9, 16, 25]

# ═══════════════════════════════════════════
# 2. 带条件过滤
# ═══════════════════════════════════════════

evens = [x for x in range(10) if x % 2 == 0]
print(evens)               # 结果：[0, 2, 4, 6, 8]

# ═══════════════════════════════════════════
# 3. 嵌套推导（笛卡尔积）
# ═══════════════════════════════════════════

pairs = [(x, y) for x in range(2) for y in range(2)]
print(pairs)               # 结果：[(0, 0), (0, 1), (1, 0), (1, 1)]

# ═══════════════════════════════════════════
# 4. 字典推导式
# ═══════════════════════════════════════════

lengths = {w: len(w) for w in ["a", "bb", "ccc"]}
print(lengths)             # 结果：{'a': 1, 'bb': 2, 'ccc': 3}

# ═══════════════════════════════════════════
# 5. 集合推导式
# ═══════════════════════════════════════════

mods = {x % 3 for x in range(6)}
print(mods)                # 结果：{0, 1, 2}，自动去重

# ═══════════════════════════════════════════
# 6. 生成器表达式与惰性求值
# ═══════════════════════════════════════════

gen = (x * x for x in range(5))
print(next(gen))           # 结果：0
print(next(gen))           # 结果：1
print(list(gen))           # 结果：[4, 9, 16]，前面的已被取走

# ═══════════════════════════════════════════
# 7. iter / next 手动迭代
# ═══════════════════════════════════════════

it = iter([10, 20])
print(next(it))            # 结果：10
print(next(it))            # 结果：20
try:
    next(it)               # 已耗尽
except StopIteration:
    print("迭代结束")       # 结果：迭代结束
