连线类型与样式：五种路径、标签与箭头

对比五种内置连线路径的差异，掌握 type、label、animated、markerEnd、style 与 default-edge-options 的用法。

开场问题：订单流程图里「锁定库存」和「核销优惠券」两条支线都汇到「仓库打包」，可画出来五条线长得一模一样——哪条是主线、哪条是绕过分支，凭什么让我一眼看出来？

订单图边数据

你在画一张订单履约流程图。数据模型其实已经很清楚：nodes 摆好节点，edges 用 source 与 target 写好连接关系，画布照着把线一根根拉出来。麻烦出现在下一句——这些线全长一个样：同样的弧度、同样的粗细、同样没有方向。于是这张图只能「看得到结构」，却「读不出信息」：哪条是正常主流程、哪条是异常绕行、数据往哪个方向流，全靠盯着节点位置去猜。

如果不给线赋予形态，流程图就退化成一堆连线的集合，节点越多越没人愿意看。真正要解决的是：怎么让「关系」本身也携带语义，让读图的人不用点开任何节点就能分清主次。

默认连线绘制

最省事的做法是接受默认：所有边都交给 Vue Flow 自己画。连线路径它会根据两个节点的位置自动算出一条贝塞尔曲线，起止点、弧度都不需要你操心。

这个方案对在一件事上：它先保证了「连对」。只有 edges 的关系数据是准确的，后面才有谈样式的余地；反过来先急着调外观、关系却连错了，等于在一张错图上精装修。图只有三五个节点时，默认形态确实够用。

方向提示缺失

  • 五条线一个样，主路径和分支路径没有视觉差异，阅读顺序全靠人脑补。
  • 没有任何方向提示，谁指向谁得靠节点左右位置反推，绕行的分支尤其容易读反。
  • 关键链路（比如「用了券」这种特殊分支）混在普通线里，一眼扫不到。
  • 想统一调整所有新连线的形态，却没有全局出口，只能挨个 edge 去改 type。

路径装饰默认值

不推翻默认连线，而是给每条边装上「表达三件套」——路径、装饰、全局默认。

第一件是路径。Vue Flow 内置五种边路径，差别全在「两个点之间怎么连」。写法只是 type 上的一个字符串，适用场景却相当分明：

路径 type画法适合场景
default贝塞尔曲线，两端平滑起弧不指定时的默认形态，节点分布自由、想要柔和观感
straight直线，两点直接相连强调直线距离、线条越简越好的极简图
step直角折线，横平竖直管线、电路一类强调正交走向的图
smoothstep圆角折线，直角处圆滑过渡既要规整正交、又要柔和观感（本课默认）
simplebezier简化贝塞尔，控制点更收敛节点密集、不想让曲线甩得太开

第二件是装饰，写在单个 edge 对象上。label 放文字，把「用了券」这类条件标在线的中点上；animated 加流动虚线，让这条线动起来，天然吸引视线；markerEnd 配 MarkerType.ArrowClosed 收一个实心箭头，方向立刻可读；style 覆盖描边，例如 { stroke: 'var(--leaf-red)', strokeWidth: 2 } 就能把重点线加粗染红。

小技巧：style 里的 stroke 直接写 CSS 变量，深浅主题切换时线条颜色跟着站点自动换，不必为两套主题各维护一份色值。

第三件是全局默认。:default-edge-options 一次配好「之后新建的连线」的默认形态，本课顶部切换按钮改的正是它的 type。

最容易踩的坑：default-edge-options 只影响之后新建的连线；已经存在的 edge 形态由它自身的 type 字段决定。所以点按钮时原有五条线纹丝不动，只有你新拉的那条才会变——这不是 bug，而是「已有数据优先于默认值」的预期行为。

还有两处细节值得记牢。其一，MarkerType 枚举要从 @vue-flow/core 正确导入，手拼箭头字符串很容易踩上符号错误；其二，默认边的 label 渲染在 SVG 文本层，纯文字场景够用，一旦标签里要塞按钮、输入框这类结构，就得换成自定义连线加 EdgeLabelRenderer，那正是下一课要讲的事。

五种路径差异

连线表达语义

连线的形态，本质上是把「关系」从结构升级成表达。type 选路径、label 写条件、animated 提主次、markerEnd 标方向、style 做区分，全局则用 :default-edge-options 兜底。记住默认值只管新连线、老边只认自己的 type，这张图就从「能看」变成了「能读」。

「边路径类型」指 edge.type，内置五种：default（贝塞尔）、straight（直线）、step（直角折线）、smoothstep（圆角折线）、simplebezier（简化贝塞尔）。单条边的 label / animated / markerEnd / style 写在 edge 对象上，全局默认由 :default-edge-options 提供，且只对之后新建的连线生效。

关键代码

Vue
<script setup lang="ts">
import { ref } from 'vue'
import { MarkerType, VueFlow } from '@vue-flow/core'
import type { Edge, Node } from '@vue-flow/core'

// 五种内置连线类型：default（贝塞尔）、straight、step、smoothstep、simplebezier
const edgeTypes = ['default', 'straight', 'step', 'smoothstep', 'simplebezier'] as const
const activeType = ref<(typeof edgeTypes)[number]>('smoothstep')

const nodes = ref<Node[]>([
  { id: 'order', type: 'input', position: { x: 0, y: 160 }, data: { label: '用户下单' } },
  { id: 'stock', position: { x: 240, y: 40 }, data: { label: '锁定库存' } },
  { id: 'coupon', position: { x: 240, y: 280 }, data: { label: '核销优惠券' } },
  { id: 'pack', position: { x: 480, y: 160 }, data: { label: '仓库打包' } },
  { id: 'ship', type: 'output', position: { x: 720, y: 160 }, data: { label: '发货' } },
])

const edges = ref<Edge[]>([
  { id: 'e1', source: 'order', target: 'stock' },
  {
    id: 'e2',
    source: 'order',
    target: 'coupon',
    label: '用了券',
    animated: true,
    markerEnd: MarkerType.ArrowClosed,
    style: { stroke: 'var(--leaf-red)', strokeWidth: 2 },
  },
  { id: 'e3', source: 'stock', target: 'pack' },
  { id: 'e4', source: 'coupon', target: 'pack' },
  { id: 'e5', source: 'pack', target: 'ship', markerEnd: MarkerType.ArrowClosed },
])
</script>

<template>
  <div class="demo-card">
    <h3>连线类型与样式</h3>
    <p>
      内置五种 path：<code>default</code>（贝塞尔）、<code>straight</code>（直线）、
      <code>step</code>（直角折线）、<code>smoothstep</code>（圆角折线）、
      <code>simplebezier</code>（简化贝塞尔）。单条边在 edge 对象上写
      <code>type</code> / <code>label</code> / <code>animated</code> /
      <code>markerEnd</code> / <code>style</code>，全局默认值则配
      <code>:default-edge-options</code>。
    </p>
    <div class="vf-toolbar">
      <button
        v-for="item in edgeTypes"
        :key="item"
        :class="{ active: activeType === item }"
        @click="activeType = item"
      >
        {{ item }}
      </button>
    </div>
    <div class="vf-canvas">
      <ClientOnly>
        <VueFlow
          v-model:nodes="nodes"
          v-model:edges="edges"
          :fit-view-on-init="true"
          :default-edge-options="{ type: activeType }"
        />
        <template #fallback>
          <div class="vf-fallback">流程图画布加载中…</div>
        </template>
      </ClientOnly>
    </div>
    <p class="vf-status">
      切换按钮改的是 <code>default-edge-options.type</code>，对新连线生效；
      "用了券"这条边单独设置了 <code>label</code>、<code>animated</code> 虚线动画、
      <code>markerEnd</code> 箭头和 <code>style</code> 描边样式（枫叶红）。
    </p>
  </div>
</template>
