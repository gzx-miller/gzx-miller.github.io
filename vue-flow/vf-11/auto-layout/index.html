自动布局：Kahn 分层与坐标写回

自实现分层布局：用 Kahn 算法按依赖分派层号、层内堆叠计算坐标，updateNode 写回后 fitView 收拢。

开场问题：一张发布流水线图改了十几轮，节点已经互相压住、连线绕成一团，每次加一个环节都要把半张图重新拖一遍——能不能让画布自己按依赖关系把节点排整齐？

手工摆位局限

流程图的价值在于「一眼看出先后」。可节点位置是人手工摆的，而图是会长大的：今天插一个「静态检查」，明天在中间加一段「灰度放量」，每次插入都要求你把后续节点整体往右挪。挪到第三轮，位置记录的不是逻辑，而是历史遗留——图的形状开始和它表达的含义脱节。

更麻烦的是分工。手工摆的位置只存在于某个人的记忆里，换个人接手，改完就再也摆不回原来的样子。我们需要的是：位置由图的结构算出来，而不是由人的手感决定。只要依赖关系不变，谁点「自动布局」都该得到同一张图。

写死坐标方案

最朴素的做法是「写死坐标」：把每个节点该在的 position 手写进数组，让它们看起来是排好的。这招其实做对了一件事——它承认了位置可以被提前决定、可以被复现。同一份数据渲染出的图永远一样，这正是自动布局想追求的性质。

顺着这个思路，稍微好一点的做法是手工拖动加「保存布局」，把当前坐标存下来。位置仍然是确定的，也仍然是一条数据。

新增节点连锁改动

  • 节点一多就不可控，十个节点的相对位置还能脑补，三十个就纯粹在猜。
  • 每新增一个节点，它下游所有节点的坐标都得跟着调，改动量和图的大小成正比。
  • 写死的坐标记不住「为什么在这里」——依赖关系一变，位置不会自动跟着变。
  • 手工拖动的结果依赖于某次操作，换个环境、换个人就复现不出来。
  • 一旦用户把图拖乱，没有一键恢复的能力，只能指望撤销。

依赖关系算位置

不推翻「位置由数据决定」，而是把这句话再推一步：位置不是人给的，而是算法从依赖关系里算出来的。整件事拆成两半——用一个纯函数算出「id 到坐标」的映射，再拿着这个映射逐个写回节点。写回用 updateNode(id, { position })，最后 await fitView({ padding, duration }) 把整张图收进视野。

真正的核心在第一步，也就是分层。这里用的是 Kahn 算法的思路：按入度一层一层往下推，每个节点的层号取所有前置节点层号的最大值加一。展开成步骤是这样：

  1. 建图统计入度。遍历所有边，按 source → target 登记邻接关系，并给 target 的入度加一。指向不存在节点的边和自环直接跳过，它们不构成有效的先后关系。
  2. 找起点。入度为 0 的节点没有任何前置依赖，全部入队，层号记为 0，它们是图的第一层。
  3. 逐层推进。出队一个节点，遍历它的后继：把后继的层号更新为「当前层号 + 1」与「已有层号」中的较大值，同时把后继的入度减一；某个后继的入度减到 0 时，说明它的前置都已安排妥当，可以入队。
  4. 处理环。队列排空后仍剩余入度的节点，就是陷在环里、永远凑不齐前置的点。算法把它们统一追加到最后一层的后面，保证过程一定会终止。
  5. 换算坐标。层号决定主轴位置——层号乘以「节点尺寸 + 层间距」；同层内的序号决定副轴位置——序号乘以「节点尺寸 + 节点间距」。方向为从左到右时主轴落到 x，从上到下时主轴落到 y。

第三步里那个「取较大值」是容易被忽略的关键。它保证一个节点永远排在它所有前置节点的右边，而不只是排在最早那个前置的右边——也就是取最长路径。若图里存在 A → B → D 与 A → D 两条路径，D 的层号会跟着更长的链走到 2，绝不会因为一条捷径而提前窜到 B 前面去。

两个必须记住的约束：第一，环在流程图里是常态而不是意外（比如「驳回后回到上一环节」），算法必须显式处理它，否则队列永远推不完，程序直接卡死。第二，坐标计算用到了节点尺寸，卡片一旦改大小，nodeWidth、nodeHeight 与间距参数要同步更新，不然排好的图又会重新叠在一起。

还有一层工程上的好处值得交代：把整件事写成纯函数——输入节点与边，输出一个坐标映射 Map，过程中不碰任何响应式状态。这样它既好写单元测试（给定图结构，断言首层 x 最小、最长依赖链的节点层号最大），也方便日后换成 dagre、elkjs 这类更成熟的布局引擎：换算法只需换那个纯函数，写回的数据流一点不动。

布局只改写 position，不碰 data，也不碰连线。所以用户可以随意拖动、随意摆放，随时点一下「自动布局」就能恢复整齐——手工的自由和自动的秩序可以共存。

分层归位对比

纯函数算坐标

自动布局 = 纯函数算坐标 + 写回节点。Kahn 分层把「谁在谁后面」的依赖关系，翻译成「谁在第几层」的整齐结果；层号决定主轴，层内序号决定副轴，环上的节点统一沉底。位置从此不再是手感，而是图结构的函数。

「Kahn 分层」是一种基于入度的分层算法：入度为 0 的节点列为第一层，其余节点的层号取所有前置节点层号的最大值加一（即最长路径），入度减到 0 时才入队；队列排空后仍有剩余入度的节点属于环，统一追加到最后一层以保证算法终止。算出层号后用 updateNode 写回 position，再 fitView 收拢视野。

关键代码

Vue
<script setup lang="ts">
import { ref } from 'vue'
import { VueFlow, useVueFlow } from '@vue-flow/core'
import { layoutByLayers } from '../composables/useFlowAutoLayout'
import type { Edge, Node } from '@vue-flow/core'

// 故意打乱位置的发布流水线：点击"自动布局"一键归位
const nodes = ref<Node[]>([
  { id: 'code', type: 'input', position: { x: 520, y: 40 }, data: { label: '提交代码' } },
  { id: 'lint', position: { x: 60, y: 260 }, data: { label: '静态检查' } },
  { id: 'test', position: { x: 380, y: 160 }, data: { label: '跑单测' } },
  { id: 'build', position: { x: 200, y: 20 }, data: { label: '构建镜像' } },
  { id: 'deploy', type: 'output', position: { x: 640, y: 280 }, data: { label: '部署上线' } },
])

const edges = ref<Edge[]>([
  { id: 'e1', source: 'code', target: 'lint' },
  { id: 'e2', source: 'lint', target: 'test' },
  { id: 'e3', source: 'test', target: 'build' },
  { id: 'e4', source: 'build', target: 'deploy' },
])

const direction = ref<'LR' | 'TB'>('LR')
const message = ref('节点位置是故意打乱的，点「自动布局」试试')

const { updateNode, fitView } = useVueFlow()

async function applyLayout() {
  const positions = layoutByLayers(nodes.value, edges.value, {
    direction: direction.value,
    layerGap: 70,
    nodeGap: 30,
    nodeWidth: 120,
    nodeHeight: 40,
  })
  // updateNode 逐个写入新坐标，画布响应式重排
  for (const node of nodes.value) {
    const position = positions.get(node.id)
    if (position) updateNode(node.id, { position })
  }
  await fitView({ padding: 0.25, duration: 400 })
  message.value = `已按 ${direction.value === 'LR' ? '从左到右' : '从上到下'} 分层对齐（Kahn 分层算法）`
}
</script>

<template>
  <div class="demo-card">
    <h3>自动布局：分层归位</h3>
    <p>
      自动布局 = 算坐标 + 写回节点。本例的 <code>layoutByLayers</code>（见
      <code>src/composables/useFlowAutoLayout.ts</code>）用 Kahn 分层：
      入度为 0 的节点当第一层，其余节点取"最长前置路径 + 1"，环上节点沉底。
      坐标算好后用 <code>updateNode</code> 写回，再 <code>fitView</code> 收进视野。
      更复杂的图可以换成 dagre / elkjs 等图布局库，套路不变。
    </p>
    <div class="vf-toolbar">
      <button @click="applyLayout">自动布局</button>
      <button @click="direction = direction === 'LR' ? 'TB' : 'LR'">
        当前方向：{{ direction === 'LR' ? '从左到右' : '从上到下' }}（点击切换）
      </button>
    </div>
    <div class="vf-canvas">
      <ClientOnly>
        <VueFlow v-model:nodes="nodes" v-model:edges="edges" :fit-view-on-init="true" />
        <template #fallback>
          <div class="vf-fallback">流程图画布加载中…</div>
        </template>
      </ClientOnly>
    </div>
    <p class="vf-status">{{ message }}</p>
  </div>
</template>
