只读展示与双主题适配

用组织架构图演示只读/编辑开关组合，并通过变量映射与 data-theme 选择器让画布跟随站点深浅主题。

开场问题：把组织架构图放进深色主题的介绍页，浅色的节点卡片白得刺眼；更糟的是访客随手一拖，整张图就被拖得七零八落——一张纯展示的图，为什么还背着一整套编辑交互？

编辑器与展示态

画布写了两类需求，它们的诉求几乎是相反的。一类是编辑器：用户要能拖节点、拉连线、改结构，交互越全越好。另一类是展示：组织架构、业务全景、数据流向，读者只想看清楚，一个多余的操作都是干扰。

麻烦的是这两类需求共用同一套渲染。你用一个组件写好了编辑画布，展示页直接复用它，于是三种代价同时出现：访客误拖误连线，把只读内容改得面目全非；站点切到深色主题，画布仍按自己的浅色配色渲染，一块白光贴在页面上；画布内的缩放控件还带着硬编码的颜色，在深色背景里看不清。展示场景要的安静与一致，一个都没拿到。

截图贴图方案

最省事的做法是截图：把画布截成一张图片贴上去。这一招确实彻底——图片不能被拖动，不会有任何误操作，也绝对忠实于当时的样子。

它也承认了一个正确的判断：展示型内容不需要编辑能力。这个方向是对的，只是手段太粗暴。

静态图片缺陷

  • 图片不响应主题，站点切到深色，那张浅色截图依然是刺眼的白。
  • 图片不能缩放平移，节点一多，字小到看不清，也没法用缩略图导航。
  • 组织架构每变一次就得重新截图、重新替换资源，维护成本全压在人工上。
  • 标题、说明这类文字变成了像素，无法被搜索、无法被无障碍工具朗读。
  • 切屏或高倍缩放下图片发虚，和周围的原生文字不在一个画质档次。

交互能力开关化

不推翻「展示不需要编辑」，而是把它做成一排可以关掉的开关，同时把配色的决定权交给站点主题。整件事分成三层下手，从交互到配色逐层收敛。

第一层是交互收敛。Vue Flow 把编辑能力拆成了若干独立的布尔属性，按需关即可：nodes-draggable 关掉节点拖拽，nodes-connectable 关掉新建连线，edges-updatable 关掉改线，pane-movable 关掉画布平移。它们都按 !readonly 绑定，一个开关就能在两个模式之间切换。注意只读不等于失去一切：MiniMap 导航与缩放仍应保留，展示场景同样需要「在缩略图上找到某个节点」的能力，只关掉编辑类交互，体验才完整。

第二层是变量映射。这是双主题适配的主干。Vue Flow 的节点、连线、连接桩都走自己的 CSS 变量，如 --vf-node-bg、--vf-handle、--vf-edge。我们不去逐条覆盖组件样式，而是把这些变量映射到站点的主题变量上——浅色主题下它们自动取到站点的一套色值，画布于是天然融进页面，不需要为每个主题写一份样式。

映射覆盖不到的地方，靠选择器补。控件按钮这类颜色是硬编码的，就得在深色分支里用 [data-theme="dark"] 显式覆盖。关键收益是切换成本：主题只改根元素上的 <html data-theme>，整张画布随之响应，不必重建画布，也不必重新挂载组件。

第三层是属性级配色。有些颜色不走 CSS，而是作为属性传给组件，比如背景网格的 pattern-color。这类值绑到主题计算属性上即可：isDark 为真时用一个深色，为假时用浅色，主题一换，网格颜色跟着变。

两个工程细节：画布组件依赖浏览器环境，在服务端渲染或静态预渲染下要包一层 ClientOnly，否则会在构建阶段报错；画布内的浮层用官方 core 包自带的 Panel 组件，配合 PanelPosition 定位到四角，适合放模式徽标、图例或操作区，不必自己拿绝对定位去怼。

最后要做的是一次完整走查：把只读开关来回切一遍，再切一次主题，逐一确认节点底色、连线颜色、连接桩、控件按钮与背景网格都跟着变对了。双主题最容易漏的就是这种「某一处硬编码忘了覆盖」，而它偏偏在深色下最显眼。

只读主题联动

能力外观可配置

只读与双主题是同一件事的两面：把「能力」和「外观」都变成可配置项。交互开关决定画布能做什么，变量映射与 data-theme 选择器决定它长什么样。想清楚展示场景真正需要什么，就不会把编辑器整套能力原样端给读者。

「只读与主题适配」只读靠四个属性收敛能力：nodes-draggable、nodes-connectable、edges-updatable、pane-movable，按 !readonly 绑定即可一键切换（MiniMap 与缩放建议保留）。主题适配分两层：把 --vf-node-bg、--vf-handle、--vf-edge 等官方变量映射到站点变量，再用 [data-theme="dark"] 覆盖控件等硬编码颜色；属性级配色（如 pattern-color）绑定主题计算属性。只改根元素的 <html data-theme> 即可全画布生效。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue'
import { Panel, PanelPosition, VueFlow } from '@vue-flow/core'
import { Background } from '@vue-flow/background'
import { useTheme } from '../composables/useTheme'
import type { Edge, Node } from '@vue-flow/core'

// 组织架构图：只读展示模式 + 双主题联动
const readonly = ref(true)
const { theme, isDark, toggleTheme } = useTheme()

const modeLabel = computed(() => (readonly.value ? '只读展示' : '编辑模式'))

const patternColor = computed(() => (isDark.value ? '#6b5238' : '#d9a05f'))

const nodes = ref<Node[]>([
  { id: 'ceo', type: 'input', position: { x: 240, y: 0 }, data: { label: '园长 · 松果董事长' } },
  { id: 'dev', position: { x: 80, y: 140 }, data: { label: '前端组' } },
  { id: 'design', position: { x: 400, y: 140 }, data: { label: '设计组' } },
  { id: 'vue', position: { x: 0, y: 280 }, data: { label: 'Vue 小队' } },
  { id: 'react', position: { x: 160, y: 280 }, data: { label: 'React 小队' } },
  { id: 'ui', position: { x: 330, y: 280 }, data: { label: 'UI 小队' } },
  { id: 'illu', position: { x: 490, y: 280 }, data: { label: '插画小队' } },
])

const edges = ref<Edge[]>([
  { id: 'e1', source: 'ceo', target: 'dev' },
  { id: 'e2', source: 'ceo', target: 'design' },
  { id: 'e3', source: 'dev', target: 'vue', type: 'smoothstep' },
  { id: 'e4', source: 'dev', target: 'react', type: 'smoothstep' },
  { id: 'e5', source: 'design', target: 'ui', type: 'smoothstep' },
  { id: 'e6', source: 'design', target: 'illu', type: 'smoothstep' },
])
</script>

<template>
  <div class="demo-card">
    <h3>只读模式与双主题适配</h3>
    <p>
      展示型场景（组织架构、架构图）应关闭编辑能力：<code>nodes-draggable、
      nodes-connectable、edges-updatable、pane-movable</code> 等开关按需组合。
      双主题则靠 <code>src/vue-flow/theme.css</code> 把官方配色映射到站点 CSS 变量，
      再叠加 <code><html data-theme></code> 选择器——点下面按钮实时切换观察。
    </p>
    <div class="vf-toolbar">
      <button @click="readonly = !readonly">
        切换模式：{{ modeLabel }}
      </button>
      <button @click="toggleTheme">
        切换主题：当前{{ theme === 'light' ? '浅色 🍂' : '深色 🌙' }}
      </button>
    </div>
    <div class="vf-canvas">
      <ClientOnly>
        <VueFlow
          v-model:nodes="nodes"
          v-model:edges="edges"
          :fit-view-on-init="true"
          :nodes-draggable="!readonly"
          :nodes-connectable="!readonly"
          :edges-updatable="!readonly"
          :pane-movable="!readonly"
        >
          <Background variant="dots" :pattern-color="patternColor" :gap="22" />
          <Panel :position="PanelPosition.TopLeft" class="vf-mode-panel">
            {{ modeLabel }} · {{ theme === 'light' ? '秋日暖阳' : '夜森林' }}
          </Panel>
        </VueFlow>
        <template #fallback>
          <div class="vf-fallback">流程图画布加载中…</div>
        </template>
      </ClientOnly>
    </div>
    <p class="vf-status">
      Panel 是官方提供的画布内浮层组件（core 包自带），适合放模式徽标、图例或操作按钮。
    </p>
  </div>
</template>
