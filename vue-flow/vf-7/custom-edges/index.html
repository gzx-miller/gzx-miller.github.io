自定义连线：状态标签与路径算法

用 #edge-approval 插槽配合 getBezierPath 生成路径、EdgeLabelRenderer 挂载 HTML 标签，画出带通过/驳回状态的审批线。

开场问题：请假审批流里「主管 → 老板」这条是驳回、「主管 → 休假成功」这条是通过，可两条线都灰扑扑一根，读图的人根本分不出哪条被驳回了。

请假审批流分支

你画的是一张请假审批流程图：员工提交、主管审批，之后分两路——通过就走「休假成功」，驳回就送「老板特批」。三条线都老老实实连好了，可它们在画面上完全一样。麻烦在于：「通过」和「驳回」是两种截然不同的业务结果，理应在图上就看得出来，现在却只能靠节点名字去脑补。

代价很实在。审批人一眼扫过去，分不清哪条是正常出口、哪条是异常出口，这张图等于白画。上一课给边加了颜色和箭头能解决一部分，但一旦标签要显示「通过 ✓」「驳回 ✗」这种带状态、要换色、以后还可能点一下展开详情的结构，默认的 SVG 文本标签就彻底不够用了。

状态驱动标签

最省事的做法，还是把状态塞进默认边的 label：给它写死一串「通过」或「驳回」。

这个方案对在：状态只要不变，这样确实能看，而且完全不用碰渲染逻辑，改一个字段名就行。它把「状态」和「展示」做了最直接的绑定。

文本标签局限

  • 默认 label 是 SVG 文本，只能渲染文字，做不出圆角胶囊、背景色、图标这类结构。
  • 通过和驳回的线色本应不同，但改文案并不改线色，两个维度是割裂的。
  • 想给标签加点按交互时，SVG 里根本承载不了。
  • 状态更新往往要手动重建整条边，背离了「改数据即改图」的范式。

连线渲染接管

不推翻「用状态驱动连线」，而是把连线的渲染权也收回来。做法和自定义节点同构：给 edge.type 起一个自定义名，比如 approval，再用同名插槽 #edge-approval 接管它的画法。

关键点一：插槽参数给的是几何信息——来自起点的 sourceX / sourceY、落在终点的 targetX / targetY，以及两端各自的方位。你要自己算出一条 SVG 路径：调用 getBezierPath，它会返回 [path, labelX, labelY]，本课只取第一项当作 <path> 的 d 属性。

必须保留的官方特征：这个 <path> 要带上 fill="none" 与 vue-flow__edge-path 类，一个都不能少。缺了它们，选中高亮、拖拽改线这些内置特性会直接失效——线虽然是你画的，但仍要伪装成官方连线，才能继续享受整套交互。

关键点二：线色与文案由 edge.data 里的业务状态驱动。在 data 上放一个 status，取 'pass' 或 'reject'，path 的 class 与颜色都跟着它切换，绿色表示通过、红色表示驳回。

关键点三：要叠 HTML 标签，就用 <EdgeLabelRenderer>。它悬在画布上层，是一个独立的渲染层，普通 HTML 标签放进去即可；标签的位置用起终点坐标的中点（两者相加再除以二）做绝对定位，胶囊的 class 同样由 data.status 决定。

为什么一定要这个悬层：画布本体是 SVG，里面塞不进交互型的 HTML。所以复杂标签一律走 EdgeLabelRenderer。只是它的标签默认不接收指针事件（pointer-events: none），需要可点击时要手动开启。

收口时再看一眼数据流：只改 edge.data，线的颜色与标签文案就会响应式更新，不需要手动重绘。这正是自定义连线的价值——渲染形态由你定，驱动方式仍然是数据。

颜色与标签联动

插槽自定义连线

自定义连线把「线的画法」交还给你：类型名对上 #edge-类型名 插槽，坐标由插槽给出，路径交给 getBezierPath 计算，HTML 标签挂到 EdgeLabelRenderer 这个悬层上。别忘了保留官方 class 与内联属性，剩下的就交给 edge.data——业务状态一变，线的颜色和文案自动跟上。

「自定义连线」指给 edge.type 起自定义名，用同名插槽 #edge-类型名 接管渲染。插槽给出 sourceX/Y、targetX/Y 与两端方位，用 getBezierPath 生成 path 的 d；HTML 标签交给 EdgeLabelRenderer 悬层渲染（默认不接收指针事件）。自定义连线需保留官方 class 与内联属性，否则选中、拖拽等特性会失效。

关键代码

Vue
<script setup lang="ts">
import { ref } from 'vue'
import { EdgeLabelRenderer, VueFlow, getBezierPath } from '@vue-flow/core'
import type { Edge, Node } from '@vue-flow/core'

type ApprovalData = {
  status: 'pass' | 'reject'
}

const nodes = ref<Node[]>([
  { id: 'apply', type: 'input', position: { x: 0, y: 120 }, data: { label: '员工请假' } },
  { id: 'leader', position: { x: 260, y: 120 }, data: { label: '主管审批' } },
  { id: 'boss', position: { x: 520, y: 20 }, data: { label: '老板特批' } },
  { id: 'rest', type: 'output', position: { x: 520, y: 240 }, data: { label: '休假成功' } },
])

const edges = ref<Edge<ApprovalData>[]>([
  { id: 'e1', source: 'apply', target: 'leader', type: 'approval', data: { status: 'pass' } },
  { id: 'e2', source: 'leader', target: 'boss', type: 'approval', data: { status: 'reject' } },
  { id: 'e3', source: 'leader', target: 'rest', type: 'approval', data: { status: 'pass' } },
])

function toggleStatus(edgeId: string) {
  const edge = edges.value.find((item) => item.id === edgeId)
  if (!edge?.data) return
  edge.data.status = edge.data.status === 'pass' ? 'reject' : 'pass'
}
</script>

<template>
  <div class="demo-card">
    <h3>自定义连线：带状态标签的审批线</h3>
    <p>
      连线同样支持插槽接管：<code>type</code> 设为 <code>approval</code> 后用
      <code>#edge-approval</code> 渲染。插槽参数给出起止坐标
      <code>sourceX/Y、targetX/Y</code> 与方向，先调
      <code>getBezierPath</code> 生成 path，再用 <code><EdgeLabelRenderer></code>
      把 HTML 标签叠在画布上（直接写在 SVG 里无法承载复杂交互）。
    </p>
    <div class="vf-toolbar">
      <button @click="toggleStatus('e2')">切换「主管 → 老板」状态</button>
      <button @click="toggleStatus('e3')">切换「主管 → 休假」状态</button>
      <span class="vf-tip">绿色=通过，红色=驳回</span>
    </div>
    <div class="vf-canvas">
      <ClientOnly>
        <VueFlow v-model:nodes="nodes" v-model:edges="edges" :fit-view-on-init="true">
          <template #edge-approval="edgeProps">
            <path
              :id="edgeProps.id"
              class="vue-flow__edge-path"
              :d="getBezierPath({
                sourceX: edgeProps.sourceX,
                sourceY: edgeProps.sourceY,
                sourcePosition: edgeProps.sourcePosition,
                targetX: edgeProps.targetX,
                targetY: edgeProps.targetY,
                targetPosition: edgeProps.targetPosition,
              })[0]"
              :class="{ rejected: edgeProps.data?.status === 'reject' }"
              fill="none"
            />
            <EdgeLabelRenderer>
              <div
                class="edge-label"
                :class="{ rejected: edgeProps.data?.status === 'reject' }"
                :style="{
                  position: 'absolute',
                  transform: `translate(-50%, -50%) translate(${(edgeProps.sourceX + edgeProps.targetX) / 2}px, ${(edgeProps.sourceY + edgeProps.targetY) / 2}px)`,
                }"
              >
                {{ edgeProps.data?.status === 'pass' ? '通过 ✓' : '驳回 ✗' }}
              </div>
            </EdgeLabelRenderer>
          </template>
        </VueFlow>
        <template #fallback>
          <div class="vf-fallback">流程图画布加载中…</div>
        </template>
      </ClientOnly>
    </div>
    <p class="vf-status">
      标签位置用起终点的中点坐标做绝对定位；线的颜色由 edge 的 <code>data.status</code>
      驱动，业务状态一变，视图自动更新。
    </p>
  </div>
</template>
